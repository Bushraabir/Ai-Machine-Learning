> _"An algorithm is not a recipe. It is a proof that a problem can be solved within a resource bound. Every model you train is an algorithm. Every inference you run is a search. The cleaner your algorithmic thinking, the cleaner your ML intuition."_

This is the index for Data Structures and Algorithms — scoped specifically for the AI/ML + Competitive Programming dual path. The sequencing is intentional: master the foundation layer before graphs, graphs before DP, DP before probabilistic reasoning. CP-only topics are explicitly flagged and deprioritised for ML work.

## Priority Order for AI/ML Path

```
Tier 1 — Mandatory shared core (learn first, no exceptions):
  Arrays+Strings → Hashing → Sorting → Binary Search → Stack/Queue → Recursion → Basic DP → BFS/DFS

Tier 2 — Important for both CP and ML (learn after Tier 1):
  Graphs (Dijkstra, topo sort) → Trees (DFS patterns, heaps) → Probability → LIS/Knapsack DP → Union-Find

Tier 3 — CP-heavy, low ML priority (only after Tier 1 and 2 are solid):
  Segment tree → Fenwick tree → Advanced graph theory → Bitmask DP → Advanced DP optimisations

ML layer — Learn in parallel with Tier 2:
  Vectorisation thinking → Gradient computation intuition → Numerical stability → Sampling
```
