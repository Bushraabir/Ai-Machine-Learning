A matrix $B$ is the inverse of $A$ if: $$AB = BA = I_n$$
- $A$ is called **invertible** (or **nonsingular**) when this $B$ exists.
- We write $B = A^{-1}$.
- two properties of matrix inverse are:
	1. The inverse is unique
		There can only ever be **one** inverse. Because:
		Suppose $B$ and $C$ are both inverses of $A$: $$C = CI = C(AB) = (CA)B = IB = B$$ So $C = B$. Only one inverse is possible.
	2. One side is enough (for square matrices)
		If $AB = I$, you automatically get $BA = I$ too — you don't need to check both sides.

> [!note] Why? $AB = I$ forces $A$ to have full rank (rank $n$), which means $Ax = 0$ only when $x = 0$. From there: $A(BAx) = (AB)Ax = Ax$, so $A(BAx - x) = 0$, so $BAx = x$ for all $x$. Therefore $BA = I$. ✓
## The Invertible Matrix Theorem

All of these statements say the **exact same thing** about a square $n \times n$ matrix $A$. If any one is true, they're all true. If any one fails, they all fail.

| #   | Statement                                                       |
| --- | --------------------------------------------------------------- |
| 1   | $A$ is invertible                                               |
| 2   | $Ax = 0$ has only the solution $x = 0$ (no "accidental zeroes") |
| 3   | Row-reducing $A$ gives the identity $I_n$                       |
| 4   | $A$ is a product of elementary matrices (row operations)        |
| 5   | $Ax = b$ has exactly one solution for every $b$                 |
| 6   | $\text{rank}(A) = n$ (full rank)                                |
| 7   | Null space of $A$ is just ${0}$                                 |
| 8   | Columns of $A$ are linearly independent                         |
| 9   | Columns of $A$ span all of $\mathbb{R}^n$                       |
| 10  | Rows of $A$ are linearly independent                            |
| 11  | $\det(A) \neq 0$                                                |
| 12  | $0$ is not an eigenvalue of $A$                                 |
| 13  | $A^T$ is also invertible                                        |

> [!tip] Mental model Invertible = the matrix **doesn't collapse anything**. It stretches/rotates space without destroying information. You can always reverse it.

---

## Algebraic Rules

**(i) Reverse order when inverting a product** $$(AB)^{-1} = B^{-1} A^{-1}$$ Think: if you put on socks then shoes, to undo it you take off shoes **first**, then socks.

**(ii) Inverse of a transpose** $$(A^T)^{-1} = (A^{-1})^T$$ Transpose and inverse commute — order doesn't matter. So $A^{-T}$ is unambiguous.

**(iii) Inverse of an inverse** $$(A^{-1})^{-1} = A$$ Undoing the undo gives you back the original.

**(iv) Inverse with a scalar** $$(\alpha A)^{-1} = \frac{1}{\alpha} A^{-1}, \quad \alpha \neq 0$$

**(v) Negative powers** $$A^{-k} = (A^{-1})^k = (A^k)^{-1}$$

## Formulas for Small Cases

### $1 \times 1$

If $A = (a)$, then $A^{-1} = (1/a)$, as long as $a \neq 0$.

### $2 \times 2$ (memorize this)

$$A = \begin{pmatrix} a & b \\ c & d \end{pmatrix} \implies A^{-1} = \frac{1}{ad - bc} \begin{pmatrix} d & -b \\ -c & a \end{pmatrix}$$

> [!tip] The $2\times 2$ recipe
> 
> 1. **Swap** the two diagonal entries ($a \leftrightarrow d$)
> 2. **Negate** the off-diagonal entries ($b \to -b$, $c \to -c$)
> 3. **Divide everything** by $\det(A) = ad - bc$

Fails when $ad - bc = 0$ (singular matrix).

### $n \times n$ — the Adjugate Formula (theory only)

$$A^{-1} = \frac{1}{\det(A)} \text{adj}(A)$$

- $\text{adj}(A)$ = transpose of the cofactor matrix
- **Never use this for computation** when $n \geq 4$ — it's astronomically slow
- Use Gauss-Jordan instead (see below)

---

## How to Actually Compute $A^{-1}$: Gauss-Jordan

Write $A$ next to the identity matrix and row-reduce until $A$ becomes $I$. Whatever the identity turns into on the right is $A^{-1}$:

$$[A \mid I] \xrightarrow{\text{row operations}} [I \mid A^{-1}]$$

> [!warning] If during row reduction you ever get a **zero row on the left side**, $A$ is singular — stop, no inverse exists.

**Cost:** $O(n^3)$ — same as matrix multiplication. This is optimal.
see more: [[06.Gauss–Jordan Elimination]]

## The Determinant Test

$A$ is invertible **if and only if** $\det(A) \neq 0$.

- If $AB = I$, then $\det(A)\det(B) = 1$, so neither can be zero.
- The adjugate formula gives an explicit inverse whenever $\det(A) \neq 0$.

> [!note] Intuition $\det(A)$ measures how much $A$ scales volumes. If $\det(A) = 0$, the transformation **flattens** space into a lower dimension — you can't undo that.

## The Rank-Nullity View (Geometric Lens)

For $A : \mathbb{R}^n \to \mathbb{R}^n$: $$\text{rank}(A) + \text{nullity}(A) = n$$

$A$ is invertible $\iff$ nullity $= 0$ $\iff$ rank $= n$.

> [!tip] Geometric intuition
> 
> - **Injective** (one-to-one): no two inputs map to the same output → null space is trivial
> - **Surjective** (onto): every output is reachable → columns span $\mathbb{R}^n$ For square matrices, injective $\iff$ surjective. You get both for free.

see more[[07.Rank and the Row Reduced Form]]

## Special Matrices with Easy Inverses

### Diagonal matrix -> just flip the entries
$$D = \text{diag}(d_1, \ldots, d_n) \implies D^{-1} = \text{diag}(1/d_1, \ldots, 1/d_n)$$
All $d_i$ must be nonzero.

### Orthogonal matrix -> free inverse

$$Q^{-1} = Q^T$$ The inverse is just the transpose. No computation needed. (Columns are orthonormal.)
see more [[10.Orthogonal Matrix]]
### Triangular matrices

- Lower triangular $L$ → $L^{-1}$ is also lower triangular (find via forward substitution)
- Upper triangular $U$ → $U^{-1}$ is also upper triangular (find via backward substitution)
- Diagonal entries of $L^{-1}$ are $1/l_{ii}$

### Block diagonal matrix -> invert each block separately
$$\text{diag}(A_1, \ldots, A_k)^{-1} = \text{diag}(A_1^{-1}, \ldots, A_k^{-1})$$

### Block $2\times 2$ matrix -> uses the Schur complement
$$\begin{pmatrix} A & B \\ C & D \end{pmatrix}^{-1}$$ Key object: $S = D - CA^{-1}B$ (called the **Schur complement** of $A$)
see  more [[08.Schur Complement]]
This shows up constantly in Gaussian conditioning and statistics.

## Sherman-Morrison: Cheap Rank-1 Updates

If you already know $A^{-1}$ and change $A$ by a rank-1 matrix $\mathbf{u}\mathbf{v}^T$: $$(A + \mathbf{u}\mathbf{v}^T)^{-1} = A^{-1} - \frac{A^{-1}\mathbf{u}\mathbf{v}^T A^{-1}}{1 + \mathbf{v}^T A^{-1} \mathbf{u}}$$

> [!tip] Why this matters
> 
> - Full inversion costs $O(n^3)$
> - After a rank-1 update, you get the new inverse in $O(n^2)$ — massively cheaper
> - Foundation of: **Kalman filter**, **recursive least squares**, **online learning**

**Generalization (rank-$k$ updates):** Woodbury identity: $$(A + UCV)^{-1} = A^{-1} - A^{-1}U(C^{-1} + VA^{-1}U)^{-1}VA^{-1}$$
see more: [[11.Sherman-Morrison --Updating an Inverse After a Small Change]]

## Numerical Note: Condition Number

Singular matrices are rare (measure zero in $\mathbb{R}^{n\times n}$) — a random matrix is invertible with probability 1.

But in practice, matrices can be **nearly singular**, which causes numerical errors.

The **condition number** $\kappa(A) = |A| \cdot |A^{-1}|$ measures this:

- $\kappa(A) \approx 1$ → well-conditioned, safe
- $\kappa(A) \gg 1$ → ill-conditioned, numerically dangerous

## When No Inverse Exists: The Pseudoinverse $A^+$

For non-square or singular matrices, use the **Moore-Penrose pseudoinverse**:

| Case              | Formula                                                               |
| ----------------- | --------------------------------------------------------------------- |
| Full column rank  | $A^+ = (A^T A)^{-1} A^T$ — used in least squares                      |
| Full row rank     | $A^+ = A^T(AA^T)^{-1}$                                                |
| General (via SVD) | $A^+ = V\Sigma^+ U^T$, where $\Sigma^+$ flips nonzero singular values |

$x = A^+b$ gives the **minimum-norm least-squares solution** to $Ax = b$.

---

## What Goes Wrong Without Invertibility

If $A$ is singular:

- $Ax = b$ has **no solution or infinitely many** — never exactly one
- $Ax = 0$ has nontrivial solutions — $A$ **destroys information**
- The map $x \mapsto Ax$ is not reversible
- In probability: if $\Sigma$ is singular, $\mathcal{N}(\mu, \Sigma)$ has **no density** — it's stuck in a subspace

## Key Proof to Internalize

**Claim:** $AB = I \implies B = A^{-1}$

**Proof:**

1. $AB = I \implies \text{rank}(A) \geq \text{rank}(AB) = n$, so $\text{rank}(A) = n$
2. So $A$ is invertible; let $C = A^{-1}$
3. Then $B = IB = (CA)B = C(AB) = CI = C = A^{-1}$ ✓

The same argument works with left and right swapped: $BA = I \implies B = A^{-1}$ too.
