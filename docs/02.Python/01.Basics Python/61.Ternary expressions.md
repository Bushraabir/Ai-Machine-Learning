# 61. Ternary Expressions

## What Is a Ternary Expression?

A ternary expression is a **conditional expression that evaluates to one of two values depending on a condition** -- all in a single line. It is the expression form of an `if/else` statement.

```python
# if/else statement -- a block, produces no value itself
if condition:
    x = value_a
else:
    x = value_b

# Ternary expression -- produces a value directly
x = value_a if condition else value_b
```

The word "ternary" means "composed of three parts": the true value, the condition, and the false value.

---

## Syntax

```python
value_if_true if condition else value_if_false
```

The order is deliberately readable: lead with what you want, state the condition, fall back to the alternative.

```python
age = 20
label = "adult" if age >= 18 else "minor"
print(label)   # "adult"
```

---

## How Python Evaluates It

The condition is evaluated first. Exactly one branch is then evaluated -- the other is not touched.

```python
def a():
    print("a called")
    return 1

def b():
    print("b called")
    return 2

result = a() if True else b()
# prints: "a called"
# b() is never called

result = a() if False else b()
# prints: "b called"
# a() is never called
```

This lazy evaluation matters when branches have side effects or are expensive to compute.

## Common Usage Patterns

### Assigning based on a condition

```python
score = 73
grade = "pass" if score >= 50 else "fail"
```

### Default value when something is None or falsy

```python
name = user_input if user_input else "Anonymous"

# More explicit -- check specifically for None
name = user_input if user_input is not None else "Anonymous"
```

### Inside f-strings

```python
count = 1
print(f"{count} item{'s' if count != 1 else ''}")
# "1 item"

count = 5
print(f"{count} item{'s' if count != 1 else ''}")
# "5 items"
```

### Inside a list or as a function argument

```python
values = [x if x > 0 else 0 for x in [-1, 2, -3, 4]]
print(values)   # [0, 2, 0, 4]

print("even" if n % 2 == 0 else "odd")
```

### Return value from a function

```python
def absolute(n):
    return n if n >= 0 else -n

print(absolute(-5))   # 5
print(absolute(3))    # 3
```

## Ternary vs if/else -- When to Use Which

The ternary expression is appropriate when:

- The result is a single value, not a block of logic
- Both branches are short and fit comfortably on one line
- The condition and both values are immediately readable together

Use a full `if/else` block when:

- Either branch involves multiple statements
- The condition is complex enough that splitting aids comprehension
- Nesting would be required (almost always use blocks instead)

```python
# Clear -- use ternary
status = "active" if user.is_logged_in else "inactive"

# Too complex -- use if/else block
if user.is_logged_in and user.has_permission("admin"):
    status = "admin"
    log_access(user)
else:
    status = "restricted"
    redirect_to_login()
```

---

## Nesting -- Technically Valid, Practically Dangerous

Ternary expressions can be nested, but readability degrades sharply.

```python
# Nested ternary -- legal but hard to parse
score = 85
grade = "A" if score >= 90 else "B" if score >= 80 else "C" if score >= 70 else "F"
print(grade)   # "B"
```

Python evaluates this left to right:

```
"A" if score >= 90 else ("B" if score >= 80 else ("C" if score >= 70 else "F"))
```

Beyond two levels, an `if/elif/else` block or a dictionary lookup is always clearer.

```python
# Clearer alternative for multi-branch grading
def get_grade(score):
    if score >= 90: return "A"
    if score >= 80: return "B"
    if score >= 70: return "C"
    return "F"
```

## Interaction with Truthiness

The condition is evaluated as a boolean, so Python's truthiness rules apply.

```python
data = []
result = "has data" if data else "empty"
print(result)   # "empty" -- [] is falsy

items = [0, 1, 2]
result = items[0] if items else -1
print(result)   # 0 -- items is truthy even though items[0] is falsy
```

Be precise when the value could be falsy but valid:

```python
count = 0
# Incorrect -- 0 is falsy, falls through to default
label = count if count else "none"   # "none" -- wrong when count is 0

# Correct -- check explicitly for None
label = count if count is not None else "none"   # 0
```

## Ternary in Comprehensions

Ternary expressions inside comprehensions serve two distinct purposes that are easy to confuse.

### Transform -- ternary inside the output expression

Applied to every element. Nothing is filtered out.

```python
numbers = [-2, -1, 0, 1, 2]
result = [x if x >= 0 else -x for x in numbers]
print(result)   # [2, 1, 0, 1, 2]  -- absolute values, all 5 elements kept
```

### Filter -- `if` clause at the end of the comprehension

Removes elements. No `else` branch.

```python
result = [x for x in numbers if x >= 0]
print(result)   # [0, 1, 2]  -- only 3 elements
```

### Both together -- transform and filter

```python
# Keep only negatives, and negate them to make positive
result = [-x for x in numbers if x < 0]
print(result)   # [2, 1]
```

The structure is: `[transform(x) if cond else alt for x in iterable if filter_cond]`

```python
# Replace negatives with 0, keep only non-zero results
result = [x if x > 0 else 0 for x in numbers if x != 0]
# numbers without zero: [-2, -1, 1, 2]
# ternary applied: [0, 0, 1, 2]
print(result)   # [0, 0, 1, 2]
```

## Comparison With Other Languages

Most languages use a `?:` operator for the same concept.

```
# C, C++, Java, JavaScript
condition ? value_if_true : value_if_false

# Python
value_if_true if condition else value_if_false
```

Python's syntax reads more like English but places the true branch first, which differs from the `?:` convention of leading with the condition. If you come from C++ (relevant for your CLRS and systems work), this ordering is the one adjustment to make.

## Common Pitfalls

```python
# Pitfall 1 -- forgetting the else clause
x = 1 if condition    # SyntaxError -- else is mandatory
x = 1 if condition else None   # valid -- explicit None
```

```python
# Pitfall 2 -- operator precedence surprises
# What does this return?
result = 1 + 2 if True else 3 + 4

# Parsed as: (1 + 2) if True else (3 + 4)
# result = 3, not 1 + (2 if True else 3) + 4
print(result)   # 3

# When in doubt, use parentheses
result = 1 + (2 if True else 4)   # 3, explicit
```

```python
# Pitfall 3 -- assignment inside ternary (use walrus awareness)
# This does NOT assign to x inside the condition
val = x if (x = 10) else 0   # SyntaxError -- use walrus if needed
val = x if (x := 10) else 0  # valid, but unusual
```

```python
# Pitfall 4 -- confusing filter-if with ternary-if in comprehensions
# These are different:
[x for x in data if x > 0]            # filter -- removes elements
[x if x > 0 else 0 for x in data]     # ternary -- transforms elements
```

## Quick Reference

```python
# Basic form
result = a if condition else b

# With None fallback
result = value if value is not None else default

# Inside f-string
f"{'yes' if flag else 'no'}"

# Inside comprehension -- transform
[f(x) if condition else g(x) for x in iterable]

# Inside comprehension -- filter (not a ternary, just if)
[x for x in iterable if condition]

# Nested (avoid beyond two levels)
a if p else b if q else c
```
