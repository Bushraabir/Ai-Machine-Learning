> _"Pandas is where raw data becomes something a model can reason about. Every cleaning decision you make here is a modelling decision in disguise."_

This is the index for Pandas — the data wrangling layer between raw files and numerical arrays. In the AI/ML pipeline, Pandas sits between data ingestion and NumPy/scikit-learn. You will spend more time here than you expect. Master it completely.

## Priority Order for AI/ML Path

```
Phase 1 (Core data model):          1 → 2 → 3 → 4
Phase 2 (Cleaning and wrangling):   5 → 6 → 7
Phase 3 (Aggregation and reshape):  8 → 9 → 10
Phase 4 (Specialist accessors):     11 → 12 → 13 → 14
```

Phases 1–3 are non-negotiable before writing a single sklearn pipeline. Phase 4 becomes critical when you hit real-world datasets with text columns, timestamps, and hierarchical indices. Phase 5 is where Pandas connects to the rest of your stack.

## Synergy Map

|Pandas Topic|Where It Appears in ML/DL|
|---|---|
|`dropna`, `fillna`|Missing value imputation (AIMA Ch. 18, ESL Ch. 9)|
|`get_dummies`|One-hot encoding before logistic regression, SVMs|
|`groupby` + `transform`|Group-level normalisation, target encoding|
|`resample`, `rolling`|Time-series feature engineering for RNNs, LSTMs|
|`pivot_table`|Constructing feature matrices from transactional data|
|`merge` (left join)|Joining feature tables in tabular ML pipelines|
|`cut`, `qcut`|Binning for decision tree features, calibration|
|`astype('category')`|Memory reduction before passing to LightGBM, CatBoost|
|`shift`, `diff`|Lag features for sequential models|
|`to_numpy()`|Final handoff to NumPy, scikit-learn, PyTorch|
