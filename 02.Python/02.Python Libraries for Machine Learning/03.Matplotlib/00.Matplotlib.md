> _"A plot is not decoration. It is a hypothesis about the structure of your data. Every visualisation you make is a question you are asking — and the answer will change what model you build next."_

This is the index for Matplotlib — the foundational plotting library of the scientific Python ecosystem. In the AI/ML pipeline, Matplotlib is your primary tool for EDA, debugging model behaviour, visualising training dynamics, and communicating results. Seaborn and Pandas plotting are wrappers around it. Understanding Matplotlib at the object level means you are never at the mercy of a high-level API.

## Synergy Map

|Matplotlib Topic|Where It Appears in ML/DL|
|---|---|
|`plot()` loss curves|Every training loop in PyTorch and TensorFlow|
|`imshow()`|CNN filter visualisation, attention maps, confusion matrix|
|`contourf()` + meshgrid|Decision boundary visualisation for any classifier|
|`scatter()` with colour|t-SNE, UMAP, PCA embedding visualisation|
|`barh()`|Feature importance (Random Forests, XGBoost, SHAP)|
|`fill_between()`|Confidence intervals, bias-variance tradeoff diagrams|
|`hist()`|Weight distribution monitoring, gradient histograms|
|`errorbar()`|Cross-validation score reporting with std|
|`colorbar()` + `imshow()`|Heatmaps, correlation matrices, attention weights|
|`FuncAnimation`|Animating gradient descent convergence|
