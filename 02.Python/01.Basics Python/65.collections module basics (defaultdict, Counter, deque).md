# 65. collections Module Basics — `defaultdict`, `Counter`, `deque`

## What is `collections`?

`collections` is a standard library module providing **specialized container datatypes** — alternatives to Python's built-in `dict`, `list`, `set`, and `tuple` that handle specific patterns more cleanly and efficiently.

```python
from collections import defaultdict, Counter, deque
```

These three are the ones you will reach for constantly in algorithms, data processing, and ML pipelines.

---

## Mental Model — Why They Exist

Every one of these solves a recurring pattern that naive code handles badly:

|Problem|Naive approach|collections solution|
|---|---|---|
|Missing key in dict crashes|`if key not in d: d[key] = []` everywhere|`defaultdict`|
|Counting occurrences|Manual loop + `dict.get()`|`Counter`|
|Fast append/pop from both ends|`list` (O(n) left insert)|`deque`|

---

## 1. `defaultdict` — Dictionary With a Default Factory

### What it does

A `defaultdict` is a subclass of `dict` that **automatically creates a default value** for missing keys instead of raising a `KeyError`.

```python
from collections import defaultdict

d = defaultdict(list)
d["key"].append(1)   # No KeyError — creates [] automatically
print(d)             # defaultdict(<class 'list'>, {'key': [1]})
```

### Syntax

```python
defaultdict(default_factory)
```

`default_factory` is a **callable with no arguments** that returns the default value. Common choices:

|Factory|Default value created|
|---|---|
|`list`|`[]`|
|`int`|`0`|
|`set`|`set()`|
|`str`|`""`|
|`lambda: 42`|`42`|
|`lambda: None`|`None`|

### The problem it solves

```python
# ❌ Naive grouping — boilerplate everywhere
groups = {}
words = ["apple", "ant", "banana", "bear", "cherry"]

for word in words:
    key = word[0]              # group by first letter
    if key not in groups:      # required check — crashes otherwise
        groups[key] = []
    groups[key].append(word)

# ✅ With defaultdict — clean, no guard needed
groups = defaultdict(list)

for word in words:
    groups[word[0]].append(word)

print(dict(groups))
# {'a': ['apple', 'ant'], 'b': ['banana', 'bear'], 'c': ['cherry']}
```

### Counting with `int`

```python
from collections import defaultdict

text = "mississippi"
freq = defaultdict(int)

for char in text:
    freq[char] += 1    # starts at 0 automatically

print(dict(freq))
# {'m': 1, 'i': 4, 's': 4, 'p': 2}
```

### Nested defaultdict

```python
# Adjacency list for a graph
graph = defaultdict(list)

edges = [(1, 2), (1, 3), (2, 4), (3, 4)]
for u, v in edges:
    graph[u].append(v)
    graph[v].append(u)   # undirected

print(dict(graph))
# {1: [2, 3], 2: [1, 4], 3: [1, 4], 4: [2, 3]}
```

```python
# Nested defaultdict — 2D table
from collections import defaultdict

table = defaultdict(lambda: defaultdict(int))
table["Alice"]["math"]    += 90
table["Alice"]["science"] += 85
table["Bob"]["math"]      += 78

print(table["Alice"]["math"])    # 90
print(table["Bob"]["history"])   # 0 — created with default
```

### Accessing vs. `dict.get()`

```python
d = defaultdict(list)

# Accessing a missing key CREATES it
val = d["missing"]      # creates key with []
print(d)                # defaultdict(..., {'missing': []})

# Use .get() when you want to CHECK without creating
val = d.get("other")    # returns None, does NOT create key
```

**Important:** Accessing a missing key via `d[key]` always triggers the factory and inserts the key. Use `.get()` for read-only checks.

### `defaultdict` is a full `dict`

It inherits everything from `dict` — `.keys()`, `.values()`, `.items()`, `.update()`, iteration, everything. The only difference is missing-key behavior.

```python
d = defaultdict(int, {"a": 1, "b": 2})   # initialize with existing data
```

## 2. `Counter` — Multiset / Frequency Map

### What it does

`Counter` is a `dict` subclass specialized for **counting hashable objects**. It maps elements to their integer counts.

```python
from collections import Counter

c = Counter("mississippi")
print(c)
# Counter({'i': 4, 's': 4, 'p': 2, 'm': 1})
```

### Syntax — three ways to create

```python
from collections import Counter

# From an iterable — counts elements
c1 = Counter([1, 1, 2, 3, 3, 3])
# Counter({3: 3, 1: 2, 2: 1})

# From a string
c2 = Counter("aabbbc")
# Counter({'b': 3, 'a': 2, 'c': 1})

# From keyword arguments
c3 = Counter(red=3, blue=1, green=2)
# Counter({'red': 3, 'green': 2, 'blue': 1})
```

### `most_common(n)`

Returns the `n` most frequent elements as a list of `(element, count)` tuples.

```python
words = ["apple", "banana", "apple", "cherry", "banana", "apple"]
c = Counter(words)

print(c.most_common(2))
# [('apple', 3), ('banana', 2)]

print(c.most_common())    # all, sorted by frequency
```

### Missing keys return 0 — not KeyError

```python
c = Counter("hello")
print(c["z"])    # 0 — not KeyError
print(c["l"])    # 2
```

### Arithmetic operations

Counter supports `+`, `-`, `&`, `|` — this is unique to Counter.

```python
from collections import Counter

a = Counter("aaabbc")
b = Counter("aabbd")

# Addition — sum counts
print(a + b)   # Counter({'a': 5, 'b': 4, 'c': 1, 'd': 1})

# Subtraction — keeps only positive results
print(a - b)   # Counter({'a': 1, 'c': 1})

# Intersection — minimum of each count
print(a & b)   # Counter({'a': 2, 'b': 2})

# Union — maximum of each count
print(a | b)   # Counter({'a': 3, 'b': 2, 'c': 1, 'd': 1})
```

### `.update()` and `.subtract()`

```python
c = Counter(["a", "b", "a"])

c.update(["a", "c"])        # adds counts
print(c)   # Counter({'a': 3, 'b': 1, 'c': 1})

c.subtract(["a", "a"])      # subtracts counts (can go negative)
print(c)   # Counter({'b': 1, 'c': 1, 'a': 1})
```

### Convert to dict / list / sorted items

```python
c = Counter("aabbbc")

dict(c)                          # {'a': 2, 'b': 3, 'c': 1}
list(c)                          # ['a', 'b', 'c'] — keys only
list(c.elements())               # ['a', 'a', 'b', 'b', 'b', 'c'] — expanded
sorted(c.items(), key=lambda x: -x[1])  # sorted by count desc
```

### ML application — vocabulary / token frequency

```python
from collections import Counter

corpus = [
    "the cat sat on the mat",
    "the cat is on the mat",
    "the dog sat on the log"
]

all_words = " ".join(corpus).split()
vocab = Counter(all_words)

print(vocab.most_common(5))
# [('the', 6), ('on', 3), ('mat', 2), ('cat', 2), ('sat', 2)]

# Top-1000 vocabulary (common in NLP pipelines)
top_1000 = {word for word, _ in vocab.most_common(1000)}
```

## 3. `deque` — Double-Ended Queue

### What it does

A `deque` (pronounced "deck") is a **doubly-linked list** that supports O(1) append and pop from **both ends**. A Python `list` only provides O(1) operations at the right end — left-end operations (`list.insert(0, x)`, `list.pop(0)`) are O(n).

```python
from collections import deque

d = deque([1, 2, 3])
d.appendleft(0)    # O(1) — impossible efficiently with list
d.append(4)        # O(1) — right end
print(d)           # deque([0, 1, 2, 3, 4])
```

### Syntax

```python
deque(iterable=[], maxlen=None)
```

### Core operations — all O(1)

```python
from collections import deque

d = deque([1, 2, 3])

# Append
d.append(4)         # right:  deque([1, 2, 3, 4])
d.appendleft(0)     # left:   deque([0, 1, 2, 3, 4])

# Pop
d.pop()             # right:  returns 4, deque([0, 1, 2, 3])
d.popleft()         # left:   returns 0, deque([1, 2, 3])

# Extend
d.extend([4, 5])          # right: deque([1, 2, 3, 4, 5])
d.extendleft([0, -1])     # left:  deque([-1, 0, 1, 2, 3, 4, 5])
                          # note: extendleft reverses order

# Rotate
d = deque([1, 2, 3, 4, 5])
d.rotate(2)     # shift right:  deque([4, 5, 1, 2, 3])
d.rotate(-2)    # shift left:   deque([1, 2, 3, 4, 5])
```

### `maxlen` — bounded / sliding window deque

When `maxlen` is set, the deque **automatically discards** from the opposite end when full.

```python
from collections import deque

window = deque(maxlen=3)

for x in [1, 2, 3, 4, 5]:
    window.append(x)
    print(list(window))

# [1]
# [1, 2]
# [1, 2, 3]
# [2, 3, 4]   ← 1 discarded automatically
# [3, 4, 5]   ← 2 discarded automatically
```

This is the canonical sliding window implementation. No manual index management.

### As a Queue (FIFO)

```python
from collections import deque

queue = deque()

# Enqueue
queue.append("task_1")
queue.append("task_2")
queue.append("task_3")

# Dequeue
print(queue.popleft())   # "task_1"
print(queue.popleft())   # "task_2"
```

This is how BFS is implemented correctly in Python. Using `list.pop(0)` for a queue is O(n) per operation — a common performance bug.

### BFS with deque

```python
from collections import deque

def bfs(graph, start):
    visited = set()
    queue   = deque([start])
    order   = []

    while queue:
        node = queue.popleft()     # O(1)
        if node in visited:
            continue
        visited.add(node)
        order.append(node)
        for neighbor in graph[node]:
            if neighbor not in visited:
                queue.append(neighbor)

    return order

graph = {1: [2, 3], 2: [4], 3: [4], 4: []}
print(bfs(graph, 1))   # [1, 2, 3, 4]
```

### As a Stack (LIFO)

```python
from collections import deque

stack = deque()

stack.append(1)     # push
stack.append(2)
stack.append(3)

print(stack.pop())  # 3 — LIFO
print(stack.pop())  # 2
```

A `list` works equally well as a stack — `deque` only wins when you need both-end access or a bounded buffer.

### Performance comparison vs. list

```python
import timeit
from collections import deque

# list.insert(0, x) — O(n) — shifts entire array
list_time = timeit.timeit(
    stmt="lst.insert(0, 1)",
    setup="lst = list(range(10000))",
    number=10000
)

# deque.appendleft(x) — O(1)
deque_time = timeit.timeit(
    stmt="dq.appendleft(1)",
    setup="from collections import deque; dq = deque(range(10000))",
    number=10000
)

print(f"list: {list_time:.4f}s")    # ~0.05s
print(f"deque: {deque_time:.4f}s")  # ~0.001s
```

### deque indexing

```python
d = deque([10, 20, 30, 40, 50])

print(d[0])    # 10  — O(1)
print(d[-1])   # 50  — O(1)
print(d[2])    # 30  — O(n) — random access is NOT O(1)
```

`deque` is optimized for end access. If you need heavy random access by index, use a `list`.

## Side-by-Side Summary

```python
from collections import defaultdict, Counter, deque

# defaultdict — auto-initializes missing keys
word_positions = defaultdict(list)
for i, w in enumerate("the cat sat on the mat".split()):
    word_positions[w].append(i)
# {'the': [0, 4], 'cat': [1], 'sat': [2], 'on': [3], 'mat': [5]}

# Counter — frequency counting + arithmetic
freq = Counter("the cat sat on the mat".split())
print(freq.most_common(2))   # [('the', 2), ('cat', 1)]

# deque — O(1) both-end queue for BFS / sliding window
recent = deque(maxlen=3)
for item in range(10):
    recent.append(item)
print(list(recent))   # [7, 8, 9]
```

## Comparison Table

|Feature|`defaultdict`|`Counter`|`deque`|
|---|---|---|---|
|Base class|`dict`|`dict`|—|
|Missing key|Returns factory default|Returns `0`|N/A|
|Primary use|Grouping, accumulation|Frequency counting|Queue, sliding window|
|Key operation|`d[k].append(x)`|`c.most_common(n)`|`appendleft / popleft`|
|Left insert|N/A|N/A|O(1)|
|Arithmetic|No|Yes (`+`, `-`, `&`, `\|`)|No|
|Bounded size|No|No|Yes (`maxlen`)|

## Common Pitfalls

```python
# ❌ Accessing defaultdict key "just to check" — creates it
d = defaultdict(list)
if d["x"]:             # creates 'x': [] as a side effect
    pass

# ✅ Use .get() or 'in' for read-only checks
if "x" in d:
    pass
if d.get("x"):
    pass
```

```python
# ❌ Counter subtraction can go negative — elements() ignores them
c = Counter(a=3)
c.subtract({"a": 5})
print(c["a"])           # -2
print(list(c.elements()))  # [] — negatives excluded from elements()

# ✅ Use max(0, ...) or filter if you need non-negative
```

```python
# ❌ deque random access is O(n) — not a list replacement
d = deque(range(100000))
d[50000]    # slow — traverses the linked list

# ✅ Use list when you need frequent random indexing
```
