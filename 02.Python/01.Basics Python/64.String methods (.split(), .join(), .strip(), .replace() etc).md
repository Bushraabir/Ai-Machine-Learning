# 64. String Methods — `.split()`, `.join()`, `.strip()`, `.replace()` etc.

## What Are String Methods?

String methods are **built-in functions attached to every `str` object** that return new strings (or useful data) without modifying the original. Strings are immutable — every method produces a new object.

```python
s = "hello"
s.upper()     # returns "HELLO"
print(s)      # still "hello" — s is unchanged
```

This note covers the ~20 methods you will use constantly. They are grouped by purpose, not alphabetically.

---

## Mental Model — Strings Are Immutable Sequences

Every string method follows this contract:

1. **Does not modify in place** — returns a new string
2. **Is chainable** — `s.strip().lower().replace(" ", "_")`
3. **Works on Unicode** — handles international characters correctly

```python
s = "  Hello, World!  "
result = s.strip().lower().replace(",", "").replace("!", "")
print(result)   # "hello world"
```

## 1. Splitting and Joining

### `.split(sep=None, maxsplit=-1)`

Splits a string into a **list of substrings**.

```python
s = "apple,banana,cherry"
print(s.split(","))         # ['apple', 'banana', 'cherry']

s = "one two   three"
print(s.split())            # ['one', 'two', 'three']  — splits on any whitespace
print(s.split(" "))         # ['one', 'two', '', '', 'three']  — exact split on " "
```

**Key distinction — `split()` vs `split(" ")`:**

```python
s = "a  b  c"

s.split()      # ['a', 'b', 'c']   — collapses all whitespace, strips edges
s.split(" ")   # ['a', '', 'b', '', 'c']  — splits on exactly one space
```

Without arguments, `split()` treats any run of whitespace (spaces, tabs, newlines) as a single delimiter and strips leading/trailing whitespace. This is almost always what you want for parsing natural text.

**`maxsplit` — limit the number of splits:**

```python
s = "a:b:c:d"
s.split(":", 1)    # ['a', 'b:c:d']  — only first split
s.split(":", 2)    # ['a', 'b', 'c:d']
```

**`.splitlines()` — split on line boundaries:**

```python
text = "line one\nline two\nline three"
print(text.splitlines())
# ['line one', 'line two', 'line three']
```

More robust than `.split("\n")` — handles `\r\n`, `\r`, `\n`, and Unicode line endings.

---

### `.join(iterable)`

The **inverse of split**. Joins an iterable of strings into one string, with the calling string as separator.

```python
words = ["apple", "banana", "cherry"]

",".join(words)      # "apple,banana,cherry"
" ".join(words)      # "apple banana cherry"
"".join(words)       # "applebananacherry"
"\n".join(words)     # "apple\nbanana\ncherry"
" | ".join(words)    # "apple | banana | cherry"
```

**Critical rule — all elements must be strings:**

```python
nums = [1, 2, 3]
",".join(nums)              # ❌ TypeError
",".join(str(n) for n in nums)   # ✅ "1,2,3"
```

**Why join beats concatenation:**

```python
# ❌ Slow — creates a new string object at every step — O(n²)
result = ""
for word in words:
    result += word + ","

# ✅ Fast — join allocates once — O(n)
result = ",".join(words)
```

This matters when building strings in loops. In ML pipelines processing millions of tokens, this difference is measurable.

**Round-trip: split → process → join**

```python
sentence = "the quick brown fox"
words    = sentence.split()
words    = [w.capitalize() for w in words]
result   = " ".join(words)
print(result)   # "The Quick Brown Fox"
```

## 2. Whitespace and Stripping

### `.strip(chars=None)`

Removes **leading and trailing** characters. Defaults to whitespace.

```python
s = "  hello  "
s.strip()         # "hello"

s = "###hello###"
s.strip("#")      # "hello"

s = "  \t\nhello\n  "
s.strip()         # "hello"  — strips all whitespace types
```

**`chars` is a set of characters, not a substring:**

```python
"xxhelloyx".strip("xy")    # "hello"  — strips any x or y from edges
"abcba".strip("ab")        # "c"      — strips a or b from both ends
```

### `.lstrip(chars=None)` / `.rstrip(chars=None)`

Strip from left only or right only.

```python
"  hello  ".lstrip()    # "hello  "
"  hello  ".rstrip()    # "  hello"

">>>hello<<<".lstrip(">")    # "hello<<<"
">>>hello<<<".rstrip("<")    # ">>>hello"
```

**Common use case — cleaning file lines:**

```python
with open("data.txt") as f:
    lines = [line.rstrip("\n") for line in f]
    # or simply:
    lines = [line.strip() for line in f]
```

## 3. Searching and Testing

### `.find(sub, start=0, end=len(s))`

Returns the **index of the first occurrence** of `sub`, or **-1** if not found.

```python
s = "hello world"
s.find("world")     # 6
s.find("xyz")       # -1
s.find("o")         # 4  — first occurrence
s.find("o", 5)      # 7  — search from index 5
```

### `.index(sub)`

Same as `.find()` but **raises `ValueError`** if not found.

```python
s = "hello"
s.index("l")     # 2
s.index("z")     # ValueError: substring not found
```

Use `.find()` when absence is possible. Use `.index()` when absence is a bug.

### `.count(sub)`

Number of non-overlapping occurrences.

```python
"mississippi".count("ss")    # 2
"aaa".count("aa")            # 1  — non-overlapping
"hello".count("l")           # 2
```

### `.startswith(prefix)` / `.endswith(suffix)`

```python
s = "hello.py"

s.startswith("hello")    # True
s.endswith(".py")        # True
s.endswith(".txt")       # False

# Accepts a tuple of options
s.endswith((".py", ".txt", ".csv"))   # True
```

**Practical use:**

```python
files = ["data.csv", "model.py", "notes.txt", "train.py"]
py_files = [f for f in files if f.endswith(".py")]
# ['model.py', 'train.py']
```

### `.in` operator — membership test

```python
"world" in "hello world"    # True
"xyz"   in "hello world"    # False
```

Prefer `in` over `.find() != -1` for readability.

## 4. Replacing

### `.replace(old, new, count=-1)`

Returns a new string with all occurrences of `old` replaced by `new`.

```python
s = "hello world"
s.replace("world", "Python")    # "hello Python"
s.replace("l", "L")             # "heLLo worLd"
s.replace("l", "L", 1)          # "heLlo world"  — only first occurrence
```

**Deleting characters — replace with empty string:**

```python
"hello, world!".replace(",", "").replace("!", "")
# "hello world"
```

**Normalizing separators:**

```python
path = "some\\windows\\path"
path.replace("\\", "/")    # "some/windows/path"
```

## 5. Case Conversion

```python
s = "Hello World"

s.lower()        # "hello world"
s.upper()        # "HELLO WORLD"
s.title()        # "Hello World"  — capitalizes each word
s.capitalize()   # "Hello world"  — only first character
s.swapcase()     # "hELLO wORLD"
```

**Testing case:**

```python
"hello".islower()      # True
"HELLO".isupper()      # True
"Hello World".istitle() # True
"hello123".islower()   # True — digits ignored
"Hello World".istitle() # True
```

**NLP normalization pipeline:**

```python
def normalize(text):
    return text.lower().strip()

tokens = ["  Hello ", "WORLD", "foo"]
normalized = [normalize(t) for t in tokens]
# ['hello', 'world', 'foo']
```

## 6. Padding and Alignment

### `.center(width, fillchar=" ")` / `.ljust()` / `.rjust()`

```python
"hello".center(11)          # "   hello   "
"hello".center(11, "-")     # "---hello---"
"hello".ljust(10)           # "hello     "
"hello".rjust(10)           # "     hello"
"hello".ljust(10, ".")      # "hello....."
```

### `.zfill(width)`

Pads with leading zeros — useful for fixed-width numeric strings.

```python
"42".zfill(5)      # "00042"
"-42".zfill(5)     # "-0042"  — handles sign correctly
"3.14".zfill(7)    # "0003.14"
```

## 7. Checking Character Content

```python
"hello123".isalpha()     # False  — has digits
"hello".isalpha()        # True   — only letters
"123".isdigit()          # True
"hello123".isalnum()     # True   — letters or digits
"   ".isspace()          # True
"Hello World".istitle()  # True
```

## 8. Encoding

### `.encode(encoding="utf-8")`

Converts string to `bytes`.

```python
s = "hello"
b = s.encode("utf-8")    # b'hello'
s2 = b.decode("utf-8")   # "hello"
```

You will use this when working with file I/O, network sockets, or feeding raw bytes into ML models.

## 9. Formatting (f-strings and `.format()`)

### f-strings — preferred

```python
name  = "Alice"
score = 98.5

f"Name: {name}"                  # "Name: Alice"
f"Score: {score:.2f}"            # "Score: 98.50"
f"Score: {score:.0f}"            # "Score: 99"   — rounded
f"{1000000:,}"                   # "1,000,000"   — thousands separator
f"{0.75:.1%}"                    # "75.0%"       — percentage
f"{'left':<10}"                  # "left      "  — left-align in 10 chars
f"{'right':>10}"                 # "     right"
f"{'center':^10}"                # "  center  "
```

### `.format()` — older style, still common

```python
"{} + {} = {}".format(1, 2, 3)         # "1 + 2 = 3"
"{name} is {age}".format(name="Alice", age=30)
"{0:.2f}".format(3.14159)              # "3.14"
```

### `%` formatting — legacy, avoid in new code

```python
"Hello, %s! Score: %.2f" % ("Alice", 98.5)
# "Hello, Alice! Score: 98.50"
```

## 10. Less Common but Useful

### `.partition(sep)`

Splits into exactly **three parts**: before, separator, after. Always returns a 3-tuple.

```python
"user@example.com".partition("@")
# ('user', '@', 'example.com')

"no-at-sign".partition("@")
# ('no-at-sign', '', '')  — separator not found
```

More reliable than `split("@", 1)` when you need to know if the separator was present.

### `.translate(table)` + `str.maketrans()`

Efficient **character-level replacement** — faster than multiple `.replace()` calls.

```python
table = str.maketrans("aeiou", "AEIOU")
"hello world".translate(table)    # "hEllO wOrld"

# Delete characters (map to None)
table = str.maketrans("", "", "aeiou")
"hello world".translate(table)    # "hll wrld"
```

### `.expandtabs(tabsize=8)`

```python
"a\tb\tc".expandtabs(4)    # "a   b   c"
```

## Common Patterns in Practice

### CSV row parsing

```python
row = "  Alice , 30 , engineer  "
fields = [f.strip() for f in row.split(",")]
# ['Alice', '30', 'engineer']
```

### Slug generation (URL-safe string)

```python
title = "  Hello, World! This is Python  "
slug  = title.strip().lower().replace(",", "").replace("!", "").replace(" ", "-")
# "hello-world-this-is-python"
```

### Token normalization (NLP preprocessing)

```python
import re

def clean_token(token):
    return token.strip().lower().replace("'", "")

tokens = ["  Hello ", "don't", "WORLD!"]
cleaned = [clean_token(t) for t in tokens]
# ['hello', 'dont', 'world!']
```

### Building a formatted report

```python
headers = ["Name", "Score", "Grade"]
rows    = [["Alice", 98.5, "A"], ["Bob", 74.2, "C"]]

print(" | ".join(f"{h:<10}" for h in headers))
print("-" * 36)
for row in rows:
    print(f"{row[0]:<10} | {row[1]:<10.1f} | {row[2]:<10}")

# Name       | Score      | Grade
# ------------------------------------
# Alice      | 98.5       | A
# Bob        | 74.2       | C
```

## Common Pitfalls

```python
# ❌ Forgetting that string methods return new values
s = "hello"
s.upper()         # result discarded
print(s)          # "hello" — nothing changed

# ✅ Assign the result
s = s.upper()
print(s)          # "HELLO"
```

```python
# ❌ split(" ") vs split() confusion
"  a  b  ".split()     # ['a', 'b']   — correct for most use cases
"  a  b  ".split(" ")  # ['', '', 'a', '', 'b', '', '']  — probably not what you want
```

```python
# ❌ join on non-strings
",".join([1, 2, 3])              # TypeError
",".join([str(x) for x in [1,2,3]])  # ✅ "1,2,3"
```

```python
# ❌ Using find() result without checking -1
s = "hello"
idx = s.find("z")
print(s[idx])    # s[-1] = 'o' — silent wrong answer, not an error

# ✅ Always check
if idx != -1:
    print(s[idx])
```
