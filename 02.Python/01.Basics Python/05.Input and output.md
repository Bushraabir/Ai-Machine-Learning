Input and output (I/O) is how a Python program communicates with the outside world — reading data from the user, writing results to the terminal, reading from files, writing to files. Mastering I/O is not optional — every real program processes data from somewhere and sends results somewhere.

Python's primary I/O mechanisms:
- `print()` — write to the terminal (stdout)
- `input()` — read a line from the terminal (stdin)
- File I/O — read and write files on disk

- ## print()
`print()` writes to standard output (the terminal by default). It converts its arguments to strings using `str()` and writes them separated by a space, ending with a newline.
```python
print("Hello, World!")       # Hello, World!
print(42)                    # 42
print(3.14)                  # 3.14
print(True)                  # True
print(None)                  # None
print([1, 2, 3])             # [1, 2, 3]
print()                      # empty line
```
#### Multiple Arguments
`print()` accepts any number of arguments, separated by a space by default.
```python
name  = "Alice"
score = 95
grade = "A"

print(name, score, grade)    # Alice 95 A
print("Name:", name, "Score:", score)    # Name: Alice Score: 95
```
#### sep: Custom Separator
```python
print("Alice", "Bob", "Carol")              # Alice Bob Carol
print("Alice", "Bob", "Carol", sep=", ")    # Alice, Bob, Carol
print("Alice", "Bob", "Carol", sep=" | ")   # Alice | Bob | Carol
print("Alice", "Bob", "Carol", sep="")      # AliceBobCarol
print(2024, 6, 15, sep="-")                 # 2024-6-15
```
#### end: Custom Line Ending
By default, `print()` ends with `\n` (newline). Override with `end`.
```python
print("Loading", end="")
print("...", end="")
print("done")
# Loading...done  — all on one line

# Progress on one line
for i in range(5):
    print(i, end=" ")
print()    # final newline
# 0 1 2 3 4

# Custom ending
print("Step 1", end=" -> ")
print("Step 2", end=" -> ")
print("Step 3")
# Step 1 -> Step 2 -> Step 3
```

#### file: Redirect Output
By default, `print()` writes to `sys.stdout`. You can redirect to any file-like object.
```python
import sys

print("Error occurred", file=sys.stderr)    # write to stderr

with open("log.txt", "w") as f:
    print("Log entry 1", file=f)
    print("Log entry 2", file=f)
# writes to file instead of terminal
```

#### flush: Force Immediate Write
Output is often buffered. `flush=True` forces the buffer to be written immediately — useful for progress displays.
```python
import time

for i in range(5):
    print(f"\rProgress: {i+1}/5", end="", flush=True)
    time.sleep(0.5)
print()    # final newline
```
`\r` (carriage return) moves the cursor to the start of the line without a newline — combined with `flush=True`, this produces an in-place updating progress display.

### print() with Formatting
Combine `print()` with f-strings for clean, readable output.
```python
name      = "Alice"
score     = 95.678
iterations = 1_000_000

print(f"Name:       {name}")
print(f"Score:      {score:.2f}")
print(f"Iterations: {iterations:,}")
# Name:       Alice
# Score:      95.68
# Iterations: 1,000,000
```

- ## input()
`input()` reads one line from standard input (the terminal). It always returns a **string** — regardless of what the user types.

```python
name = input("Enter your name: ")
print(f"Hello, {name}!")
```
The optional argument is a prompt string — displayed before waiting for input, with no trailing newline.
```python
# input() always returns str
x = input("Enter a number: ")
print(type(x))    # <class 'str'>
print(x + 1)      # TypeError — cannot add str and int
```
#### Converting input
Always convert explicitly to the type you need.
```python
age      = int(input("Enter your age: "))
height   = float(input("Enter your height in metres: "))
accepted = input("Accept? (y/n): ").lower() == "y"

print(f"Age: {age}, Height: {height:.2f}m, Accepted: {accepted}")
```

#### Safe Input: Handling Errors
`input()` returns raw text. Users type unexpected things. Always validate.

```python
# Basic safe conversion
raw = input("Enter a number: ")
try:
    value = float(raw)
    print(f"You entered: {value}")
except ValueError:
    print(f"'{raw}' is not a valid number")
```

```python
# Validation loop — keep asking until valid
def get_int(prompt, lo=None, hi=None):
    while True:
        raw = input(prompt)
        try:
            value = int(raw)
        except ValueError:
            print(f"  Invalid — '{raw}' is not an integer. Try again.")
            continue

        if lo is not None and value < lo:
            print(f"  Invalid — must be >= {lo}. Try again.")
            continue

        if hi is not None and value > hi:
            print(f"  Invalid — must be <= {hi}. Try again.")
            continue

        return value

age = get_int("Enter your age: ", lo=0, hi=150)
print(f"Age: {age}")
```

### Reading Multiple Values on One Line
```python
# Space-separated integers
raw = input("Enter three numbers: ")       # "1 2 3"
a, b, c = map(int, raw.split())
print(a + b + c)

# Comma-separated
raw = input("Enter names (comma-separated): ")    # "Alice, Bob, Carol"
names = [name.strip() for name in raw.split(",")]
print(names)    # ['Alice', 'Bob', 'Carol']
```

```python
# Read multiple lines until blank
lines = []
print("Enter lines (blank line to stop):")
while True:
    line = input()
    if line == "":
        break
    lines.append(line)

print(f"You entered {len(lines)} lines")
```


## sys.stdin and sys.stdout

For programs that read from pipes or redirect I/O (common in scripting and competitive programming):

```python
import sys

# Read all stdin at once
content = sys.stdin.read()

# Read line by line from stdin
for line in sys.stdin:
    process(line.strip())

# Write to stdout explicitly
sys.stdout.write("Hello\n")

# Write to stderr (for error messages and logs)
sys.stderr.write("Error: file not found\n")
print("Debug info", file=sys.stderr)
```

## Summary

| Operation          | Function/Method                 | Notes                                     |
| ------------------ | ------------------------------- | ----------------------------------------- |
| Print to terminal  | `print()`                       | sep, end, file, flush options             |
| Read from terminal | `input(prompt)`                 | Always returns str — convert explicitly   |
| Open file          | `open(path, mode)`              | Always use with — always specify encoding |
| Read entire file   | `f.read()`                      | String — loads all into memory            |
| Read one line      | `f.readline()`                  | String with \n                            |
| Read all lines     | `f.readlines()`                 | List of strings with \n                   |
| Iterate file       | `for line in f`                 | Most memory efficient                     |
| Write string       | `f.write(str)`                  | No automatic newline                      |
| Write lines        | `f.writelines(lst)`             | No automatic newlines                     |
| Append mode        | `open(path, "a")`               | Does not overwrite                        |
| Read CSV           | `csv.reader` / `csv.DictReader` | Use newline=""                            |
| Write CSV          | `csv.writer`                    | Use newline=""                            |
| Read JSON          | `json.load(f)`                  | File object                               |
| Write JSON         | `json.dump(obj, f)`             | File object, use indent=2                 |
| File paths         | `pathlib.Path`                  | Cross-platform, modern                    |

## Common Mistakes to Avoid

```python
# Mistake 1: treating input() as anything other than str
age = input("Enter age: ")
if age > 18:    # TypeError — str vs int comparison
    ...
age = int(input("Enter age: "))    # correct

# Mistake 2: opening files without with
f = open("data.txt")
data = f.read()
# f.close() forgotten — file handle leaks

# Mistake 3: opening files without encoding
with open("data.txt", "r") as f:    # encoding depends on OS
    ...
with open("data.txt", "r", encoding="utf-8") as f:    # explicit, portable

# Mistake 4: loading large files entirely into memory
content = open("10gb_file.txt").read()    # MemoryError
for line in open("10gb_file.txt"):        # correct — stream line by line
    process(line)

# Mistake 5: writing without newline
f.write("Line 1")
f.write("Line 2")    # "Line 1Line 2" — no separation
f.write("Line 1\n")
f.write("Line 2\n")  # correct

# Mistake 6: using "w" mode when you mean "a"
with open("log.txt", "w") as f:    # overwrites everything
    f.write("new entry\n")
with open("log.txt", "a") as f:    # appends to existing
    f.write("new entry\n")

# Mistake 7: building file paths with string concatenation
path = base_dir + "/" + subdir + "/" + filename    # breaks on Windows (\)
path = Path(base_dir) / subdir / filename          # correct — pathlib

# Mistake 8: not stripping newlines from file lines
lines = f.readlines()
for line in lines:
    print(repr(line))    # 'Line 1\n' — has trailing newline
for line in lines:
    print(repr(line.strip()))    # 'Line 1' — clean
```
