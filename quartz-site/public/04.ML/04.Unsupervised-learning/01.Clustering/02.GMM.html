Gaussian Mixture Models

“The EM algorithm is to unsupervised learning what gradient descent is to supervised learning: the workhorse you return to whenever direct optimisation is intractable because something is hidden.”

Tags: #unsupervised #clustering #probabilistic #em #mle #latent-variables Status: #core Depends on: 03.Probability Review · 01.K-Means Leads to: 03.Hierarchical Clustering · 04.DBSCAN · 03.Gaussian Processes · 04.Representation Learning · 01.Bayesian Networks

§1 — Motivation: What K-Means Cannot Do

K-Means makes three hard assumptions baked into its objective function:

  1. Hard assignments — every point belongs to exactly one cluster with certainty.
  2. Spherical geometry — clusters are balls (Σk​=σ2I, isotropic covariance).
  3. Equal weight — all clusters are implicitly treated as equally probable.

Real data violates all three. GMM relaxes each explicitly:

PropertyK-MeansGMM
AssignmentsHard: rik​∈0,1Soft: rik​∈[0,1], ∑k​rik​=1
Cluster shapeSpherical (isotropic)Ellipsoidal (full Σk​)
Cluster weightImplicit equal weightExplicit mixing weights πk​
ObjectiveGeometric: minimise WCSSProbabilistic: maximise log-likelihood

The price of this generality: we cannot solve the learning problem in closed form. We need the Expectation-Maximisation (EM) algorithm.

Professor’s marginal note: K-Means is EM in disguise. It is exactly the limit of GMM-EM as σ2→0. We will make this precise in §10. Always derive the general case first, recover the special case second.

§2 — The Generative Model

A GMM posits that each data point xi​∈Rd was generated by the following stochastic process:

Step 1. Draw a discrete latent variable zi​∈1,…,K from a categorical distribution: P(zi​=k)=πk​,πk​≥0,∑k=1K​πk​=1

The πk​ are called mixing weights.

Step 2. Draw the observed point from the selected Gaussian component: xi​∣zi​=k;∼;N(μk​,Σk​)

The joint distribution is: P(xi​,zi​=k)=πk​,N(xi​∣μk​,Σk​)

Marginalising over the unobserved zi​:

p(xi​)=k=1∑K​πk​,N(xi​∣μk​,Σk​)​

where the d-dimensional Gaussian density is: N(x∣μ,Σ)=(2π)d/2∣Σ∣1/21​exp!(−21​(x−μ)TΣ−1(x−μ))

The model parameters are θ=πk​,μk​,Σk​k=1K​, totalling (K−1)+Kd+K⋅d(d+1)/2 free parameters.

Why zi​ is latent: We observe xi​ but not zi​. If we observed zi​, the MLE would be trivial: fit each component independently to its assigned points. The whole difficulty of GMM is that zi​ is hidden.

§3 — Why Direct MLE Fails: The Log-Sum Problem

Given n i.i.d. observations, the log-likelihood is:

ℓ(θ)=∑i=1n​logp(xi​)=∑i=1n​log(∑k=1K​πk​,N(xi​∣μk​,Σk​))

Setting ∂ℓ/∂μk​=0:

∂μk​∂ℓ​=∑i=1n​=:;rik​∑j​πj​N(xi​∣μj​,Σj​)πk​,N(xi​∣μk​,Σk​)​​​⋅Σk−1​(xi​−μk​)=0

This gives μk​=∑i​rik​∑i​rik​xi​​, but rik​ itself depends on μk​ through the denominator. The equations are coupled and self-referential. No closed-form solution exists.

The obstacle is structural: the log sits outside the sum over k. This is the defining signature of a latent variable model — the component label zi​ is unobserved, so we cannot separate the likelihood into K independent parts.

§4 — The EM Algorithm: Derivation from First Principles

4.1 Constructing a Tractable Lower Bound

Introduce an arbitrary distribution qi​(zi​) over the latent variable for each observation. Using the identity logx=log(x⋅qi​(k)qi​(k)​):

ℓ(θ)=∑i​log∑k​qi​(k)⋅qi​(k)πk​N(xi​∣μk​,Σk​)​

Apply Jensen’s inequality (log is concave, so logE[X]≥E[logX]):

ℓ(θ)≥∑i​∑k​qi​(k)logqi​(k)πk​N(xi​∣μk​,Σk​)​;≡;L(q,θ)

This lower bound is the Evidence Lower Bound (ELBO). Expanding:

L(q,θ)=expected complete-data log-likelihoodi∑​k∑​qi​(k)logP(xi​,zi​=k;θ)​​;+;entropy of qi∑​H(qi​)​​

The gap between ℓ and L is:

ℓ(θ)−L(q,θ)=∑i​DKL​(qi​,∣,P(zi​∣xi​,θ))≥0

This gap vanishes — the bound is tight — when qi​(k)=P(zi​=k∣xi​,θ), the true posterior over latent variables.

4.2 Coordinate Ascent on the ELBO

E-step (Expectation): Fix θ. Maximise L(q,θ) over q by zeroing the KL gap: qi​(k);←;P(zi​=k∣xi​,θ) After this step, L(qnew,θ)=ℓ(θ) — the bound is tight.

M-step (Maximisation): Fix q. Maximise L(q,θ) over θ. The entropy H(qi​) does not depend on θ, so: θ;←;argmaxθ​∑i​∑k​qi​(k)logP(xi​,zi​=k;θ) This is the expected complete-data log-likelihood and has a closed-form maximiser for exponential family models (including Gaussians).

4.3 Monotonic Convergence Proof

ℓ(θt+1);≥;L(qt+1,θt+1);≥;L(qt+1,θt);=;ℓ(θt)

  • First ≥: L is always a lower bound on ℓ (KL ≥0).
  • Second ≥: The M-step maximises L over θ at fixed qt+1.
  • Equality: After the E-step, qt+1 makes the bound tight at θt.

Therefore ℓ(θ) is monotonically non-decreasing at every EM iteration. Since it is bounded above (likelihoods ≤1 for proper densities — with the caveat of singularities), it converges. But only to a local maximum or saddle point, not the global maximum in general.

§5 — EM for GMM: Explicit Update Equations

5.1 E-Step: Compute Responsibilities

The posterior over latent variables is obtained by Bayes’ theorem:

rik​=P(zi​=k∣xi​,θ)=j=1∑K​πj​,N(xi​∣μj​,Σj​)πk​,N(xi​∣μk​,Σk​)​​

Numerator: prior weight times likelihood for component k. Denominator: marginal likelihood (normalisation). Each rik​∈[0,1] and ∑k​rik​=1 for every i.

Interpretation: rik​ is the probability that point xi​ was generated by component k, given the current parameter estimates.

5.2 M-Step: Update Parameters

Define the effective cluster size: Nk​=∑i=1n​rik​.

Mixing weights (Lagrange multiplier for ∑k​πk​=1):

πk​=nNk​​​

Full derivation: The relevant terms in L are ∑k​Nk​logπk​. Form the Lagrangian L′=∑k​Nk​logπk​−λ(∑k​πk​−1). Setting ∂L′/∂πk​=Nk​/πk​−λ=0 gives πk​=Nk​/λ. The constraint ∑k​πk​=1 gives λ=∑k​Nk​=n.

Means:

μk​=Nk​i=1∑n​rik​,xi​​​

Full derivation: The relevant terms are −21​∑i​rik​(xi​−μk​)TΣk−1​(xi​−μk​). Differentiating with respect to μk​: Σk−1​∑i​rik​(xi​−μk​)=0. Since Σk​ is positive definite (invertible), the factor in parentheses must vanish: ∑i​rik​xi​=Nk​μk​.

Covariances:

Σk​=Nk​i=1∑n​rik​,(xi​−μk​)(xi​−μk​)T​​

Full derivation: Differentiate with respect to the precision matrix Λk​=Σk−1​, using the matrix identity ∂log∣Λk​∣/∂Λk​=Λk−1​=Σk​ and ∂,tr(Λk​A)/∂Λk​=AT. Setting the gradient to zero and solving gives the weighted sample covariance above.

Universal pattern: All three M-step updates are responsibility-weighted MLE estimates. Hard counts nk​=∣i:zi​=k∣ are replaced by soft counts Nk​; sums over hard-assigned points are replaced by responsibility-weighted sums over all points. This pattern holds for any exponential family component in an EM derivation.

5.3 Complete Algorithm

Input:  data X ∈ ℝ^{n×d}, components K, tolerance ε
Output: parameters {π_k, μ_k, Σ_k}

Initialise:
  μ_k ← K-Means centroids (recommended)
  Σ_k ← I_d  for all k
  π_k ← 1/K  for all k

Repeat until |ℓ^{t+1} − ℓ^t| < ε:

  ── E-STEP ──
  For i = 1..n, k = 1..K:
    log_num_{ik} = log π_k + log N(x_i | μ_k, Σ_k)
  For i = 1..n:
    log_denom_i  = logsumexp_k [log_num_{ik}]
    r_{ik}       = exp(log_num_{ik} − log_denom_i)

  ── M-STEP ──
  For k = 1..K:
    N_k   = Σ_i r_{ik}
    π_k   = N_k / n
    μ_k   = (Σ_i r_{ik} x_i) / N_k
    Σ_k   = (Σ_i r_{ik} (x_i − μ_k)(x_i − μ_k)^T) / N_k
    Σ_k  += ε_reg · I               ← numerical floor

  ── LOG-LIKELIHOOD ──
  ℓ = Σ_i log_denom_i

Return {π_k, μ_k, Σ_k}

§6 — Numerical Issues

6.1 Log-Sum-Exp Trick (Non-Negotiable)

Computing ∑k​πk​N(xi​∣μk​,Σk​) naively underflows to zero for d≳20, because N can evaluate to numbers like 10−500.

Solution: Work in log space, using the log-sum-exp identity:

\log \sum_k e^{a_k} = a^* + \log \sum_k e^{a_k - a^_}, \quad a^_ = \max_k a_k

All subtracted exponentials are ≤1 — no overflow. Adding a∗ back via the outer log is exact.

Use scipy.special.logsumexp in production.

6.2 Covariance Collapse (Singularities)

A component can degenerate: μk​→xj​ for some j, rjk​→1, Σk​→0, and logN(xj​∣μk​,Σk​)→+∞. The log-likelihood has genuine singularities at these degenerate solutions — ℓ→∞ trivially but meaninglessly.

Detection: Nk​<1 signals collapse (a component has claimed less than one effective point).

Fixes:

  • Covariance flooring: Add ϵreg​I (e.g., ϵ=10−6) after each M-step.
  • Component reinitialisation: If Nk​<1, resample μk​ from a high-residual data point.
  • MAP / Bayesian GMM: Place an inverse-Wishart prior on Σk​. The MAP M-step adds a prior pseudo-count, bounding Σk​ away from zero.

6.3 Identifiability and Label Switching

Permuting component labels leaves ℓ(θ) unchanged — the likelihood is invariant under the group of K! permutations. This creates K! equivalent global maxima. It does not affect clustering quality but complicates parameter interpretation across runs and is a serious issue for Bayesian inference (MCMC chains switch labels mid-run).

§7 — Worked Example: Two Gaussians in 1D

Let K=2, n=5 points: X=1.0,;1.5,;5.0,;5.5,;6.0.

Initialise: μ1​=2.0, μ2​=5.0, σ12​=σ22​=1.0, π1​=π2​=0.5.

E-step, x=1.0:

N(1.0∣2.0,,1)=2π​1​e−0.5≈0.2420,N(1.0∣5.0,,1)=2π​1​e−8≈3.35×10−4

r1,1​=0.5×0.2420+0.5×3.35×10−40.5×0.2420​≈0.9986

Point x=1.0 is 99.86 assigned to component 1. By symmetry, x=5.5 and x=6.0 will be >99 assigned to component 2.

M-step (approximate, after computing all responsibilities):

N1​≈2.0,N2​≈3.0,π1​≈0.4,π2​≈0.6 μ1​≈21.0+1.5​=1.25,μ2​≈35.0+5.5+6.0​=5.5

After a few iterations: μ1​≈1.25, μ2​≈5.5, σ12​≈0.06, σ22​≈0.17, π1​=0.4, π2​=0.6.

Lesson: The log-likelihood at the true clusters far exceeds the initialisation value. For well-separated components, EM converges in very few iterations because responsibilities quickly polarise.

§8 — Covariance Structures

The GMM family is parameterised by the constraint placed on Σk​. sklearn exposes this via covariance_type:

TypeΣk​ structureFree params/componentCluster geometry
'spherical'σk2​I1 scalarSphere, varying radius
'diag'diag(σk12​,…,σkd2​)d scalarsAxis-aligned ellipsoid
'tied'Σ (shared across components)d(d+1)/2 totalSame shape, different centres
'full'Σk​ unrestricted SPDd(d+1)/2 eachArbitrary ellipsoid

'spherical' is K-Means in the soft-assignment limit (see §10). 'full' is the most expressive but most prone to overfitting and covariance collapse. Choosing covariance_type is a regularisation decision: more constrained = fewer parameters = more bias, less variance.

§9 — Model Selection: How Many Components?

Unlike K-Means where the elbow method is heuristic, GMM admits principled information-theoretic model selection.

9.1 Bayesian Information Criterion (BIC)

BIC(K)=ln(n)⋅∣θK​∣−2ℓ(θ^K​)

where ∣θK​∣ is the number of free parameters for K components. Choose K minimising BIC.

Why ln(n)? BIC approximates −2logP(D) (the marginal likelihood) under a broad prior via Laplace approximation. The ln(n) penalty grows with the dataset size, making BIC a consistent model selector: as n→∞, it selects the true K (if the model is well-specified).

9.2 Akaike Information Criterion (AIC)

AIC(K)=2∣θK​∣−2ℓ(θ^K​)

AIC uses a fixed penalty of 2 per parameter, derived as an estimate of out-of-sample prediction error (Kullback-Leibler divergence to the true model). AIC is not consistent for model selection — it tends to overestimate K. Prefer BIC for structure discovery; AIC if you care about predictive accuracy.

9.3 Bayesian / Variational GMM

A principled alternative: place a Dirichlet prior on π (and conjugate priors on μk​, Σk​) and train via Variational Bayes. Components with low effective count will have their πk​→0, automatically pruning excess components. Start with Kmax​ and let the model kill off unneeded ones.

Available in sklearn as BayesianGaussianMixture(n_components=K_max).

§10 — K-Means as a Special Case of GMM-EM

Setup: Consider GMM-EM with equal mixing weights (πk​=1/K) and isotropic, equal covariances (Σk​=σ2I).

E-step responsibilities become:

rik​=j∑​exp!(−2σ2∣xi​−μj​∣2​)exp!(−2σ2∣xi​−μk​∣2​)​

This is a softmax over negative squared distances with temperature σ2.

Take the limit σ2→0:

For any point xi​, let k∗=argmink​∣xi​−μk​∣2. For any k=k∗:

\frac{e^{-|x_i - \mu_k|^2 / 2\sigma^2}}{e^{-|x_i - \mu_{k^_}|^2 / 2\sigma^2}} = e^{-(|x_i - \mu_k|^2 - |x_i - \mu_{k^_}|^2)/2\sigma^2} \xrightarrow{\sigma^2 \to 0} 0

since the exponent →−∞. Therefore:

rik​;σ2→0​;{1​k=argminj​∣xi​−μj​∣2 0​otherwise​

This is precisely the K-Means ASSIGN step. The M-step μk​=Nk​∑i​rik​xi​​ remains the mean of hard-assigned points.

Consequence: The K-Means objective WCSS = ∑i​∑k​rik​∣xi​−μk​∣2 is (up to constants) the negative expected complete-data log-likelihood of this degenerate GMM. K-Means minimises a geometric surrogate; GMM maximises the true log-likelihood.

§11 — GMM as a Density Estimator

GMM is not just a clustering algorithm — it is a universal density approximator:

Any continuous density on a compact domain can be approximated arbitrarily closely by a GMM with sufficiently many components (density approximation theorem for mixtures).

As a density estimator, GMM competes with Kernel Density Estimation (KDE):

KDEGMM
Number of parametersn (one kernel per data point)O(Kd2) (fixed K)
Evaluation cost per queryO(nd)O(Kd2)
Out-of-sampleDirectDirect
InterpretabilityNoneComponents have semantic meaning
Model selectionBandwidth hNumber of components K

For large n, GMM is far more efficient to evaluate. For small datasets or complex density shapes, KDE with a well-chosen bandwidth can be more accurate.

§12 — Connection to AI / Deep Learning

12.1 The ELBO in Variational Autoencoders

The VAE training objective is:

LVAE​(ϕ,θ)=Eqϕ​(z∣x)​[logpθ​(x∣z)]−DKL​(qϕ​(z∣x),∣,p(z))

This is identical in structure to the GMM ELBO: LGMM​(q,θ)=∑i​Eqi​​[logP(xi​,zi​)]+H(qi​)

The difference: in GMM, the E-step has a closed-form posterior (Bayes’ theorem). In a VAE, the posterior pθ​(z∣x) is intractable for a nonlinear decoder, so qϕ​(z∣x) is a learned Gaussian approximation (the encoder network). The VAE is exactly EM with an amortised, approximate E-step.

GMM-VAE: The standard VAE uses a single isotropic Gaussian prior p(z)=N(0,I). Replacing this with a GMM prior p(z)=∑k​πk​N(μk​,Σk​) gives a structured latent space with cluster geometry, enabling conditional generation and disentanglement.

12.2 EM as a Universal Pattern in Deep Learning

The EM structure — alternate between inferring latent variables and updating parameters — appears throughout:

12.3 Mixture of Experts in Large Language Models

Modern LLMs (e.g., Mixtral, Switch Transformer) use a Mixture of Experts layer: a gate network routes each token to one or more “expert” FFN layers. The gating mechanism is a soft (top-k) assignment — analogous to the E-step responsibilities. Training balances load across experts, echoing the equal-weight challenge in GMM initialisation.

12.4 VQ-VAE and Discrete Latents

VQ-VAE (van den Oord et al., 2017) replaces the continuous latent space of a VAE with a discrete codebook learned by K-Means (which, as shown in §10, is a hard-assignment GMM). The encoder output is quantised to the nearest codebook vector via straight-through gradient estimation. This connects the GMM density model directly to modern generative modelling.

12.5 Speaker Verification (GMM-UBM)

Before neural embeddings, speaker verification used GMM-UBM: a Universal Background Model (large GMM trained on many speakers) adapted per-speaker via MAP. The MAP adaptation update is a convex combination of the UBM parameters and the speaker’s MLE parameters — a direct application of the GMM MAP M-step. Many design principles (adaptation, scoring, normalisation) from GMM-UBM persist in modern x-vector and ECAPA-TDNN systems.

§16 — Common Mistakes and Gotchas

  1. Not standardising features. A feature with scale 104 will dominate the Mahalanobis distance computation, forcing all variance onto one dimension even with full covariance.

  2. Not adding covariance regularisation. Covariance collapse is a real failure mode. reg_covar=1e-6 is not a hack — it is numerically necessary for high-dimensional or low-n settings.

  3. Using a single EM run. EM converges to a local maximum. Always use n_init ≥ 5. sklearn’s GaussianMixture default is n_init=1 — override it.

  4. Using AIC instead of BIC for component selection. AIC overestimates K in finite samples. BIC is consistent.

  5. Interpreting component parameters across runs as comparable. Label-switching: component 0 in run A may correspond to component 2 in run B. Only within-run parameters are meaningful.

  6. Assuming convergence means global optimality. EM monotonically increases ℓ but only to a local maximum. Multiple random restarts and the best ℓ across them is the standard mitigation.

  7. Using GMM on non-Gaussian clusters expecting it to handle them. Full-covariance GMM fits ellipsoidal Gaussians. For crescent-shaped or toroidal clusters, GMM will fail exactly as K-Means does, just with slightly more flexibility. GMM is not a universal shape detector.
