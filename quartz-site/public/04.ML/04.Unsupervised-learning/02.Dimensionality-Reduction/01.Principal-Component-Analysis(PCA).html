01.Principal Component Analysis(PCA)

Apr 26, 202617 min read

“PCA does not discover structure in the data. It discovers the directions of maximum spread. Whether spread means structure is a question you must answer yourself.”

Part of: 00.Dimensionality Reduction · 04.Unsupervised Learning
Requires: linear algebra (eigendecomposition, SVD, orthogonal projections), 03.Probability Review (covariance matrix, expectations)
Connects to: 02.Kernel PCA (nonlinear extension), 03.t-SNE and 04.Uniform Manifold Approximation and Projection (UMAP) (contrast: local vs. global), 04.Representation Learning (autoencoders as learned PCA), 04.Support Vector Machines (kernel trick appears again in Kernel PCA)

✦ The Setup

We have data X∈Rn×d: n observations, d features. Assume the data is centred: n1​∑i​xi​=0. If not, subtract the mean first — this is not optional, it is part of the algorithm.

We want to find a sequence of orthonormal directions v1​,v2​,…,vk​∈Rd (with k≤d) such that projecting the data onto these directions retains as much variance as possible.

The projected coordinates are the principal components. The directions vj​ are the principal axes (also called loadings, or eigenvectors of the covariance matrix). The j-th principal component of observation xi​ is the scalar zij​=vjT​xi​.

✦ Derivation I: Maximum Variance Formulation

First Principal Component

Find the unit vector v1​∈Rd such that the projected data v1T​xi​i=1n​ has maximum variance.

The sample variance of the projections is: Var(v1T​X)=n1​∑i=1n​(v1T​xi​)2=n1​v1T​XTXv1​=v1T​Σv1​

where Σ=n1​XTX∈Rd×d is the (sample) covariance matrix (valid since data is centred).

The optimisation problem: v1​=∣v∣=1argmax​ vTΣv

Using a Lagrange multiplier λ for the constraint ∣v∣2=1: L(v,λ)=vTΣv−λ(vTv−1)

Setting the gradient to zero: ∂v∂L​=2Σv−2λv=0⟹Σv=λv

So v1​ must be an eigenvector of Σ. Substituting back: v1T​Σv1​=v1T​(λ1​v1​)=λ1​

The variance of the projection equals the eigenvalue. To maximise variance, choose v1​ as the eigenvector corresponding to the largest eigenvalue λ1​.

Subsequent Principal Components

v2​ solves the same problem subject to v2​⊥v1​. By induction (deflation argument), vj​ is the eigenvector corresponding to the j-th largest eigenvalue λj​.

Proof of orthogonality. Since Σ is real symmetric and positive semi-definite, the spectral theorem guarantees that its eigenvectors can be chosen to be orthonormal. The principal axes form an orthonormal basis of Rd.

✦ Derivation II: Minimum Reconstruction Error Formulation

An equivalent derivation from a completely different starting point. We want a k-dimensional affine subspace S minimising the sum of squared distances from each xi​ to its projection onto S.

Let Vk​=[v1​∣⋯∣vk​]∈Rd×k with orthonormal columns. The projection of xi​ onto the subspace spanned by Vk​ is x^i​=Vk​VkT​xi​.

Reconstruction error: R(Vk​)=∑i=1n​∣xi​−Vk​VkT​xi​∣2=∑i=1n​∣xi​∣2−∑i=1n​∣VkT​xi​∣2

The first term is constant. Minimising R is equivalent to maximising ∑i=1n​∣VkT​xi​∣2=tr(VkT​XTXVk​)=tr(VkT​(nΣ)Vk​).

This is maximised when the columns of Vk​ are the top k eigenvectors of Σ — exactly the same answer as Derivation I.

The two formulations are equivalent. Maximum variance projection = minimum reconstruction error. This is not a coincidence — it is a consequence of the Pythagorean theorem in Rd.

✦ Derivation III: The SVD Connection

This is the computationally important formulation. Let X∈Rn×d (centred). The thin SVD of X is:

X=UΣsv​VT

where:

  • U∈Rn×r: left singular vectors, orthonormal columns (UTU=Ir​)
  • Σsv​∈Rr×r: diagonal matrix of singular values σ1​≥σ2​≥⋯≥σr​≥0
  • V∈Rd×r: right singular vectors, orthonormal columns (VTV=Ir​)
  • r=rank(X)≤min(n,d)

Now observe: n1​XTX=n1​(UΣsv​VT)T(UΣsv​VT)=n1​VΣsv2​VT

So the covariance matrix Σ=n1​XTX has:

  • Eigenvectors = columns of V (the right singular vectors of X)
  • Eigenvalues = λj​=nσj2​​

The principal axes are the right singular vectors of the (centred) data matrix, and the j-th eigenvalue equals σj2​/n.

The principal component scores (projected coordinates) are: Z=XVk​=Uk​Σsv,k​

where Vk​ and Uk​ are the first k columns, Σsv,k​ the top-left k×k block.

Why use SVD instead of eigendecomposition?

  1. Numerical stability. Computing XTX squares the condition number of X. SVD operates directly on X and is far more numerically stable when singular values span many orders of magnitude.
  2. Efficiency when n≪d or d≪n. The covariance matrix is d×d; for d=104, storing and decomposing it is expensive. Thin SVD of X costs O(ndmin(n,d)) — for n≪d, much cheaper.
  3. Randomised SVD. For very large matrices, randomised SVD (Halko et al., 2011) computes the top-k singular vectors in O(ndk) — linear in n and d.

In practice: always use SVD. The eigendecomposition of Σ is presented for understanding; SVD is what you implement.

✦ The Full Algorithm

Input:  X ∈ ℝⁿˣᵈ (raw data), number of components k
Output: Z ∈ ℝⁿˣᵏ (scores), V_k ∈ ℝᵈˣᵏ (principal axes), λ ∈ ℝᵏ (eigenvalues)

1. Centre:      μ = (1/n) Σᵢ xᵢ
                X_c = X - 1μᵀ              [subtract mean from each row]

2. Decompose:   U, σ, Vᵀ = svd(X_c, full_matrices=False)
                             [thin SVD: σ is vector of singular values]

3. Sort:        (already sorted descending by numpy/scipy convention)

4. Extract:     V_k = V[:, :k]             [first k right singular vectors]
                λ = σ[:k]² / n             [eigenvalues]
                Z = X_c @ V_k              [project: scores, shape (n, k)]

5. (Optional)   X_hat = Z @ V_k.T + μ      [reconstruction]
                error = ||X_c - Z @ V_k.T||_F²

✦ Implementation from Scratch (NumPy)

Note on sign ambiguity. Eigenvectors are defined up to a sign flip (v and −v are both valid). sklearn uses a convention (largest absolute value in each component is positive) to make results deterministic. When comparing PCA implementations, compare subspaces (via ∣VVT∣), not individual vectors.

✦ Geometric Interpretation

PCA rotates the coordinate system to align with the axes of maximum variance of the data ellipsoid. The covariance matrix Σ defines an ellipsoid x:xTΣ−1x=1. The principal axes of this ellipsoid are the eigenvectors; the axis lengths are λj​​ (the standard deviations of the projections).

Original coordinates:       After PCA rotation:

   x₂                           PC2
    │   ●  ●                      │
    │ ● ● ●  ●                ●   │
    │  ● ●● ●●         ● ●● ●●●●●─────── PC1
    │   ● ●  ●                ●   │
    └──────────── x₁               │
                           (ellipse aligned with axes)

The first k principal components define the k-dimensional hyperplane that is closest to all data points in the least-squares sense — the best-fit flat subspace.

Projection is orthogonal. The residual xi​−x^i​ is perpendicular to the subspace spanned by Vk​. This is not a choice — it is forced by the least-squares criterion.

✦ Explained Variance and Choosing k

The explained variance ratio of the j-th component: EVRj​=∑l=1d​λl​λj​​=∑l=1d​σl2​σj2​​=∣Xc​∣F2​σj2​​

The cumulative explained variance for the first k components: CEV(k)=∑j=1d​λj​∑j=1k​λj​​

How to choose k:

  1. Threshold: Choose smallest k such that CEV(k)≥0.95 (or 0.99 for lossless-ish compression).
  2. Scree plot: Plot λj​ vs. j. Look for the “elbow” — the point where eigenvalues level off. Components before the elbow carry signal; after it, noise.
  3. Reconstruction error: Plot R(k) vs. k and look for diminishing returns.
  4. Downstream task: Use cross-validation on the downstream task (classification, regression) treating k as a hyperparameter.

✦ Probabilistic PCA (PPCA)

Standard PCA has no probabilistic model — it is a purely geometric operation. Probabilistic PCA (Tipping & Bishop, 1999) embeds PCA in a latent variable model:

z∼N(0,Ik​) x∣z∼N(Wz+μ,σ2Id​)

where W∈Rd×k is the loading matrix (to be learned).

The marginal p(x)=N(μ,WWT+σ2Id​) is a Gaussian with a rank-k plus isotropic noise covariance.

MLE solution: As σ2→0, the MLE of W converges to the PCA solution (up to rotation within the principal subspace). For σ2>0, PPCA softens the projection — points close to the decision boundary have uncertain latent coordinates.

Advantages of PPCA:

  1. Principled handling of missing data (via EM).
  2. Defines a proper generative model — can sample from p(x).
  3. Model selection via marginal likelihood (avoids scree-plot heuristics).
  4. Generalises to Factor Analysis (heteroscedastic noise: σ2I→Ψ diagonal).

The EM algorithm for PPCA:

E-step: Compute posterior p(z∣x)=N(M−1WT(x−μ), σ2M−1) where M=WTW+σ2Ik​.

M-step: Update W and σ2 using the expected sufficient statistics from the E-step.

✦ Whitening

After PCA projection to k dimensions, the components zj​=vjT​x have variance λj​ — they are uncorrelated but not unit-variance.

Whitening (or sphering) additionally scales each component to unit variance: z~j​=λj​​zj​​=λj​​vjT​x​

Equivalently, the whitening transform is: Z~=ZΛk−1/2​where Λk​=diag(λ1​,…,λk​)

The whitened data satisfies n1​Z~TZ~=Ik​ — identity covariance in the projected space.

When whitening matters:

  • Preprocessing for algorithms that assume spherical data (KNN, SVMs with RBF kernel, ICA).
  • ICA requires whitening as a preprocessing step: uncorrelated components are a necessary (not sufficient) condition for independence.
  • Deep learning: batch normalisation is approximately whitening per layer.

When to avoid whitening:

  • If some components have near-zero variance (e.g., last PCA components), dividing by λj​≈0​ amplifies noise catastrophically.
  • In reconstruction tasks: whitening is not an isometry, so reconstruction errors become hard to interpret.

✦ Limitations of PCA

1. Linearity

PCA can only find linear subspaces. The canonical example: the Swiss roll — data on a 2D curved surface embedded in R3. PCA projects onto a 2D hyperplane, collapsing the roll and destroying the intrinsic 2D structure. Kernel PCA and UMAP handle this correctly.

2. Variance ≠ Information

PCA maximises variance. But variance is not the same as signal. If a dataset has a strong nuisance factor (e.g., batch effects in genomics, illumination in images) with high variance, PC1 captures the nuisance, not the biology/content. Always interpret principal components — do not blindly trust that PC1 is the “most important” direction.

3. Sensitivity to Scale

The covariance matrix Σ is sensitive to the units of each feature. A feature measured in millimetres will dominate one measured in kilometres, purely due to scale. Always standardise (divide by standard deviation) before running PCA if features are in different units. If all features are genuinely comparable (e.g., pixel intensities, gene expression after normalisation), standardisation may not be needed — use judgment.

4. No Supervision

PCA ignores labels. The direction of maximum variance may be unrelated to the direction that separates classes. Linear Discriminant Analysis (LDA) maximises between-class to within-class variance ratio — supervised DR. For classification tasks, LDA projections are often far more useful than PCA projections.

5. Gaussian Assumption (implicit)

PCA fully characterises the data distribution only when the data is Gaussian (for which mean and covariance are sufficient statistics). For non-Gaussian data, PCA captures second-order structure but misses higher-order dependencies. ICA addresses this by seeking statistically independent (not merely uncorrelated) components.

6. Outlier Sensitivity

The covariance matrix is a second moment — quadratically sensitive to outliers. A single point far from the cluster can dramatically shift the principal axes. Robust PCA (RPCA, Candès et al., 2011) decomposes X=L+S where L is low-rank (the PCA structure) and S is sparse (the outliers). It recovers the true principal subspace even under gross corruption.

✦ Connection to AI, ML, and Deep Learning

PCA as a Special Case of Autoencoders

A linear autoencoder — an autoencoder with linear encoder z=Wx+b and linear decoder x^=W′z+b′, trained with MSE loss — converges to the PCA solution. The weight matrix W at convergence spans the same subspace as the top-k principal axes (up to rotation within that subspace).

Proof sketch. The MSE loss of the linear autoencoder is exactly the PCA reconstruction error R(Vk​). Both are minimised by the same subspace. The autoencoder does not necessarily recover the same orthogonal basis (the rotation within the subspace is underdetermined), but it recovers the same projection.

Implication: PCA is the simplest possible autoencoder. Deep nonlinear autoencoders are learned nonlinear generalisations of PCA.

Attention and Low-Rank Structure

The self-attention mechanism projects inputs via WQ​,WK​,WV​∈Rd×dk​ where dk​≪d (typically dk​=d/h for h heads). This is a learned linear projection — structurally identical to PCA, but optimised for the attention task rather than variance. The “dk​-dimensional attention space” is the PCA-like bottleneck of the transformer.

Covariance and Batch Normalisation

Batch normalisation (BN) standardises each feature to zero mean and unit variance across the batch. This is diagonal whitening — it only removes per-feature variance, not cross-feature covariances. Layer normalisation normalises across features, not batch. Neither is full PCA whitening (which also removes cross-covariances), but both are motivated by the same idea: controlling the covariance structure of activations stabilises training.

PCA for Overparameterised Models

Recent work on neural collapse (Papyan et al., 2020) shows that at the end of training, the last-layer features of a deep classifier collapse onto a simplex equiangular tight frame — a structured low-dimensional manifold. The PCA of the final-layer activations reflects the class structure precisely. PCA is thus a diagnostic tool for understanding what a trained neural network has learned.

Eigenfaces and Image Compression

A classical application: apply PCA to a dataset of face images (flattened to vectors). The principal components are “eigenfaces” — the directions of maximum variance across the face dataset. Representing each face as a linear combination of the top k eigenfaces achieves lossy compression and enables face recognition via nearest-neighbour search in the low-dimensional eigenface space.

This is structurally identical to the modern “embedding + nearest neighbour” paradigm — the only difference is that modern methods use nonlinear encoders (deep networks) rather than linear PCA.

LoRA: Low-Rank Adaptation

LoRA (Hu et al., 2022) constrains weight updates during fine-tuning: ΔW=AB where A∈Rd×r and B∈Rr×d with r≪d. This is exactly a rank-r matrix — the same constraint PCA imposes on the data matrix. The motivation: the intrinsic dimensionality of the fine-tuning update is low (cf. the manifold hypothesis), so a full-rank update wastes parameters.

Randomised PCA for Large Models

Computing PCA on the weight matrices or activation matrices of large models requires efficient algorithms. Randomised SVD (Halko, Martinsson & Tropp, 2011) computes the top-k singular vectors of an m×n matrix in O(mnk) — much faster than the O(mnmin(m,n)) full SVD. It works by projecting onto a random k-dimensional subspace (via Johnson-Lindenstrauss) and then running exact SVD on the small projected matrix. Used in sklearn’s TruncatedSVD and in interpretability tools for large language models.

✦ Kernel PCA Preview

PCA is linear. It cannot unfold a Swiss roll or separate two concentric rings. Kernel PCA (02.Kernel PCA) extends PCA to nonlinear manifolds by the kernel trick:

Instead of computing Σ=n1​XTX and finding its eigenvectors, compute the kernel (Gram) matrix Kij​=k(xi​,xj​)=ϕ(xi​)Tϕ(xj​) and find its eigenvectors.

The key insight: PCA in the feature space ϕ(X) can be performed entirely via the kernel matrix K without ever computing ϕ(x) explicitly — even when ϕ maps to an infinite-dimensional space (RBF kernel).

The j-th kernel PC score for xi​ is: zij​=∑l=1n​αlj​k(xl​,xi​)

where αj​ is the j-th eigenvector of the centred kernel matrix K~.
