Kernel PCA

“PCA finds the directions of maximum variance in the space you give it. Kernel PCA finds the directions of maximum variance in a space you never explicitly construct — and that is precisely what makes it powerful.”

Part of: 00.Dimensionality Reduction · 04.Unsupervised Learning
Requires: 01.PCA (must be solid — Kernel PCA is PCA in a different space), 04.Support Vector Machines (the kernel trick and Mercer’s theorem), linear algebra (eigendecomposition, Gram matrices), 03.Probability Review (inner products, feature maps)
Connects to: 03.t-SNE and 04.Uniform Manifold Approximation and Projection (UMAP) (nonlinear DR alternatives), 04.Support Vector Machines (shared kernel machinery), 03.Gaussian Processes (RKHS is common ground)

✦ The Problem with Linear PCA

PCA finds principal axes by eigendecomposing the covariance matrix Σ=n1​XTX. It is a linear operation — it can only find structure that lives in a linear subspace of Rd.

Consider two concentric rings:

    ● ● ●                  The two rings are linearly inseparable.
  ●       ●                PCA projects onto a line or plane —
 ●  ○ ○ ○  ●               the two classes collapse onto each other.
 ●  ○   ○  ●               No linear projection separates them.
  ●  ○ ○  ●
    ● ● ●

Or the Swiss roll: a 2D surface rolled into a 3D ambient space. PCA in R3 gives you a 2D projection that crushes the roll flat — destroying the intrinsic geometry. The true 2D coordinates (position along the roll, position across the roll) are nonlinearly embedded.

Linear PCA has no recourse. We need to operate in a richer space.

✦ The Core Idea: PCA in Feature Space

The kernel trick, which you have already seen in SVMs (04.Support Vector Machines), says: replace ⟨xi​,xj​⟩ with k(xi​,xj​)=⟨ϕ(xi​),ϕ(xj​)⟩H​ where ϕ:X→H maps data into a (possibly infinite-dimensional) Hilbert space H.

The idea for Kernel PCA: run PCA in H, not in Rd.

The covariance matrix in H is: Σ~=n1​∑i=1n​ϕ(xi​)ϕ(xi​)T

We want eigenvectors v∈H: Σ~v=λv.

The crucial observation: every eigenvector of Σ~ lies in the span of ϕ(x1​),…,ϕ(xn​).

Proof. Σ~v=λv with λ>0 implies v=λ1​Σ~v=nλ1​∑i=1n​ϕ(xi​)ϕ(xi​)Tv=nλ1​∑i=1n​⟨ϕ(xi​),v⟩H​⋅ϕ(xi​). This is a linear combination of the ϕ(xi​). □

So we can write v=∑i=1n​αi​ϕ(xi​) for some α∈Rn. We never need to know ϕ explicitly — we only need inner products ⟨ϕ(xi​),ϕ(xj​)⟩H​=k(xi​,xj​).

✦ Derivation: From Covariance Eigenproblem to Kernel Eigenproblem

Step 1: The covariance eigenproblem in H

We want v∈H with ∣v∣=1 satisfying: Σ~v=λv

Substituting Σ~=n1​∑i​ϕ(xi​)ϕ(xi​)T and v=∑j​αj​ϕ(xj​):

n1​∑i=1n​ϕ(xi​)ϕ(xi​)T∑j=1n​αj​ϕ(xj​)=λ∑j=1n​αj​ϕ(xj​)

n1​∑i=1n​ϕ(xi​)∑j=1n​αj​k(xi​,xj​)=λ∑j=1n​αj​ϕ(xj​)

n1​∑i=1n​ϕ(xi​)(Kα)i​=λ∑j=1n​αj​ϕ(xj​)

where K∈Rn×n is the kernel (Gram) matrix with Kij​=k(xi​,xj​).

Step 2: Project onto ϕ(xl​) for arbitrary l

Take inner product of both sides with ϕ(xl​):

n1​∑i=1n​k(xl​,xi​)(Kα)i​=λ∑j=1n​αj​k(xl​,xj​)

n1​(K2α)l​=λ(Kα)l​

In matrix form: n1​K2α=λKα.

Step 3: Simplify

Assuming K is invertible (or restricting to its range):

n1​Kα=λα⟹Kα=nλα

Renaming nλ→λ′: we need the eigenvectors of the kernel matrix K.

Kα=λ′α

This is the central result. The n×n kernel matrix K plays the role of the d×d covariance matrix Σ. PCA in feature space reduces to eigendecomposing the Gram matrix.

Step 4: Normalisation constraint

We need ∣v∣H​=1: ∣v∣2=​∑j​αj​ϕ(xj​)​2=∑i,j​αi​αj​k(xi​,xj​)=αTKα=1

Since Kα=λ′α: αTKα=λ′∣α∣2=1⟹∣α∣2=λ′1​.

So after computing eigenvectors αl​ of K with eigenvalue λl′​, normalise by α^l​=λl′​​αl​​.

✦ Computing Kernel PCA Projections

The l-th kernel PC score for a training point xi​ is:

zil​=⟨vl​,ϕ(xi​)⟩H​=∑j=1n​α^jl​,k(xj​,xi​)=α^lT​ki​

where ki​=(k(x1​,xi​),…,k(xn​,xi​))T∈Rn.

In matrix form, the full embedding of training data to p kernel PCs:

Z=KA^∈Rn×p

where A^=[α^1​∣⋯∣α^p​]∈Rn×p (columns are normalised eigenvectors of K).

But since Kα^l​=λl′​α^l​:

Z=KA^=diag(λ1′​,…,λp′​)A^⋅A^A^​⋅A^

More directly: Zil​=λl′​α^il​ — the l-th kernel PC score for point xi​ is λl′​α^il​.

Wait — let us be careful. Kα^l​=λl′​α^l​, so (KA^)il​=λl′​α^il​. And α^il​=λl′​​αil​​, so:

Zil​=λl′​⋅λl′​​αil​​=λl′​​,αil​

where αl​ is the unit-norm eigenvector of K (before the α^ normalisation). This is the sklearn convention.

✦ Centring in Feature Space

The derivation above assumes ∑i​ϕ(xi​)=0 — i.e., that the data is centred in feature space H. This is generally not true even if the original data X is centred, because ϕ is nonlinear.

We must centre the kernel matrix. The centred kernel matrix is:

K~=K−1n​K−K1n​+1n​K1n​

where 1n​=n1​11T∈Rn×n (matrix of all 1/n).

Entry-wise: K~ij​=k(xi​,xj​)−n1​∑l=1n​k(xl​,xj​)−n1​∑l=1n​k(xi​,xl​)+n21​∑l,m=1n​k(xl​,xm​)

This is the kernel-space analogue of subtracting the mean before computing PCA. Always centre the kernel matrix. Failing to do so is the most common implementation error in Kernel PCA.

Geometric interpretation: K~ij​=⟨ϕ(xi​)−μϕ​,,ϕ(xj​)−μϕ​⟩H​ where μϕ​=n1​∑i​ϕ(xi​) is the mean in feature space. The centred kernel matrix is the covariance inner product matrix in H.

Centring for out-of-sample points

For a new point x__, its kernel vector is k__ = (k(x_1, x__), \ldots, k(x_n, x__))^T. The centred version: k~∗​=k∗​−n1​K1−1n​k∗​+n21​1TK1

where 1∈Rn is the all-ones vector. In practice, store n1​K1 and n21​1TK1 from the training fit.

✦ Out-of-Sample Extension

A fundamental limitation of Kernel PCA (compared to linear PCA): the eigenvectors vl​ live in H and are expressed via the training data. Projecting a new point x∗​ requires:

z_{_l} = \langle v_l, \phi(x__)\rangle_\mathcal{H} = \sum_{j=1}^n \hat{\alpha}_{jl}, \tilde{k}(x_j, x_*)

where \tilde{k}(x_j, x__) is the centred kernel between training point xj​ and the new point x__.

This is O(n) per new point per component — and requires storing all n training points. Contrast with linear PCA: out-of-sample projection is O(d) and requires only the k×d weight matrix.

Practical consequence: Kernel PCA does not scale to large n. For n>104, it is typically replaced by:

  • Approximate methods: Nyström approximation (subsample m≪n “landmark” points, build Km​)
  • Sparse kernel PCA
  • UMAP (which also learns a nonlinear embedding but scales better)

✦ The Full Algorithm

Input:  X = {x₁,...,xₙ} ∈ ℝᵈ, kernel function k(·,·), n_components p
Output: Z ∈ ℝⁿˣᵖ (kernel PCA scores), stored training data for projection

--- TRAINING ---

1. Compute kernel matrix:
   K ∈ ℝⁿˣⁿ,  K[i,j] = k(xᵢ, xⱼ)

2. Centre the kernel matrix:
   row_means = K.mean(axis=1, keepdims=True)      # (n,1)
   col_means = K.mean(axis=0, keepdims=True)       # (1,n)
   grand_mean = K.mean()
   K̃ = K - row_means - col_means + grand_mean

3. Eigendecompose K̃:
   eigenvalues λ', eigenvectors α  (K̃ α = λ'α)
   Sort descending by λ'

4. Keep top p eigenvectors: A = [α₁|...|αₚ]  (n×p)
   Normalise: Â[:,l] = A[:,l] / sqrt(λ'_l)

✦ Common Kernels and What They Do

Linear Kernel

k(x,y)=xTy

Kernel PCA with the linear kernel is identical to standard PCA. This is the sanity check: if you implement Kernel PCA correctly and run it with a linear kernel, you recover PCA exactly (up to sign and scaling).

Why? The Gram matrix Kij​=xiT​xj​=(XXT)ij​. The centred Gram matrix has the same eigenvectors as the centred covariance XTX (up to the U-V duality in the SVD X=UΣVT: XXT=UΣ2UT vs. XTX=VΣ2VT).

Polynomial Kernel

k(x,y)=(γxTy+c0​)d

Corresponds to a feature map ϕ containing all monomials of degree ≤d. Dimension of ϕ: (degd+deg​) — exponential in degree.

For degree d=2, Rp input: ϕ has 1+p+(2p​) features (constant, linear, and quadratic monomials). Kernel PCA in this space can separate data by quadratic boundaries.

RBF (Gaussian) Kernel

k(x,y)=exp!(−γ∣x−y∣2)=exp!(−2σ2∣x−y∣2​)

where γ=2σ21​.

Corresponds to an infinite-dimensional feature map. The feature space H is the RKHS of the Gaussian kernel — functions that are smooth in proportion to σ.

Proof of infinite dimensionality. Via Mercer’s theorem and the Taylor expansion of the exponential: exp(−γ∣x−y∣2)=exp(−γ∣x∣2)exp(2γxTy)exp(−γ∣y∣2) =exp(−γ∣x∣2)exp(−γ∣y∣2)∑n=0∞​n!(2γ)n​(xTy)n

Each term (xTy)n corresponds to degree-n polynomial features. Summing over all n=0,1,2,… gives countably infinite features. The kernel evaluates all of them implicitly in O(d) via the exponential.

The γ hyperparameter:

  • Large γ (small σ): narrow kernel → points must be very close to have nonzero similarity → captures fine-grained local structure → risk of overfitting / fragmented clusters.
  • Small γ (large σ): broad kernel → all points are similar to all others → approaches linear PCA → loses nonlinear structure.

The RBF kernel is the default choice for Kernel PCA when the appropriate feature map is unknown.

Choosing the Kernel

There is no universal best kernel — this is the No Free Lunch theorem applied to kernels. Guidelines:

  • Linear: baseline, interpretable, equivalent to PCA.
  • Polynomial: use when you have reason to believe the relevant structure is polynomial (e.g., interaction terms matter).
  • RBF: default for smooth, unknown manifolds. Tune γ via the explained variance of the kernel PCs or a downstream task.
  • Custom: domain-specific kernels encode prior knowledge (string kernels for text, graph kernels for molecular structures).

For Kernel PCA specifically, a useful heuristic for γ in RBF: set σ= median pairwise distance of the training data (the “median heuristic”), i.e., γ=2⋅median(∣xi​−xj​∣2)1​.

✦ Mercer’s Theorem: When Is k a Valid Kernel?

Not every function k:X×X→R corresponds to a valid inner product. We need:

Mercer’s Theorem. A continuous, symmetric function k:X×X→R is a valid kernel (i.e., ∃ Hilbert space H and map ϕ s.t. k(x,y)=⟨ϕ(x),ϕ(y)⟩H​) if and only if the kernel matrix K∈Rn×n is positive semi-definite for all finite sets of points x1​,…,xn​⊂X.

Equivalently: ∑i,j​ci​cj​k(xi​,xj​)≥0 for all n∈N, all xi​, all c∈Rn.

Why this matters for Kernel PCA: If k is not a valid Mercer kernel, the Gram matrix K may have negative eigenvalues. These are not interpretable as variances. Centering can also introduce spurious negative eigenvalues for near-valid kernels. In the implementation, we clip eigenvalues at zero — but if many eigenvalues are substantially negative, the kernel is wrong for the data.

Constructing valid kernels: Valid kernels are closed under:

  • Positive scaling: c⋅k for c>0
  • Addition: k1​+k2​
  • Multiplication: k1​⋅k2​
  • Composition: k(x,y)=k0​(f(x),f(y)) for any f
  • Exponentiation: exp(k0​)

This allows building complex kernels from simple ones: e.g., k(x,y)=exp(−γ∣x−y∣2)⋅cos(ωT(x−y)) is valid (product of valid kernels).

✦ Geometric Interpretation: Unfolding Manifolds

The RBF kernel assigns high similarity to nearby points and near-zero similarity to distant ones. In the feature space H, all points are mapped to the unit sphere (since k(x,x)=1 for RBF): ∣ϕ(x)∣H​=1 for all x.

The Kernel PCA embedding then places similar points near each other on this hypersphere. The first kernel PC direction is the direction of maximum variance on this sphere — which corresponds to the principal direction of the manifold structure.

For the Swiss roll example: the RBF kernel in R3 assigns high similarity to nearby points along the roll. PCA in this kernel space separates the “position along the roll” direction from the “position across the roll” direction — exactly the intrinsic 2D coordinates. Linear PCA cannot do this because the Swiss roll is not linear.

✦ Nyström Approximation: Scaling to Large n

The bottleneck of Kernel PCA is O(n2) to form K and O(n3) (or O(n2p) with partial eigendecomposition) to decompose it. For n=105, storing K alone requires 80 GB.

Nyström approximation (Williams & Seeger, 2001): subsample m≪n “landmark” points xl1​​,…,xlm​​ and approximate the full kernel matrix:

K≈Knm​Kmm−1​Kmn​

where Knm​∈Rn×m: kernel between all n points and the m landmarks, Kmm​∈Rm×m: kernel among landmarks.

Approximate Kernel PCA via Nyström:

  1. Choose m landmark points (randomly, or by k-means).
  2. Compute Knm​ and Kmm​.
  3. Eigendecompose Kmm​=Um​Λm​UmT​.
  4. Approximate eigenvectors of K: U^=nm​​Knm​Um​Λm−1​.
  5. Orthonormalise U^ via QR decomposition.

Cost: O(m2n) instead of O(n2p). For m=1000, n=106: manageable.

The approximation error is controlled by how well Kmm​ “spans” the full kernel matrix — related to the spectral decay of K.

When to choose Kernel PCA over t-SNE/UMAP:

  • You need out-of-sample projection (new test points must be embedded).
  • You have a domain-informed kernel encoding structural similarity.
  • You want a method with a clear objective function (eigenvalue problem) rather than stochastic optimisation.
  • You care about explained variance (kernel eigenvalues are interpretable).

When to prefer UMAP:

  • n>104 and Nyström is insufficient.
  • You want a good 2D visualisation and don’t need out-of-sample.
  • The manifold is locally uniform but globally complex.

✦ Connection to AI, ML, and Deep Learning

The Shared Foundation with SVMs

Kernel PCA and SVMs both rest on the same kernel trick and Mercer’s theorem. In both cases:

  • The algorithm operates entirely through Kij​=k(xi​,xj​).
  • The solution lives in the span of the training data (representer theorem).
  • The feature map ϕ is implicit and potentially infinite-dimensional.

The mathematical machinery is identical; the objectives differ (unsupervised variance maximisation vs. supervised margin maximisation).

The Kernel Trick and Neural Networks

Deep networks can be interpreted as learning the kernel. The Neural Tangent Kernel (NTK, Jacot et al., 2018) shows that infinitely wide neural networks trained with gradient descent are equivalent to kernel regression with a specific kernel determined by the architecture. The features learned by a neural network implicitly define a kernel — and the “kernel PCA” of those features is exactly the PCA of the network’s learned representation.

This connection provides a theoretical foundation for understanding why deep networks generalise: they are learning good kernels.

Gaussian Processes and the RKHS

Gaussian Processes (03.Gaussian Processes) also operate in the RKHS of a kernel k. The GP posterior mean is the kernel regression estimate; kernel PCA extracts the principal directions of this space. Both methods share:

  • The same n×n kernel matrix K.
  • The same O(n3) computational bottleneck.
  • The same Nyström / inducing point approximations for scaling.

The RKHS is the shared mathematical home of SVMs, Kernel PCA, and GPs.

Kernel Methods and Pre-trained Embeddings

A modern workflow: use a pre-trained neural network (ResNet, BERT) as a fixed feature extractor ϕ, then run linear PCA on the embeddings ϕ(xi​)∈Rk. This is equivalent to Kernel PCA with the kernel k(xi​,xj​)=ϕ(xi​)Tϕ(xj​) — the linear kernel in embedding space. The pre-trained network has implicitly learned the right ϕ; linear PCA then extracts the principal structure.

This is a central pattern in modern ML: use deep networks to learn the feature map, then use classical kernel/linear methods on top.

Spectral Clustering

Spectral clustering (a graph-based clustering method) is closely related to Kernel PCA. Both:

  1. Compute a n×n affinity/kernel matrix.
  2. Eigendecompose it.
  3. Use the top eigenvectors as a new representation.

The difference: spectral clustering uses the graph Laplacian L=D−K (where D is the degree matrix) rather than the centred kernel matrix, and runs K-Means on the eigenvectors rather than using them directly as coordinates. Kernel PCA with subsequent K-Means is essentially spectral clustering with a different normalisation.
