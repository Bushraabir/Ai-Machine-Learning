01.Bayesian Networks

01.Bayesian Networks

Apr 24, 202617 min read

  • P-hard

A Bayesian network is a marriage of graph theory and probability theory. The graph encodes what is independent of what; the probability tables encode how much. Together they give you a compact, interpretable representation of a joint distribution over dozens or hundreds of variables — something a full joint table could never provide.

Tags: #probabilistic-graphical-models #bayesian #inference #directed-graphical-models
Part of: Part 5 — Probabilistic Graphical Models
Prerequisites: Bayes’ theorem, conditional independence, chain rule of probability, DAGs conceptually, basic graph theory

✦ The Problem Bayesian Networks Solve

Suppose you have d binary random variables X1​,…,Xd​. A full joint distribution requires specifying 2d−1 numbers. For d=30: over a billion parameters. Storing, estimating, and querying this table is completely intractable.

Bayesian networks exploit conditional independence structure to represent the same joint distribution far more compactly. If variable Xi​ only directly depends on a small set of “parent” variables Pa(Xi​), then specifying P(Xi​∣Pa(Xi​)) for each i suffices to reconstruct the full joint — and each conditional table is tiny.

The key insight: most variables in the world do not directly cause most other variables. Causal structure is sparse. A Bayesian network makes this sparsity explicit.

✦ Formal Definition

A Bayesian network (also: Bayes net, belief network, directed graphical model) is a pair (G,P) where:

  • G=(V,E) is a directed acyclic graph (DAG) with one node per random variable
  • P=P(Xi​∣PaG​(Xi​))i=1d​ is a set of conditional probability distributions (CPDs), one per node

The joint distribution factorises as:

P(X1​,X2​,…,Xd​)=i=1∏d​P(Xi​∣PaG​(Xi​))​

This is the chain rule of Bayesian networks — it follows from the chain rule of probability plus the conditional independence structure encoded in G.

Notation: PaG​(Xi​) denotes the set of direct parents of Xi​ in G. If Xi​ has no parents, P(Xi​∣Pa(Xi​))=P(Xi​), a marginal.

Why Must G Be Acyclic?

A cycle Xi​→Xj​→Xi​ would require Xi​ to cause Xj​ and Xj​ to simultaneously cause Xi​. This makes the factorisation self-referential and undefined — there is no valid topological ordering in which to apply the chain rule. Acyclicity is not a modelling convenience; it is a logical requirement for the factorisation to define a valid distribution.

✦ A Canonical Example: The Student Network

A classic example (Koller & Friedman). Five variables:

  • D: Difficulty of exam (easy/hard)
  • I: Intelligence of student (low/high)
  • G: Grade received (A/B/C)
  • S: SAT score (high/low)
  • L: Reference letter quality (strong/weak)
    D ──┐     I ──┐
        ▼         ▼
        G         S
        │
        ▼
        L

The factorisation:

P(D,I,G,S,L)=P(D),P(I),P(G∣D,I),P(S∣I),P(L∣G)

Parameter count: D: 1, I: 1, G∣D,I: 2×2×3−1=11, S∣I: 2, L∣G: 6. Total: 21 parameters. The full joint has 2×2×3×2×2−1=47 parameters. The network is more than twice as compact — and more interpretable.

For a network with d nodes each with at most k parents over binary variables: at most d⋅2k parameters, vs. 2d for the full joint. Exponential compression.

✦ Conditional Independence and D-Separation

Local Markov Property

The factorisation implies a fundamental independence statement: every variable is conditionally independent of its non-descendants given its parents:

Xi​⊥!!!⊥NonDesc(Xi​)∣Pa(Xi​)

This is the local Markov property. It is equivalent to the factorisation above.

D-Separation

But the Bayesian network encodes more independences than just the local ones. The full set is read off the graph via d-separation (directional separation).

Definition: A path π between nodes X and Y is blocked by a set Z if there exists a node V on π such that one of:

  1. Chain: A→V→B and V∈Z — conditioning on V blocks the flow of information along the chain.
  2. Fork: A←V→B and V∈Z — conditioning on the common cause V blocks the spurious correlation it induces.
  3. Collider: A→V←B and V∈/Z and no descendant of V is in Z — the collider is not conditioned on, so it blocks by default.

X and Y are d-separated by Z (written X⊥G​Y∣Z) if every path between X and Y is blocked by Z.

The Soundness Theorem: If X⊥G​Y∣Z, then X⊥!!!⊥Y∣Z in every distribution P consistent with G.

The Faithfulness/Completeness Theorem: Conversely (under faithfulness), if X⊥G​Y∣Z, then there exists a distribution P consistent with G in which X⊥!!!⊥Y∣Z. The graph captures all and only the structural independences.

The Three Fundamental Motifs

These three patterns are the atoms of d-separation. Every complex network decomposes into combinations of them.

1. Chain (Serial Connection)

A ──► B ──► C

P(A,B,C)=P(A),P(B∣A),P(C∣B)

A⊥!!!⊥C∣B,A⊥!!!⊥C

Intuition: B is the mediator. Conditioning on B blocks the information flow from A to C. Example: Season → Sprinkler → Wet grass. Knowing the sprinkler state, the season tells you nothing about the grass.

2. Fork (Common Cause)

A ◄── B ──► C

P(A,B,C)=P(B),P(A∣B),P(C∣B)

A⊥!!!⊥C∣B,A⊥!!!⊥C

Intuition: B is a common cause that induces a spurious correlation between A and C. Conditioning on B removes the spurious dependence. Example: Season → Rain, Season → Sprinkler. Without knowing the season, rain and sprinkler are correlated. Knowing the season, they are independent.

3. Collider (Common Effect / v-Structure)

A ──► C ◄── B

P(A,B,C)=P(A),P(B),P(C∣A,B)

A⊥!!!⊥B,A⊥!!!⊥B∣C

Intuition: The collider C is blocked by default — A and B are marginally independent. But conditioning on C (or any descendant of C) opens the path — it creates a dependence. This is Berkson’s paradox / explaining away.

Explaining away: Suppose C = “car won’t start”, A = “battery dead”, B = “out of fuel”. Marginally, battery state and fuel state are independent. But given that the car won’t start, learning that the battery is fine makes “out of fuel” much more likely — the two causes compete to explain C.

Collider example — selection bias:

A = Talent       B = Luck
        \         /
         ▼       ▼
          C = Famous

P(Talent ⊥ Luck) = True     (in the general population)
P(Talent ⊥ Luck | Famous) = False  (among famous people, high luck → lower talent, and vice versa)

This is one of the most common sources of spurious correlations in observational studies. Any time you condition on a collider — including by selecting a sample based on a collider — you induce spurious dependence between its parents.

✦ Worked D-Separation Examples

Using the Student network: D→G←I→S, G→L.

Query 1: Is D⊥!!!⊥I?
Path: D→G←I. This path has a collider at G. G∈/∅ and no descendant of G is in ∅. Blocked. No other paths. ⇒D⊥!!!⊥I. ✓ (Difficulty and intelligence are marginally independent — sensible.)

Query 2: Is D⊥!!!⊥I∣G?
Path: D→G←I. Collider at G; now G∈G. Not blocked. ⇒D⊥!!!⊥I∣G. ✓ (Given a student’s grade, difficulty and intelligence become dependent — knowing the exam was hard makes low grade less informative about intelligence.)

Query 3: Is D⊥!!!⊥S∣G?
Paths from D to S: only D→G←I→S.

  • At G: collider, G∈G → open.
  • At I: chain, I∈/G → open.
    Path is not blocked. ⇒D⊥!!!⊥S∣G.

Query 4: Is D⊥!!!⊥S∣G,I?
Path: D→G←I→S.

  • At G: collider, G∈G,I → open.
  • At I: chain, I∈G,I → blocked.
    All paths blocked. ⇒D⊥!!!⊥S∣G,I. ✓ (Given both grade and intelligence, difficulty tells you nothing about SAT score.)

✦ Inference

Given a Bayesian network and some observed evidence e (values of a subset of variables), compute the posterior over query variables Q:

P(Q∣e)=P(e)P(Q,e)​=∑q,h​P(q,e,h)∑h​P(Q,e,h)​

where h are the hidden (unobserved) variables. Naïve computation sums over all configurations of h — exponential in the number of hidden variables.

Exact Inference

Variable Elimination

The key insight: the factorisation of the joint distribution means many sum-product computations can be reordered and cached.

Factor: A factor ϕ(Xi1​​,…,Xik​​) is a non-negative function over a subset of variables. The joint distribution is a product of factors.

Variable elimination sums out one variable at a time in a chosen order, multiplying and marginalising factors:

P(Q∣e)∝∑X1​​∑X2​​⋯∏i​ϕi​(scopei​)

The order of summation determines the computational cost. Finding the optimal elimination order is NP-hard in general, but good heuristics exist (min-fill, min-degree).

Example (using Student network, query P(L∣D=d0)):

P(L∣d0)∝∑G​P(L∣G)∑I​P(G∣d0,I),P(I)∑S​P(S∣I)

The inner sum ∑S​P(S∣I)=1 (marginalising a complete CPD). This cancels S with zero cost. The remaining sums are over I and G — small tables.

Complexity: Exponential in the treewidth of the graph — a measure of how “tree-like” the graph is. For trees and polytrees, exact inference is polynomial. For general graphs, it is P-hard.

Belief Propagation (Sum-Product Algorithm)

For trees (no undirected cycles), exact inference runs in O(n⋅k2) time via message passing.

Each node sends messages to its neighbours. The message μX→Y​(y) represents a summary of what X knows about Y, based on X‘s other neighbours:

μX→Y​(y)=∑x​ϕ(x,y)∏Z∈Ne(X)∖Y​μZ→X​(x)

The marginal at each node is proportional to the product of all incoming messages:

P(X∣e)∝∏Y∈Ne(X)​μY→X​(x)

For directed trees, this decomposes into two passes: a forward (upward, leaves-to-root) pass and a backward (downward, root-to-leaves) pass.

Loopy belief propagation (LBP): Run the same message-passing algorithm on a graph with cycles. The algorithm is no longer exact — messages depend on each other cyclically — but it often converges and gives good approximations. LBP underlies modern LDPC error-correcting codes and is used in computer vision (stereo matching, image segmentation).

Approximate Inference

For graphs with high treewidth, exact inference is intractable. The two main approaches:

Markov Chain Monte Carlo (MCMC)

Construct a Markov chain whose stationary distribution is P(X∣e). Sample from it.

Gibbs sampling (most common for Bayesian networks): repeatedly sample each variable from its Markov blanket — its parents, children, and children’s other parents:

Xi(t+1)​∼P(Xi​∣Pa(Xi​),Ch(Xi​),Pa(Ch(Xi​)))

The Markov blanket is exactly the minimal set you need to condition on to make Xi​ independent of all other variables — a direct consequence of d-separation.

Convergence: guaranteed to the correct distribution asymptotically. Mixing time (how many samples you need) depends on the strength of correlations.

Variational Inference

Approximate P(X∣e) with a simpler distribution Q(X;λ) by minimising DKL​(Q∣P). The mean-field approximation assumes Q factorises fully: Q(X)=∏i​Qi​(Xi​). Leads to a coordinate ascent algorithm — the ELBO you saw in VAEs is exactly this.

✦ Learning Bayesian Networks

Two sub-problems:

Parameter Learning (Known Structure)

Given a fixed graph G and i.i.d. data D=x(1),…,x(n), estimate the CPDs.

With complete data (no missing values): MLE decomposes over CPDs. For a discrete variable Xi​ with parents Pa(Xi​):

\hat{P}(X_i = k \mid \text{Pa}(X_i) = \pi) = \frac{#{X_i = k, \text{Pa}(X_i) = \pi}}{#{\text{Pa}(X_i) = \pi}}

Just count — each CPD is independent and estimated by its frequency table. MLE is the empirical conditional distribution.

With missing data: The log-likelihood no longer decomposes. Must use EM (Expectation-Maximisation):

  • E-step: Compute expected sufficient statistics using current parameters and BP for inference.
  • M-step: Update each CPD using the expected counts from the E-step.

Bayesian parameter estimation: Place a Dirichlet prior over each CPD (conjugate to the Categorical). Posterior is Dirichlet with counts augmented by pseudo-counts. MAP estimate = total count+K(α−1)count+α−1​. This is Laplace smoothing for discrete CPDs.

Structure Learning (Unknown Structure)

Find the graph G that best explains the data. Two approaches:

Score-based: Search over DAG space, score each candidate graph. Common scores:

  • BIC: score(G,D)=logP(D∣θ^,G)−2logn​∣θG​∣ — penalises complexity.
  • BDe score: Bayesian Dirichlet equivalent — integrates out parameters, proper Bayesian score.

DAG space is super-exponential in d — exact search is impossible. Heuristics: greedy hill-climbing (add/remove/reverse one edge at a time), simulated annealing, genetic algorithms.

Constraint-based: Use conditional independence tests (χ2 tests, mutual information tests) to determine which edges cannot be present. The PC algorithm (Peter-Clark) works by:

  1. Start with a complete undirected graph.
  2. Remove edge (X,Y) if ∃,Z such that X⊥!!!⊥Y∣Z in the data.
  3. Orient remaining edges using v-structure identification.

The PC algorithm recovers the correct skeleton and all v-structures consistently in the large-sample limit, under faithfulness. Output is a CPDAG (completed partially directed acyclic graph) — the equivalence class of all DAGs with the same skeleton and v-structures.

✦ Markov Equivalence

Two DAGs are Markov equivalent if they encode the same set of conditional independences (same d-separation statements). Markov equivalent DAGs have the same skeleton (same undirected edges) and the same v-structures (colliders).

Implication: From observational data alone, you cannot distinguish between Markov equivalent DAGs. To identify causal direction within an equivalence class, you need either:

  • Interventional data (do-calculus, randomised experiments)
  • Additional assumptions (e.g., non-Gaussianity, as in LiNGAM)
  • Temporal order constraints

This is why correlation does not imply causation — many causal structures are observationally equivalent.

✦ Connection to AI / ML / Deep Learning

1. Naive Bayes as a Bayesian Network

The Naive Bayes classifier (see 06.Naive Bayes) is a Bayesian network with a specific structure: one class node Y pointing to all feature nodes X1​,…,Xd​ with no edges among the Xi​. The conditional independence assumption Xi​⊥!!!⊥Xj​∣Y is exactly the d-separation statement in this graph. Every Naive Bayes model is a Bayesian network; not every Bayesian network is Naive Bayes.

Naive Bayes BN:

        Y
      / | \
     ▼  ▼  ▼
    X₁ X₂ X₃   (no edges between Xᵢ)

2. Hidden Markov Models

An HMM (see 02.Markov Models) is a Bayesian network on a chain:

Z₁ ──► Z₂ ──► Z₃ ──► Z₄    (hidden states)
│      │      │      │
▼      ▼      ▼      ▼
X₁     X₂     X₃     X₄    (observations)

The Viterbi algorithm is variable elimination on this chain. The forward-backward algorithm is belief propagation on this tree. Everything in sequential modelling — speech recognition, POS tagging, protein folding — is a Bayesian network with temporal structure.

3. Variational Autoencoders

The VAE’s generative model z→x is a two-node Bayesian network:

P(z),Pθ​(x∣z)=P(x,z)

The inference network qϕ​(z∣x) approximates the posterior P(z∣x) — this is variational inference on a Bayesian network. The ELBO is exactly the variational lower bound used in general Bayesian network inference. The VAE is deep learning’s answer to intractable Bayesian network inference.

4. Causal Inference and Do-Calculus

Judea Pearl’s do-calculus (Pearl, 2000) extends Bayesian networks to reason about interventions. The do-operator do(X=x) removes all incoming edges to X in G, fixing its value. The interventional distribution P(Y∣do(X=x)) is generally different from the observational conditional P(Y∣X=x) — this is the formal statement of why correlation = causation.

Modern causal ML (IRM, causal representation learning) builds on this foundation to train models that generalise across environments — a central problem in robust ML.

5. Probabilistic Programming

PyMC, Stan, Pyro, and NumPyro all represent probabilistic models as Bayesian networks (or their continuous generalisations). Inference is automated — the user specifies structure and CPDs; the system runs MCMC or variational inference. The structure-inference separation in Bayesian networks is what makes this abstraction possible.

6. Graph Neural Networks

A Bayesian network is a graph with a probability model. GNNs learn representations over graphs — they can be applied to Bayesian networks directly, learning to do amortised inference (predict posteriors for unseen evidence configurations without re-running BP). This is an active research area.
