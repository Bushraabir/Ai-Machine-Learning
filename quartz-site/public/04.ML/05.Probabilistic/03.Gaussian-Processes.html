03.Gaussian Processes

03.Gaussian Processes

Apr 24, 202619 min read

“A Gaussian process is a probability distribution over functions, such that any finite collection of function values has a joint Gaussian distribution.” — Rasmussen & Williams, 2006

✦ Why This Note Exists

Every model we’ve built so far has been parametric: fix a functional form, learn a finite-dimensional parameter vector θ. A Gaussian process takes a different path entirely — it places a prior directly over the space of functions, then conditions on data to obtain a posterior over functions.

This sounds abstract. It is not. The payoff is a model that:

  • makes predictions with calibrated uncertainty — the posterior variance tells you where it doesn’t know
  • incorporates prior knowledge about function structure through kernel design
  • updates exactly via Bayes’ theorem, no MCMC needed (for regression)
  • subsumes kernel ridge regression, spline smoothing, and RBF-kernel SVMs as special cases

GPs sit at the intersection of Bayesian inference, kernel methods, and functional analysis. Understanding them sharpens your intuition for everything that comes after — neural network weight-space vs. function-space perspectives, neural tangent kernels, and Bayesian deep learning.

Prerequisites: 03.Probability Review · 04.Support Vector Machines (kernel trick) · Linear Algebra (eigendecomposition, positive semi-definiteness)
Feeds into: 01.Kernel Methods · 05.Hyperparameter Tuning (Bayesian optimisation) · Neural Tangent Kernel (advanced)

✦ Part 1 — From Parametric to Non-Parametric

1.1 The Parametric Bottleneck

In Bayesian linear regression, we place a prior on the weight vector w∈Rd: w∼N(0,α−1I),y=wTϕ(x)+ε,ε∼N(0,σ2)

This is expressive — but the function class is fixed by the choice of basis ϕ(x). If you pick d=10 basis functions, you’ve committed to a 10-dimensional function space. You can extend ϕ (polynomial, RBF, Fourier features…) but you’re always choosing in advance.

The weight-space view: place a prior on w, integrate out w to get a distribution over function values.

The function-space view: place the prior directly on f:X→R.

The key insight is that these are equivalent when the prior on w is Gaussian — and the function-space view generalises beyond finite-dimensional w.

1.2 What Does a Prior Over Functions Mean?

A prior over functions seems infinite-dimensional and unwieldy. The Gaussian process sidesteps this through a consistency condition:

Definition (Gaussian Process): A Gaussian process is a collection of random variables f(x):x∈X such that for any finite set of inputs x1​,…,xn​⊂X, the joint distribution: (f(x1​) ⋮ f(xn​)​)∼N(m,K) where mi​=m(xi​) and Kij​=k(xi​,xj​).

We write: f∼GP(m(x),,k(x,x′))

The GP is completely specified by:

  • Mean function m(x)=E[f(x)] — often set to zero a priori
  • Covariance function (kernel) k(x,x′)=Cov(f(x),f(x′))

The key move: you never have to work with an infinite-dimensional object. Any computation with a GP reduces to a finite-dimensional multivariate Gaussian computation on the inputs you actually care about. The Kolmogorov extension theorem guarantees that a consistent family of finite-dimensional Gaussians uniquely defines a valid stochastic process.

✦ Part 2 — The Kernel: Encoding Prior Beliefs

2.1 The Kernel as a Similarity Measure

The kernel k(x,x′) encodes our prior belief about how correlated f(x) and f(x′) are. If k(x,x′) is large, we believe f(x) and f(x′) should take similar values.

This is precisely the kernel trick from SVMs — but now it has a direct probabilistic interpretation: k is the prior covariance between function values.

Validity condition (Mercer’s theorem): k is a valid kernel iff the Gram matrix K with Kij​=k(xi​,xj​) is positive semi-definite for all finite input sets. Equivalently, k(x,x′)=⟨ϕ(x),ϕ(x′)⟩H​ for some (possibly infinite-dimensional) feature map ϕ into a Hilbert space H.

2.2 Standard Kernels

Each kernel encodes a different structural assumption about f:

Squared Exponential (RBF / Gaussian) Kernel

kSE​(x,x′)=σf2​exp!(−2ℓ2∣x−x′∣2​)

  • Hyperparameters: σf2​ (output scale), ℓ (length-scale)
  • Encodes: infinitely differentiable, very smooth functions
  • Length-scale ℓ: controls how quickly the function varies. Small ℓ → wiggly functions; large ℓ → smooth, slowly varying functions
  • Feature map: corresponds to an infinite-dimensional feature space (Fourier features expansion)
  • Caution: too smooth for many real phenomena — geological, financial, biological data often has rougher structure

Matérn Kernel

kν​(x,x′)=Γ(ν)21−ν​(ℓ2ν​∣x−x′∣​)νKν​!(ℓ2ν​∣x−x′∣​) where Kν​ is a modified Bessel function.

  • Parameter ν: controls differentiability. ν=1/2 → once-differentiable (Ornstein-Uhlenbeck); ν=3/2 → twice; ν=5/2 → three times; ν→∞ → SE kernel
  • Why it matters: ν=5/2 is the default recommendation in practice — smoother than OU, less pathologically smooth than SE
  • Special cases:
    • ν=1/2: k(r)=σ2e−r/ℓ — exponential kernel, continuous but not differentiable
    • ν=3/2: k(r)=σ2(1+ℓ3​r​)exp(−ℓ3​r​)

Periodic Kernel

kper​(x,x′)=σf2​exp!(−ℓ22sin2(π∣x−x′∣/p)​) Encodes exactly periodic functions with period p. Combine with SE kernel (multiply) to get functions that are approximately periodic with decaying coherence — standard for seasonal time series.

Linear Kernel

klin​(x,x′)=σb2​+σv2​(x−c)(x′−c) GP with this kernel is equivalent to Bayesian linear regression through the point c. Useful as a component in additive kernel decompositions.

Rational Quadratic Kernel

kRQ​(x,x′)=σf2​(1+2αℓ2∣x−x′∣2​)−α A scale mixture of SE kernels with different length-scales. As α→∞, recovers SE. Useful when the signal varies at multiple scales.

2.3 Kernel Engineering

Kernels compose:

  • Sum: k=k1​+k2​ → function is a sum of two independent GPs (additive structure)
  • Product: k=k1​⋅k2​ → modulation; e.g., periodic × SE = locally periodic
  • Composition: kSE​(g(x),g(x′)) for learned feature maps g → deep kernels, connection to deep learning

Notebook margin — the kernel as a scientist’s voice: When you choose a kernel, you are making a scientific claim about the structure of f. SE says “I believe f is very smooth.” Matérn-5/2 says “I believe f is three-times differentiable but not more.” Periodic says “I believe there is a repeating structure with period p.” The posterior will update these beliefs given data — but the kernel determines what it’s even possible to learn.

✦ Part 3 — GP Regression (Exact Inference)

3.1 The Setup

Observed data: D=(xi​,yi​)i=1n​ where yi​=f(xi​)+εi​, εi​∼i.i.d.N(0,σn2​)

Prior: f∼GP(0,k(x,x′)) (zero mean WLOG)

Goal: compute the posterior p(f∣D) and the predictive distribution p(f_* \mid x__, \mathcal{D}) at new test points x__.

3.2 The Joint Prior

Let f=(f(x1​),…,f(xn​))T and f_* = f(x__). By the GP definition: \begin{pmatrix} \mathbf{y} \ f__ \end{pmatrix} \sim \mathcal{N}!\left(\mathbf{0},, \begin{pmatrix} K(X, X) + \sigma_n^2 I & K(X, x__) \ K(x__, X) & k(x__, x__) \end{pmatrix}\right)

where:

  • K(X,X)∈Rn×n: Gram matrix, Kij​=k(xi​,xj​)
  • K(X, x__) \in \mathbb{R}^{n \times 1}: covariance between training inputs and test point, [K(X, x__)]_i = k(x_i, x_*)
  • k(x__, x__): prior variance at test point

3.3 The Posterior Predictive Distribution

Using the Gaussian conditioning formula (the fundamental operation of all Gaussian inference):

Lemma (Conditional Gaussian): If (a b​)∼N!((μa​ μb​​),(Σaa​​Σab​ Σba​​Σbb​​)) then: a∣b∼N!(μa​+Σab​Σbb−1​(b−μb​), Σaa​−Σab​Σbb−1​Σba​)

Applying this with a=f∗​, b=y:

\boxed{f_* \mid x__, X, \mathbf{y} \sim \mathcal{N}(\mu__, \sigma_*^2)}

μ∗​=K(x∗​,X),[K(X,X)+σn2​I]−1,y

\sigma__^2 = k(x__, x__) - K(x__, X),[K(X,X) + \sigma_n^2 I]^{-1},K(X, x_*)

This is the complete solution. No approximation. Exact Bayesian inference in closed form.

3.4 Interpretation — What These Equations Say

The mean μ∗​: μ∗​=K(x∗​,X)α[K(X,X)+σn2​I]−1y​​

This is a linear combination of training outputs, weighted by the covariance between x__ and each training input. Nearby training points (large k(x__, x_i)) contribute more. This is kernel regression — the GP mean is identical to kernel ridge regression with λ=σn2​/σf2​.

The variance σ∗2​: \sigma__^2 = \underbrace{k(x__, x__)}_{\text{prior variance}} - \underbrace{K(x__, X)[K + \sigma_n^2 I]^{-1}K(X, x_*)}_{\text{variance reduction from data}}

The posterior variance is the prior variance minus what we learned from the data. The second term is always non-negative (positive semi-definiteness of K), so data never increases uncertainty. Crucially:

  • At a training input xi​: σ∗2​→0 as σn2​→0 (exact fit)
  • Far from all training data: \sigma__^2 \approx k(x__, x_*) (reverts to prior)

Worked example — 1D regression:
Prior: f∼GP(0,kSE​) with ℓ=1, σf2​=1, σn2​=0.1
Training data: 5 points sampled from sin(x)+N(0,0.1)

The posterior mean threads through the data. The posterior variance (shaded region) is:

  • narrow near training points (we’ve observed f there)
  • wide in regions with no data (we genuinely don’t know)
  • wider than the noise level even at training points (because we know y=f+ε, not f directly)

This is calibrated uncertainty — the 95% confidence band actually contains 95% of future observations.

3.5 Predicting at Multiple Test Points

For a vector of test points X∗​=(x1​​,…,xm​​): \mathbf{f}__ \mid X__, X, \mathbf{y} \sim \mathcal{N}(\boldsymbol{\mu}_*, \Sigma__) \boldsymbol{\mu}__ = K(X__, X)[K(X,X) + \sigma_n^2 I]^{-1}\mathbf{y} \Sigma__ = K(X__, X__) - K(X__, X)[K(X,X) + \sigma_n^2 I]^{-1}K(X, X__)

The full posterior covariance Σ∗​ captures correlation between predictions at different test points — this is something no other standard regression model directly provides.

✦ Part 4 — Computational Complexity and the O(n3) Wall

4.1 The Bottleneck

The posterior requires computing [K(X,X)+σn2​I]−1. For n training points:

  • Matrix inversion: O(n3) via Cholesky decomposition
  • Storage: O(n2) for the kernel matrix
  • Prediction: O(n) per test point (after precomputing α), O(n2) for variance

For n=103: trivial. For n=104: feasible. For n=105: painful. For n=106: intractable.

In practice: use the Cholesky decomposition LLT=K+σn2​I (numerically stable, also gives O(n3) but with a smaller constant than naive inversion).

4.2 Approximate GP Methods

MethodIdeaComplexity
Sparse GPs (Inducing Points)Summarise n points with m≪n inducing points ZO(nm2)
FITC / VFEVariational lower bound on the marginal likelihoodO(nm2)
Random Fourier FeaturesApproximate k(x,x′)≈ϕ(x)Tϕ(x′), finite D featuresO(nD)
State-space GPsConvert GP to a linear dynamical system; Kalman filterO(n) for 1D inputs
Structured kernel interpolation (SKI)Interpolate onto a grid; FFT-based matrix-vector productsO(nlogn)

The inducing point / variational approach (Titsias 2009, Hensman et al. 2013) is the modern standard. The m inducing points Z are learnable — optimise them jointly with the hyperparameters.

Notebook margin — why Cholesky and not direct inversion? Numerically, K is often nearly singular (especially with the SE kernel and nearby points). Cholesky decomposition is numerically stable, reveals singularity, gives the log-determinant cheaply (sum of log diagonal), and allows efficient solves. Always use Cholesky for GP computations. Never call np.linalg.inv on a kernel matrix.

✦ Part 5 — Learning Hyperparameters: Marginal Likelihood

5.1 The Problem

The GP prior k(x,x′;θ) has hyperparameters θ — e.g., θ=(ℓ,σf2​,σn2​) for the SE kernel. How do we choose them?

Not cross-validation: too expensive (each CV fold requires an O(n3) solve).

Bayesian answer: marginalise over the latent function f (already done in the posterior), then maximise the marginal likelihood p(y∣X,θ) over θ.

5.2 The Log Marginal Likelihood

logp(y∣X,θ)=−21​yT(Kθ​+σn2​I)−1y−21​log∣Kθ​+σn2​I∣−2n​log2π

Three terms:

  1. −21​yT(Kθ​+σn2​I)−1y — data fit: how well the model fits the observations
  2. −21​log∣Kθ​+σn2​I∣ — complexity penalty (Occam factor): penalises models that can explain too many datasets
  3. −2n​log2π — normalisation constant

The marginal likelihood automatically balances fit and complexity — models that overfit have high fit but are penalised by the log-determinant term. This is automatic Occam’s razor.

5.3 Optimisation

Differentiate with respect to θ and use gradient-based optimisation (L-BFGS or Adam): ∂θj​∂​logp(y∣X,θ)=21​tr![(K−1yyTK−1−K−1)∂θj​∂K​]

where K=Kθ​+σn2​I.

Gradient cost: O(n3) per evaluation — same as the posterior. Run from multiple random initialisations (marginal likelihood is non-convex in θ).

What the marginal likelihood does to hyperparameters:
If ℓ is too small: the model is wiggly, many functions fit the data, large ∣K∣, large complexity penalty.
If ℓ is too large: the model is too smooth, fits the data poorly, large data-fit term.
The marginal likelihood finds the length-scale where these forces balance — the one that best explains the data without overfitting. This is Bayesian model selection in action.

✦ Part 6 — GP Classification

For binary classification, y∈0,1 and we want: p(y_* = 1 \mid x__, \mathcal{D}) = \int \sigma(f__), p(f_* \mid x__, \mathcal{D}), df__

The GP prior is the same — but now the likelihood is Bernoulli, not Gaussian. The posterior p(f∣X,y) is no longer Gaussian. Exact inference is intractable.

Approximate inference methods:

MethodIdeaQuality
Laplace approximationFit a Gaussian at the posterior modeFast, good for unimodal posteriors
Expectation Propagation (EP)Approximate each factor in the likelihood with a GaussianMore accurate than Laplace
Variational inference (SVGP)Variational lower bound, scalable with inducing pointsModern standard for large-scale GP classification

Multi-class: one GP per class (one-vs-rest) with softmax likelihood, or multi-output GP.

✦ Part 7 — Connection to Other Models

7.1 GP = Kernel Ridge Regression (in the noise-free limit)

The GP posterior mean: μ∗​=K(x∗​,X)[K(X,X)+σn2​I]−1y is exactly the kernel ridge regression predictor with regularisation parameter λ=σn2​/σf2​. GPs give kernel ridge regression a Bayesian interpretation — and add uncertainty quantification for free.

7.2 GP = Infinite-Width Neural Networks

Neal (1994) showed: a single-hidden-layer neural network with i.i.d. priors on weights converges in distribution to a GP as the number of hidden units →∞. The kernel is determined by the activation function.

More recently (Lee et al. 2018, Jacot et al. 2018): deep networks trained with gradient descent correspond (in the infinite-width limit) to kernel regression with the Neural Tangent Kernel (NTK). This is a GP in function space. The NTK connection is an active research area linking GPs to deep learning theory.

7.3 GP Prior on the Parameters of a Deep Network

In deep kernel learning, replace the hand-crafted feature map with a neural network: k(x,x′)=kbase​(gθ​(x),gθ​(x′)) where gθ​ is a neural network. Jointly optimise θ and GP hyperparameters via marginal likelihood. This combines the representational power of deep networks with GP uncertainty quantification — a practically important model class.

7.4 GP and SVMs

The SVM with RBF kernel and GP regression with SE kernel share the same kernel function. The difference:

  • SVM: finds a maximum-margin classifier; no probabilistic output; sparse (support vectors)
  • GP: full posterior distribution over f; uncertainty quantification; not sparse

For classification: GP gives calibrated class probabilities; SVM gives a hard boundary. The GP is preferred when uncertainty matters (medical diagnosis, active learning, safety-critical systems).

7.5 GP in Bayesian Optimisation

This is the primary industrial application of GPs today — used inside every major AutoML system and neural architecture search tool.

Setup: You want to minimise f(x) where f is expensive to evaluate (e.g., training a neural network with hyperparameters x). You have a budget of T evaluations.

Algorithm:

  1. Place a GP prior on f
  2. Observe f(x1​),…,f(xt​) — update GP posterior
  3. Choose next query xt+1​ by maximising an acquisition function α(x)
  4. Repeat

Acquisition functions:

FunctionFormulaBehaviour
Expected Improvement (EI)E[max(f∗−f(x),0)]Balances exploration/exploitation; most popular
Upper Confidence Bound (UCB)μ(x)+κσ(x)Explicit exploration parameter κ
Probability of ImprovementP(f(x)<f∗−ξ)Pure exploitation focus
Thompson SamplingSample f~​∼p(f∣D), maximise f~​Simple, strong theoretical guarantees

Why GPs specifically? The acquisition function requires both a prediction μ(x) and an uncertainty σ(x) at every point in the input space — not just at training points. GPs provide exactly this, in closed form, for any x.

Connection to hyperparameter tuning (Section 2.5 of the index): every time you use Optuna, Ray Tune, or a Gaussian Process optimiser to tune neural network hyperparameters, there is a GP computing posterior means and variances under the hood.

✦ Part 8 — Sampling from a GP

How do you actually draw a sample function f∼GP(0,k)?

  1. Choose a grid of points X=(x1​,…,xn​)
  2. Compute the Gram matrix Kij​=k(xi​,xj​)
  3. Add a small jitter for numerical stability: K←K+10−6I
  4. Compute Cholesky: L=chol(K)
  5. Sample z∼N(0,In​)
  6. Return f=Lz

This gives a draw from N(0,K) — a finite-dimensional realisation of the GP prior.

Try this with different kernels (SE with varying ℓ, Matérn, periodic) — you will immediately develop intuition for what each kernel encodes.

✦ Part 10 — Deep Learning Connections (Extended)

10.1 The Weight-Space / Function-Space Duality

PerspectivePrior lives onInferencePredictions
Bayesian NN (weight-space)p(w)Posterior p(w∣D) — intractable∫p(y∣x,w)p(w∣D)dw — approximate
GP (function-space)p(f) — GP priorPosterior p(f∣D) — exact GaussianExact predictive distribution

For finite-width networks, the weight-space prior induces a non-Gaussian process over functions. In the infinite-width limit, the central limit theorem makes it Gaussian — a GP. The kernel is determined by the network architecture and activation function.

10.2 Why This Matters for Modern DL

  • Uncertainty quantification: GPs give exact posteriors. BNNs don’t. The deep learning community’s various approaches to UQ (MC Dropout, deep ensembles, SWAG) can often be understood as approximate GP inference.
  • Generalisation theory: NTK analysis (a GP analysis) is currently one of the main tools for understanding why overparameterised networks generalise — a central open question in deep learning theory.
  • Structured prediction: GP multi-output models, GP latent variable models, and deep GPs are active research directions that directly compete with (and complement) deep learning approaches.

10.3 Where GPs Are Preferred Over Neural Networks

ScenarioReason
Small data (n<103)GPs are non-parametric; NNs overfit
Calibrated uncertainty neededExact GP posteriors vs. approximate NN uncertainty
Scientific inferenceKernel design encodes domain knowledge interpretably
Optimisation (Bayesian opt.)Closed-form acquisition; cheap to evaluate
Interpretability requiredKernel hyperparameters have direct physical meaning

✦ Visualising the Posterior

Prior (no data):
f(x)
 │     ~~~~
 │   ~~    ~~
 │  ~        ~   (3 sample functions, all plausible)
 │~            ~~
 └──────────────── x
   wide shaded region = prior uncertainty

Posterior (5 training points observed, marked ×):
f(x)
 │          ×
 │    ×   ~~~~×~~~
 │  ~~× ~~       ~
 │~~                ~
 └──────────────────── x
   narrow band at × (data reduces uncertainty)
   wide band far from data (prior uncertainty returns)
   mean function threads through observations

This picture — posterior mean threading through data, variance collapsing at observations and widening in unobserved regions — is the visual essence of a Gaussian Process. Any model that behaves this way is doing Bayesian inference correctly.
