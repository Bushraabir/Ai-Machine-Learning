01.Linear Regression

Apr 26, 202612 min read

“All models are wrong, but some are useful.” — George Box

The Setup

We have n training examples (x(i),y(i))i=1n​ where x(i)∈Rd and y(i)∈R. We want to learn a function f:Rd→R.

Linear regression says: assume f is affine.

y^​=wTx+b=w1​x1​+w2​x2​+⋯+wd​xd​+b

Absorbing the bias. Append a constant feature x0​=1 to every input vector. Then:

y^​=wTx,w∈Rd+1,x=[1 x1​ ⋮ xd​​]

In matrix form, stack training examples as rows:

X=[1​x1(1)​​⋯​xd(1)​ ⋮​​​⋮ 1​x1(n)​​⋯​xd(n)​​]∈Rn×(d+1),y=[y(1) ⋮ y(n)​]

Predictions: y^​=Xw.

The Loss Function

We minimise the Mean Squared Error (MSE):

L(w)=n1​∣Xw−y∣2=n1​(Xw−y)T(Xw−y)

Why squared error? Three answers, increasing in depth:

  1. Convenient: differentiable everywhere, unique minimum (if X has full column rank).
  2. Geometric: minimising MSE = finding the projection of y onto col(X).
  3. Probabilistic: MSE = MLE under a Gaussian noise model (derived below).

Solution 1 — The Normal Equation (Closed Form)

Derivation

Expand the loss:

L(w)=n1​(wTXTXw−2wTXTy+yTy)

Take the gradient with respect to w and set to zero. Using the matrix calculus identities ∇w​(wTAw)=2Aw (for symmetric A) and ∇w​(bTw)=b:

∇w​L=n2​(XTXw−XTy)=0

w^=(XTX)−1XTy​

This is the Normal Equation.

Geometric Interpretation

The residual r=y−Xw^ must be orthogonal to every column of X:

XTr=XT(y−Xw^)=0⟹XTy=XTXw^

These are exactly the normal equations. The fitted values y^​=Xw^ are the orthogonal projection of y onto col(X).

         y
         |  \
         |    \  residual r = y - ŷ
         |      \
col(X) ──────────ŷ = Xw_hat

The projection matrix (hat matrix) is:

H=X(XTX)−1XT,y^​=Hy

Properties: H2=H (idempotent), HT=H (symmetric), eigenvalues are 0 or 1.

When Does (XTX) Fail to Be Invertible?

(XTX) is singular when the columns of X are linearly dependent — i.e., multicollinearity.

Causes:

  • Exact duplicates of a feature.
  • One feature is a linear combination of others (e.g., temperature in Celsius and Fahrenheit both included).
  • d>n: more features than samples — infinitely many solutions exist.

Fix: use Ridge regression (adds λI to make (XTX+λI) always invertible) or feature selection.

Computational Cost

Forming XTX: O(nd2). Inverting it: O(d3). For large d (e.g., d>104), prefer gradient descent.

Solution 2 — Gradient Descent

For large n or d, the Normal Equation is impractical. We iteratively move in the direction of steepest descent.

Gradient

∇w​L=n2​XT(Xw−y)

Intuition: Xw−y is the vector of residuals. We’re summing up the influence of each training example, weighted by how wrong we are.

Update Rule

w←w−α∇w​L=w−n2α​XT(Xw−y)

where α>0 is the learning rate (step size).

Variants

VariantGradient computed onUpdate frequencyNotes
Batch GDFull datasetOnce per epochStable, exact gradient, slow for large n
Stochastic GD (SGD)Single example iEvery exampleNoisy, can escape local minima, fast
Mini-batch GDBatch of size BEvery B examplesBest of both; standard in practice

The mini-batch gradient estimator is unbiased: E[∇w​L^B​]=∇w​L.

Convergence

For batch GD, convergence is guaranteed if α<L1​ where L is the Lipschitz constant of the gradient (largest eigenvalue of n2​XTX).

Learning rate schedules:

  • Constant: αt​=α. May oscillate near minimum.
  • Step decay: αt​=α0​⋅γ⌊t/k⌋.
  • Cosine annealing: αt​=αmin​+21​(αmax​−αmin​)(1+cos(πt/T)).
  • 1-cycle: warm up, then decay — widely used in deep learning.

Probabilistic View — MLE Recovers OLS

The Noise Model

Assume each observation is generated as:

y(i)=wTx(i)+ϵ(i),ϵ(i)∼N(0,σ2) i.i.d.

Then y(i)∣x(i);w∼N(wTx(i),σ2).

Likelihood

L(w)=∏i=1n​p(y(i)∣x(i);w)=∏i=1n​2πσ2​1​exp!(−2σ2(y(i)−wTx(i))2​)

Log-Likelihood

logL(w)=−2n​log(2πσ2)−2σ21​∑i=1n​(y(i)−wTx(i))2

Maximising this is equivalent to minimising ∣y−Xw∣2.

So: OLS = MLE under the Gaussian noise assumption. This is not a coincidence — it tells us exactly when OLS is appropriate (when noise is symmetric and light-tailed).

Regularisation

Regularisation adds a penalty on w to the loss, discouraging complex models. This is the standard solution to overfitting.

Ridge Regression (L2)

LRidge​(w)=n1​∣Xw−y∣2+λ∣w∣2

Closed form: w^=(XTX+λI)−1XTy

Note: (XTX+λI) is always invertible for λ>0. This is another reason to use Ridge.

Effect: shrinks all coefficients toward zero, but never exactly to zero.

Probabilistic view: Ridge = MAP estimation with a Gaussian prior w∼N(0,λσ2​I).

MAP objective−logP(w∣D)​​∝NLL∣Xw−y∣2​​+log-priorλ∣w∣2​​

Lasso Regression (L1)

LLasso​(w)=n1​∣Xw−y∣2+λ∣w∣1​

No closed form (L1 is not differentiable at 0). Solved with coordinate descent or subgradient methods.

Effect: produces sparse solutions — many coefficients are exactly zero. Performs implicit feature selection.

Why sparsity? Geometrically, the L1 ball (a diamond in 2D) has corners on the axes. The loss contours will likely touch the constraint at a corner where some wj​=0.

L2 ball (circle)          L1 ball (diamond)
      ___                      /\
    /     \                   /  \
   |       |                 /    \
   |       |    ←→          /      \
   |       |               \      /
    \     /                 \    /
      ---                    \  /
                              \/

Loss ellipse touches          Loss ellipse likely
at interior point             touches at a corner
(no sparsity)                 (sparsity: w_j = 0)

Probabilistic view: Lasso = MAP with Laplace prior wj​∼Laplace(0,1/λ).

Elastic Net

LEN​(w)=n1​∣Xw−y∣2+λ1​∣w∣1​+λ2​∣w∣2

Combines L1 (sparsity) and L2 (handles correlated features gracefully). Preferred over pure Lasso when features are correlated.

Polynomial Regression as Feature Engineering

This deserves its own callout: polynomial regression is still linear regression.

Given x∈R, define new features:

ϕ(x)=[1 x x2 x3​]

Then fit y=wTϕ(x). The model is linear in w, not linear in x. Everything above — Normal Equation, gradient descent, regularisation — applies without modification.

More generally: feature engineering = mapping x→ϕ(x), then doing linear regression in ϕ-space. This is also the foundation of the kernel trick (see 04.Support Vector Machines).

Assumptions of Linear Regression

Linear regression is optimal when these hold:

  1. Linearity: E[y∣x]=wTx. The true relationship is linear (or close to it).
  2. Independence: Examples (x(i),y(i)) are i.i.d.
  3. Homoscedasticity: Var(ϵ(i))=σ2 constant — variance doesn’t change with x.
  4. No multicollinearity: Columns of X are linearly independent.
  5. Normality of residuals: For inference (confidence intervals, hypothesis tests), not for prediction.

Professor’s note: In practice, linear regression is surprisingly robust to violations of 3 and 5. What kills it is violation of 1 (genuine nonlinearity) and severe violation of 4 (near-singular XTX). Always plot your residuals — they tell you more than any single metric.

Diagnosing and Evaluating

Metrics

  • MSE: n1​∣y−y^​∣2 — in squared units, penalises large errors heavily.
  • RMSE: MSE​ — in original units, interpretable.
  • MAE: n1​∣y−y^​∣1​ — robust to outliers; doesn’t penalise large errors as heavily.
  • R2: 1−SStot​SSres​​=1−∣y−yˉ​∣2∣y−y^​∣2​. Fraction of variance explained. R2=1 → perfect fit; R2=0 → model no better than predicting the mean.

R2 can be negative on test data (your model is worse than the mean — a bad sign).

Connection to AI, Machine Learning, and Deep Learning

Linear Regression as the Simplest Neural Network

A linear regression model with a single output is a neural network with no hidden layers and a linear activation:

Input layer          Output
  x_1 ──── w_1 ───┐
  x_2 ──── w_2 ───┤──→ ŷ = w^Tx + b
   ⋮              ⋮
  x_d ──── w_d ───┘

Every concept here reappears in deep learning:

  • Gradient descent is the core training algorithm for all neural networks.
  • Regularisation (L1, L2, dropout, weight decay) fights overfitting in all of them.
  • The MSE loss is the default loss for regression heads in deep networks.
  • The Normal Equation is the closed-form solution for the final linear layer in least-squares regression (used in transfer learning when fine-tuning just the head).

Feature Learning

In classical ML, we hand-engineer ϕ(x). Deep learning learns ϕ from data. The final layer of a neural network is still a linear model:

y^​=Wout​⋅learned representationϕθ​(x)​​+b

Training the whole network end-to-end jointly optimises the feature extractor ϕθ​ and the linear head Wout​. This is why linear regression is not a toy model — it is the building block of every output layer in deep learning.

Gradient Descent at Scale

Mini-batch SGD on the MSE loss for linear regression has the exact same update rule as a forward pass + backward pass in a single-layer neural network:

w←w−B2α​∑i∈B​(wTx(i)−y(i))x(i)

This is backpropagation with one layer. Learning this first makes the chain rule for deep networks much less mysterious.

Regularisation and Weight Decay

In deep learning, L2 regularisation on all weights is called weight decay and is standard (e.g., weight_decay=1e-4 in PyTorch optimisers). It corresponds exactly to a Gaussian prior on every weight. The Bayesian interpretation of Ridge carries over unchanged.

The Gauss-Markov Theorem (Why OLS is Special)

Among all linear unbiased estimators of w, OLS has the smallest variance. This is BLUE: Best Linear Unbiased Estimator.

Formal statement: if w~ is any other linear estimator satisfying E[w~]=w, then for any vector c:

Var(cTw^OLS​)≤Var(cTw~)

Conditions: linearity, independence, zero-mean errors, homoscedasticity (no normality required).

Note: “best among linear unbiased” is a limited guarantee. Ridge is biased but can have lower MSE than OLS. The Gauss-Markov theorem says Ridge is worse within the linear unbiased class, but Ridge wins when we’re willing to accept bias for reduced variance. This is the bias-variance tradeoff in action.
