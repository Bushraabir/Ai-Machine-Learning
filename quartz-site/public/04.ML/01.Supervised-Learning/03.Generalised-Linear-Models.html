03.Generalised Linear Models

Apr 26, 202611 min read

“Once you see the GLM framework, you cannot unsee it. Linear regression and logistic regression stop being two separate algorithms and become two instantiations of a single idea. Poisson regression, gamma regression, and multinomial regression are three more. The framework tells you exactly how to construct a new regression model for any response distribution in the exponential family — and guarantees that the gradient will always have the same clean residual form.”

The Unifying Observation

Look at the gradients derived in the two previous notes:

ModelLossGradient ∇w​L
Linear RegressionMSE (= Gaussian NLL)n1​XT(y^​−y)
Logistic RegressionBinary cross-entropy (= Bernoulli NLL)n1​XT(p^​−y)

The gradient has the same form in both cases: XT(prediction−target).

This is not a coincidence. Both models are Generalised Linear Models (GLMs). The GLM framework explains why this happens, and constructs the full family of models that share this property.

The Exponential Family

The exponential family is the class of probability distributions that can be written as:

p(y;η)=h(y)exp!(ηTT(y)−A(η))

where:

  • η is the natural parameter (also called canonical parameter)
  • T(y) is the sufficient statistic — all information about η in the data is contained in T(y)
  • A(η) is the log-partition function (log-normaliser): ensures the distribution integrates to 1
  • h(y) is the base measure

For most distributions we care about, T(y)=y (the identity sufficient statistic). We focus on this case.

Why “Sufficient Statistic”?

T(y) is sufficient for η if p(y∣T(y);η)=p(y∣T(y)) — the data y contains no additional information about η beyond what T(y) already tells us. For the Gaussian, the sample mean and variance are sufficient statistics for μ and σ2. The exponential family is precisely the class of distributions admitting finite-dimensional sufficient statistics (by the Pitman–Koopman–Darmois theorem).

Key Members

Gaussian (for regression)

p(y;μ)=2πσ2​1​exp!(−2σ2(y−μ)2​)

Rewrite in exponential family form (treating σ2 as fixed):

=2πσ2​1​exp!(σ2μ​y−2σ2μ2​)⋅exp!(−2σ2y2​)

Matching terms:

η=σ2μ​,T(y)=y,A(η)=2σ2μ2​=2η2σ2​,h(y)=2πσ2​1​e−y2/2σ2

The natural parameter is η=μ/σ2, so μ=ησ2. The mean function is μ(η)=ησ2 — linear in η.

Bernoulli (for classification)

p(y;ϕ)=ϕy(1−ϕ)1−y,y∈0,1

=exp!(ylog1−ϕϕ​+log(1−ϕ))

Matching terms:

η=log1−ϕϕ​(the log-odds!),T(y)=y,A(η)=log(1+eη),h(y)=1

Inverting: ϕ=1+eηeη​=σ(η). The mean function is μ(η)=σ(η) — the sigmoid.

Poisson (for count data)

p(y;λ)=y!λye−λ​,y∈0,1,2,…

=y!1​exp!(ylogλ−λ)

Matching terms:

η=logλ,T(y)=y,A(η)=eη=λ,h(y)=y!1​

Inverting: λ=eη. The mean function is μ(η)=eη — the exponential.

The Log-Partition Function Encodes Everything

This is a key theorem: the derivatives of A(η) give the cumulants.

dηdA​=E[T(y)]=E[y]=μ(η)

dη2d2A​=Var(y)

Proof sketch: Differentiate ∫p(y;η)dy=1 with respect to η twice. The first derivative gives E[T(y)]=A′(η); the second gives Var(T(y))=A′′(η)≥0, which also proves A is convex.

Distribution    A(η)           A'(η) = μ       A''(η) = Var(y)
─────────────────────────────────────────────────────────────
Gaussian        η²σ²/2         ησ² = μ         σ² (constant)
Bernoulli       log(1+eη)      σ(η) = p        p(1−p)
Poisson         eη             eη = λ          λ (mean=variance!)

The Poisson identity Var(y)=E[y]=λ falls out automatically from A′′=A′ when A(η)=eη.

Three Components of a GLM

A GLM specifies three things:

1. Random Component

The response y(i) is drawn from an exponential family distribution with natural parameter η(i): y(i)∼ExpFam(η(i))

2. Systematic Component (Linear Predictor)

The natural parameter is a linear function of the input: η(i)=wTx(i)

3. Link Function

The link function g connects the mean μ=E[y] to the linear predictor: g(μ(i))=η(i)=wTx(i)

Equivalently, the mean function (inverse link) is μ=g−1(η).

When g is the canonical link — the natural mapping from the mean to the natural parameter — the model has the cleanest properties (see gradient derivation below).

Input x ──→ Linear predictor η = w^Tx ──→ Mean μ = g⁻¹(η) ──→ Response y ~ ExpFam(μ)

        [systematic component]      [random component]
              (always linear)         (chosen by modeller)

The Universal Gradient Result

This is the theorem that explains why linear regression and logistic regression have the same gradient structure.

Theorem. For any GLM with canonical link, the gradient of the negative log-likelihood with respect to w is:

∇w​L(w)=n1​XT(μ^​−y)

where μ^​(i)=g−1(wTx(i)) is the predicted mean.

Proof

The log-likelihood for a single example (with T(y)=y, η=wTx):

logp(y(i);η(i))=η(i)y(i)−A(η(i))+logh(y(i))

Negative log-likelihood over n examples:

L(w)=−n1​∑i=1n​[η(i)y(i)−A(η(i))]+const

Since η(i)=wTx(i), differentiate with respect to wj​:

∂wj​∂L​=−n1​∑i=1n​[y(i)xj(i)​−A′(η(i))xj(i)​]

Now use the key identity A′(η)=μ(η)=μ^​(i):

∂wj​∂L​=n1​∑i=1n​[μ^​(i)−y(i)]xj(i)​

In matrix form:

∇w​L=n1​XT(μ^​−y)​■

The canonical link choice is what makes A′(η)=μ appear so cleanly. A non-canonical link introduces an extra Jacobian term.

Why This Matters

One gradient formula covers every GLM. To implement gradient descent for:

  • Linear regression: μ^​=η=wTx. Same formula.
  • Logistic regression: μ^​=σ(wTx). Same formula.
  • Poisson regression: μ^​=ewTx. Same formula.

The training loop is identical. Only the mean function changes.

Poisson Regression in Detail

Poisson regression is the GLM for count data: number of events, website visits, defects per unit, etc.

Model

λ(i)=ewTx(i),y(i)∼Poisson(λ(i))

The log link ensures λ>0 (counts cannot be negative). The model is:

logE[y∣x]=wTx

So a unit increase in xj​ multiplies the expected count by ewj​.

Loss (Poisson NLL)

L(w)=−n1​∑i​[y(i)logλ(i)−λ(i)]=−n1​∑i​[y(i)wTx(i)−ewTx(i)]

Gradient

By the universal result:

∇w​L=n1​XT(eXw−y)

where the exponential is applied elementwise.

When to Use

  • Response is a non-negative integer (count).
  • Events are rare relative to the exposure (otherwise Gaussian approximation works).
  • Overdispersion (Var(y)>E[y]): use Negative Binomial regression instead.
Use case             Response type        GLM to use
───────────────────────────────────────────────────────
House price          Continuous           Gaussian (OLS)
Spam or not          Binary               Logistic (Bernoulli)
# of website visits  Count (Poisson)      Poisson regression
Insurance claim amt  Positive continuous  Gamma regression
# of accidents/year  Count, overdispersed Negative Binomial

The Inductive Bias of GLMs

Every GLM makes the same core assumption:

The mean of the response is related to a linear function of the inputs.

Specifically: g(E[y∣x])=wTx. The relationship between the mean (not the raw output) and the inputs is linear. For logistic regression, the log-odds is linear. For Poisson regression, the log-rate is linear.

This is the GLM’s inductive bias — the prior assumption baked into the model family. It fails when the true relationship (on the link scale) is genuinely nonlinear. Remedies: (1) feature engineering, (2) kernel methods, (3) neural networks.

MLE for GLMs: Convexity

For any GLM with canonical link, the negative log-likelihood is convex in w.

Proof sketch: The Hessian is:

H=n1​XTWX

where W=diag(A′′(η(i))) is a diagonal matrix of variances. Since A(η) is convex, A′′(η)≥0, so W⪰0, so H⪰0. The objective is convex. ■

When W≻0 (strictly positive variances) and X has full column rank, the problem is strictly convex — unique global minimum, gradient descent converges.

This Hessian is also the key to Newton’s method (aka IRLS — Iteratively Reweighted Least Squares), the standard solver for GLMs in statistics:

w←w−H−1∇w​L

IRLS converges in far fewer iterations than gradient descent (quadratic vs. linear convergence), but each step costs O(d3) for the matrix inverse.

The GLM as a Probabilistic Model

GLMs are discriminative probabilistic models: they model p(y∣x;w) and give calibrated probability estimates (unlike, e.g., SVMs). This matters for:

  • Uncertainty quantification: the model outputs a full distribution, not just a point prediction.
  • Decision theory: if the loss is not symmetric (e.g., false negatives cost more than false positives), you threshold at something other than 0.5 using the probability output.
  • Bayesian extension: place a prior on w, compute the MAP estimate (equivalent to regularised GLM) or the full posterior.

Connection to AI, Machine Learning, and Deep Learning

GLMs as Single-Layer Networks

Every GLM is a neural network with zero hidden layers:

Input layer             Output
  x_1 ──w_1─┐
  x_2 ──w_2─┤──→ η = w^Tx ──→ μ = g⁻¹(η) ──→ y ~ ExpFam(μ)
   ⋮        ⋮
  x_d ──w_d─┘

        Linear layer       Activation        Distribution
       (always linear)   (= inverse link)   (= loss function)

The activation function in deep learning is exactly the inverse link function of the corresponding GLM:

  • Sigmoid output + BCE loss ← Bernoulli GLM
  • Linear output + MSE loss ← Gaussian GLM
  • Softmax output + categorical CE loss ← Multinomial GLM
  • Exponential output + Poisson NLL ← Poisson GLM

Generalised Linear Models → Generalised Neural Networks

Deep learning generalises GLMs by inserting hidden layers between input and the final GLM output layer:

μ^​=g−1(WL​⋅ReLU(WL−1​⋯ReLU(W1​x)))

The final layer is always a GLM. The hidden layers learn the features ϕθ​(x) on which the GLM operates. The loss function is always the NLL of the appropriate exponential family distribution.

This is why knowing the GLM framework matters for deep learning: it tells you exactly which loss function and output activation to pair, and why those specific combinations are principled.

When you see a deep learning practitioner choose nn.BCEWithLogitsLoss for binary classification or nn.CrossEntropyLoss for multi-class, they are — whether they know it or not — choosing the canonical GLM for the Bernoulli or Multinomial family.

Natural Gradient Descent

The Fisher information matrix of a GLM is:

F=E[∇w​logp(y∣x;w)⋅∇w​logp(y∣x;w)T]=n1​XTWX

This is the same as the Hessian. Natural gradient descent uses F−1 instead of the identity as the metric:

w←w−αF−1∇w​L

This is equivalent to IRLS for GLMs, and is the motivation for K-FAC and other second-order optimisers used in large neural network training. The GLM is where this theory is cleanest and most tractable.
