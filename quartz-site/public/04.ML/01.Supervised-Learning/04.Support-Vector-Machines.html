04.Support Vector Machines

04.Support Vector Machines

Apr 26, 202615 min read

  • foundational

“The SVM is one of the most intellectually satisfying algorithms in machine learning. It turns a geometric intuition — find the widest possible street between two classes — into a convex quadratic programme, solves it via Lagrangian duality, and then, almost miraculously, discovers that the solution never needed the data points themselves — only their pairwise inner products. That last observation is the kernel trick, and it opens the door to infinite-dimensional feature spaces computed in finite time.”

The Geometric Intuition

Given linearly separable data with y(i)∈−1,+1, many hyperplanes separate the classes. Which one should we pick?

Class +1: ●         Class -1: ○

    ○  ○                ○  ○
  ○      ○            ○      ○
      /                   |
  ●  / ●               ●  | ●
    /                      |
  ●/    ●               ●  |  ●

  Arbitrary separator    Maximum margin separator
  (unstable, poor gen.)  (SVMs pick this one)

The maximum margin separator is the most robust: it is as far as possible from both classes. Small perturbations in the data or new test points near the boundary are less likely to be misclassified.

Setting Up the Geometry

A hyperplane in Rd is x:wTx+b=0. The signed distance from a point x(i) to this hyperplane is:

dist(x(i))=∣w∣wTx(i)+b​

We want all positives on one side and all negatives on the other:

y(i)=+1⟹wTx(i)+b≥0 y(i)=−1⟹wTx(i)+b≤0

Combined: y(i)(wTx(i)+b)≥0 for all i.

Canonical Scale Convention

The margin is the distance from the hyperplane to the closest point on either side. We have a free scaling: if (w,b) defines a separator, so does (cw,cb) for any c>0. We use this freedom to fix the scale so that the closest points satisfy:

y(i)(wTx(i)+b)=1

These closest points are the support vectors. Under this convention:

  • Points with y(i)=+1 satisfy wTx(i)+b≥1
  • Points with y(i)=−1 satisfy wTx(i)+b≤−1

The two margin hyperplanes are wTx+b=+1 and wTx+b=−1.

Width of the Margin

The distance between the two margin planes is the width of the street we are trying to maximise:

margin=∣w∣2​

Derivation: Take two points x+​ on the +1 margin and x−​ on the −1 margin. Then wT(x+​−x−​)=2. The distance between the planes in the direction of w/∣w∣ is ∣w∣wT(x+​−x−​))​=∣w∣2​.

        w^Tx + b = +1
             |     ← margin = 1/‖w‖
w^Tx + b = 0 |
             |     ← margin = 1/‖w‖
        w^Tx + b = -1

Total street width = 2/‖w‖
Support vectors lie on the margin planes

Hard-Margin SVM

Primal Problem

Maximising ∣w∣2​ is equivalent to minimising 21​∣w∣2:

minw,b​21​∣w∣2subject toy(i)(wTx(i)+b)≥1∀i

This is a convex quadratic programme (QP): convex objective, linear constraints. Unique global minimum.

Why 21​? Purely notational convenience — the 21​ cancels the factor of 2 that appears when differentiating ∣w∣2. The solution is identical.

Limitations of Hard-Margin

Hard-margin SVM fails when:

  1. Data is not linearly separable — no feasible solution exists.
  2. Data is nearly separable but with a few outliers — a single mislabelled point forces a tiny margin.

Soft-Margin SVM

The Relaxation

Introduce slack variables ξi​≥0 that allow points to violate the margin:

minw,b,ξ​21​∣w∣2+C∑i=1n​ξi​

subject toy(i)(wTx(i)+b)≥1−ξi​∀i,ξi​≥0∀i

Three cases for each point:

  • ξi​=0: correctly classified, outside or on margin. No penalty.
  • 0<ξi​<1: inside the margin but correct side. Small penalty.
  • ξi​≥1: misclassified. Penalty ≥1.
                  w^Tx+b=1    w^Tx+b=0    w^Tx+b=-1
                      |           |            |
class +1:  ●          |  ●(ξ=0)   |            |
           ●(ξ=0.3)───│───────────│            |
                      |           |  ●(ξ=1.5)  |     ← misclassified
class -1:             |           |            | ○
                      |           |            | ○  ○
                      |      ○(ξ=0.7)          |

The Hyperparameter C

C controls the tradeoff between margin width and training error:

  • Large C: heavily penalises slack → small margin, few violations → risk of overfitting.
  • Small C: tolerates violations → wide margin → risk of underfitting.
Small C (wide margin,          Large C (narrow margin,
 tolerates violations)          almost no violations)

  ○  ○    ●  ●                  ○ ○   ●  ●
   ○  |  |  ●                   ○|   | ●
      |  |                       |   |
   ○  |  |  ●                   ○|   | ●
                                 |   |
Wide street, outliers OK        Narrow street, near-perfect fit

C is a hyperparameter tuned by cross-validation.

Lagrangian Duality — The Dual Problem

This is the theoretical core of SVMs. We derive the dual formulation, which:

  1. Reveals that the solution depends only on inner products between training points.
  2. Identifies support vectors as the only points that matter.
  3. Opens the door to the kernel trick.

The Lagrangian

For the soft-margin SVM, form the Lagrangian by introducing multipliers αi​≥0 for the margin constraints and μi​≥0 for ξi​≥0:

L(w,b,ξ,α,μ)=21​∣w∣2+C∑i​ξi​−∑i​αi​[y(i)(wTx(i)+b)−1+ξi​]−∑i​μi​ξi​

Primal → Dual: Minimise over Primal Variables

∇w​L=0:

w−∑i​αi​y(i)x(i)=0⟹w=i∑​αi​y(i)x(i)​

∂b∂L​=0:

∑i​αi​y(i)=0

∂ξi​∂L​=0:

C−αi​−μi​=0⟹αi​=C−μi​

Since μi​≥0: 0≤αi​≤C.

Substituting Back

Substitute w=∑i​αi​y(i)x(i) into L:

L=21​​∑i​αi​y(i)x(i)​2+…

After substitution and simplification (expand the norm, cancel terms using ∑i​αi​y(i)=0):

αmax​i∑​αi​−21​i,j∑​αi​αj​y(i)y(j)(x(i))Tx(j)​

subject to0≤αi​≤C∀i,∑i​αi​y(i)=0

This is the dual problem. It is also a convex QP, but in the n-dimensional dual variable α rather than the (d+1)-dimensional primal variable (w,b).

When is the dual better? When n≪d — many features, few examples — solve the dual. When d≪n, solve the primal. For kernel SVMs, the dual is always used (since d is infinite).

KKT Conditions

The KKT conditions are necessary and sufficient for optimality (since the problem is convex). The complementary slackness conditions are particularly important:

αi​[y(i)(wTx(i)+b)−1+ξi​]=0∀i

μi​ξi​=0⟹(C−αi​)ξi​=0∀i

From the first condition:

  • If αi​>0: the constraint is active — y(i)(wTx(i)+b)=1−ξi​.
  • If αi​=0: the point is outside the margin, contributes nothing to w.

Definition: A support vector is any training point with αi​>0. These are the only points that determine w.

Three types of support vectors:

α_i = 0           0 < α_i < C        α_i = C
────────────       ───────────────    ───────────────
Not a support      On the margin      Inside margin or
vector. Ignored.   ξ_i = 0            misclassified
in prediction.     (from KKT)         ξ_i > 0

Prediction at Test Time

y^​(x)=sign(∑i​αi​y(i)(x(i))Tx+b)

Again, only support vectors (αi​>0) contribute. If the data has m≪n support vectors, prediction costs O(md) not O(nd).

The Kernel Trick

The Key Observation

The dual objective and the prediction function depend on the data only through inner products x(i)Tx(j).

This means: if we map x→ϕ(x) for some feature map ϕ:Rd→F, the inner products become ϕ(x(i))Tϕ(x(j)). And we never need to compute ϕ(x) explicitly — only the inner product.

Define: A kernel function k:Rd×Rd→R is any function of the form:

k(x,x′)=ϕ(x)Tϕ(x′)

for some feature map ϕ. Replace every x(i)Tx(j) in the dual with k(x(i),x(j)).

Why This is Remarkable

The feature map ϕ can map to infinite-dimensional spaces. Yet if we can compute k(x,x′) efficiently, we get the power of infinite features at finite computational cost.

The kernel matrix (Gram matrix) K∈Rn×n with Kij​=k(x(i),x(j)) is all we need.

Common Kernels

Linear kernel:

k(x,x′)=xTx′

Equivalent to no feature mapping. Hard-margin SVM with linear kernel = standard hard-margin SVM.

Polynomial kernel:

k(x,x′)=(xTx′+c)d

Corresponds to a feature map containing all monomials up to degree d. For d=2, c=1, x∈R2:

k(x,x′)=(x1​x1′​+x2​x2′​+1)2=x12​x1′2​+x22​x2′2​+1+2x1​x2​x1′​x2′​+2x1​x1′​+2x2​x2′​

This corresponds to ϕ(x)=(x12​,x22​,1,2​x1​x2​,2​x1​,2​x2​) — a 6-dimensional feature map computed in O(d) via the kernel, not O(d2) explicitly.

RBF (Gaussian) kernel:

k(x,x′)=exp!(−2σ2∣x−x′∣2​)

This corresponds to an infinite-dimensional feature map. Let’s prove it.

Proof that RBF corresponds to an infinite feature map:

Using the Taylor expansion of ez=∑n=0∞​zn/n!:

exp!(−2σ2∣x−x′∣2​)=exp!(−2σ2∣x∣2​)exp!(σ2xTx′​)exp!(−2σ2∣x′∣2​)

=exp!(−2σ2∣x∣2​)∑n=0∞​σ2nn!(xTx′)n​exp!(−2σ2∣x′∣2​)

Each term (xTx′)n/n! corresponds to a polynomial feature map. The infinite sum corresponds to an infinite-dimensional feature map. ■

The bandwidth σ controls the locality:

  • Small σ: kernel decays quickly → model fits locally, high variance, risk of overfitting.
  • Large σ: kernel decays slowly → model is smoother, higher bias.
Small σ (peaked kernel)      Large σ (flat kernel)
  k(x,x')                      k(x,x')
  1 ┤ ╭╮                       1 ┤ ╭──────╮
    │ │ │                         │╭╯      ╰╮
  0 ┤─╯ ╰─────  ‖x-x'‖         0 ┤╯        ╰──  ‖x-x'‖
   Local influence only          Wide influence
   → Complex boundary            → Smooth boundary

Mercer’s Theorem

When is a function k a valid kernel (i.e., corresponds to some inner product in some feature space)?

Mercer’s Theorem: A symmetric function k:X×X→R is a valid kernel if and only if the kernel matrix K is positive semi-definite for every finite set of inputs x(1),…,x(n):

∑i,j​ci​cj​k(x(i),x(j))≥0∀c∈Rn

Equivalently: all eigenvalues of K are ≥0.

Closure properties (useful for building new kernels):

OperationResult
k1​+k2​Valid kernel
c⋅k1​ for c>0Valid kernel
k1​⋅k2​Valid kernel
exp(k1​)Valid kernel
f(x)k1​(x,x′)f(x′) for any fValid kernel

This lets you design kernels for structured inputs (strings, graphs, trees) where Euclidean distance is not meaningful.

SVM as Hinge Loss Minimisation

The soft-margin SVM primal can be rewritten in unconstrained form. Substituting the optimal slack variables:

ξi​=max(0,1−y(i)(wTx(i)+b))

The primal becomes:

minw,b​2λ​∣w∣2+n1​∑i=1n​max!(0,1−y(i)(wTx(i)+b))

where λ=1/(nC). The second term is the hinge loss:

ℓhinge​(y,y^​)=max(0,1−yy^​)

Hinge loss vs. Logistic loss vs. 0-1 loss

  Loss
  3 ┤
    │  hinge ╲
  2 ┤         ╲
    │  logistic ╲___
  1 ┤            ╲  ─────
    │  0-1 loss   ╲________
  0 ┤──────────────╲────────────
   -2   -1    0    1    2    yŷ

                   ↑
              margin = 1

This is the loss perspective on SVMs:

  • Hinge loss is zero when yy^​≥1 (correct and confident). No gradient from well-classified points.
  • Linear penalty for yy^​∈[0,1] (correct but within margin).
  • Linear penalty for yy^​<0 (misclassified).

Compare with logistic loss (smooth everywhere) and 0-1 loss (non-convex, combinatorial). Hinge loss is the tightest convex surrogate for 0-1 loss.

SMO Algorithm (Conceptual)

The dual QP has n variables with a linear equality constraint. Sequential Minimal Optimisation (SMO) solves it efficiently by:

  1. Select the two most violating αi​,αj​ (by the KKT conditions).
  2. Optimise over αi​,αj​ analytically while keeping all others fixed.
  3. The 2-variable subproblem with one linear constraint has a closed-form solution.
  4. Repeat until KKT conditions are satisfied to tolerance.

SMO is O(n2) in the worst case but much faster in practice due to caching of kernel evaluations.

Practical Considerations

Scaling is Mandatory

SVMs use Euclidean distances. If feature j has range [0,10000] and feature k has range [0,1], the distance is dominated by feature j. Always standardise before fitting an SVM.

Choosing the Kernel

──────────────────────────────────────────────
Many features, sparse           Linear (fast)
Moderate features, nonlinear    RBF (default)
Known polynomial structure      Polynomial
Text/sequences                  String kernel
Graphs                          Graph kernel

For RBF SVM, always tune both C and γ together:

SVMs do not scale well beyond n≈105. For large datasets, use linear SVM (Pegasos, LinearSVC) or approximate kernel methods (Nyström approximation, random Fourier features).

Connection to AI, Machine Learning, and Deep Learning

SVMs vs. Neural Networks: A Historical Note

Through the 1990s and early 2000s, SVMs dominated ML benchmarks. The kernel trick gave them nonlinear power, the max-margin principle gave them strong generalisation, and convexity gave them reliable training. Neural networks were widely dismissed as unreliable and hard to train.

The 2012 ImageNet result (AlexNet) reversed this. Deep networks outperformed kernel SVMs on vision tasks by a large margin — not because the theory of SVMs was wrong, but because:

  1. SVMs require hand-engineered features; deep networks learn them.
  2. The kernel matrix is O(n2) memory; deep networks scale to n=108.
  3. Deep networks compose representations; SVMs compute a single kernel.

SVMs Survive in Deep Learning

Despite this history, SVM ideas are alive in modern deep learning:

Hinge loss appears directly in:

  • Multi-class SVM loss (Weston-Watkins, Crammer-Singer): used in some image classifiers.
  • Margin-based losses in metric learning (triplet loss, contrastive loss — used in FaceNet, SimCLR).
  • torch.nn.MarginRankingLoss, torch.nn.MultiMarginLoss.

Max-margin thinking underpins:

  • The success of large-margin classifiers in NLP (structured SVMs for sequence labelling).
  • Implicit regularisation in deep networks — recent theoretical work shows SGD on deep networks with cross-entropy loss has an implicit max-margin bias on linearly separable data.

The kernel perspective is central to:

  • Neural Tangent Kernel (NTK) theory: infinitely wide neural networks are equivalent to kernel methods with a specific kernel determined by the architecture.
  • Gaussian Processes (03.Gaussian Processes): Bayesian kernel machines, dual to SVMs.
  • Attention mechanisms in Transformers can be interpreted as kernel-weighted averaging: Attention(Q,K,V)=softmax!(dk​​QKT​)V The term QKT is a matrix of inner products — exactly the kernel matrix.

Support vectors and sparsity:

  • The SVM solution is sparse in the dual — most αi​=0.
  • This is analogous to L1 regularisation (Lasso) inducing sparsity in the primal.
  • Sparse solutions generalise better and are cheaper at inference.

The Representer Theorem

The SVM solution satisfies:

w∗=∑i​αi​y(i)ϕ(x(i))

This says: the optimal weight vector in feature space is a linear combination of the training data feature maps. This is an instance of the Representer Theorem (01.Kernel Methods):

For any regularised ERM problem with a differentiable, strictly increasing regulariser Ω(∣f∣H​), the optimal solution has the form f∗(x)=∑i​αi​k(x(i),x).

Neural networks can be seen as learning a data-dependent kernel — and the final classifier is still a linear combination over training data in the learned representation space.
