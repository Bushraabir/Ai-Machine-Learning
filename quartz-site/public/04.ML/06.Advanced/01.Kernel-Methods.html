The Central Problem

Most machine learning algorithms assume a fixed, finite-dimensional feature representation. You hand the model a vector x∈Rd, and it does something with it. But what if the data is not linearly separable in Rd? The naive solution: map to a higher-dimensional space where it is.

ϕ:Rd→RD,D≫d(possibly D=∞)

The brutal fact: computing in RD is expensive. If D=d2 (all pairwise products), you’re already in trouble for modest d. If D=∞ — you literally cannot compute ϕ(x) explicitly.

The kernel trick resolves this: you never need ϕ(x) explicitly. You only ever need inner products ⟨ϕ(xi​),ϕ(xj​)⟩, and a kernel function computes this cheaply.

k(xi​,xj​)=def⟨ϕ(xi​),ϕ(xj​)⟩H​

1. Feature Maps and the Kernel Function

Setup

Let X be the input space (e.g., Rd). A feature map is ϕ:X→H where H is a Hilbert space (a complete inner product space — possibly infinite dimensional).

A kernel function is any function k:X×X→R such that:

k(x,x′)=⟨ϕ(x),ϕ(x′)⟩H​

for some feature map ϕ. The point: we define k first, then the feature map ϕ is implied by k — we may never need to construct it.

Canonical Example: The Polynomial Kernel

Let x,x′∈R2. Define:

k(x,x′)=(x⊤x′+c)2,c≥0

Expand for x=(x1​,x2​)⊤, x′=(x1′​,x2′​)⊤, c=1:

k(x,x′)=(x1​x1′​+x2​x2′​+1)2 =x12​x1′2​+x22​x2′2​+1+2x1​x1′​x2​x2′​+2x1​x1′​+2x2​x2′​

This is precisely ⟨ϕ(x),ϕ(x′)⟩ where:

ϕ(x)=(x12​, x22​, 1, 2​x1​x2​, 2​x1​, 2​x2​)⊤∈R6

Key observation: computing k(x,x′) costs O(d) — one inner product and a squaring. Computing ⟨ϕ(x),ϕ(x′)⟩ directly costs O(D) where D=(2d+2​) grows quadratically in d. The kernel saves us this cost.

The RBF (Gaussian) Kernel — An Infinite-Dimensional Feature Map

k(x,x′)=exp!(−2σ2∣x−x′∣2​)

Claim: This corresponds to an infinite-dimensional feature map.

Proof sketch: Expand via the Taylor series of exp:

exp!(−2σ2∣x∣2+∣x′∣2−2x⊤x′​)=e−∣x∣2/2σ2⋅e−∣x′∣2/2σ2⋅ex⊤x′/σ2

The last factor: ex⊤x′/σ2=∑n=0∞​n!σ2n(x⊤x′)n​. Each term (x⊤x′)n corresponds to a degree-n polynomial kernel, which has its own feature map of dimension (nd+n​). Summing infinitely many such maps gives an infinite-dimensional ϕ. Yet k(x,x′) is a single exponential — O(d) to evaluate. □

This is the fundamental power: the feature space can be infinite-dimensional while the kernel evaluation remains cheap.

2. Mercer’s Theorem — When is k a Valid Kernel?

Not every function k:X×X→R corresponds to a valid inner product. We need a characterisation.

Definition: Positive Semi-Definite Kernel

A symmetric function k is a positive semi-definite (PSD) kernel (also called a Mercer kernel) if for any finite set x1​,…,xn​⊂X and any c∈Rn:

∑i=1n​∑j=1n​ci​cj​k(xi​,xj​)≥0

Equivalently, the Gram matrix K∈Rn×n with Kij​=k(xi​,xj​) is positive semi-definite for all choices of x1​,…,xn​.

Mercer’s Theorem (Statement)

Let k:X×X→R be continuous and symmetric. Then k is a valid kernel (i.e., k(x,x′)=⟨ϕ(x),ϕ(x′)⟩H​ for some Hilbert space H and feature map ϕ) if and only if k is positive semi-definite.

Proof direction (necessity): If k(x,x′)=⟨ϕ(x),ϕ(x′)⟩, then ∑i,j​ci​cj​k(xi​,xj​)=∣∑i​ci​ϕ(xi​)∣2≥0. □

The sufficiency direction is harder — it constructs the RKHS explicitly from k. See Section 4.

How to Check Validity

  1. Directly verify PSD on the Gram matrix.
  2. Use closure properties (easier in practice):
    • If k1​,k2​ are valid kernels, so are k1​+k2​, αk1​ (α>0), k1​⋅k2​
    • k(x,x′)=f(x)k1​(x,x′)f(x′) for any function f
    • k(x,x′)=ϕ(x)⊤Aϕ(x′) where A⪰0

3. The Representer Theorem

This is the theorem that justifies using kernels for learning. It says: when you minimise a regularised loss over a function space, the optimal solution lives in the span of the training data’s feature maps.

Theorem (Representer Theorem — Schölkopf, Herbrich, Smola, 2001)

Let H be an RKHS with kernel k. Consider the optimisation problem:

f^​=argminf∈H​empirical lossi=1∑n​L(yi​,f(xi​))​​+regularisationΩ(∣f∣H​)​​

where L is any loss function and Ω:[0,∞)→R is any strictly increasing function. Then the optimal f^​ has the form:

f^​(⋅)=∑i=1n​αi​k(⋅,xi​)

for some coefficients α1​,…,αn​∈R.

Proof

Decompose f∈H into a component in the span of k(⋅,xi​) and its orthogonal complement:

f=f∥​i=1∑n​αi​k(⋅,xi​)​​+f⊥​

By the reproducing property of the RKHS (see Section 4):

f(xj​)=⟨f,k(⋅,xj​)⟩H​=⟨f∥​,k(⋅,xj​)⟩H​+=0⟨f⊥​,k(⋅,xj​)⟩H​​​=f∥​(xj​)

So adding f⊥​ does not change any training prediction, but ∣f∣H2​=∣f∥​∣2+∣f⊥​∣2≥∣f∥​∣2, which means f⊥​ only hurts the regularisation term. Therefore the optimal solution has f⊥​=0. □

What this buys you: instead of optimising over an infinite-dimensional function space, you optimise over n real numbers α1​,…,αn​. The learning problem reduces to finite-dimensional optimisation.

4. The Reproducing Kernel Hilbert Space (RKHS)

This is the natural home for kernel methods. Understanding the RKHS is understanding why the whole framework is coherent.

Construction

Given a PSD kernel k, we construct the RKHS Hk​ as follows:

Step 1. Start with the set of all “feature functions”: for each x∈X, define kx​:=k(⋅,x) as a function X→R.

Step 2. Consider the linear span: \mathcal{F} = \left{ \sum_{i=1}^m \alpha_i k_{x_i} \mid m \in \mathbb{N},\ \alpha_i \in \mathbb{R},\ x_i \in \mathcal{X} \right}

Step 3. Define an inner product on F:

⟨∑i​αi​kxi​​, ∑j​βj​kxj′​​⟩H​:=∑i​∑j​αi​βj​k(xi​,xj′​)

This is well-defined because k is PSD.

Step 4. Complete F under the induced norm ∣f∣H​=⟨f,f⟩H​​ to get the Hilbert space Hk​.

The Reproducing Property

The defining property of the RKHS, which gives it its name:

f(x)=⟨f,k(⋅,x)⟩H​∀f∈Hk​, x∈X

In other words: evaluating a function f at a point x is an inner product with the kernel function k(⋅,x). This is the reason the representer theorem proof works.

Sanity check: Set f=k(⋅,x′). Then:

⟨k(⋅,x′),k(⋅,x)⟩H​=k(x′,x)✓

The RKHS norm ∣f∣H​ has a concrete meaning: it measures the smoothness of f with respect to the kernel. The smoother the function, the smaller the norm. Regularisation with ∣f∣H2​ is literally a smoothness penalty.

5. Kernelised Algorithms

The representer theorem + the kernel trick allows us to kernelise any algorithm that depends on the data only through inner products. We replace xi⊤​xj​↦k(xi​,xj​) everywhere.

Kernel Ridge Regression

Primal: minw∈H​∣Xw−y∣2+λ∣w∣2

Primal solution: w^=(X⊤X+λI)−1X⊤y — works in Rd, breaks for infinite-dim ϕ.

Dual: By the representer theorem, f^​=∑i​αi​k(⋅,xi​). Substituting:

α^=(K+λI)−1y

where Kij​=k(xi​,xj​) is the n×n Gram matrix. Prediction:

\hat{f}(x^_) = \sum_i \hat{\alpha}_i k(x^_, x_i) = k(x^*)^\top (K + \lambda I)^{-1} y

where k(x^_)_i = k(x^_, x_i).

Cost: O(n3) to invert (K+λI) vs. O(d3) for ridge regression. Kernel methods trade d for n in complexity — they scale with the number of samples, not the feature dimensionality.

Connection to Gaussian Processes: The kernel ridge regression predictor is identical to the GP posterior mean under an RBF prior. This is not a coincidence — they are the same model derived from different perspectives.

Kernel SVM

Recall the SVM dual:

maxα​∑i​αi​−21​∑i,j​αi​αj​yi​yj​xi⊤​xj​s.t. ∑i​αi​yi​=0, 0≤αi​≤C

Replace xi⊤​xj​↦k(xi​,xj​):

maxα​∑i​αi​−21​∑i,j​αi​αj​yi​yj​k(xi​,xj​)s.t. ∑i​αi​yi​=0, 0≤αi​≤C

Decision function:

y^​(x)=sign!(∑i∈SV​αi​yi​k(x,xi​)+b)

We never need ϕ explicitly. We never need to work in the feature space. Everything is mediated by k.

Kernel Logistic Regression

Replace the weight vector w with ∑i​αi​k(⋅,xi​) and optimise over α. The log-likelihood becomes:

ℓ(α)=∑i​logσ!(yi​∑j​αj​k(xi​,xj​))−λα⊤Kα

The regularisation term α⊤Kα=∣f∣H2​ — this is the RKHS norm.

Kernel PCA

Standard PCA: find eigenvectors of the covariance matrix C=n1​X⊤X.

Kernel PCA: find principal components in the RKHS by computing the eigendecomposition of the centred Gram matrix K~:

K~=K−1n​K−K1n​+1n​K1n​

where (1n​)ij​=1/n. This centres the data in feature space without constructing ϕ(x) explicitly.

The projection of a new point x∗ onto the j-th principal component:

z_j(x^_) = \sum_i \alpha_j^{(i)} k(x^_, x_i)

6. Kernel Design — Encoding Prior Knowledge

The choice of kernel is a choice of inductive bias. When you pick the RBF kernel, you’re saying: “I believe the function is smooth, and similar inputs should have similar outputs, where similarity decays exponentially with Euclidean distance.” Different kernels encode different beliefs.

Stationary Kernels

k(x,x′)=k(x−x′) — depends only on the difference between inputs. Implies translation invariance (stationarity).

  • RBF: k(r)=exp(−r2/2σ2) — infinitely differentiable. Use when the target function is very smooth.
  • Laplace: k(r)=exp(−∣r∣/σ) — only once-differentiable. Better for non-smooth functions.
  • Matérn-ν: interpolates between Laplace (ν=1/2) and RBF (ν→∞). The parameter ν controls differentiability.

Non-stationary Kernels

  • Linear: k(x,x′)=x⊤x′ — equivalent to linear models. No nonlinearity.
  • Polynomial: encodes feature interactions up to degree d.
  • Periodic: k(x,x′)=exp(−2sin2(π∣x−x′∣/p)/ℓ2) — for periodic functions (e.g., seasonal data).

Kernels for Structured Data

The true power of kernels: they extend machine learning to non-Euclidean inputs by defining similarity directly.

  • String kernels: k(s,s′)= number of common substrings of length p. Used in text classification and bioinformatics (protein sequences).
  • Graph kernels: k(G,G′)= a function of shared subgraph patterns. Used in chemoinformatics (molecular property prediction).
  • Tree kernels: for parse trees in NLP.

The definition of valid kernel is preserved: as long as the Gram matrix is PSD, any similarity function is a valid kernel — no matter how exotic the input space.

7. Computational Considerations

The O(n3) Problem

Kernel methods require computing and storing the n×n Gram matrix K. For large n:

  • Storage: O(n2) — infeasible at n=106
  • Inversion (kernel ridge): O(n3) — infeasible much earlier
  • This is why kernel methods fell out of favour when deep learning arrived

Approximate Kernel Methods

Nyström approximation: approximate K using a low-rank factorisation:

K≈Knm​Kmm−1​Knm⊤​

where m≪n are randomly selected “landmark” points. Reduces to O(nm2) computation.

Random Fourier Features (Rahimi & Recht, 2007): for shift-invariant kernels, Bochner’s theorem guarantees:

k(x,x′)=Eω​![eiω⊤(x−x′)]

Sample D random frequencies ω1​,…,ωD​∼p(ω) and construct:

z(x)=D2​​!(cos(ω1⊤​x+b1​),…,cos(ωD⊤​x+bD​))⊤

Then k(x,x′)≈z(x)⊤z(x′). This reduces to a standard linear method in RD, costing O(nD).

8. Connection to AI, Deep Learning, and Neural Networks

Kernel methods and deep learning are more deeply connected than they might appear. Understanding this connection is important for a modern practitioner.

Neural Tangent Kernel (NTK)

The central result (Jacot, Gabriel, Hongler, 2018): An infinitely wide neural network trained by gradient descent is equivalent to kernel regression with the Neural Tangent Kernel:

kNTK​(x,x′)=Eθ∼init​![∇θ​f(x;θ)⊤∇θ​f(x′;θ)]

At infinite width:

  • The NTK stays constant throughout training (it doesn’t change as weights update)
  • The network converges to a global minimum
  • The final predictor is a kernel regression predictor with kernel kNTK​

What this means practically: For very wide networks, the NTK regime predicts behaviour well. For finite-width networks (real practice), the NTK drifts during training — this is called feature learning and is what makes practical deep learning powerful beyond kernel methods. The kernel regime cannot learn new features; it is fixed by the initialisation.

Deep Kernels

One response to the expressive power gap: learn the kernel. Define:

k(x,x′)=kbase​(ϕθ​(x),ϕθ​(x′))

where ϕθ​ is a neural network and kbase​ is a standard kernel (e.g., RBF). Train θ jointly with the kernel machine. This is the basis of Deep Kernel Learning (Wilson et al., 2016) and gives a principled Bayesian uncertainty estimate from a deep model.

SVMs vs. Neural Networks — Historical Perspective

In the 1990s, SVMs were the dominant large-margin classifier. The shift to neural networks was driven by:

  1. Scalability: Deep learning trains in O(n) per epoch via SGD; kernel SVMs scale as O(n2)–O(n3).
  2. Representation learning: CNNs learn the right features for images; SVMs with RBF kernels cannot exploit spatial structure as efficiently.
  3. Compositionality: Deep networks compose simple functions hierarchically; kernels are a single layer of feature mapping.

Yet SVMs with carefully designed kernels still dominate in domains with small n and structured data (e.g., genomics, cheminformatics). The choice is not doctrinal; it’s empirical.

Kernel Machines in Modern ML

  • Gaussian Processes (used in hyperparameter optimisation via Bayesian optimisation, as uncertainty-aware surrogates in RL and AutoML) are fully defined by their kernel.
  • Graph Neural Networks can be understood as learnable graph kernels.
  • Attention in Transformers: the scaled dot-product attention softmax(QK⊤/dk​​)V is a data-dependent kernel. Q⊤K/dk​​ computes kernel similarities between query and key representations. This is the connection that has been formalised in kernel attention and Performer architectures.
  • Support Vector Regression (SVR) is still used as a strong baseline in time series and scientific ML.

9. Worked Example — Kernel SVM vs. Linear SVM

Consider the XOR problem: 4 points in R2:

x1​=(1,1), y1​=+1x2​=(−1,−1), y2​=+1 x3​=(1,−1), y3​=−1x4​=(−1,1), y4​=−1

Linear SVM: not separable in R2 — no hyperplane separates the classes.

Polynomial kernel of degree 2: k(x,x′)=(x⊤x′)2. The feature map is (for c=0):

ϕ(x1​,x2​)=(x12​,x22​,2​x1​x2​)

In this space:

  • ϕ(1,1)=(1,1,2​), class +1
  • ϕ(−1,−1)=(1,1,2​), class +1
  • ϕ(1,−1)=(1,1,−2​), class −1
  • ϕ(−1,1)=(1,1,−2​), class −1

Now the classes separate perfectly along the third coordinate 2​x1​x2​: positive class has x1​x2​>0, negative has x1​x2​<0. The hyperplane is w3​z3​=0, i.e., the product x1​x2​=0.

12. Summary and Exit Criteria

The logical chain:

PSD kernelMercer​valid inner productRKHS construction​Hilbert space Hk​Representer theorem​finite-dim optimisation over α∈Rn

The kernel trick reduces any algorithm that uses data only through inner products to kernel evaluations. Kernelise the inner products, and the algorithm works in an implicit infinite-dimensional space at the cost of O(n2) storage and O(n3) computation.

You know this when you can:

  1. State Mercer’s theorem and use it to verify or refute that a given function is a valid kernel.
  2. Derive the kernel ridge regression dual from the representer theorem — without looking it up.
  3. Prove the representer theorem using the orthogonal decomposition argument.
  4. Explain why the RBF kernel corresponds to an infinite-dimensional feature map (via Taylor expansion of exp).
  5. Implement kernel ridge regression and kernel PCA in NumPy (~50 lines each).
  6. Explain the NTK connection and what it implies about the relationship between kernel methods and infinitely wide neural networks.
  7. Explain why Transformer attention is a form of data-dependent kernel.
