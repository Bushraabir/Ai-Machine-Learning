02.Learning with Structured Outputs

02.Learning with Structured Outputs

Apr 24, 202617 min read

“Most of what matters in the world has structure. A sentence is not a bag of words. A protein is not a bag of amino acids. The challenge is to make the model know this.”

✦ Why This Note Exists in the Map

Standard supervised learning assumes Y is simple: a scalar (regression) or a finite label (classification). But the real world rarely cooperates. Consider:

  • Sequence labelling: given a sentence, tag each word as NOUN, VERB, ADJ, … — the output is a sequence of the same length as the input.
  • Parsing: given a sentence, produce a parse tree — the output is a variable-size tree.
  • Image segmentation: given an image, label each pixel — the output has H×W interdependent labels.
  • Translation: given an English sentence, produce a German sentence of different length.

In all of these, the output components are not independent given the input. The label of word i depends on the label of word i−1. Predicting each output independently (the “flat” approach) discards this structure and produces incoherent outputs.

This note builds the machinery to handle structured outputs properly, with rigour. Two major frameworks:

  1. Linear-Chain Conditional Random Fields (CRFs) — for sequence labelling.
  2. Structured SVMs — generalising the SVM margin to arbitrary output spaces.

✦ Prerequisites

Before reading this note you should be comfortable with:

  • 04.Support Vector Machines — the margin, dual problem, KKT conditions
  • 03.Probability Review — log-likelihood, conditional distributions
  • 02.Statistical Learning Theory — ERM, structured loss functions
  • 02.Logistic Regression — log-linear models, the softmax

✦ 1. The Structured Prediction Problem — Setting Up Formally

Setup. Let:

  • X = input space (e.g., sequences of words)
  • Y = structured output space (e.g., sequences of POS tags, trees, segmentation masks)
  • (xi​,yi​)i=1n​∼D — training data

The goal is to learn f:X→Y that minimises some task-specific loss Δ(y,y^​) (e.g., Hamming loss on sequences, tree edit distance on parse trees).

The key difficulty. ∣Y∣ is exponentially large. For a sequence of length T with K possible labels per position, ∣Y∣=KT. We cannot enumerate all outputs. Any tractable algorithm must exploit the structure of Y.

The key insight. We will define a scoring function s(x,y;θ)∈R and predict: y^​=argmaxy∈Y​s(x,y;θ)

If s decomposes over the structure of y, then this maximisation — called inference or decoding — can be solved efficiently by dynamic programming.

✦ 2. Sequence Labelling — The Problem in Concrete Form

Running example throughout this note: Part-of-speech (POS) tagging.

Input: x=[‘The”,‘cat”,“sat”] Output: y=[DET,NOUN,VERB]

The correct label of “sat” is VERB, and this is influenced by the fact that the previous tag is NOUN — the model should know NOUN → VERB is a common transition.

Why not just use a classifier at each position? We could train a multi-class classifier P(yt​∣x) and apply it independently at each timestep. This ignores two critical signals:

  1. Transition patterns: DET → NOUN is far more common than DET → VERB.
  2. Long-range context: the label of position t may depend on positions far away.

A sequence model encodes both.

✦ 3. Conditional Random Fields (CRFs)

3.1 From Logistic Regression to CRF

Logistic regression for a single label: P(y∣x)=∑y′​exp(w⊤ϕ(x,y′))exp(w⊤ϕ(x,y))​

where ϕ(x,y) is a feature vector. This is a log-linear model (also called a maximum entropy model).

The linear-chain CRF is exactly this — but the output y is now a sequence, and ϕ(x,y) is defined to decompose over the sequence. Define:

P(y∣x;w)=Z(x,w)1​exp!(∑t=1T​w⊤ϕ(x,yt​,yt−1​,t))

where: Z(x,w)=∑y′∈Y​exp!(∑t=1T​w⊤ϕ(x,yt′​,yt−1′​,t))

is the partition function (normalisation constant), and ϕ(x,yt​,yt−1​,t) is a feature vector that can look at the entire input x at position t, the current label yt​, and the previous label yt−1​.

Why “conditional”? A CRF models P(y∣x) directly — it is discriminative. Compare to a Hidden Markov Model (HMM), which models P(x,y) jointly — it is generative. The CRF does not need to model the distribution of inputs; it only models the output given input.

3.2 The Feature Function — What Goes In ϕ

The power of a CRF lies in the richness of the feature function ϕ(x,yt​,yt−1​,t). Typical features:

Feature typeExample feature
Emission1[wordt​="sat"∧yt​=VERB]
Transition1[yt−1​=NOUN∧yt​=VERB]
Prefix/suffix1[wordt​ ends in "-ing"∧yt​=VERB]
Context window1[wordt+1​="."∧yt​=NOUN]
Capitalisation1[wordt​ is capitalised∧yt​=NOUN]

Each feature is an indicator function (0 or 1). The weight vector w has one entry per feature. Training learns which features are informative.

Contrast with HMMs: An HMM must model P(wordt​∣yt​) as a probability distribution over all words — it cannot naturally use arbitrary features of the input. A CRF can.

3.3 Training — Maximum Conditional Log-Likelihood

Given training data (xi​,yi​)i=1n​, we maximise: L(w)=∑i=1n​logP(yi​∣xi​;w)=∑i=1n​[∑t=1Ti​​w⊤ϕ(xi​,yit​,yi,t−1​,t)−logZ(xi​,w)]

Computing the gradient. Taking ∇w​L: ∇w​L(w)=∑i=1n​​observed feature countst∑​ϕ(xi​,yit​,yi,t−1​,t)​​−expected feature countsEP(y∣xi​;w)​![t∑​ϕ(xi​,yt​,yt−1​,t)]​​​

The gradient is: observed counts minus expected counts under the model. This is the standard result for log-linear models — the same structure appears in logistic regression.

The hard part: computing the expectation — i.e., the partition function Z(x,w) and the marginals P(yt​,yt−1​∣x;w) — over all KT possible sequences. We need dynamic programming.

3.4 The Forward-Backward Algorithm

Define the score of a partial sequence ending with label k at position t: αt​(k)=∑y1:t​:yt​=k​exp!(∑s=1t​w⊤ϕ(x,ys​,ys−1​,s))

Forward recursion: αt​(k)=∑j=1K​αt−1​(j)⋅exp!(w⊤ϕ(x,k,j,t))

with base case α1​(k)=exp(w⊤ϕ(x,k,START,1)).

The partition function: Z(x,w)=∑k​αT​(k).

Backward recursion: similarly define βt​(k) summing over all extensions from position t to T: βt​(k)=∑j=1K​exp!(w⊤ϕ(x,j,k,t+1))⋅βt+1​(j)

Marginals: P(yt​=k,yt−1​=j∣x;w)=Z(x,w)αt−1​(j)⋅exp(w⊤ϕ(x,k,j,t))⋅βt​(k)​

Both forward and backward passes are O(K2T) — polynomial in sequence length, not exponential.

Complexity summary:

OperationComplexity
Naïve (enumerate all y)O(KT)
Forward-backward (train)O(K2T)
Viterbi (decode)O(K2T)

3.5 Decoding — The Viterbi Algorithm

At test time, we want: y^​=argmaxy∈Y​∑t​w⊤ϕ(x,yt​,yt−1​,t)

This is the maximum weight path in a trellis — solved by the Viterbi algorithm, which replaces the ∑ in the forward pass with max:

δt​(k)=maxy1:t−1​​∑s=1t​w⊤ϕ(x,ys​,ys−1​,s)​yt​=k​

Viterbi recursion: δt​(k)=maxj​[δt−1​(j)+w⊤ϕ(x,k,j,t)]

Store the argmax at each step for backtracing.

Trellis diagram for POS tagging (T=3, K=3 tags: DET, NOUN, VERB):

t=1 (The)    t=2 (cat)    t=3 (sat)
  DET -------> DET -------> DET
    \         /|\          /|\
     \       / | \        / | \
  NOUN -----> NOUN -----> NOUN
     /       \ | /        \ | /
    /         \|/          \|/
  VERB -------> VERB -------> VERB

Each arrow = transition score + emission score.
Viterbi finds the maximum-weight path through this graph.
Optimal path here: DET → NOUN → VERB.

3.6 CRF vs. HMM — A Precise Comparison

PropertyHMMLinear-Chain CRF
Model typeGenerative: P(x,y)Discriminative: P(y∥x)
Emission modelP(xt​∥yt​) — one word given tagϕ(x,yt​,t) — arbitrary features of entire x
TransitionP(yt​∥yt−1​) — Markovϕ(yt​,yt−1​) — same, but learned discriminatively
TrainingEM (Baum-Welch) or MLE on countsGradient ascent on conditional log-likelihood
DecodingViterbiViterbi (identical structure)
Performance on NLPGood baselineTypically stronger (richer features)

The key advantage of CRFs: you can add any features you want without worrying about whether they form a valid probability model. You cannot do this in an HMM.

✦ 4. Structured SVMs — Margin for Structured Outputs

4.1 Motivation

The CRF is a probabilistic model. The structured SVM is the large-margin alternative — it extends the binary SVM to arbitrary output spaces. This is sometimes called Structured Output Learning or the Max-Margin Markov Network (M³N).

Recall the binary SVM. We want: w⊤ϕ(x,y)−w⊤ϕ(x,y′)≥1∀y′=y

The left side is the score margin between the correct output and the best competitor. We want this margin to be at least 1.

4.2 The Structured SVM Objective

For structured outputs, we want the correct output yi​ to score higher than every other output y′∈Y by at least a task-specific margin Δ(yi​,y′):

w⊤ϕ(xi​,yi​)≥w⊤ϕ(xi​,y′)+Δ(yi​,y′)−ξi​∀y′=yi​

where ξi​≥0 is a slack variable and Δ(yi​,y′) is the task loss (e.g., Hamming distance between two label sequences).

This gives the optimisation problem: minw,ξ​21​∣w∣2+C∑i​ξi​ s.t.w⊤[ϕ(xi​,yi​)−ϕ(xi​,y′)]≥Δ(yi​,y′)−ξi​∀i,∀y′∈Y

The problem: there are exponentially many constraints (one per output y′ per training example). We cannot enumerate them.

The solution: Cutting-plane algorithms maintain a working set of active constraints and iterate:

  1. Solve the QP with the current working set.
  2. Find the most violated constraint for each training example — this is the key step.
  3. Add it to the working set.
  4. Repeat until convergence.

4.3 The Loss-Augmented Inference Step

Finding the most violated constraint for example i reduces to: yi∗​=argmaxy′∈Y​[Δ(yi​,y′)+w⊤ϕ(xi​,y′)−w⊤ϕ(xi​,yi​)]

Dropping the constant −w⊤ϕ(xi​,yi​): yi∗​=argmaxy′∈Y​[Δ(yi​,y′)+w⊤ϕ(xi​,y′)]

This is called loss-augmented inference — it is inference (finding the best output) but with the task loss Δ added to the score. For Hamming loss on sequences, this decomposes position-by-position and can be solved with a modified Viterbi in O(K2T) — the same complexity as standard decoding.

4.4 The Structured Hinge Loss

We can write the Structured SVM objective as minimising a regularised structured hinge loss: Lstruct​(w)=21​∣w∣2+C∑i​structured hinge loss for example iy′max​[Δ(yi​,y′)+w⊤ϕ(xi​,y′)]−w⊤ϕ(xi​,yi​)​​

The structured hinge loss is zero when the correct output scores higher than all others by the loss-weighted margin, and positive otherwise.

Comparison with binary SVM:

Binary SVMStructured SVM
Output space−1,+1Arbitrary Y
Margin1Δ(y,y′) (task-dependent)
Inference at test timesign(w⊤x)argmaxy​w⊤ϕ(x,y)
Training-time computationSolve a QPSolve a QP + loss-augmented inference
Key algorithmSMOCutting-plane + Viterbi (for sequences)

4.5 Connection: Structured SVM ↔ CRF

The structured SVM and the CRF are two approaches to the same problem. Their relationship:

  • CRF: log-linear model, trained with maximum likelihood. Produces probability estimates.
  • Structured SVM: margin-based model, trained with structured hinge loss. Does not produce probabilities.
  • Unifying perspective: both learn a scoring function s(x,y;w) of the form w⊤ϕ(x,y). They differ only in the loss function used to train w.

In practice, CRFs became the dominant approach in NLP because:

  1. Probabilistic outputs are useful downstream.
  2. Maximum likelihood has cleaner behaviour in the large-data regime.
  3. Deep learning made it natural to parameterise ϕ(x,yt​,yt−1​,t) with a neural network — the BiLSTM-CRF and Transformer-CRF architectures.

✦ 5. Application: Named Entity Recognition (NER)

NER: tag each word in a sentence with its entity type — PER (person), ORG (organisation), LOC (location), O (other).

Input: ["Barack", "Obama", "visited", "Paris"] Output: [B-PER, I-PER, O, B-LOC]

(BIO tagging scheme: B- = beginning of entity, I- = inside, O = outside.)

Why a CRF? B-PER followed by I-ORG is illegal — the CRF’s transition features learn to assign −∞ weight to such transitions. A flat classifier would not know this.

Features a linear-chain CRF might use:

  • Is the word capitalised? → strong signal for PER or ORG
  • Does the word appear in a gazetteer of known cities? → signal for LOC
  • Previous word is a title (“President”, “Dr.”)? → strong signal for B-PER
  • Transition: B-PER → I-PER vs. B-PER → O — the CRF learns this

Modern approach: Replace the hand-crafted ϕ with a BiLSTM or Transformer to compute a contextual embedding at each position. The CRF layer sits on top:

Input:  [Barack,   Obama,    visited,  Paris  ]
         ↓         ↓         ↓         ↓
BiLSTM: [h_1,     h_2,      h_3,      h_4    ]  ← contextual embeddings
         ↓         ↓         ↓         ↓
Emit:   [e(h_1),  e(h_2),   e(h_3),   e(h_4) ]  ← emission scores (K-dim)
         ↓         ↓         ↓         ↓
CRF:    [B-PER,   I-PER,    O,        B-LOC  ]  ← globally optimal sequence

The CRF layer adds K×K transition parameters on top of the neural emission scores. Viterbi decoding is applied at the output.

✦ 6. Other Structured Output Spaces

6.1 Sequence-to-Sequence (different input/output length)

For translation, summarisation, and similar tasks, the output sequence length differs from the input. The linear-chain CRF cannot handle this — the output structure no longer aligns position-by-position with the input.

Solutions:

  • Encoder-decoder with attention (the dominant approach): encode the input into a context vector, decode autoregressively. Not a CRF — instead uses a left-to-right language model.
  • CTC (Connectionist Temporal Classification): for speech recognition, where output phonemes don’t align to input frames.

6.2 Structured Outputs Over Trees

For constituency parsing, the output is a parse tree. The structured SVM generalises — you need:

  • A feature function ϕ(x,tree) that decomposes over tree nodes.
  • An efficient inference algorithm — in this case, the CKY (Cocke-Kasami-Younger) algorithm for context-free grammars.

6.3 Image Segmentation

Each pixel receives a label. The output space is a grid. A Markov Random Field (MRF) or CRF on a grid is the natural model — neighbouring pixels tend to have the same label. Inference on grids is harder than on chains (NP-hard in general) and requires approximate methods (graph cuts, mean field).

✦ 7. Connection to AI / ML / Deep Learning

7.1 The BiLSTM-CRF — State of the Art Before Transformers

The model of Lample et al. (2016) set the standard for NER:

  • BiLSTM encodes the sentence bidirectionally → contextual embeddings.
  • CRF decodes the label sequence respecting transition constraints.

This architecture is a structured prediction model where ϕ(x,yt​,yt−1​,t) is parameterised by a neural network. The Viterbi and forward-backward algorithms run exactly as above — the only difference is that emission scores come from a BiLSTM rather than hand-crafted features.

7.2 Transformers and Structured Outputs

Modern approaches (BERT-based NER, T5, etc.) often drop the CRF layer entirely, relying on the Transformer’s attention mechanism to model inter-label dependencies implicitly. But CRF layers are still used when:

  • Hard constraints matter (e.g., no I-PER without a preceding B-PER).
  • The training set is small (CRF transition constraints act as regularisation).
  • Calibrated probabilities are needed.

7.3 Structured Outputs in Reinforcement Learning

The policy π(a∣s) in RL is a structured output when the action space has structure. Sequence-to-sequence models trained with RLHF (Reinforcement Learning from Human Feedback) generate tokens autoregressively — this is structured prediction with an RL objective.

7.4 The Argmax Bottleneck and Differentiable Structure

A core challenge: the argmax in structured prediction is not differentiable, which complicates end-to-end training with neural networks. Active research directions:

MethodIdea
STE (Straight-Through Estimator)Treat argmax as identity in backward pass
Gumbel-SoftmaxContinuous relaxation of categorical sampling
CRF with marginal inferenceReplace argmax with expected feature counts — differentiable
SPIGOTProject gradient through argmax using polytope geometry

These are active research areas connecting structured prediction to deep learning.

Define emission scores (already computed from w⊤ϕ):

t=1 (cat)t=2 (sat)
N1.50.2
V0.32.0

Transition scores (learned):

→ N→ V
START0.80.1
N →0.61.2
V →0.40.9

Forward pass (αt​(k) in log-space =logα, actually in score space here for clarity):

t=1: α1​(N)=exp(0.8+1.5)=e2.3≈9.97 α1​(V)=exp(0.1+0.3)=e0.4≈1.49

t=2: α2​(N)=α1​(N)⋅e0.6+0.2+α1​(V)⋅e0.4+0.2 =9.97⋅e0.8+1.49⋅e0.6≈9.97⋅2.23+1.49⋅1.82≈22.23+2.71=24.94

α2​(V)=α1​(N)⋅e1.2+2.0+α1​(V)⋅e0.9+2.0 =9.97⋅e3.2+1.49⋅e2.9≈9.97⋅24.53+1.49⋅18.17≈244.6+27.1=271.7

Partition function: Z=α2​(N)+α2​(V)≈24.94+271.7=296.64

Posterior of N → V (the true sequence “cat sat” = NOUN VERB): P(N,V∣x)=Zα1​(N)⋅e1.2+2.0​=296.649.97⋅24.53​≈296.64244.6​≈0.824

The model assigns 82.4% probability to the correct sequence — before any training.

Viterbi decoding would trace back the path through the trellis:

  • At t=2: V wins (α2​(V)=271.7≫α2​(N)=24.94)
  • Backtrack: best predecessor of V at t=2 is N (score 9.97⋅e3.2=244.6 vs 1.49⋅e2.9=27.1)
  • Prediction: [N, V] = [NOUN, VERB] ✓

  1. Derive the CRF partition function and explain why it requires the forward algorithm — not brute-force enumeration.
  2. State the complexity of the forward-backward and Viterbi algorithms and explain where the K2 factor comes from.
  3. Write the CRF gradient in terms of observed vs. expected feature counts and explain why this is the same structure as logistic regression.
