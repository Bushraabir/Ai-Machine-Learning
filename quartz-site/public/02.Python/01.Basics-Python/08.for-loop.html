08.for loop

Apr 27, 202610 min read

A for loop iterates over the items of any iterable — one item at a time — and executes a block of code for each item. An iterable is any object that can return its elements sequentially: lists, tuples, strings, dicts, sets, ranges, files, generators, and more.

Python’s for loop is not a counting loop like in C or Java. It is a for-each loop. It does not operate on indices by default — it operates on values directly.

range() → Counting Loops

range() generates a sequence of integers. It does not create a list in memory — it produces values on demand (lazy evaluation).

range() with a negative step iterates backwards. range(start, stop, step) — stop is always exclusive.

Loop Control:

  • break (Exit the Loop Early)

Stops the loop immediately and exits, regardless of remaining items.

Common use: searching for the first match.

  • continue (Skip to the Next Iteration)

Skips the rest of the current iteration and moves to the next item.

Use continue to filter out unwanted items cleanly, avoiding deeply nested if blocks inside loops.

  • else Clause on a for Loop

The else block runs after the loop completes normally — only if the loop was NOT exited by break.

The for/else pattern is useful for search loops where you need to know if the loop completed without finding a match.

This pattern is unique to Python. It is not widely known but is cleaner than using a flag variable.

For very large sequences, use a generator expression instead of a list comprehension. It produces values one at a time without loading everything into memory.

The generator version uses a fraction of the memory. For ML datasets with millions of rows, this distinction matters enormously.
