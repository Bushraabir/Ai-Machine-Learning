17.Nested data structures

Apr 24, 20269 min read

Core Idea

A nested data structure is any collection that contains other collections as elements. Python places no restriction on what a list, dict, set, or tuple can hold — including other lists, dicts, sets, and tuples, to any depth.

Nested structures are everywhere — JSON responses, dataset records, graph representations, configuration files, ML model parameters. Fluency with them is non-negotiable.

JSON — the Real-World Nested Structure

JSON maps directly to Python nested dicts and lists. Knowing how to navigate JSON is knowing how to navigate nested Python structures.

API responses, dataset metadata, model configs — all of this is JSON. Navigating it is identical to navigating nested Python dicts and lists.
