34. iter() and next()

“An iterator is a machine that produces one value at a time, on demand. Understanding it is understanding how Python’s entire for loop works under the hood.”

Prerequisites: 26.Classes and objects · 27.init, self · 32.Dunder or magic methods · 33.Encapsulation basics

The Problem Iterators Solve

Suppose you have a billion-element dataset. Loading it all into a list and then looping over it requires a billion elements in memory simultaneously. An iterator gives you one element at a time — the next element is computed only when asked for. Memory usage stays constant regardless of dataset size.

This is the lazy evaluation model. It is foundational to how Python handles for loops, file reading, database cursors, and — critically — how PyTorch DataLoader feeds batches to a neural network.

Two Distinct Protocols

Python separates two concerns cleanly:

ProtocolDunder MethodsRole
Iterable__iter__”I can produce an iterator”
Iterator__iter__ + __next__”I am the thing that yields values one by one”

Every iterator is also an iterable (it returns itself from __iter__). Not every iterable is an iterator — a list is iterable but not an iterator; it produces a fresh iterator each time you iterate over it.

iter() — Obtaining an Iterator

iter(obj) calls obj.__iter__() and returns an iterator object.

The list nums itself has not changed. it is a separate object that maintains a position pointer into nums.

next() — Advancing the Iterator

next(it) calls it.__next__(). It returns the next value and advances the internal pointer. When exhausted, it raises StopIteration.

StopIteration is not an error to be alarmed by — it is the signal Python’s for loop uses to know when to stop.

iter() with a Sentinel — The Two-Argument Form

iter(callable, sentinel) is a lesser-known but powerful pattern. It calls callable() repeatedly and stops when the return value equals sentinel.

The sentinel form is elegant for consuming streams where you don’t know the length in advance.

Relation to Built-ins That Return Iterators

Many Python built-ins return iterators, not lists. This is intentional — they are lazy.

Connection to AI/ML and Deep Learning

PyTorch DataLoader — Industrial Iterator

The most important iterator you will use in deep learning is torch.utils.data.DataLoader. It is an iterator over your dataset that handles batching, shuffling, and parallel data loading.

Under the hood, DataLoader.__iter__ returns a _SingleProcessDataLoaderIter or _MultiProcessingDataLoaderIter. Each __next__ call collates a batch from the dataset. The for loop drives this via the exact protocol you just learned.

Why lazy loading matters at scale: ImageNet has 1.2 million high-resolution images. Loading the full dataset into RAM is impossible. The DataLoader iterator reads only the current batch from disk, preprocesses it, and yields it. Memory usage is bounded by batch_size, not dataset size.

Summary

The iterator protocol is two dunder methods: __iter__ returns an iterator, __next__ returns the next value and raises StopIteration when done. Every for loop, every comprehension, every map, filter, zip, and enumerate runs on this protocol. The distinction between an iterable (can produce an iterator) and an iterator (is the thing producing values) is the most important conceptual boundary in this note.
