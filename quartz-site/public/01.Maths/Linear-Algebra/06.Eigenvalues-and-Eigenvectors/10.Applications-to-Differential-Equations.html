The Central Problem

A system of first-order linear ODEs with constant coefficients:

dtdu​=Au,u(0)=u0​

where A is an n×n constant matrix and u(t)∈Rn. This is the continuous-time analogue of the discrete recurrence uk+1​=Auk​ from Matrix Powers. Every structural question about the solution — does it grow, decay, oscillate, blow up — is answered by the eigenvalues of A.

The scalar case u′=au has solution u(t)=eatu0​. The matrix case has solution u(t)=eAtu0​. Eigenvalues tell us what eAt does.

Why Eigenvectors Decouple the System

Suppose Ax=λx. Try the ansatz u(t)=eλtx:

dtdu​=λeλtx=eλt(Ax)=A(eλtx)=Au

It solves the equation exactly. Each eigenvector gives a pure mode solution. The system is decoupled in the eigenvector basis — each mode evolves independently.

If A has n linearly independent eigenvectors x1​,…,xn​ with eigenvalues λ1​,…,λn​, the general solution is:

u(t)=c1​eλ1​tx1​+c2​eλ2​tx2​+⋯+cn​eλn​txn​

Apply the initial condition u(0)=u0​:

u0​=c1​x1​+c2​x2​+⋯+cn​xn​

This is Pc=u0​, so c=P−1u0​. The complete solution is:

u(t)=eAtu0​=PeDtP−1u0​

where eDt is diagonal with entries eλi​t.

Personal note: this is the continuous-time mirror of Ak=PDkP−1 from Matrix Powers. Replace λik​ with eλi​t. The structure is identical. Strang points this out explicitly and it is worth internalizing — discrete and continuous dynamics are the same linear algebra, different functions applied to the eigenvalues.

The Matrix Exponential

The solution operator eAt deserves its own definition. Define it by the power series:

eAt=I+At+2!(At)2​+3!(At)3​+⋯=∑k=0∞​k!(At)k​

This converges for all t and all matrices A. It satisfies:

  • eA⋅0=I
  • dtd​eAt=AeAt
  • If AB=BA then e(A+B)t=eAteBt
  • (eAt)−1=e−At

For diagonalizable A=PDP−1:

eAt=PeDtP−1,eDt=(eλ1​t​​ ​⋱​ ​​eλn​t​)

For a Jordan block Jk​(λ0​) (when A is not diagonalizable):

eJk​(λ0​)t=eλ0​t(1​t​2!t2​​⋯​(k−1)!tk−1​ 0​1​t​⋯​(k−2)!tk−2​ ⋮​​⋱​​⋮ 0​⋯​​0​1​)

The polynomial factors tj/j! are the signature of a defective eigenvalue. Solutions involving a Jordan block of size k grow like tk−1eλ0​t.

Stability

The most important qualitative question: does u(t)→0 as t→∞?

From the general solution u(t)=∑ci​eλi​txi​, each mode decays if and only if Re(λi​)<0.

Theorem. The system u′=Au is asymptotically stable (all solutions decay to zero) if and only if every eigenvalue of A has strictly negative real part.

Eigenvalue conditionBehavior
All Re(λi​)<0Stable: all solutions decay to 0
Some Re(λi​)>0Unstable: some solutions grow without bound
All Re(λi​)≤0, some =0Neutrally stable (or unstable if defective)
λ=±bi (purely imaginary)Oscillates without decay

The last row deserves attention. A purely imaginary eigenvalue λ=bi gives a factor ebit=cos(bt)+isin(bt) — pure oscillation. For a defective purely imaginary eigenvalue, the Jordan block contributes a factor of t, and the solution grows like t⋅ebit. Neutral stability is fragile.

Worked Example: 2×2 Decoupled System

\frac{d}{dt}\begin{pmatrix}u\v\end{pmatrix} = \begin{pmatrix}-1 & 0 \ 0 & -3\end{pmatrix}\begin{pmatrix}u\v\end{pmatrix}, \qquad \begin{pmatrix}u(0)\v(0)\end{pmatrix} = \begin{pmatrix}2\5\end{pmatrix}

A is already diagonal. Eigenvalues λ1​=−1, λ2​=−3, eigenvectors e1​,e2​.

(u(t)(ˇ​t)​)=2e−t(1\0​)+5e−3t(0\1​)=(2e−t\5e−3t​)

Both eigenvalues negative: stable. The e−3t mode decays faster; for large t, the solution approaches zero along the u-axis direction.

Worked Example: 2×2 Coupled System

\frac{d}{dt}\begin{pmatrix}u\v\end{pmatrix} = \begin{pmatrix}1 & 2 \ 0 & -1\end{pmatrix}\begin{pmatrix}u\v\end{pmatrix}, \qquad \begin{pmatrix}u(0)\v(0)\end{pmatrix} = \begin{pmatrix}3\1\end{pmatrix}

Eigenvalues: λ1​=1, λ2​=−1 (upper triangular, read diagonal).

Eigenvectors:

For λ1​=1: (A−I)=(0​2\0​−2​), giving v=0, u free. x1​=(1\0​).

For λ2​=−1: (A+I)=(2​2\0​0​), giving u+v=0. x2​=(1\-1​).

Initial conditions: c1​x1​+c2​x2​=(3\1​):

\begin{pmatrix}1 & 1\0 & -1\end{pmatrix}\begin{pmatrix}c_1\c_2\end{pmatrix} = \begin{pmatrix}3\1\end{pmatrix}

Row 2: −c2​=1⇒c2​=−1. Row 1: c1​=3−c2​=4.

Solution:

(u(t)(ˇ​t)​)=4et(1\0​)−e−t(1\-1​)=(4et−e−t\e−t​)

Stability: λ1​=1>0. Unstable. The et mode grows. The e−t mode is irrelevant for large t — the solution is dominated entirely by the c1​etx1​ term.

Worked Example: Complex Eigenvalues — Oscillation

\frac{d}{dt}\begin{pmatrix}u\v\end{pmatrix} = \begin{pmatrix}0 & -\omega \ \omega & 0\end{pmatrix}\begin{pmatrix}u\v\end{pmatrix}

This is a pure rotation matrix scaled by ω. Eigenvalues: λ=±iω (purely imaginary).

The complex solution involves eiωt=cosωt+isinωt. Taking real and imaginary parts, the real general solution is:

(u(t)(ˇ​t)​)=c1​(cosωtsinωt​)+c2​(−sinωtcosωt​)

Every solution is a circle in the (u,v) plane, traversed with angular frequency ω. No decay, no growth. Neutral stability.

This is the matrix form of simple harmonic motion.

Second-Order ODEs Reduced to First-Order Systems

A single second-order ODE

u′′+bu′+cu=0

becomes a first-order system by setting \mathbf{u} = \begin{pmatrix}u\u'\end{pmatrix}:

\frac{d}{dt}\begin{pmatrix}u\u'\end{pmatrix} = \begin{pmatrix}0 & 1\-c & -b\end{pmatrix}\begin{pmatrix}u\u'\end{pmatrix}

The companion matrix A=(0​1\-c​−b​) has characteristic polynomial:

det(A−λI)=λ2+bλ+c=0

which is exactly the characteristic equation you would write down directly for u′′+bu′+cu=0. The eigenvalues of the companion matrix are the roots of the characteristic equation of the ODE. This is not a coincidence — it is the same object.

Example: damped harmonic oscillator. u′′+2u′+5u=0.

Characteristic equation: λ2+2λ+5=0⇒λ=−1±2i.

Real part −1<0: stable. Imaginary part ±2: oscillates at frequency 2. The solution decays while oscillating:

u(t)=e−t(c1​cos2t+c2​sin2t)

This is underdamped oscillation. The three regimes:

Discriminant b2−4cEigenvaluesRegime
<0α±iβ, α<0Underdamped: decaying oscillation
=0Repeated real λ=−b/2Critically damped: (c1​+c2​t)eλt
>0Two distinct realOverdamped: sum of two exponentials

The critically damped case has a repeated eigenvalue. If b2=4c, the companion matrix has a defective eigenvalue and is not diagonalizable. The Jordan block produces the factor of t in (c1​+c2​t)eλt — exactly as predicted by Nondiagonalizable Matrices Jordan Form.

Decoupling via Eigenvectors: The Change of Variables

The technique in all of the above is one idea. If A=PDP−1, substitute u=Pv:

Pv′=APv=PDP−1Pv=PDv

v′=Dv

The system in v is diagonal — n independent scalar equations:

vi′​=λi​vi​⟹vi​(t)=vi​(0)eλi​t

Transform back: u(t)=Pv(t). This is the eigenvector decomposition written as a change of variables. The eigenvector basis diagonalizes the system.

Exponential of a Non-Diagonalizable Matrix

When A=PJP−1 with J the Jordan form, the matrix exponential is:

eAt=PeJtP−1

and eJt is block diagonal with blocks eJk​(λi​)t as given above. For a 2×2 Jordan block:

eJ2​(λ0​)t=eλ0​t(1​t 0​1​)

This gives the solution structure for a defective system. The extra factor of t is the continuous-time version of the polynomial correction in Jm from Nondiagonalizable Matrices Jordan Form.

Example: A=(3​1 0​3​), a single Jordan block.

eAt=e3t(1​t 0​1​)

General solution with initial condition u0​=(a\b​):

u(t)=e3t(a+bt b​)

The v-component decays like a pure exponential; the u-component grows like te3t. The eigenvalue is 3>0, so the system is unstable. But even if λ0​<0, the teλ0​t term would still be present — it decays to zero, but slower than eλ0​t alone for large t.

Fourier Series and Differential Equations

The connection between Fourier Series and differential equations is that sines and cosines are the eigenfunctions of d2/dx2.

On [0,π] with boundary conditions u(0)=u(π)=0:

−dx2d2u​=λu

The solutions are un​(x)=sin(nx) with eigenvalues λn​=n2. These are the eigenvectors of the differential operator −d2/dx2, which is a Hermitian operator on function space.

The Fourier sine series is the eigenfunction expansion of a function in this operator’s eigenbasis. Solving the heat equation ut​=uxx​ amounts to writing u(x,0) in the Fourier basis and letting each mode decay:

u(x,t)=∑n=1∞​bn​e−n2tsin(nx)

The eigenvalue λn​=n2 appears in the exponent as e−n2t. Higher modes decay faster. This is the continuous-spectrum analogue of u(t)=∑ci​eλi​txi​. Same structure, infinite-dimensional.

Everything reduces to: find the eigenvalues, find the eigenvectors, write the initial condition in the eigenvector basis, let each mode evolve independently.
