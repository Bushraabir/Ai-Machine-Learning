23.Positive Semidefinite Matrices

23.Positive Semidefinite Matrices

Apr 07, 202611 min read

The Definition

A real symmetric matrix A is positive semidefinite (PSD) if for every x∈Rn:

xTAx≥0

The difference from positive definite (PD) is the ≥ instead of >. The quadratic form is allowed to be zero for nonzero x.

That single change — allowing equality — has deep consequences. PSD matrices can be singular. Their null space is nontrivial. The level set x:xTAx=0 is no longer just the origin — it is the entire null space of A. The geometry collapses in certain directions.

I want to understand PSD not just as “PD with some eigenvalues equal to zero” but as its own object with its own character.

The Canonical Example: ATA

The single most important class of PSD matrices is Gram matrices.

For any matrix A (not necessarily square, not necessarily symmetric), the matrix ATA is always symmetric and positive semidefinite.

Proof.

Symmetry: (ATA)T=AT(AT)T=ATA. ✓

Semidefiniteness: for any x, xT(ATA)x=(Ax)T(Ax)=∣Ax∣2≥0

This is zero when Ax=0, i.e., when x∈ker(A).

So:

  • ATA is positive definite ⟺ ker(A)=0 ⟺ A has linearly independent columns.
  • ATA is positive semidefinite but not definite ⟺ A has a nontrivial null space ⟺ A has dependent columns.

Every PSD matrix is a Gram matrix of some other matrix. This is not obvious — it follows from the Cholesky-type factorization I will prove below.

Five Tests, Adjusted for Semidefiniteness

For a real symmetric matrix A, the following are equivalent:

  1. xTAx≥0 for all x (definition)
  2. All eigenvalues λi​≥0
  3. All pivots di​≥0 (with possible zeros, requiring row exchanges or stopping)
  4. All leading subdeterminants det(Ak​)≥0
  5. A=RTR for some matrix R (columns may be dependent)

The proofs of 1⟺2 and 1⟺5 are almost identical to the PD case, with > replaced by ≥ throughout.

Test 3 is the delicate one. When a pivot is zero, Gaussian elimination stalls — there is nothing to eliminate with. The matrix is singular and the LDLT factorization in the full sense does not exist. But the sign of the pivots that do exist is still meaningful, and the rank of A equals the number of nonzero pivots.

Test 4 is also more subtle. For PD, all det(Ak​)>0. For PSD, some det(Ak​) may be zero. But the first time a leading subdeterminant is zero signals a zero pivot at that stage, which signals a zero eigenvalue arriving at that level of the induction.

Proof: Test 1 ⟺ Test 2

Since A is symmetric, A=QΛQT. Let y=QTx:

xTAx=yTΛy=∑i=1n​λi​yi2​

This is ≥0 for all y iff every λi​≥0. □

The zero directions: if λk​=0 for some k, then taking y=ek​ (the k-th standard basis vector) gives xTAx=0, with x=Qek​=qk​=0.

Proof: Test 1 ⟺ Test 5

(5⇒1). If A=RTR:

xTAx=xTRTRx=∣Rx∣2≥0

Zero when Rx=0 — possible even for x=0 if R has dependent columns.

(1⇒5). If A is PSD, all eigenvalues λi​≥0, so λi​​ is real. Define Λ1/2=diag(λ1​​,…,λn​​). Then:

A=QΛQT=QΛ1/2Λ1/2QT=(QΛ1/2)(QΛ1/2)T=RTR

where RT=QΛ1/2, i.e., R=Λ1/2QT.

Note: if some λi​=0, the corresponding column of RT=QΛ1/2 is zero, so R has dependent columns. Consistent with the observation above. □

The matrix A1/2:=QΛ1/2QT is the square root of A — a PSD matrix satisfying (A1/2)2=A. This only makes sense because eigenvalues are non-negative. For an indefinite matrix the square root does not exist (over R).

Rank and the Null Space

For a PSD matrix A:

ker(A)=eigenspace for λ=0

Proof. If Ax=0 then certainly Ax=0⋅x, so x is an eigenvector for λ=0.

Conversely, if λk​=0 and Aqk​=0, then qk​∈ker(A). □

This means:

rank(A)=n−dim(kerA)=number of nonzero eigenvalues=number of nonzero pivots

For a PD matrix, ker(A)=0 so A is invertible. For a PSD matrix that is not PD, A is singular. The null space is the “flat” direction of the quadratic form — the directions along which A neither stretches nor compresses, because it collapses them to zero.

The Geometry: Collapsed Ellipsoid

For PD, the level set x:xTAx=1 is a bounded ellipsoid with all finite, nonzero semi-axes 1/λi​​.

For PSD with some λk​=0: the “semi-axis” in the qk​ direction is 1/0​=∞. The ellipsoid degenerates — it becomes an infinite cylinder (or slab, or all of Rn if all eigenvalues are zero). The level set xTAx=1 is unbounded.

Equivalently, xTAx=0 is satisfied by the entire subspace ker(A)=spanqk​:λk​=0, not just the origin. The quadratic form is flat along the null space.

This is the geometric distinction I should keep in mind: PD = compact ellipsoid, PSD = degenerate collapsed ellipsoid extending to infinity in the null directions.

A Worked Example

A=[1​1​0 1​1​0 0​0​2​]

Test 2 (eigenvalues):

tr(A)=4, det(A)=0 (rows 1 and 2 are identical, so A is singular).

Since det(A)=λ1​λ2​λ3​=0, at least one eigenvalue is zero.

The matrix has rank 2 (two independent rows: row 1 and row 3). So the null space is 1-dimensional, meaning exactly one zero eigenvalue.

For the third row acting independently: by inspection, A[0\0\1​]=[0\0\2​]=2[0\0\1​], so λ=2 with eigenvector q3​=[0\0\1​].

The null space: Ax=0 gives x1​+x2​=0 and 2x3​=0, so x=t[1\-1\0​]. Zero eigenvalue with eigenvector q1​=2​1​[1\-1\0​].

Remaining eigenvalue: tr(A)=λ1​+λ2​+λ3​=0+λ2​+2=4, so λ2​=2 with eigenvector orthogonal to both q1​ and q3​: q2​=2​1​[1\1\0​].

Eigenvalues: 0,2,2. All ≥0. PSD (not PD). ✓

Test 1 (quadratic form):

xTAx=x12​+2x1​x2​+x22​+2x32​=(x1​+x2​)2+2x32​≥0

Zero when x1​+x2​=0 and x3​=0, i.e., along [1\-1\0​] — exactly the null space. ✓

Test 5 (factorization):

A=RTR with R=Λ1/2QT. Since λ1​=0, the first row of R is the zero vector. But we can also read it from the quadratic form directly: xTAx=(x1​+x2​)2+(2​,x3​)2=∣Rx∣2 with

R=[1​1​0 0​0​2​​]

A 2×3 matrix — fewer rows than columns, hence dependent columns. ATA of this R is not A, but RTR is:

RTR=[1​0\1​0\0​2​​][1​1​0\0​0​2​​]=[1​1​0\1​1​0\0​0​2​]=A✓

PSD is Closed Under Addition and Positive Scaling

If A and B are PSD, then:

  • A+B is PSD: xT(A+B)x=xTAx+xTBx≥0.
  • cA is PSD for any c≥0: xT(cA)x=c(xTAx)≥0.

This makes the set of n×n PSD matrices a convex cone in the space of symmetric matrices. Any non-negative linear combination of PSD matrices is PSD.

This is heavily used in optimization — semidefinite programming (SDP) optimizes a linear objective over this cone, and it is one of the richest and most useful classes of convex optimization problems.

PSD vs PD: The Boundary

PD matrices form an open set in the space of symmetric matrices. You can perturb a PD matrix slightly in any direction and it remains PD (all eigenvalues stay positive under small perturbation).

PSD matrices that are not PD sit on the boundary of this open set. A PSD matrix with a zero eigenvalue is “one perturbation away” from becoming indefinite — perturb it in the wrong direction and a zero eigenvalue becomes negative.

Concretely: Aϵ​=A+ϵI is PD for any ϵ>0 if A is PSD (since eigenvalues of Aϵ​ are λi​+ϵ>0). This is called Tikhonov regularization — adding ϵI to a singular or near-singular PSD matrix to make it invertible. The price is a small perturbation of the solution; the gain is numerical stability.

PSD in Statistics: Covariance Matrices

Every covariance matrix is PSD. If X is a random vector with mean μ, the covariance matrix is:

Σ=E[(X−μ)(X−μ)T]

This is PSD because it is an expectation of rank-one PSD matrices vvT (each outer product (X−μ)(X−μ)T satisfies xTvvTx=(vTx)2≥0). Expectations preserve the inequality.

Σ is PD iff no component of X is an exact linear combination of the others — i.e., no perfect collinearity. If some variables are perfectly linearly dependent, Σ is PSD but singular.

In principal component analysis (PCA), the covariance matrix Σ is diagonalized as Σ=QΛQT, the eigenvectors give the principal axes of variation, and the eigenvalues give the variance in each direction. Zero eigenvalues correspond to directions of zero variance — flat, degenerate directions in the data.

The Loewner Order

PSD matrices carry a natural partial order. For two symmetric matrices A and B:

A⪰B⟺A−B is PSD

This is the Loewner order (or semidefinite order). It satisfies:

  • A⪰A (reflexive)
  • A⪰B and B⪰A ⟹ A=B (antisymmetric)
  • A⪰B and B⪰C ⟹ A⪰C (transitive)

But it is only a partial order — most pairs of symmetric matrices are incomparable.

In this order, A⪰0 means A is PSD, and A≻0 means A is PD. The PSD cone is the set of matrices ⪰0 in the Loewner order.

This notation appears constantly in optimization, control theory, and statistics, so it is worth knowing.

Things to Come Back To

  • Semidefinite programming (SDP): optimization over the PSD cone. The feasible set is convex (the PSD cone is convex), and the objective is linear in the matrix variable. Far more expressive than linear programming.
  • The matrix square root A1/2 and its uniqueness for PSD matrices: among all PSD matrices B with B2=A, there is exactly one. This is not true for indefinite matrices.
  • Moore-Penrose pseudoinverse: for a PSD matrix A with spectral decomposition A=QΛQT, the pseudoinverse is A+=QΛ+QT where Λ+ replaces each nonzero λi​ with 1/λi​ and leaves zeros as zeros. This gives the minimum-norm least-squares solution.
  • Kernel methods in machine learning: kernel matrices are PSD by construction, and the theory of reproducing kernel Hilbert spaces is built entirely on PSD operators.

Summary

A real symmetric matrix is positive semidefinite when xTAx≥0 for all x, with the equality allowed for nonzero x — specifically for x∈ker(A). The five tests from positive definiteness carry over with > replaced by ≥, except that test 3 (pivots) becomes delicate when a pivot is zero and elimination stalls. The Gram matrix ATA is the canonical example and the factorization A=RTR characterizes PSD completely. The geometry is a degenerate ellipsoid: finite axes in the positive eigenvalue directions, infinite extent in the null space directions. PSD matrices form a convex cone, closed under addition and positive scaling, and the Loewner order A⪰B generalizes the notion of “larger” to symmetric matrices. The PSD condition is everywhere in applications — covariance matrices, kernel matrices, Hessians at saddle points, and the constraints of semidefinite programs.
