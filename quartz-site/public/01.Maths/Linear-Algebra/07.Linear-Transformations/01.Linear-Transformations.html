01.Linear Transformations

01.Linear Transformations

Apr 14, 20268 min read

Why this matters — before any definition

Every matrix A is secretly a function. When I write Ax, I am not just doing arithmetic — I am applying a rule that sends every vector x in Rn to some vector in Rm. The whole machinery of linear algebra — null spaces, eigenvalues, diagonalization — is really the study of what these functions do to space.

The punchline I want to internalize: linear transformations are the morphisms of linear algebra. They are the maps that respect the structure. Everything else is a consequence of that.

The Definition

Let V and W be vector spaces over a field F (think R for now, but nothing stops us from working over C later).

Definition. A function T:V→W is a linear transformation if it satisfies two axioms for all u,v∈V and all scalars c∈F:

T(u+v)=T(u)+T(v)(additivity)

T(cu)=c,T(u)(homogeneity)

These two can be collapsed into a single condition:

T(cu+dv)=c,T(u)+d,T(v)

and by induction, T preserves all linear combinations:

T!(∑i=1k​ci​vi​)=∑i=1k​ci​,T(vi​)

This is the essential point. A linear transformation is completely determined by what it does to a basis. Once I know T(e1​),T(e2​),…,T(en​), I know everything.

Immediate consequences — things to prove, not memorize

Proposition 1. T(0)=0.

Proof. T(0)=T(0⋅0)=0⋅T(0)=0. □

This is a quick check: if a candidate map doesn’t send zero to zero, it is not linear. Full stop.

Proposition 2. T(−v)=−T(v).

Proof. T(−v)=T((−1)v)=(−1)T(v)=−T(v). □

The matrix representation — the big theorem

This is where abstraction meets computation.

Theorem. Let V=Rn with standard basis e1​,…,en​ and W=Rm. Every linear transformation T:Rn→Rm is of the form T(x)=Ax for a unique m×n matrix A.

Proof. Write any x∈Rn as x=x1​e1​+⋯+xn​en​. By linearity:

T(x)=x1​T(e1​)+x2​T(e2​)+⋯+xn​T(en​)

Now define A to be the matrix whose j-th column is T(ej​):

A=[∣​∣​​∣ T(e1​)​T(e2​)​⋯​T(en​) ∣​∣​​∣​]

Then the expression above is exactly matrix-vector multiplication Ax. Uniqueness: if Bx=Ax for all x, plug in ej​ to get B‘s columns equal A‘s columns, so B=A. □

The moral. To find the matrix of any linear transformation from Rn, just feed in the standard basis vectors one at a time and record the outputs as columns.

A worked example — rotation in R2

Let T:R2→R2 be counterclockwise rotation by angle θ.

Feed in e1​=[1 0​]. After rotation:

T(e1​)=[cosθ sinθ​]

Feed in e2​=[0 1​]. After rotation:

T(e2​)=[−sinθ cosθ​]

So the rotation matrix is:

Rθ​=[cosθ​−sinθ sinθ​cosθ​]

Notice: det(Rθ​)=cos2θ+sin2θ=1. Rotations preserve area and orientation. That is not a coincidence — it is encoded in the determinant.

Kernel and Image

These are the two fundamental subspaces of a linear map.

Definition. The kernel (or null space) of T:V→W is:

ker(T)=v∈V:T(v)=0

Definition. The image (or range) of T is:

im(T)=T(v):v∈V⊆W

Proposition. ker(T) is a subspace of V and im(T) is a subspace of W.

Proof (kernel). If T(u)=T(v)=0, then T(u+v)=T(u)+T(v)=0, and T(cu)=cT(u)=0. Closed under addition and scalar multiplication, and contains 0. □

In matrix language: ker(T)=N(A) (the null space) and im(T)=C(A) (the column space).

The Rank-Nullity Theorem

This is one of the most elegant facts in linear algebra. I should know this cold.

Theorem (Rank-Nullity). Let T:V→W be a linear transformation with dimV=n<∞. Then:

dim(kerT)+dim(imT)=n

or equivalently, nullity(T)+rank(T)=n.

Proof. Let v1​,…,vk​ be a basis for ker(T). Extend it to a basis of V:

v1​,…,vk​,u1​,…,un−k​

I claim T(u1​),…,T(un−k​) is a basis for im(T).

Spanning: Any T(x) with x=∑ci​vi​+∑dj​uj​ gives

T(x)=∑ci​=0T(vi​)​​+∑dj​T(uj​)=∑dj​T(uj​)

so the T(uj​) span im(T).

Independence: Suppose ∑dj​T(uj​)=0. Then T!(∑dj​uj​)=0, so ∑dj​uj​∈ker(T). Write it as a linear combination of the vi​‘s. But vi​,uj​ is a basis, so all coefficients are zero — in particular all dj​=0.

Therefore dim(imT)=n−k and dim(kerT)=k, giving k+(n−k)=n. □

What this says concretely. For an m×n matrix A:

rank(A)+nullity(A)=n

Every “dimension lost” into the null space is a “dimension lost” from the output. The theorem is a conservation law.

Composition and matrix multiplication — the real reason AB is defined the way it is

If T:Rp→Rn has matrix B and S:Rn→Rm has matrix A, then the composition S∘T:Rp→Rm is also linear (easy to check), and its matrix is AB.

This is why matrix multiplication is defined the way it is. It is not an arbitrary rule. It is the formula that makes the correspondence between linear maps and matrices preserve composition.

composition of maps(S∘T)(x)​​=A(Bx)​=product of matrices(AB)x​​

The non-commutativity of matrix multiplication (AB=BA in general) reflects the non-commutativity of function composition — rotate then reflect is different from reflect then rotate.

Invertible transformations

T:V→W is invertible if there exists T−1:W→V with T−1∘T=idV​ and T∘T−1=idW​.

Proposition. T is invertible if and only if it is bijective (injective and surjective).

Injective ⟺ ker(T)=0.
Surjective ⟺ im(T)=W.

For a square matrix A (n×n): A is invertible ⟺ ker(A)=0 ⟺ rank(A)=n ⟺ det(A)=0. These are all equivalent. I should be able to go between them without thinking.

General vector spaces — the abstract version

Nothing above required V=Rn. Here are the examples I should keep in mind:

Pn​ (polynomials deg ≤n)Pn−1​T(p)=p′ (differentiation)constant polynomials

Differentiation is linear. Integration (as a map from C[a,b] to R) is linear. The transpose map A↦AT is linear. These are not exotic — they are everywhere.

The matrix of T in a general basis

Suppose V has basis B=b1​,…,bn​ and W has basis C=c1​,…,cm​.

To find the matrix [T]CB​ representing T with respect to these bases:

  1. Compute T(bj​) for each j.
  2. Express T(bj​) as a linear combination of the ci​‘s: T(bj​)=∑i​aij​ci​.
  3. The column j of the matrix is (a1j​,a2j​,…,amj​)T.

The standard basis case is just this with all basis vectors being ei​, which is why the columns are exactly T(ej​).

This setup leads directly to the change of basis formula: if P is the change-of-basis matrix, then for a transformation T:V→V:

[T]B​=P−1[T]std​P

Two matrices related this way are called similar. Similar matrices represent the same linear transformation in different bases. This is the right way to think about similarity — it is a statement about the underlying map, not just the matrix.

Things I keep confusing — honest notes to self

  • T:Rn→Rm has an m×n matrix. The output dimension determines the rows. I mix this up when I’m tired.
  • The image lives in W, not V. The kernel lives in V. They are subspaces of different spaces.
  • T injective means ker(T) is trivial. T surjective means im(T)=W. For square transformations on finite-dimensional spaces, one implies the other. Not true in infinite dimensions — worth remembering.
  • Differentiation D:Pn​→Pn−1​ is surjective but not injective (kernel = constants). Integration in the other direction is injective but not surjective. The rank-nullity theorem works out in both cases.
