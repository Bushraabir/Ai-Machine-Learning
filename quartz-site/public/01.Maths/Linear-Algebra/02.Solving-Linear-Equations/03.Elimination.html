03.Elimination

Apr 15, 20269 min read

Elimination is the systematic algorithm for solving Ax=b. The core idea: apply a sequence of row operations to A that preserve the solution set of Ax=b, and drive the system into upper triangular form. Once the system is triangular, back-substitution solves it immediately. The deeper idea: elimination is actually computing the LU factorization of A. The row operations I apply are being recorded as elementary matrices, and their product is the lower triangular matrix L. The end result of elimination is U — the upper triangular matrix. So A=LU. Every step of elimination is a step toward this factorization.

Three Legal Row Operations:

These are the only operations I am allowed to perform. Each one preserves the solution set of Ax=b. 1. Row swap: interchange two rows. Ri​↔Rj​ 2. Scalar multiplication: multiply a row by a nonzero constant c=0. Ri​←c⋅Ri​ 3. Row replacement: replace a row by itself plus a multiple of another row. Ri​←Ri​−ℓ⋅Rj​,j<i

Gaussian elimination uses almost exclusively the third operation. The multiplier ℓ is chosen to kill an entry below a pivot. Why do these preserve the solution set? Each operation corresponds to multiplying both sides of Ax=b by an invertible elementary matrix E on the left: EAx=Eb. Since E is invertible, the new system has exactly the same solutions.

The Pivot

The pivot is the first nonzero entry in a row after elimination has cleared everything below and to the left of it. Concretely: after I have eliminated all entries in column j below row i, the entry aii​ that was used to do the eliminating is the pivot for that step.

Pivots must be nonzero. This is not optional — the multiplier ℓij​=aij​/ajj​ requires dividing by the pivot. A zero pivot means I need to swap rows (a row exchange) to bring a nonzero entry into the pivot position. If no nonzero entry exists in that column, the matrix is singular and I cannot get a pivot there.

The pivots are the diagonal entries of U after all row operations are complete. Their product is the determinant:

det(A)=∏i​uii​⋅(±1) where the ±1 accounts for any row swaps.

Algorithm:

let, The input is A and b; I work on the augmented matrix [A∣b].

  • Step 1. Use the (1,1) entry as the first pivot. For each row i>1, compute the multiplier: ℓi1​=a11​ai1​​ and replace Ri​←Ri​−ℓi1​⋅R1​. This kills every entry in column 1 below the pivot.
  • Step 2. Move to the (2,2) entry (or whatever is now in the second pivot position). Repeat: compute multipliers, eliminate below.
  • Step k. At stage k, the pivot is the (k,k) entry. Eliminate all entries in column k below row k using multipliers ℓik​=aik(k)​/akk(k)​, where the superscript (k) denotes the matrix after k−1 stages of elimination.
  • Continue until the matrix is upper triangular.

Elimination as Matrix Multiplication: The E Matrices

Each row operation “replace Ri​ by Ri​−ℓRj​” corresponds to left-multiplying by an elementary matrix Eij​. For a 3×3 system, the matrix that subtracts ℓ times row 1 from row 2 is: E21​=​1−ℓ21​0​010​001​​ Left-multiplying A by E21​ does exactly the row operation. The full elimination is: E32​E31​E21​A=U (applying operations right to left). So: A=E21−1​E31−1​E32−1​U=LU The matrix L=E21−1​E31−1​E32−1​ is lower triangular. And crucially, inverting each Eij​ is trivial: just flip the sign of the multiplier. E21−1​=​1ℓ21​0​010​001​​ The multipliers ℓij​ drop directly into L without any additional computation.

LU Factorization:

This is the payoff of the elimination viewpoint. Once I have run elimination (with no row swaps), the result is: A=LU where: L=​1ℓ21​ℓ31​​01ℓ32​​001​​,U=​u11​00​u12​u22​0​u13​u23​u33​​​ L → unit lower triangular (ones on the diagonal; the multipliers fill the lower triangle). U → upper triangular (the result of elimination; the pivots are on the diagonal).

For the example above, reading off the multipliers ℓ21​=−3/2, ℓ31​=−1, ℓ32​=4: L=​1−23​−1​014​001​​,U=​200​121​0​−121​−1​​

Why LU and Not Just Elimination?

Once I have A=LU, solving Ax=b splits into two triangular systems: Lc=b(forward substitution) Ux=c(back substitution) Both are O(n2) to solve. The factorization itself costs O(n3) — and I only do it once. If I need to solve Ax=b for many different right-hand sides b, I factor A once and then solve each new b in O(n2) time. This is the practical reason LU matters. see more10. A = LU

When Elimination Breaks Down — Row Exchanges

If during elimination a zero appears in the pivot position, but nonzero entries exist below it in the same column, I can fix this with a row swap. The corrected algorithm that incorporates row swaps is PA=LU factorization, where P is a permutation matrix. PA=LU P records which row swaps were performed. It is an orthogonal matrix (PT=P−1) with exactly one 1 per row and per column.

If no nonzero entry exists below a zero pivot position, then the matrix is singular — no row swap can save it. Elimination produces a row of zeros, and the rank is less than n.

A zero pivot is a warning. No possible pivot is a verdict. see more:16.PA = LU

Failure: The Singular Case

Suppose after all row operations, the final matrix looks like: ​200​121​0​−121​0​81c​​ If c=0: the third equation says 0=c. No solution. The right-hand side b is not in the column space of A. If c=0: the third equation says 0=0. Infinitely many solutions. The variable corresponding to the missing third pivot is free — it can take any value, and the other variables adjust accordingly.

The number of pivots equals the rank r. The number of free variables is n−r.

The Cost of Elimination

For an n×n matrix, how many operations does elimination require?

At stage k, I eliminate entries in column k below the pivot. There are n−k rows to update, and each row requires n−k+1 multiplications and subtractions (updating the remaining n−k+1 entries in that row, including the augmented column).

Total operations:

∑k=1n−1​(n−k)(n−k+1)≈∑k=1n​k2≈3n3​

So elimination costs O(n3) — roughly n3/3 multiplications. For n=1000, that is roughly 3×108 operations. For n=106, elimination becomes impractical — this is why iterative methods exist.

Back-substitution costs O(n2), which is negligible compared to n3/3.
