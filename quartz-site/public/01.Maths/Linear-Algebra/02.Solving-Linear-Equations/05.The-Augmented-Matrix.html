05.The Augmented Matrix

05.The Augmented Matrix

Apr 16, 20269 min read

When I solve Ax=b, I am performing row operations on A — but every row operation on A must be simultaneously applied to b. If I manipulate A and forget to carry b along, the right-hand side no longer corresponds to the transformed system and the solution is wrong.

The augmented matrix is the bookkeeping device that prevents this mistake. I attach b as an extra column to A, separated by a vertical bar to remind me it plays a different role:

[A∣b]=​a11​a21​⋮am1​​a12​a22​⋮am2​​⋯⋯⋱⋯​a1n​a2n​⋮amn​​b1​b2​⋮bm​​​ Now every row operation I perform on the left automatically carries through to the right. The vertical bar is a reminder — not a mathematical boundary — that the last column is b, not a column of A.

row operations on [A∣b] produce [A′∣b′] where A′x=b′ has exactly the same solution set as Ax=b.

Row Operations

Each legal row operation corresponds to left-multiplying by an elementary matrix E: E[A∣b]=[EA∣Eb] Since E is invertible, the systems Ax=b and (EA)x=Eb have identical solution sets. The augmented matrix packages both sides so this simultaneous transformation is automatic.

After the full sequence of elimination steps Ek​⋯E2​E1​, I arrive at: [U∣c] where U is upper triangular and c=Ek​⋯E1​b is the transformed right-hand side. Then back-substitution on Ux=c gives the solution.

Anatomy of the Augmented Matrix After Elimination

After row reduction to row echelon form, the augmented matrix [U∣c] for an m×n system of rank r looks like this: ​p1​00⋮00⋮0​∗00000​∗p2​0000​∗∗0000​∗∗p3​000​∗∗∗⋱000​∗∗∗pr​00​c1​c2​c3​⋮cr​cr+1​⋮cm​​​ The bold entries p1​,…,pr​ are the pivots. Everything below each pivot in its column is zero.

The rows r+1 through m (if any) are all-zero rows on the left side. Whether the system is consistent or inconsistent is determined entirely by the corresponding entries cr+1​,…,cm​ on the right.

Reading the Three Cases Directly from [U∣c]

Case 1 : Unique solution: r=n=m. ​p1​00​∗p2​0​∗∗p3​​c1​c2​c3​​​ Every column has a pivot, every row has a pivot. No free variables, no zero rows. Back-substitution gives a unique (x1​,x2​,x3​).

Case 2 — No solution: r<m and some ci​=0 for i>r. ​p1​00​∗p2​0​∗∗0​c1​c2​c3​​​with c3​=0 The third row says 0⋅x1​+0⋅x2​+0⋅x3​=c3​=0. This is 0=c3​, a contradiction. The system is inconsistent. No solution exists. Geometrically: b is not in the column space of A.

Case 3 — Infinitely many solutions: r<n and all ci​=0 for i>r. ​p1​00​∗00​∗p2​0​c1​c2​0​​

Column 2 has no pivot — it is a free column. The variable x2​ is free: it can take any value t∈R, and x1​,x3​ are expressed in terms of t via back-substitution. The solution set is a line (or affine subspace of dimension n−r) in Rn.

The Augmented Matrix for Finding A−1

There is a second major use of the augmented matrix: computing the inverse. If A is square and invertible, I augment with the identity: [A∣I] Then I row reduce all the way to 04.Reduced Row Echelon Form (RREF) — not just echelon form, but with zeros above the pivots as well, and pivots scaled to 1. The result is: [I∣A−1]

Why this works: I am applying the same sequence of row operations to both A and I. The operations turn A into I, meaning I applied Ek​⋯E1​A=I, so Ek​⋯E1​=A−1. The same operations applied to I give Ek​⋯E1​I=A−1.

This is Gauss-Jordan elimination. The cost is O(n3), same as LU factorization, but now I get the full inverse rather than just a factorization.

When to use A−1 vs LU: If I need to solve Ax=b for one or a few b, use LU. If I genuinely need A−1 itself (e.g., to form the matrix A−1B for some other matrix B), use Gauss-Jordan.

Reduced Row Echelon Form

The echelon form U has pivots in staircase position with zeros below each pivot. The reduced row echelon form (RREF) goes further:

  • Zeros above each pivot as well as below.
  • Each pivot scaled to exactly 1.

RREF is unique — every matrix has exactly one RREF. Echelon form is not unique (the operations used to reach it can vary). RREF is the canonical form.

For solving Ax=b: either echelon form followed by back-substitution, or RREF with the answer readable directly. For finding A−1: RREF is required (Gauss-Jordan).

The RREF of A is often written R:

R=rref(A)

For an invertible n×n matrix: R=I.

For a singular matrix: R has at least one all-zero row, and the pivot columns of R are standard basis vectors. see more04.Reduced Row Echelon Form (RREF)
