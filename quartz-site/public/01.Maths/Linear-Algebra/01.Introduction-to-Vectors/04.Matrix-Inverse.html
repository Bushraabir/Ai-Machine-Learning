04.Matrix Inverse

04.Matrix Inverse

Apr 09, 20268 min read

Let A be an n×n matrix. A matrix B is called the inverse of A if: AB=BA=In​ When such B exists, A is called invertible (or nonsingular), and we write B=A−1. The inverse is unique. Suppose B and C both satisfy AB=I and CA=I. Then: C=CI=C(AB)=(CA)B=IB=B So there is at most one inverse. We can speak of the inverse. One-sided inverses suffice for square matrices. If A is n×n and AB=I for some B, then automatically BA=I as well. This is not obvious and requires rank arguments:

Proof. AB=I implies rank(A)≥rank(AB)=rank(I)=n, so rank(A)=n, so A has trivial null space, so Ax=0⟹x=0. Now consider BA: for any x, A(BAx)=(AB)Ax=Ax, so A(BAx−x)=0, so BAx−x=0, so BAx=x. Thus BA=I. ■

This is why the one-sided inverse condition is enough for square matrices, and why left-inverse and right-inverse automatically coincide.

The Invertible Matrix Theorem

For a square n×n matrix A, the following are all equivalent. If any one holds, all hold; if any one fails, all fail.

  1. A is invertible.
  2. Ax=0 has only the trivial solution x=0.
  3. The RREF of A is In​.
  4. A is a product of elementary matrices.
  5. Ax=b has a unique solution for every b∈Rn.
  6. rank(A)=n.
  7. null(A)=0 (trivial null space).
  8. The columns of A are linearly independent.
  9. The columns of A span Rn.
  10. The rows of A are linearly independent.
  11. det(A)=0.
  12. 0 is not an eigenvalue of A.
  13. AT is invertible.

I will not prove all of these here, but the logical skeleton is: (1) ⇔ (3) via Gauss-Jordan; (3) ⇔ (2) ⇔ (7) ⇔ (8) via rank-nullity; (8) ⇔ (9) since both say rank(A)=n; (11) ⇔ (1) via the determinant formula; (12) ⇔ (11) since det(A)=∏i​λi​. The whole theorem is one big equivalence class.

Formulas for Small Cases

1×1:

Trivially: if A=(a), then A−1=(1/a) provided a=0.

2×2:

A=(ac​bd​),A−1=ad−bc1​(d−c​−ba​) provided det(A)=ad−bc=0. The pattern: swap the diagonal entries, negate the off-diagonal entries, divide by the determinant. Worth memorizing.

Proof. Direct multiplication: ad−bc1​(ac​bd​)(d−c​−ba​)=ad−bc1​(ad−bc0​0ad−bc​)=I.✓

n×n: The Adjugate Formula:

For general n: A−1=det(A)1​adj(A) where adj(A) is the adjugate (classical adjoint): the transpose of the cofactor matrix.

The (i,j) entry of adj(A) is the (j,i) cofactor of A: [adj(A)]ij​=Cji​=(−1)j+iMji​ where Mji​ is the (j,i) minor (determinant of A with row j and column i deleted).This formula is theoretically important (it shows A−1 depends rationally on the entries of A) but computationally terrible for n≥4. Never use it numerically. Use Gauss-Jordan.

Computing A−1: Gauss-Jordan

The practical method. Augment A with I and row reduce until the left block is I: [A∣I]row ops​[I∣A−1]

The elementary matrices E1​,E2​,…,Ep​ encoding the row operations satisfy Ep​⋯E1​A=I, so Ep​⋯E1​=A−1. Applying the same sequence to I on the right gives A−1.

If at any point during row reduction the left block develops a zero row, A is singular. Stop.

Cost: O(n3) operations. This is the same order as matrix multiplication, and it is optimal up to constants.

The Determinant Criterion

A is invertible if and only if det(A)=0. This follows from two facts:

  • det(AB)=det(A)det(B)
  • det(I)=1

If AB=I then det(A)det(B)=1, so det(A)=0. Conversely, the adjugate formula gives an explicit inverse when det(A)=0.

The Rank-Nullity View

For A:Rn→Rn (viewing A as a linear map):

rank(A)+nullity(A)=n

A is invertible if nullity(A)=0 if rank(A)=n.

This is the clean way to think about it geometrically. Invertibility means A neither collapses any direction (injective) nor misses any direction (surjective). For linear maps on finite-dimensional spaces, these two conditions are equivalent.

The Sherman-Morrison Formula

A rank-1 update to an invertible matrix: (A+uvT)−1=A−1−1+vTA−1uA−1uvTA−1​

provided 1+vTA−1u=0.

Proof. Multiply (A+uvT) by the right-hand side and verify you get I. The key step uses the scalar 1+vTA−1u to collapse the rank-1 correction. ■

Why this matters: if you already have A−1 and you perturb A by a rank-1 matrix, you get the new inverse in O(n2) time instead of O(n3). This is the computational foundation of sequential updates in statistics (online learning, recursive least squares, the Kalman filter).

Invertibility and the Determinant: A Deeper Note

The determinant is a polynomial in the entries of A. The set of singular matrices is A:det(A)=0, a closed set of measure zero in Rn×n. In other words, a random matrix (say with i.i.d. Gaussian entries) is invertible with probability 1. Singularity is the exceptional case, not the rule.

This has a practical implication: if you see a nearly-singular matrix in computation (determinant very small but not exactly zero), the issue is usually numerical conditioning, not theoretical non-invertibility. The condition number κ(A)=∣A∣∣A−1∣ measures how close A is to being singular from a numerical standpoint.

When There Is No Inverse: The Pseudoinverse

For a non-square or singular matrix, the ordinary inverse does not exist. The Moore-Penrose pseudoinverse A+ generalizes the inverse:

  • If A has full column rank: A+=(ATA)−1AT (the left inverse, used in least squares).
  • If A has full row rank: A+=AT(AAT)−1 (the right inverse).
  • In general: A+=VΣ+UT where A=UΣVT is the SVD and Σ+ replaces each nonzero singular value σi​ by 1/σi​.

The pseudoinverse gives the minimum-norm least-squares solution to Ax=b: x=A+b.

What Fails Without Invertibility

If A is singular:

  • Ax=b either has no solution or infinitely many.
  • Ax=0 has a nontrivial solution - A collapses some direction entirely.
  • The transformation x↦Ax is not bijective: information is lost.
  • In probability: if X∼N(μ,Σ) and Σ is singular, the distribution is degenerate - it lives on a lower-dimensional affine subspace and has no density with respect to Lebesgue measure on Rn.

A Proof I Want to Keep

Claim: If A and B are n×n and AB=I, then A is invertible and B=A−1.

Proof. AB=I implies rank(AB)=n. But rank(AB)≤rank(A)≤n, so rank(A)=n. Thus A is invertible; let C=A−1. Then B=IB=(CA)B=C(AB)=CI=C=A−1. ■

The same argument with left and right swapped shows: BA=I⟹B=A−1 as well.
