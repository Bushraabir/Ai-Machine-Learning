10.Projection Using Orthogonal Bases

10.Projection Using Orthogonal Bases

Apr 06, 20267 min read

The Problem With What We Had

In the last two notes, projecting onto C(A) required solving the normal equations ATAx^=ATb. This works, but it has a cost: we form ATA, which squares the condition number of A, and then we solve a system whose matrix can be badly conditioned even when A itself is not.

There is a better way, and it comes from asking: what if the columns of A were orthogonal to begin with?

The answer is that ATA becomes diagonal, the normal equations decouple, and each coefficient is just a dot product divided by a norm squared. No system to solve. The projection formula collapses into something almost trivially clean.

This note is about that situation — and about how to manufacture it when it does not arise naturally.

Projection onto a Single Vector

Start with the simplest case. Project b∈Rm onto the line spanned by a single nonzero vector q1​.

The projection is

b^=q1T​q1​q1T​b​q1​

The scalar x^1​=q1T​q1​q1T​b​ is the coefficient, and q1​x^1​ is the closest point on the line to b. The error b−b^ is orthogonal to q1​ by construction.

If q1​ happens to be a unit vector — i.e., ∣q1​∣=1 so q1T​q1​=1 — then this simplifies to

b^=(q1T​b),q1​,x^1​=q1T​b

The projection matrix for this single direction is P1​=q1​q1T​ (rank 1, m×m).

Projection onto a Subspace with an Orthonormal Basis

Now let S be a k-dimensional subspace of Rm, and suppose we have an orthonormal basis for S:

q1​,q2​,…,qk​∈Rm,qiT​qj​={1​i=j 0​i=j​

Form the matrix Q=(q1​​q2​​⋯​qk​​), which is m×k. The orthonormality conditions say exactly

QTQ=Ik​

Claim: The projection of b onto S=C(Q) is

b^=QQTb

and the coefficient vector is x^=QTb, meaning

x^i​=qiT​bfor each i=1,…,k

Why? The normal equations for projecting b onto C(Q) are

QTQx^=QTb

But QTQ=Ik​, so the normal equations are just

Ik​x^=QTb⟹x^=QTb

The system is already solved. No elimination needed. Each coefficient x^i​=qiT​b is computed independently of the others.

The projection matrix is

P=Q(QTQ)−1QT=QIk−1​QT=QQT

Why This Is So Much Better

With a general basis, the projection required inverting the k×k matrix ATA. With an orthonormal basis, ATA=I and no inversion is needed at all.

More precisely: the coefficient of b in the direction qi​ is completely decoupled from every other direction. I can compute x^i​=qiT​b without knowing anything about qj​ for j=i. This is the defining feature of orthonormal bases — coordinates are independent.

This is also why adding a new basis vector qk+1​ to an orthonormal set does not change any of the previous coefficients. With a general basis, adding a new column to A changes ATA and hence changes every coefficient. With an orthonormal basis, old coefficients are untouched.

The Full Projection Formula

Expanding b^=QQTb:

b^=∑i=1k​(qiT​b),qi​

This is completely explicit. The projection onto S is the sum of projections onto each individual direction qi​. These projections add because the qi​ are orthogonal — they do not interfere with each other.

The projection matrix P=QQT is m×m, symmetric, idempotent. Written out:

P=∑i=1k​qi​qiT​

Each qi​qiT​ is the rank-1 projection onto the line spanned by qi​. The full projection onto S is their sum. This decomposition is only valid because the qi​ are mutually orthogonal — otherwise projecting onto each line separately and adding would double-count the overlapping directions.

A Concrete Example

Let S be the subspace of R3 spanned by

q1​=2​1​(1\1\0​),q2​=6​1​(1\-1\2​)

Check orthonormality:

q1T​q1​=21​(1+1+0)=1✓ q2T​q2​=61​(1+1+4)=1✓ q1T​q2​=12​1​(1⋅1+1⋅(−1)+0⋅2)=12​1​(0)=0✓

Project b=(1\0\0​) onto S.

x^1​=q1T​b=2​1​(1)=2​1​

x^2​=q2T​b=6​1​(1)=6​1​

b^=x^1​q1​+x^2​q2​=2​1​⋅2​1​(1\1\0​)+6​1​⋅6​1​(1\-1\2​)

=21​(1\1\0​)+61​(1\-1\2​)=(1/2+1/6 1/2−1/6 1/3​)=(2/3\1/3\1/3​)

Verify: e=b−b^=(1/3\-1/3\-1/3​).

Check e⊥q1​: q1T​e=2​1​(1/3−1/3+0)=0. ✓

Check e⊥q2​: q2T​e=6​1​(1/3+1/3−2/3)=6​1​(0)=0. ✓

The projection matrix is:

P=q1​q1T​+q2​q2T​=21​(1​1​0\1​1​0\0​0​0​)+61​(1​−1​2\-1​1​−2\2​−2​4​)=(2/3​1/3​1/3\1/3​2/3​−1/3\1/3​−1/3​2/3​)

Verify Pb=b^:

(2/3​1/3​1/3\1/3​2/3​−1/3\1/3​−1/3​2/3​)(1\0\0​)=(2/3\1/3\1/3​)✓

The Special Case: Q is Square

If Q is m×m — i.e., the orthonormal basis spans all of Rm — then QTQ=I and QQT=I as well. Q is an orthogonal matrix (the standard term, despite the columns being orthonormal). In this case:

P=QQT=I

Projection onto Rm is the identity — of course. The formula x^=QTb in this case gives the coordinates of b in the orthonormal basis q1​,…,qm​.

For a square orthogonal Q: Q−1=QT. Inverting an orthogonal matrix is free — just transpose.

Connection to Gram-Schmidt and QR

Where do orthonormal bases come from? If A has independent columns a1​,…,ak​, the Gram-Schmidt process constructs orthonormal vectors q1​,…,qk​ with C(q1​,…,qj​)=C(a1​,…,aj​) for each j.

In matrix language, Gram-Schmidt is the QR factorization A=QR, where:

  • Q is m×k with orthonormal columns
  • R is k×k upper triangular with positive diagonal entries

The normal equations ATAx^=ATb become, via A=QR:

(QR)T(QR)x^=(QR)Tb RTQTQRx^=RTQTb RTRx^=RTQTb

Since R is invertible (positive diagonal), multiply on the left by (RT)−1:

Rx^=QTb

This is a triangular system — solved by back-substitution in O(k2) operations, with no formation of ATA and no squaring of the condition number.

This is why QR is the right way to solve least squares problems numerically. The orthonormal basis implicit in Q is the key.

The orthonormal row is simply cleaner in every column.

Things to Remember (for Myself)

  • With an orthonormal basis, the normal equations are Ix^=QTb. They solve themselves.
  • Each coefficient x^i​=qiT​b depends only on qi​ and b — not on the other basis vectors. This independence is the whole point of orthogonality.
  • The projection b^=∑(qiT​b)qi​ is a sum of rank-1 projections. This sum is valid because the qi​ are orthogonal — the components do not overlap.
  • P=QQT only when Q has orthonormal columns. If Q is square, then P=I.
  • Gram-Schmidt gives A=QR. The normal equations become Rx^=QTb — triangular, well-conditioned, no ATA required.
  • Any time I find myself computing ATA for a projection, I should ask whether Gram-Schmidt first would make the problem cleaner.
