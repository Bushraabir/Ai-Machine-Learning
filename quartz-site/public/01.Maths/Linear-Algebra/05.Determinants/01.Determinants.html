The Right Way to Think About Determinants

The determinant is a single number assigned to a square matrix. It is tempting to define it by the cofactor expansion formula and be done with it — but that approach hides all the structure. The right approach, the one Strang takes and the one I find most satisfying, is to start from the properties that any reasonable determinant function must satisfy, and derive everything — including the cofactor formula — as consequences.

There are three fundamental properties. Everything else follows from them.

The Three Fundamental Properties

Let det(A) denote the determinant of an n×n matrix A.

Property 1 (Normalization). det(I)=1.

Property 2 (Sign reversal under row exchange). Exchanging any two rows of A reverses the sign of det(A).

Swap rows i and j⟹det(A)→−det(A)

Property 3 (Linearity in each row separately). The determinant is linear as a function of each individual row, with all other rows held fixed.

That is, if row i of A is replaced by αu+βv while all other rows stay the same, then

det(A)=αdet(A with row i=u)+βdet(A with row i=v)

These three properties define the determinant. Any function of square matrices satisfying all three must be the determinant. (Existence and uniqueness of such a function is a theorem, but I will take it as given here and focus on consequences.)

Ten Derived Properties

Every other property of determinants follows from Properties 1–3 by pure logic. I will derive each one carefully.

Property 4. If two rows of A are equal, then det(A)=0.

Proof. Swap the two equal rows. By Property 2, the determinant changes sign. But swapping two identical rows does not change the matrix at all — so det(A)=−det(A), which forces det(A)=0. □

Property 5. Subtracting a multiple of one row from another row leaves det(A) unchanged.

Proof. Suppose we replace row i by row i minus ℓ times row j. By Property 3 (linearity in row i):

det(…,rowi​−ℓ,rowj​,…)=det(…,rowi​,…)−ℓ,det(…,rowj​,…,rowj​,…)

The second determinant has row j appearing twice (once in position i, once in position j), so by Property 4 it is zero. Hence

det(…,rowi​−ℓ,rowj​,…)=det(A)

□

This means elimination steps do not change the determinant. This is the key computational fact.

Property 6. If A has a row of zeros, then det(A)=0.

Proof. By Property 3, scale the zero row by t: the matrix is unchanged, so det(A)=t⋅det(A) for all t. Setting t=0 gives det(A)=0. □

Property 7. For a triangular matrix, det(A)=∏i=1n​aii​ (product of diagonal entries).

Proof. Consider upper triangular A with diagonal entries d1​,…,dn​. Use Property 3 to factor each diagonal entry out of its row:

det(A)=d1​d2​⋯dn​⋅det(B)

where B is upper triangular with all ones on the diagonal. Now subtract multiples of each row from lower rows (Property 5 — determinant unchanged) to clear all entries above the diagonal without changing the diagonal. The result is I. So det(B)=det(I)=1.

Hence det(A)=d1​d2​⋯dn​. □

In particular, det of a diagonal matrix is just the product of diagonal entries.

Property 8. A is singular if and only if det(A)=0.

Proof.

(⇒) If A is singular, elimination leads to a row of zeros. By Property 6, the determinant at that stage is zero. By Property 5, elimination does not change the determinant. So det(A)=0.

(⇐) If A is nonsingular, elimination produces an upper triangular matrix U with nonzero diagonal. By Property 7, det(U)=0. Since Property 5 keeps the determinant invariant, det(A)=0. □

This is the connection between determinants and invertibility. det(A)=0⟺A is singular ⟺ columns are dependent ⟺ Ax=0 has a nontrivial solution.

Property 9. det(AB)=det(A)det(B).

Proof sketch. Define f(A)=det(AB)/det(B) for fixed invertible B. One checks that f satisfies Properties 1, 2, and 3, so f(A)=det(A), giving det(AB)=det(A)det(B). □

Consequences:

  • det(A−1)=1/det(A), since det(A)det(A−1)=det(I)=1.
  • det(A2)=det(A)2.
  • det(cA)=cndet(A) for n×n matrices (factor c out of each of the n rows).

Property 10. det(AT)=det(A).

Proof. If A is invertible, use A=LU (ignoring row exchanges for now). Then AT=UTLT. Both L and U are triangular, so det(L)=1 (unit lower triangular, diagonal all ones) and det(U)=∏uii​. Same for LT and UT. So det(AT)=det(UT)det(LT)=det(U)det(L)=det(A).

If A is singular, both sides are zero. □

This means everything stated for rows also holds for columns: the determinant is linear in each column, swapping two columns reverses sign, equal columns give zero.

Property 11. Multiplying one row by a scalar c multiplies det(A) by c.

Proof. This is just Property 3 with α=c, β=0, v=0. □

Property 12. det(A)=0⟺ rows (or equivalently columns) of A are linearly independent.

This follows from Property 8 and the fact that row operations (Properties 4, 5) provide the test for linear independence.

The Formula via Permutations

Properties 1–3 uniquely determine det(A). From them one can derive an explicit formula.

For a 2×2 matrix:

det(a​b c​d​)=ad−bc

Derivation. Expand using linearity in row 1, then row 2:

det(a​b c​d​)=a,det(1​0 c​d​)+b,det(0​1 c​d​)

=a[c,det(1​0\0​0​)+d,det(1​0\0​1​)]+b[c,det(0​1\1​0​)+d,det(0​1\0​1​)]

The matrices with two identical columns have determinant zero (Property 4 applies to columns by Property 10). The identity gives 1 (Property 1). The swap gives −1 (Property 2). So:

=a(d⋅1)+b(c⋅(−1))=ad−bc

For a 3×3 matrix, the same expansion gives six terms:

det(a11​​a12​​a13​\a21​​a22​​a23​\a31​​a32​​a33​​)=∑σ∈S3​​sgn(σ),a1σ(1)​,a2σ(2)​,a3σ(3)​

The six permutations σ of 1,2,3 are:

σ(σ(1),σ(2),σ(3))sgn(σ)Term
e(1,2,3)+1a11​a22​a33​
(12)(2,1,3)−1−a12​a21​a33​
(13)(3,2,1)−1−a13​a22​a31​
(23)(1,3,2)−1−a11​a23​a32​
(123)(2,3,1)+1a12​a23​a31​
(132)(3,1,2)+1a13​a21​a32​

So:

det(A)=a11​a22​a33​+a12​a23​a31​+a13​a21​a32​−a11​a23​a32​−a12​a21​a33​−a13​a22​a31​

This is Sarrus’ rule. It only works for 3×3.

The general permutation formula for n×n:

det(A)=σ∈Sn​∑​sgn(σ)i=1∏n​ai,σ(i)​​

The sum is over all n! permutations σ of 1,…,n. Each permutation contributes a product of n entries, one from each row and one from each column, with sign equal to sgn(σ)=(−1)number of transpositions in σ.

The Sign of a Permutation

A transposition is a swap of two elements. Every permutation decomposes into transpositions, and while this decomposition is not unique, the parity of the number of transpositions is always the same. The sign is:

sgn(σ)=(−1)number of transpositions={+1​σ is even −1​σ is odd​

Equivalently: sgn(σ)=(−1)number of inversions, where an inversion is a pair (i,j) with i<j but σ(i)>σ(j).

For n=3: the three transpositions (12),(13),(23) each have sign −1. The two cyclic permutations (123),(132) have sign +1. The identity e has sign +1.

Cofactor Expansion

The permutation formula involves n! terms — useful theoretically but impractical for large n. The cofactor expansion is a recursive version.

Definition. The (i,j) cofactor Cij​ of A is

Cij​=(−1)i+jMij​

where Mij​ is the minor — the determinant of the (n−1)×(n−1) matrix obtained by deleting row i and column j.

Cofactor expansion along row i:

det(A)=∑j=1n​aij​Cij​=∑j=1n​(−1)i+jaij​Mij​

Cofactor expansion along column j:

det(A)=∑i=1n​aij​Cij​=∑i=1n​(−1)i+jaij​Mij​

Both give the same answer — this follows from det(AT)=det(A).

Derivation of cofactor expansion. Fix row 1 for concreteness. By linearity in row 1:

det(A)=∑j=1n​a1j​det(Bj​)

where Bj​ is the matrix A with row 1 replaced by the j-th standard basis vector ejT​. The matrix Bj​ has a 1 in position (1,j) and zeros elsewhere in row 1. Move the first row to position 1 (it is already there) and column j to position 1 by doing j−1 column swaps, picking up sign (−1)j−1. The resulting matrix has a leading 1 in position (1,1) and the remaining (n−1)×(n−1) minor M1j​ in the bottom-right block. So

det(Bj​)=(−1)j−1⋅1⋅M1j​=(−1)1+jM1j​=C1j​

Hence det(A)=∑j=1n​a1j​C1j​. □

Cofactor Expansion: 3×3 Example

A=(1​2​3 4​5​6 7​8​9​)

Expand along row 1:

C11​=(+1)det(5​6\8​9​)=45−48=−3

C12​=(−1)det(4​6\7​9​)=−(36−42)=6

C13​=(+1)det(4​5\7​8​)=32−35=−3

det(A)=1(−3)+2(6)+3(−3)=−3+12−9=0

The determinant is zero — the rows 1,2,3 and 4,5,6 and 7,8,9 are in arithmetic progression and hence linearly dependent. (Row 2 = average of rows 1 and 3: (1+7)/2=4, (2+8)/2=5, (3+9)/2=6.) ✓

The Adjugate and Cramer’s Rule

Definition. The adjugate (classical adjoint) of A is the transpose of the cofactor matrix:

(adj,A)ij​=Cji​

That is, entry (i,j) of adj,A is the (j,i) cofactor of A.

Theorem. A,(adj,A)=det(A),I.

Proof. The (i,k) entry of A,(adj,A) is ∑j​aij​Ckj​.

  • If i=k: this is ∑j​aij​Cij​=det(A) (cofactor expansion along row i).
  • If i=k: this is the cofactor expansion of the matrix obtained by replacing row k of A with row i — a matrix with two identical rows — so its determinant is zero.

Hence A,(adj,A)=det(A),I. □

Corollary (Inverse formula). When det(A)=0:

A−1=det(A)1​adj,A

So (A−1)ij​=det(A)Cji​​.

For 2×2:

\begin{pmatrix}a&b\c&d\end{pmatrix}^{-1} = \frac{1}{ad-bc}\begin{pmatrix}d&-b\-c&a\end{pmatrix}

The 2×2 inverse is just the adjugate divided by the determinant.

Cramer’s Rule. For Ax=b with det(A)=0, the j-th component of the solution is

xj​=det(A)det(Bj​)​

where Bj​ is the matrix A with column j replaced by b.

Derivation. Write x=A−1b=det(A)1​adj(A),b. The j-th component is

xj​=det(A)1​∑i​Cij​bi​=det(A)1​∑i​bi​Cij​

But ∑i​bi​Cij​ is exactly the cofactor expansion of det(Bj​) along column j. □

Cramer’s rule is theoretically elegant but computationally expensive — it requires n+1 determinant evaluations, each costing O(n!) or O(n3) depending on method. It is almost never used in practice.

The Determinant as Volume

The determinant has a fundamental geometric meaning: ∣det(A)∣ is the volume of the parallelepiped spanned by the rows (or columns) of A.

For n=2: ∣det(A)∣ is the area of the parallelogram spanned by the two row vectors.

For n=3: ∣det(A)∣ is the volume of the parallelepiped spanned by the three row vectors.

The sign of det(A) encodes orientation. If the rows form a right-handed system in R3, the determinant is positive.

Why this is consistent with Property 2: swapping two row vectors corresponds to reflecting the parallelepiped, which reverses orientation and negates the signed volume.

Why this is consistent with Property 3: scaling one row scales the parallelepiped in one direction, multiplying the volume by the same scalar.

Why det(AB)=det(A)det(B) geometrically: the linear map A followed by B scales volumes by ∣det(A)∣ then ∣det(B)∣, so the composition scales by the product.

Computing det via Elimination

The most efficient computation of det(A) for large n is via LU factorization.

With PA=LU (including row exchange matrix P):

det(A)=det(P)⋅det(L−1)det(U)​=(−1)number of row swaps⋅∏i=1n​uii​

Since L is unit lower triangular, det(L)=1. Since P is a permutation matrix, det(P)=±1, with sign (−1)number of transpositions.

So:

det(A)=(−1)swaps⋅u11​⋅u22​⋯unn​​

This takes O(n3) operations, the same as solving Ax=b. The cofactor expansion takes O(n!) — catastrophically slower.

Example. Eliminate A=(2​1​1\4​3​3\8​7​9​).

R2​←R2​−2R1​, R3​←R3​−4R1​:

(2​1​1\0​1​1\0​3​5​)

R3​←R3​−3R2​:

(2​1​1\0​1​1\0​0​2​)

No row swaps. det(A)=2⋅1⋅2=4.

Things to Remember (for Myself)

  • Start from the three properties and derive everything. The cofactor formula is a consequence, not the definition. This is important — defining by cofactors obscures why any of this works.
  • Property 5 (elimination invariance) is the key to computation. Reduce to triangular form, track sign changes from row swaps, multiply the pivots.
  • det(AB)=det(A)det(B) is the single most useful identity for theoretical arguments. Use it constantly.
  • det(AT)=det(A) means I can always work with columns if rows are inconvenient.
  • The permutation formula has n! terms. Never use it to compute for n>3. Use elimination.
  • Cramer’s rule is beautiful and useless computationally. It is worth knowing for theory (and for 2×2 or 3×3 by hand), not for implementation.
  • If any row (or column) is a linear combination of the others, det=0.
  • The geometric interpretation — volume of a parallelepiped — is the reason the determinant exists. Keep this picture in mind.
