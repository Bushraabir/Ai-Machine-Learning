07.Singular Matrix

07.Singular Matrix

Apr 14, 20268 min read

A square matrix A is singular if it has no inverse. That is, there is no matrix B such that:

AB=BA=I

A matrix that does have an inverse is called invertible or non-singular.

This definition is clean but not illuminating. The real content is in the equivalent characterisations below — each one is a different face of the same geometric reality.

Five Equivalent Characterisations

The following are all equivalent for a square n×n matrix A:

#Statement
1A has no inverse
2det(A)=0
3The columns of A are linearly dependent
4Ax=0 has a non-trivial solution (some x=0)
5Ax=b has either no solution or infinitely many solutions for some b

These are not five separate definitions. They are the same fact viewed from algebra, geometry, and the theory of linear systems. Any one of them can be taken as the definition; the others follow.

The Determinant View

The most common test for singularity in practice:

A is singular⟺det(A)=0

For a 2×2 matrix, this is immediate:

A = \begin{bmatrix} a & b \\ c & d \end{bmatrix}$$$$ \implies \det(A) = ad - bc

If ad−bc=0, the matrix is singular.

Example : A=[21​42​] det(A)=(2)(2)−(4)(1)=4−4=0✓ singular

B=[21​32​] det(B)=(2)(2)−(3)(1)=4−3=1=0✓ invertible For 3×3 and larger matrices, computing the determinant is more involved, but the criterion is the same: zero determinant means singular.

The Column Picture

This is the view Strang insists on, and it is the most geometric.

Write Ax=b as a linear combination of columns:

x1​c1​+x2​c2​+⋯+xn​cn​=b

where c1​,…,cn​ are the columns of A.

The question is: can every b∈Rn be written as such a combination?

  • If the columns span Rn — if they are linearly independent — yes. The matrix is invertible.
  • If the columns are linearly dependent — if some column lies in the span of the others — the columns do not fill Rn. They span a lower-dimensional subspace. Many b vectors are simply unreachable. The matrix is singular.

Column 1: [2 1​], Column 2: [4 2​]=2⋅[2 1​]

The second column is exactly twice the first. Both columns lie on the same line through the origin in R2.

The Null Space View

A is singular if and only if Ax=0 has a non-trivial solution; a solution x=0.

The set of all solutions to Ax=0 is called the null space (or kernel) of A:

N(A)=x∈Rn:Ax=0

-If A is invertible: N(A)=0. The only solution is the trivial one. -If A is singular: N(A) contains non-zero vectors. The null space has positive dimension.

For the singular example above: A=[21​42​],Ax=0 [21​42​][x1​x2​​]=[00​]

Row 1: 2x1​+4x2​=0 ⟹x1​=−2x2​ Row 2: x_1 + 2x_2 = 0$$ \implies x_1 = -2x_2$

Both rows say the same thing. The solution is: x=t[−21​]for any t∈R The null space is a whole line through the origin. The matrix collapses this entire line to 0.

What Happens During Elimination

Gaussian Elimination reveals singularity directly. Attempt to row-reduce A: A=[21​42​] Step 1: Subtract 21​ times row 1 from row 2: [21−21​(2)​42−21​(4)​]=[20​40​] A row of zeros appears. There is no pivot in the second row. Elimination has broken down.

In general: a singular matrix produces at least one zero row during elimination (assuming no row exchanges save it). The number of non-zero rows after full elimination is the rank of A.

  • n×n matrix with full rank r=n: invertible.
  • n×n matrix with rank r<n: singular.

A zero row in the reduced form means the corresponding equation contributes no information. The system is either inconsistent or underdetermined.

This is why singularity splits into two sub-cases: no solution vs infinitely many solutions — the matrix A is singular in both, but the behaviour depends on whether b lies in the column space.

Rank and the Dimension of the Null Space

For an n×n matrix A, define: rank(A)=number of pivots=dim(column space) The rank-nullity theorem says: rank(A)+dim(N(A))=n So:

  • Full rank (r=n): null space is 0, matrix is invertible.
  • Rank deficient (r<n): null space has dimension n−r>0, matrix is singular. The null space dimension n−r is called the nullity of A. It counts the number of “free directions” — the dimensions along which A collapses information.

Why Singularity Means Non-Invertibility

This is worth proving directly, not just asserting.

Claim. If Ax=0 has a non-trivial solution, then A cannot have an inverse.

Proof. Suppose x0​=0 satisfies Ax0​=0. Suppose for contradiction that A−1 exists. Then:

x0​=Ix0​=(A−1A)x0​=A−1(Ax0​)=A−10=0

This contradicts x0​=0. So A−1 cannot exist. ■

The geometric reading. If A collapses a whole subspace to 0, then knowing Ax=b does not tell you which x produced b — many x values give the same output. You cannot reverse a map that loses information.

Singular vs Near-Singular

A matrix can be non-singular and still behave badly — if its columns are nearly linearly dependent, small errors in b produce large errors in the solution x=A−1b. This is measured by the condition number: κ(A)=∣A∣,∣A−1∣ A singular matrix has κ(A)=∞ (since A−1 does not exist). A matrix with very large condition number is ill-conditioned — it is technically invertible but numerically unreliable. The columns are nearly dependent.

This is not just a computational concern. It reflects genuine geometric near-singularity: the column space is nearly lower-dimensional, and the matrix is close to losing a dimension.

The Determinant Connection — Why det=0

The determinant measures the volume scaling factor of the linear transformation A. Specifically, if A maps the unit cube, its image has volume ∣det(A)∣.

  • Invertible matrix: ∣det(A)∣>0. The transformation preserves volume (up to scaling). No dimension is collapsed.
  • Singular matrix: ∣det(A)∣=0. The transformation squashes some dimension — the image of the unit cube has zero volume. The output lives in a subspace of dimension less than n.

A singular matrix flattens the space. The image of Rn under A is a strict subspace — a lower-dimensional object with zero n-dimensional volume.

Summary

Singularity is not one property — it is a cluster of equivalent statements:

det(A)=0 ⟺columns are linearly dependent ⟺column space⊊Rn ⟺Ax=0 has non-trivial solutions ⟺A has no inverse ⟺A collapses at least one dimension ⟺rank(A)<n

Every one of these is a rephrasing of the same geometric fact: the transformation A loses information. It maps a higher-dimensional object into a lower-dimensional one. Once information is lost, it cannot be recovered — and that is why no inverse exists.
