02.Null Space of A

Apr 06, 202613 min read

Why I’m Writing This

Solving Ax=0 feels, at first, like a trivial problem — the answer is always x=0, right? It is not, unless A has full column rank. The null space is the entire solution set of the homogeneous equation, and understanding its structure — how many free variables there are, how to find a basis for it, why it is a subspace — is the foundation for understanding the solution set of Ax=b in general. You cannot understand the particular solution without first understanding the homogeneous one.

Definition

The null space of A∈Rm×n is

N(A)=,x∈Rn:Ax=0,

It is a subspace of Rn — the domain of A, not the codomain. I established this in Vector Spaces and Subspaces. The proof is two lines: if Ax=0 and Ay=0, then A(cx+dy)=cAx+dAy=0.

What I want here is not the proof that N(A) is a subspace — that is done — but the algorithm for finding it, and the structural understanding of what it looks like.

The Algorithm: Elimination to Reduced Row Echelon Form

The tool for finding N(A) is Gaussian elimination, carried all the way to reduced row echelon form (rref), not just row echelon form. Let me be precise about what these mean.

Row echelon form (ref): After forward elimination. Upper triangular structure. The first nonzero entry in each row (the pivot) is strictly to the right of the pivot in the row above. All zero rows are at the bottom.

Reduced row echelon form (rref): Row echelon form, plus:

  • Every pivot is 1 (scaled).
  • Every entry above a pivot is 0 (eliminated upward as well as downward).

The rref of a matrix is unique — there is only one rref for a given matrix, regardless of the order of elimination steps. That uniqueness is what makes rref the right canonical form for understanding the null space.

Pivot Columns and Free Columns

After reduction to rref, columns of A fall into two categories:

Pivot columns: Columns that contain a leading 1 (a pivot). There are r of them, where r=rank(A).

Free columns: Columns with no pivot. There are n−r of them.

The variables xj​ corresponding to free columns are called free variables. They can be set to any value. Once the free variables are chosen, the pivot variables are completely determined by back substitution.

This is the structural fact I want to internalize: N(A) has dimension n−r, and I find a basis for it by setting each free variable to 1 (and all others to 0) in turn, then solving for the pivot variables.

A Full Example: 3×4 Matrix

Let

A=[1​2​2​2 2​4​6​8 3​6​8​10​]

I want to find all x∈R4 with Ax=0.

Step 1: Forward Elimination

Pivot in column 1: value 1, row 1.

Multipliers: ℓ21​=2, ℓ31​=3.

Row 2 ← Row 2 −2⋅ Row 1:

[2​4​6​8​]−2[1​2​2​2​]=[0​0​2​4​]

Row 3 ← Row 3 −3⋅ Row 1:

[3​6​8​10​]−3[1​2​2​2​]=[0​0​2​4​]

After step 1:

[1​2​2​2 0​0​2​4 0​0​2​4​]

Column 2 has no pivot — it is all zeros below row 1 (and row 1’s entry in column 2 is above the current elimination front). Column 2 is a free column.

Pivot in column 3: value 2, row 2.

Row 3 ← Row 3 −1⋅ Row 2:

[0​0​2​4​]−[0​0​2​4​]=[0​0​0​0​]

After forward elimination (row echelon form):

U=[1​2​2​2 0​0​2​4 0​0​0​0​]

Rank r=2. Pivots in columns 1 and 3. Free columns: 2 and 4. Free variables: x2​ and x4​.

Step 2: Reduce to rref

Scale row 2 by 1/2:

[1​2​2​2 0​0​1​2 0​0​0​0​]

Eliminate above pivot in column 3: Row 1 ← Row 1 −2⋅ Row 2:

[1​2​2​2​]−2[0​0​1​2​]=[1​2​0​−2​]

Reduced row echelon form:

R=[1​2​0​−2 0​0​1​2 0​0​0​0​]

Step 3: Read Off the Solution

The system Rx=0 is:

x1​+2x2​−2x4​=0 x3​+2x4​=0

Free variables: x2​ and x4​. Solve for the pivot variables x1​ and x3​:

x1​=−2x2​+2x4​ x3​=−2x4​

Step 4: Find the Special Solutions (Basis for N(A))

Set (x2​,x4​)=(1,0): pivot variables give x1​=−2, x3​=0.

s1​=[−2 1 0 0​]

Set (x2​,x4​)=(0,1): pivot variables give x1​=2, x3​=−2.

s2​=[2 0 −2 1​]

The null space is

N(A) = \left{ x_2 \begin{bmatrix} -2 \ 1 \ 0 \ 0 \end{bmatrix} + x_4 \begin{bmatrix} 2 \ 0 \ -2 \ 1 \end{bmatrix} : x_2, x_4 \in \mathbb{R} \right} = \text{span}(\mathbf{s}_1, \mathbf{s}_2)

dimN(A)=2=n−r=4−2. The rank-nullity theorem is satisfied.

Verification

Check As1​=0:

[1​2​2​2 2​4​6​8 3​6​8​10​][−2 1 0 0​]=[−2+2 −4+4 −6+6​]=[0 0 0​]✓

Check As2​=0:

[1​2​2​2 2​4​6​8 3​6​8​10​][2 0 −2 1​]=[2+0−4+2 4+0−12+8 6+0−16+10​]=[0 0 0​]✓

The rref and the Null Space: The General Pattern

Let me make the structure explicit for the general case. Suppose A∈Rm×n has rank r. After reduction to rref, reorder the columns so that pivot columns come first. The rref looks like:

R=[Ir​​F 0​0​]

where Ir​ is r×r identity (in the pivot columns), F is r×(n−r) (the free column entries in the pivot rows), and the zero blocks are padding.

Why this structure gives the null space immediately. The equation Rx=0 with pivot variables xp​∈Rr and free variables xf​∈Rn−r reads:

Ir​xp​+Fxf​=0⟹xp​=−Fxf​

So the full solution is

x=[xp​ xf​​]=[−F In−r​​]xf​

The null space matrix is

N=[−F In−r​​]∈Rn×(n−r)

The columns of N are exactly the special solutions. The identity block In−r​ in the bottom half is what you get by setting each free variable to 1 and all others to 0 — which is exactly the procedure I followed above.

In the worked example: r=2, n−r=2. The free columns of R (columns 2 and 4) give

F=[2​−2 0​2​]

So −F=[−2​2 0​−2​] and

N=[−2​2 1​0 0​−2 0​1​]

Reading off the columns: s1​=(−2,1,0,0)T and s2​=(2,0,−2,1)T. Matches what I found above. ✓

The Rank-Nullity Theorem

Theorem. For A∈Rm×n:

rank(A)+dimN(A)=n

equivalently r+(n−r)=n.

Proof. The rref has r pivot columns and n−r free columns. Each free column produces exactly one special solution, and these solutions are linearly independent (the i-th special solution has a 1 in the i-th free variable position and 0 in all other free variable positions — the In−r​ block). So dimN(A)=n−r. □

The proof is fully constructive: not only does it tell you the dimension, it gives you the basis explicitly.

Distinct Cases by Rank

The structure of N(A) depends entirely on the rank r relative to n.

r=n (full column rank): No free variables. The only solution to Ax=0 is x=0. N(A)=0, dimension 0.

This happens exactly when the columns of A are linearly independent. The map x↦Ax is injective — different inputs give different outputs.

r<n (rank deficient in columns): There are n−r≥1 free variables. N(A) is nontrivial — it contains infinitely many vectors. Ax=0 has infinitely many solutions.

Square matrix, m=n: A is invertible if and only if r=n, i.e., N(A)=0. If A is singular, r<n and N(A) is nontrivial.

What the Null Space Really Means

Let A∈Rm×n and think of A as a linear map T:Rn→Rm, T(x)=Ax.

N(A) is the kernel of this map — the set of vectors that get sent to zero. The map collapses the entire subspace N(A) to the single point 0.

Why this matters for Ax=b. Suppose xp​ is one particular solution to Ax=b (if one exists). Then the complete solution set is:

x:Ax=b=xp​+N(A)=xp​+v:v∈N(A)

Proof. If Ax=b, then A(x−xp​)=Ax−Axp​=b−b=0, so x−xp​∈N(A). Conversely, if v∈N(A), then A(xp​+v)=Axp​+Av=b+0=b. □

The solution set of Ax=b is a coset of N(A) — a translate of the null space by the particular solution. It is not a subspace (unless b=0), but it is a flat (an affine subspace) of dimension n−r.

Remark (personal). This structure — particular solution plus null space — is the linear algebra analogue of the general solution to a linear ODE: y=yparticular​+yhomogeneous​. The homogeneous solution is always present; the particular solution shifts you to the right affine flat. I find it genuinely helpful that both settings have identical structure.

A Second Example: When There Are No Free Variables

Let

A=[1​3 2​7 0​1​]

This is 3×2, so n=2. I expect at most 2 pivots.

Forward elimination. Multiplier ℓ21​=2:

Row 2 ← Row 2 −2⋅ Row 1:

[2​7​]−2[1​3​]=[0​1​]

Row 3 has ℓ31​=0, so no change. After step 1:

[1​3 0​1 0​1​]

Row 3 ← Row 3 −1⋅ Row 2:

[0​1​]−[0​1​]=[0​0​]

Reduce to rref: Row 1 ← Row 1 −3⋅ Row 2:

[1​3​]−3[0​1​]=[1​0​]

R=[1​0 0​1 0​0​]

Rank r=2=n. Both columns are pivot columns. No free variables.

Rx=0 gives x1​=0 and x2​=0. So N(A)=0, dimension 0=n−r=2−2.

The columns of A are linearly independent.

Linear Independence via the Null Space

This gives a clean definition:

The columns of A are linearly independent if and only if N(A)=0.

Proof. The columns are linearly independent iff the only solution to Ax=0 is x=0, by definition of linear independence (x1​a1​+⋯+xn​an​=0 only when all xi​=0). This is exactly the statement N(A)=0. □

So computing the null space and testing linear independence are the same computation.

Summary of the Algorithm

Given A∈Rm×n, to find N(A):

  1. Row reduce A to rref R.
  2. Identify pivot columns and free columns. Let r = number of pivots.
  3. For each free variable xj​: set xj​=1, all other free variables =0, and solve Rx=0 for the pivot variables.
  4. Each choice gives one special solution. Collect them: s1​,…,sn−r​.
  5. N(A)=span(s1​,…,sn−r​), and s1​,…,sn−r​ is a basis for N(A).

dimN(A)=n−r. Check: r+(n−r)=n. ✓

Open Questions

  • The rref is unique: the same matrix always produces the same rref regardless of the sequence of row operations. I have used this but not proved it. The proof goes through the uniqueness of pivot positions. Worth a short proof sketch.
  • The null space of AT — the left null space N(AT) — lives in Rm and has dimension m−r. The same rref algorithm applies to AT. The left null space is orthogonal to the column space: N(AT)⊥C(A). I will establish this in Projections and Orthogonality.
  • For the complete picture: once I have N(A) and a particular solution xp​, the full solution to Ax=b is xp​+N(A). The question of when xp​ exists is the question of when b∈C(A). These two questions — solvability and solution structure — are the subject of Complete Solution to Ax=b.
