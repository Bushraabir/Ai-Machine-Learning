11.Derivative as a Function

“The derivative at a point is a number. The derivative as a function is the machine that produces that number for every point.” — Personal note, inspired by Stewart §2.2 and MIT 18.02

0. Preamble — Why This Distinction Matters

When we first define f′(a), we fix a base-point a and ask: how fast is f changing there? The answer is a single real number — the slope of the tangent line at (a,f(a)).

But nothing forced us to fix a. Let a vary freely across the domain of f, collect every such slope, and we get a new function f′ whose input is a point and whose output is the instantaneous rate of change there. This object — f′ as a function in its own right — is the subject of this note.

The conceptual leap is small but profound. Almost everything in analysis, geometry, and machine learning flows from taking this step seriously.

1. The Formal Definition

1.1 Derivative at a Point (Review)

f′(a);=;limh→0​hf(a+h)−f(a)​

provided the limit exists. Geometrically: the slope of the tangent to the graph of f at x=a.

1.2 Derivative as a Function

Definition. Let f:D⊆R→R. Define the derived function f′:D′→R by

f′(x);=;h→0lim​hf(x+h)−f(x)​​

where D′=x∈D:the above limit exists and is finite.

The variable x is now a free variable, not a fixed constant. For each x∈D′, the expression on the right produces one real number: the slope of f at that particular x.

Notation zoo. All of the following mean the same thing: f′(x);=;dxdf​;=;Df(x);=;f˙​(x);=;y′ Leibniz’s dxdf​ is particularly useful in physics and ML because it reminds you which variable you differentiated with respect to.

2. Domain of f′ — Where Differentiability Can Fail

The domain D′ of f′ can be strictly smaller than D. The limit defining f′(x) fails to exist at points where the function is:

Failure modeExampleWhat happens geometrically
Corner$f(x) =x
Cuspf(x)=x2/3 at x=0Tangent line becomes vertical (±∞)
Vertical tangentf(x)=x1/3 at x=0Slope is ±∞, limit diverges
Jump discontinuityAny step functionFunction isn’t even continuous there
Oscillationf(x)=sin(1/x) near x=0Limit does not exist

Key theorem (Stewart §2.8, Thm 4): f differentiable at a⟹f continuous at a

The converse is famously false: ∣x∣ is continuous everywhere but not differentiable at 0.

3. Computing f′ from the Definition — Worked Examples

Example 1: f(x)=x2

f′(x)=limh→0​h(x+h)2−x2​=limh→0​h2xh+h2​=limh→0​(2x+h)=2x

So f′:R→R, f′(x)=2x. Note: f′ is itself a linear function.

Example 2: f(x)=x​, domain (0,∞)

f′(x)=limh→0​hx+h​−x​​⋅x+h​+x​x+h​+x​​=limh→0​h(x+h​+x​)h​=2x​1​

Domain of f′: (0,∞) — the endpoint x=0 is excluded because f′(0)=+∞.

Example 3: f(x)=∣x∣ — a non-example

limh→0+​h∣h∣​=1,limh→0−​h∣h∣​=−1

One-sided limits disagree at x=0, so 0∈/D′. For x=0:

Reading the derivative graph:

  • Where f is increasing → f′>0
  • Where f is decreasing → f′<0
  • At a local min/max of f → f′=0 (critical point)
  • Where f is concave up → f′ is increasing → f′′>0

4.2 The “Sliding Tangent” Mental Model

Imagine a ruler tangent to the graph of f. As you slide it from left to right, the slope of the ruler at each position traces out the graph of f′.

For f(x)=sinx:

  • At x=0: tangent has slope +1 → f′(0)=1 ✓
  • At x=π/2: tangent is horizontal → f′(π/2)=0 ✓
  • At x=π: tangent has slope −1 → f′(π)=−1 ✓
  • Result: f′(x)=cosx (which the definition confirms)

5. Higher-Order Derivatives

Since f′ is itself a function, we may differentiate it again.

f′′(x)=(f′)′(x)=dx2d2f​=limh→0​hf′(x+h)−f′(x)​

Continuing inductively:

f(n)(x)=dxndnf​

Physical meaning:

  • f(t): position
  • f′(t): velocity
  • f′′(t): acceleration
  • f′′′(t): jerk (rate of change of acceleration)

Smoothness classes. We say f∈Cn(D) if f is n-times continuously differentiable on D. The hierarchy is:

C∞⊂⋯⊂C2⊂C1⊂C0

These distinctions matter enormously in analysis — and in ML, where assumptions about smoothness of loss surfaces are crucial.

6. Connection to AI, Machine Learning, and Deep Learning

This is where the derivative-as-a-function becomes operationally indispensable. Here are the key conceptual links:

6.1 Gradient Descent — The Engine of All of Modern ML

A neural network has a loss function L(θ) where θ∈Rn is a vector of millions of parameters (weights and biases). Training the network means minimizing L.

The update rule for gradient descent is:

θt+1​=θt​−η∇θ​L(θt​)

where η>0 is the learning rate and ∇θ​L is the gradient — the multivariable generalization of f′.

The derivative-as-a-function is exactly what makes this possible. We don’t just need the gradient at one fixed θ. We need it as a function of θ so that we can evaluate it at whichever θt​ we’re currently at during training. We’re sliding along the loss surface, re-computing the slope at every step.

6.2 Backpropagation — Chain Rule Applied at Scale

Backpropagation (Rumelhart et al., 1986) is an efficient algorithm for computing ∇θ​L. Its mathematical core is the chain rule:

If y=f(u) and u=g(x), then: dxdy​=dudy​⋅dxdu​

In a deep network with L layers: L=ℓL​∘ℓL−1​∘⋯∘ℓ1​(x)

Backprop computes ∂θk​∂L​ for every layer k by walking backward through the chain rule, reusing intermediate derivatives. This only makes sense if each ℓi​ is differentiable as a function — i.e., it has a well-defined derivative function we can evaluate at any point.

This is why activation functions like ReLU are analyzed so carefully. ReLU(x)=max(0,x) has ReLU′(x)=1x>0​ — it is not differentiable at x=0, but this is handled by convention (subgradient). Sigmoid σ(x)=1+e−x1​ satisfies σ′(x)=σ(x)(1−σ(x)) — a clean derivative function that’s easy to compute and enables smooth gradients.

6.3 Taylor Expansion and Second-Order Methods

The Taylor expansion of L near a point θ0​ is: L(θ0​+Δθ)≈L(θ0​)+∇L(θ0​)TΔθ+21​ΔθTHΔθ+⋯

where H=∇2L is the Hessian (matrix of second partial derivatives). Second-order optimizers (Newton’s method, L-BFGS, Shampoo) use H to take more intelligent steps. The Hessian is only available because the derivative is itself differentiable.

6.4 Automatic Differentiation (Autograd)

PyTorch, JAX, TensorFlow all implement automatic differentiation: they symbolically track the derivative function through every operation so that loss.backward() computes exact gradients (up to floating point) rather than finite differences. This is computationally possible because:

  1. Every elementary function (+, ×, sin, exp, …) has a known derivative function.
  2. The chain rule lets you compose them.
  3. The derivative is a function, so it can itself be differentiated for higher-order methods.

6.5 Differentiability as an Architectural Design Constraint

The entire paradigm of differentiable programming (or “software 2.0”) requires every component of a pipeline to have a derivative function. This drives architectural choices:

ConstraintSolutionWhy
Argmax is not differentiableSoftmax (smooth approximation)Enables gradients to flow through
Sorting is not differentiableNeuralSort, differentiable rankingSame
Discrete latent variablesGumbel-Softmax trickSame
Hard attention (argmax)Soft attentionAllows gradient-based training

7. Theorems About Differentiable Functions

7.1 Differentiability Implies Continuity

Theorem. If f is differentiable at a, then f is continuous at a.

Proof. We have f(a+h)−f(a)=hf(a+h)−f(a)​⋅h. Taking h→0: the first factor converges to f′(a) and the second to 0, so the product converges to 0. Hence limh→0​f(a+h)=f(a). ■

7.2 Rolle’s Theorem and the Mean Value Theorem

Mean Value Theorem. If f is continuous on [a,b] and differentiable on (a,b), then ∃,c∈(a,b) such that:

f′(c)=b−af(b)−f(a)​

The MVT says: the derivative function f′ must take the value of the average slope at some interior point. This theorem is the backbone of most convergence proofs in optimization theory — including guarantees on gradient descent.
