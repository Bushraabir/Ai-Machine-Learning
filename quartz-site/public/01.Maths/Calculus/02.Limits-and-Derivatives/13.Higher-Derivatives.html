The Idea: Differentiating the Derivative

If f′ is itself differentiable, we can differentiate it. The result is the second derivative:

f′′(x)=dxd​[f′(x)]=limh→0​hf′(x+h)−f′(x)​

And we can keep going. The n-th derivative of f is:

f(n)(x)=dxd​[f(n−1)(x)]

with the convention f(0)=f.

📌 Existence is not free. f′ existing at every point does not automatically mean f′′ exists. Each step of differentiation is a fresh demand on the function.

Notation (All Equivalent — Know Them All)

For the n-th derivative:

NotationRead AsTypical Use
f(n)(x)”f n-th”Pure math, when n is a variable
dxndnf​”d-n-f over d-x-n“Leibniz; PDEs, physics
dxndny​sameWhen y=f(x)
Dnf“D-n of f“Operator notation
f′′, f′′′“double prime”, “triple prime”Informal, up to n=3

⚠️ The Leibniz notation dx2d2y​ is NOT a fraction. The 2 in the numerator is an exponent on the operator d, and the 2 in the denominator is an exponent on x. This distinction matters when you get to change-of-variables.

Computing Higher Derivatives: Examples

Polynomial — Terminates

f(x)=x5−3x3+2x

f′(x)=5x4−9x2+2 f′′(x)=20x3−18x f′′′(x)=60x2−18 f(4)(x)=120x f(5)(x)=120 f(6)(x)=0and all further derivatives

General rule: dxndn​xk={(k−n)!k!​xk−n​n≤k 0​n>k​

Exponential — Never Dies

f(x)=ex⟹f(n)(x)=exfor all n≥0

This is the defining property of ex — it is a fixed point of differentiation. More generally:

dxndn​eax=aneax

Trigonometric — 4-Periodic

f(x)=sinx

f′(x)=cosx,f′′(x)=−sinx,f′′′(x)=−cosx,f(4)(x)=sinx

The cycle repeats with period 4. Compactly:

dxndn​sinx=sin!(x+2nπ​)

Proof: Check n=0,1,2,3 manually. For general n, use induction — each differentiation shifts the phase by π/2.

Natural Logarithm

f(x)=lnx

f′(x)=x−1,f′′(x)=−x−2,f′′′(x)=2x−3,f(4)(x)=−6x−4

General pattern:

f(n)(x)=xn(−1)n−1(n−1)!​,n≥1

Proof by induction: Base case n=1: f′(x)=x−1=x1(−1)0⋅0!​ ✓. Inductive step: differentiate xn(−1)n−1(n−1)!​=(−1)n−1(n−1)!⋅x−n to get (−1)n−1(n−1)!⋅(−n)x−n−1=xn+1(−1)n⋅n!​. ■

The Second Derivative: Geometric Meaning

The first derivative measures slope. The second derivative measures how the slope is changing — this is called concavity.

Concavity Defined

  • f′′>0 on (a,b): f is concave up (holds water, slopes increasing left-to-right)
  • f′′<0 on (a,b): f is concave down (spills water, slopes decreasing left-to-right)
  Concave Up (f'' > 0):       Concave Down (f'' < 0):

         /                         ---___
        /                         /      \
       /                         /        \
      /
   tangent lines lie             tangent lines lie
   BELOW the curve               ABOVE the curve

Inflection Points

A point c is an inflection point of f if f is continuous there and f′′ changes sign at c.

⚠️ f′′(c)=0 is necessary but not sufficient. Consider f(x)=x4: f′′(0)=0 but f′′≥0 everywhere — no sign change, no inflection point.

Example: f(x)=x3−3x.

f′′(x)=6x. Sign changes at x=0: negative for x<0, positive for x>0. So (0,0) is an inflection point.

The Second Derivative Test for Local Extrema

Theorem. Suppose f′(c)=0 (a critical point).

  • If f′′(c)>0: local minimum
  • If f′′(c)<0: local maximum
  • If f′′(c)=0: inconclusive — must use another method (first derivative test, or higher derivatives)

Why This Works (Intuition)

If f′(c)=0 and f′′(c)>0, then f′ is increasing at c. Since f′(c)=0 and f′ is increasing, f′ was negative just before c and positive just after — f decreased then increased, so c is a minimum.

Proof (Rigorous Version)

Assume f′(c)=0 and f′′(c)>0. By definition of f′′(c):

f′′(c)=limh→0​hf′(c+h)−f′(c)​=limh→0​hf′(c+h)​>0

Since the limit is positive, there exists δ>0 such that for 0<∣h∣<δ:

hf′(c+h)​>0

This means:

  • For h∈(0,δ): h>0 so f′(c+h)>0
  • For h∈(−δ,0): h<0 so f′(c+h)<0

Therefore f′<0 just left of c and f′>0 just right of c: c is a local minimum. ■

The n-th Derivative Test (General Case)

When f′(c)=f′′(c)=⋯=f(n−1)(c)=0 but f(n)(c)=0:

  • If n is odd: c is an inflection point (no extremum)
  • If n is even and f(n)(c)>0: local minimum
  • If n is even and f(n)(c)<0: local maximum

Example: f(x)=x4 at x=0.

f′(0)=f′′(0)=f′′′(0)=0, f(4)(0)=24>0. n=4 is even, so local minimum. ✓

Example: f(x)=x3 at x=0.

f′(0)=f′′(0)=0, f′′′(0)=6=0. n=3 is odd, so inflection point. ✓

Leibniz Rule for Higher Derivatives of a Product

For the product of two functions, the first derivative gives the product rule. For the n-th derivative:

dxndn​[f(x)g(x)]=∑k=0n​(kn​)f(k)(x),g(n−k)(x)

This is structurally identical to the binomial theorem (a+b)n=∑k=0n​(kn​)akbn−k.

Example

Find dx3d3​[x2ex].

Let f=x2, g=ex. Note f′=2x, f′′=2, f′′′=0, and g(k)=ex for all k.

dx3d3​[x2ex]=(03​)x2ex+(13​)2x⋅ex+(23​)2⋅ex+(33​)0⋅ex

=x2ex+6xex+6ex=ex(x2+6x+6)

Smooth Functions: The Class Cn

Definitions

  • f∈C0 (or just C): f is continuous
  • f∈C1: f is continuously differentiable (f′ exists and is continuous)
  • f∈Cn: f(1),f(2),…,f(n) all exist and are continuous
  • f∈C∞: f is smooth — all derivatives of all orders exist
  • f∈Cω: f is analytic — smooth AND equals its Taylor series locally

The Strict Hierarchy

Cω⊊C∞⊊⋯⊊Cn⊊Cn−1⊊⋯⊊C1⊊C0

Each inclusion is strict. Here’s the standard example separating C∞ from Cω:

f(x)={e−1/x2​x=0 0​x=0​

Claim: f(n)(0)=0 for all n≥0, yet f≡0.

Proof sketch: By induction, one shows f(n)(x)=Pn​(1/x)e−1/x2 for some polynomial Pn​, and limx→0​x−ke−1/x2=0 for every k (exponential beats any polynomial). So f(n)(0)=0 for all n.

The Taylor series of f at 0 is identically zero — but f is not zero. So f∈C∞∖Cω.

📌 This is the bump function prototype — the building block of all smooth cutoff functions in differential geometry and PDE theory.

Taylor’s Theorem: Why Higher Derivatives Matter

Higher derivatives are not just abstractions — they are the coefficients of the best polynomial approximation to f.

Taylor Polynomial of Degree n

Pn​(x)=∑k=0n​k!f(k)(a)​(x−a)k

=f(a)+f′(a)(x−a)+2!f′′(a)​(x−a)2+⋯+n!f(n)(a)​(x−a)n

Taylor’s Theorem with Remainder (Lagrange Form)

Theorem. If f∈Cn+1 on an interval containing a and x, then:

f(x)=Pn​(x)+Rn​(x)

where the remainder satisfies:

Rn​(x)=(n+1)!f(n+1)(c)​(x−a)n+1

for some c strictly between a and x.

Interpretation: The error from the degree-n approximation is controlled by the (n+1)-th derivative. The smoother the function, the faster the Taylor approximation converges.

Visualization

f(x) = sin(x) near x = 0:

    P₁(x) = x                    ≈ good for |x| < 0.5
    P₃(x) = x - x³/6             ≈ good for |x| < 1.5
    P₅(x) = x - x³/6 + x⁵/120   ≈ good for |x| < 2.5

        actual sin(x)

    P₁: ---/-----\---  (just a line, diverges fast)

The Second Derivative in Physics: Acceleration

If s(t) is position as a function of time:

  • v(t)=s′(t): velocity (rate of change of position)
  • a(t)=s′′(t)=v′(t): acceleration (rate of change of velocity)
  • j(t)=s′′′(t): jerk (rate of change of acceleration — relevant in mechanical engineering, roller coaster design)
  • s(4)(t): snap (or jounce)
  • s(5)(t): crackle
  • s(6)(t): pop

Newton’s second law F=ma=ms′′(t) is a second-order ODE. The entire framework of classical mechanics lives in second derivatives.

Connection to AI, Machine Learning & Deep Learning

Higher derivatives are not just background mathematics in ML — they drive some of the most important algorithms.

1. Loss Landscape and the Hessian

In training a neural network with parameters θ∈Rd, the loss function L(θ) is a scalar function of millions of variables. The Hessian matrix is the matrix of second partial derivatives:

Hij​=∂θi​,∂θj​∂2L​

The Hessian encodes the curvature of the loss landscape:

  • Positive definite H: local minimum (all eigenvalues >0)
  • Negative definite H: local maximum
  • Indefinite H (mixed eigenvalues): saddle point

In high-dimensional spaces (millions of parameters), saddle points are far more common than local minima. This is a second-order phenomenon entirely.

Loss landscape (schematic, 2D slice):

          saddle
    \      |      /
     \     |     /
      \____|____/    <-- local min
              
   SGD can escape saddles; Newton's method needs Hessian

2. Newton’s Method and Second-Order Optimization

Gradient descent uses only first derivatives: θ←θ−η∇θ​L

Newton’s method uses second derivatives: θ←θ−H−1∇θ​L

This is derived from the second-order Taylor expansion of L: L(θ+δ)≈L(θ)+∇LTδ+21​δTHδ

Minimizing over δ: set gradient to zero ⇒Hδ=−∇L⇒δ=−H−1∇L.

Newton’s method converges quadratically (number of correct digits doubles each step), versus gradient descent’s linear convergence. The catch: computing H−1 costs O(d3) for d parameters — completely infeasible when d=108.

K-FAC, L-BFGS, Shampoo are practical second-order optimizers that approximate H−1 efficiently. These are active research areas.

When you compute a Taylor expansion of the network output, you need higher derivatives of the activation functions. Smooth activations allow the network to represent higher-frequency content more efficiently.

4. Meta-Learning and MAML

Model-Agnostic Meta-Learning (MAML) (Finn et al., 2017) requires differentiating through the optimization process. The outer loop update involves:

∂θ∂​L!(θ−α∇θ​L(θ))

Expanding this via chain rule produces second derivatives ∂θ2∂2L​. You’re literally computing the gradient of a gradient. This is sometimes called a meta-gradient and is a second-order calculation.

First-order MAML (FOMAML) drops these second-derivative terms — it’s faster but less accurate. Reptile is another approximation that avoids second derivatives entirely. The choice is a direct engineering tradeoff around the cost of computing f′′.

5. Neural ODEs

Neural ODEs (Chen et al., 2018) define dynamics as:

dtdh​=fθ​(h(t),t)

Training these requires the adjoint method, which involves solving a related ODE backward in time. The sensitivity equations involve derivatives of fθ​ with respect to both state and parameters — essentially second-order information. This is the deep learning version of classical sensitivity analysis in ODEs.

6. Smooth Loss Landscapes and Generalization

Recent theoretical work (particularly sharpness-aware minimization, SAM) argues that minima with small ∣H∣ (flat minima, low curvature) generalize better than sharp minima (large ∣H∣, high curvature).

The intuition: if a minimum is flat (second derivative small), small perturbations to θ don’t change L much — the model is robust. If a minimum is sharp (second derivative large), tiny perturbations to θ increase loss significantly — the model may be overfitted.

SAM explicitly minimizes: max∣ϵ∣≤ρ​L(θ+ϵ)

which amounts to penalizing large Hessian eigenvalues — a second-order regularization strategy.

7. Double Descent and the Role of Curvature

The double descent phenomenon in overparameterized models (where test loss decreases again after the interpolation threshold) can be partially explained via the spectrum of the Hessian at the interpolating solution. This is an active frontier connecting second-order calculus to statistical learning theory.

Implicit Differentiation and Higher Derivatives

For implicitly defined curves F(x,y)=0, you can find y′′ by differentiating y′ implicitly.

Example: x2+y2=r2 (circle)

First derivative. Differentiate implicitly: 2x+2y⋅y′=0⟹y′=−yx​

Second derivative. Differentiate y′=−x/y implicitly: y′′=−y2y⋅1−x⋅y′​=−y2y−x(−x/y)​=−y3y2+x2​=−y3r2​

This is the formula for the curvature of a circle: κ=∣y′′∣/(1+y′2)3/2, which is constant (as expected for a circle).

Parametric Curves (MIT 18.02 Perspective)

For x=x(t), y=y(t):

dxdy​=dx/dtdy/dt​=x˙y˙​​

For the second derivative — do not differentiate y˙​/x˙ with respect to t and stop there:

dx2d2y​=dxd​![dxdy​]=x˙dtd​![x˙y˙​​]​

Example: x=t2, y=t3.

dxdy​=2t3t2​=23t​

dx2d2y​=dtd​![23t​]÷x˙=2t3/2​=4t3​

Worked Problems

Problem 1 — Find all derivatives

f(x)=sin(2x).

f′(x)=2cos(2x), f′′(x)=−4sin(2x), f′′′(x)=−8cos(2x), f(4)(x)=16sin(2x).

Pattern: f(n)(x)=2nsin(2x+nπ/2).

Problem 2 — Concavity and Inflection

f(x)=x4−4x3.

f′(x)=4x3−12x2, f′′(x)=12x2−24x=12x(x−2).

f′′=0 at x=0 and x=2.

Sign of f′′:

  • x<0: 12(−)(−)>0 — concave up
  • 0<x<2: 12(+)(−)<0 — concave down
  • x>2: 12(+)(+)>0 — concave up

Both x=0 and x=2 are inflection points (sign changes at both).

Problem 3 — Second Derivative Test

f(x)=x3−6x2+9x+1.

f′(x)=3x2−12x+9=3(x−1)(x−3).

Critical points: x=1, x=3.

f′′(x)=6x−12.

f′′(1)=−6<0 → local maximum at x=1.
f′′(3)=6>0 → local minimum at x=3.

Find dx4d4​[x3sinx].

Let f=x3 (so f(k)=0 for k>3), g=sinx (so g(k)=sin(x+kπ/2)).

dx4d4​[x3sinx]=∑k=03​(k4​)f(k)g(4−k)

=(04​)x3sin(x+2π)+(14​)3x2sin(x+23π​)+(24​)6xsin(x+π)+(34​)6sin(x+2π​)

Things to Think About

  • Is there a function f with f′′(x)>0 everywhere but f not convex in the global sense? (No — prove this using the MVT.)
  • What does f(n)≡0 tell you about f? (It’s a polynomial of degree <n.)
  • In the Taylor remainder Rn​(x)=(n+1)!f(n+1)(c)​(x−a)n+1, what does it mean for the remainder to be exactly zero?
  • How does automatic differentiation (forward-mode vs reverse-mode) handle second derivatives computationally?
  • Can you define a “fractional derivative” f(1/2)? (Yes — this is the Riemann–Liouville fractional derivative, and it’s genuinely useful in physics.)
