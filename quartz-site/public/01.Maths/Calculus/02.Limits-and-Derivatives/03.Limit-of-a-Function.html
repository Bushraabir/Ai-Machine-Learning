“The limit is not about what happens at the point. It is about what the function is trying to become. This distinction — between the value and the approach — is the philosophical heart of analysis.”

§1. The Motivating Crisis

Consider the function:

f(x)=x−1x2−1​

At x=1: the numerator is 0, the denominator is 0. The function is undefined at x=1.

And yet — something is happening near x=1. Factor:

f(x)=x−1(x−1)(x+1)​=x+1for x=1

The function wants to equal 2 at x=1, even though it doesn’t exist there.

This “wanting” is the limit. Calculus is built on making this precise.

The values approach 2 from both sides. We write:

limx→1​x−1x2−1​=2

§2. Informal Definition

Informal Definition. We write x→alim​f(x)=L and say “the limit of f(x) as x approaches a equals L” if we can make f(x) as close to L as we like by taking x sufficiently close to a (but x=a).

Three things to note immediately:

  1. x=a is mandatory. The limit is about approach, not arrival. The value f(a) is irrelevant — f need not even be defined at a.
  2. Both sides. x must be able to approach a from the left and from the right, and both approaches must yield L.
  3. L must be a finite real number (for now — we will extend to ±∞).

§3. The Formal ε-δ Definition

The informal definition uses phrases like “as close as we like” and “sufficiently close.” These are meaningless without precision. The ε-δ definition eliminates all ambiguity.

Definition (Cauchy-Weierstrass). We say x→alim​f(x)=L if:

∀ε>0, ∃δ>0  such that  0<∣x−a∣<δ⟹∣f(x)−L∣<ε

Parsing the Definition

  • ε (epsilon) measures the tolerated error in output: how close f(x) must be to L.
  • δ (delta) measures the required precision in input: how close x must be to a.
  • The challenge is: given any ε>0 (no matter how tiny), find a δ>0 that works.
  • 0<∣x−a∣ encodes x=a.
The ε-δ picture:

ε-δ Proof: Example

Claim: x→3lim​(2x−1)=5.

Proof. Let ε>0 be given. We need ∣f(x)−5∣<ε whenever 0<∣x−3∣<δ.

Compute: ∣f(x)−5∣=∣(2x−1)−5∣=∣2x−6∣=2∣x−3∣

So ∣f(x)−5∣<ε⟺2∣x−3∣<ε⟺∣x−3∣<2ε​.

Choose δ=2ε​. Then:

0<∣x−3∣<δ=2ε​⟹∣f(x)−5∣=2∣x−3∣<2⋅2ε​=ε■

The key technique: work backwards from ∣f(x)−L∣<ε to find the required δ. The algebra determines δ; then you write the proof forwards.

§4. One-Sided Limits

Sometimes f approaches different values from the left and from the right. We need finer tools.

Definition. The left-hand limit is:

limx→a−​f(x)=L(x approaches a from below)

Definition. The right-hand limit is:

limx→a+​f(x)=L(x approaches a from above)

Theorem.

limx→a​f(x)=L⟺limx→a−​f(x)=Landlimx→a+​f(x)=L

The two-sided limit exists if and only if both one-sided limits exist and are equal.

§5. When Limits Fail to Exist

There are three canonical failure modes:

Case 1: Jump Discontinuity

Left and right limits both exist but are unequal. (Heaviside function above.)

Case 2: Infinite Oscillation

f(x)=sin!(x1​)as x→0

sin(1/x) near x = 0:

  1 |  ~~~~~~~~~~~~~~~~~~~~
    |  oscillations become
  0 |  infinitely rapid
    |  as x → 0
 -1 |  ~~~~~~~~~~~~~~~~~~~~
    |________________________ x
    -0.1  0  0.1

The function oscillates infinitely between −1 and 1. Neither one-sided limit exists. No limit.

Case 3: Divergence to Infinity

limx→0​x21​=+∞

This is a convention — we say the limit is +∞ to describe the behavior, but +∞ is not a real number. The limit does not exist in R; we are describing how it fails.

§6. Limit Laws

Once we know the limit of simple functions, we can build complex limits algebraically.

Theorem (Limit Laws). If x→alim​f(x)=L and x→alim​g(x)=M, then:

LawStatement
Sumlim[f+g]=L+M
Differencelim[f−g]=L−M
Constant multiplelim[cf]=cL
Productlim[f⋅g]=L⋅M
Quotientlim[f/g]=L/M, provided M=0
Powerlim[fn]=Ln
Rootlimnf​=nL​, provided L>0 for even n

Corollary (Direct Substitution Property). If f is a polynomial or rational function and a is in the domain of f, then:

limx→a​f(x)=f(a)

This is the content of continuity — for “nice” functions, the limit and the value agree.

§7. The Squeeze Theorem

Theorem (Squeeze / Sandwich Theorem). If:

g(x)≤f(x)≤h(x)

near a (but not necessarily at a), and:

limx→a​g(x)=limx→a​h(x)=L

then:

limx→a​f(x)=L

§8. Limits at Infinity and Horizontal Asymptotes

Definition. x→+∞lim​f(x)=L means: for every ε>0, there exists N such that x>N⟹∣f(x)−L∣<ε.

The line y=L is a horizontal asymptote.

Examples

limx→∞​x1​=0,limx→∞​x2−13x2+2x​=3,limx→∞​e−x=0

§11. Connection to Continuity

Definition. f is continuous at a if all three conditions hold:

  1. f(a) is defined.
  2. x→alim​f(x) exists.
  3. x→alim​f(x)=f(a).

Failure of any one condition creates a discontinuity:

Failure modeTypeExample
f(a) undefined, limit existsRemovablex−1x2−1​ at x=1
One-sided limits unequalJumpH(x) at x=0
Limit is ±∞Infinite1/x2 at x=0
Limit doesn’t exist (oscillation)Essentialsin(1/x) at x=0

Removable discontinuity is the most important: the limit exists, but f(a) is either missing or wrong. We can repair it by redefining f(a)=L.

The derivative f′(a)=limh→0​hf(a+h)−f(a)​ is a limit of a difference quotient. Every result in differential calculus — every differentiation rule, every theorem — is a theorem about limits in disguise.

§12. Connection to AI, Machine Learning, and Deep Learning

The limit is the mathematical foundation of every continuous operation in ML. Understanding limits is understanding why neural networks can approximate, generalize, and converge.

12.1 The Universal Approximation Theorem

The Universal Approximation Theorem states (informally): a feedforward neural network with one hidden layer and enough neurons can approximate any continuous function f:Rn→R to arbitrary precision.

The word arbitrary precision is a limit statement:

∀ε>0, ∃ a network Nε​ such that supx​∣Nε​(x)−f(x)∣<ε

This is ε-δ logic applied to function spaces. Neural networks are approximating the limit of a sequence of functions. The depth of modern networks pushes this from width-approximation toward depth-approximation, but the ε-precision language is identical.

12.2 Gradient Descent Convergence

For a convex loss L, gradient descent with step size η produces iterates w(t) satisfying:

limt→∞​L(w(t))=L∗

This is a limit at infinity — the loss approaches its minimum as iteration count grows. The convergence rate determines how fast this limit is approached. For strongly convex L:

L(w(t))−L∗≤(1−ημ)t(L(w(0))−L∗)

The right side →0 as t→∞ (geometric decay). The limit is zero; convergence is guaranteed.

12.3 Softmax and the Limit as Temperature → 0

The softmax function:

softmax(z/T)i​=∑j​ezj​/Tezi​/T​

As T→0+, softmax approaches the argmax function — a one-hot vector. This is a limit of a continuous function approaching a discontinuous one. It explains why during inference (low temperature) the model becomes more “decisive,” while during training (higher temperature) probability mass is spread more smoothly.

12.4 Vanishing Gradients and Limits

In deep networks, the gradient of the loss with respect to early-layer weights involves products of Jacobians. For sigmoid activations σ(x)=1+e−x1​:

σ′(x)=σ(x)(1−σ(x))≤41​

In a network with L layers, the gradient magnitude is bounded by:

∣∇w1​​L∣≤(41​)L⋅C

As L→∞:

limL→∞​(41​)L=0

This is the vanishing gradient problem — a limit at infinity converging to zero, making early layers untrainable. The solution (BatchNorm, ResNets, ReLU) is fundamentally about preventing this limit from being reached.

12.5 L’Hôpital’s Rule in Loss Analysis

The 00​ indeterminate form appears in ML theory. For example, when analyzing the cross-entropy loss:

L=−∑i​yi​logp^​i​

as p^​i​→0 for a true class (yi​=1):

limp^​→0+​p^​logp^​=limp^​→0+​1/p^​logp^​​=L’Hlimp^​→0+​−1/p^​21/p^​​=limp^​→0+​(−p^​)=0

This ensures the loss remains finite (and the KL divergence is well-defined) even at boundary probabilities.

Every activation function is designed with its limiting behavior in mind — what does it do to very large or very small inputs? That is a question about limits at infinity.

§13. L’Hôpital’s Rule

For completeness — the most powerful tool for 00​ and ∞∞​ indeterminate forms.

Theorem (L’Hôpital). If x→alim​f(x)=0 and x→alim​g(x)=0 (or both ±∞), and g′(x)=0 near a, then:

limx→a​g(x)f(x)​=limx→a​g′(x)f′(x)​

provided the right side exists.

Example

limx→0​xex−1​=L’Hlimx→0​1ex​=1

This is the derivative of ex at x=0 — L’Hôpital confirms the definition.

Warning: L’Hôpital requires the 00​ or ∞∞​ form. Applying it to limx→0​x+1sinx​=10​ (not indeterminate!) would give the wrong answer.

§14. Precise Proof Technique Summary

When writing ε-δ proofs:

  1. Scratch work (backwards): Start from ∣f(x)−L∣<ε. Simplify. Find what ∣x−a∣< ? must be.
  2. Bound complications: If ∣f(x)−L∣ involves ∣x−a∣ multiplied by something that depends on x, bound that factor by assuming ∣x−a∣<1 (say), then choose δ=min(1,ε/bound).
  3. Write the proof forwards: State δ, assume 0<∣x−a∣<δ, chain inequalities to conclude ∣f(x)−L∣<ε.

Example with Bounding

Claim: x→2lim​x2=4.

Scratch: ∣x2−4∣=∣x−2∣∣x+2∣. Need to bound ∣x+2∣.

Assume ∣x−2∣<1, so 1<x<3, so ∣x+2∣<5.

Thus ∣x2−4∣<5∣x−2∣. Need 5∣x−2∣<ε, i.e., ∣x−2∣<ε/5.

Proof. Let ε>0. Set δ=min!(1,5ε​).

If 0<∣x−2∣<δ, then ∣x−2∣<1⇒∣x+2∣<5, and:

∣x2−4∣=∣x−2∣∣x+2∣<5ε​⋅5=ε■
