05.Infinite Limits

05.Infinite Limits

Apr 16, 202615 min read

“Infinity is not a number. It is a direction — and limits are how we speak precisely about directions.”

Tags

#calculus #real-analysis #limits #asymptotes #deep-learning #machine-learning #numerical-stability

0. Motivation: When Functions Blow Up

Consider f(x)=x21​.

As x→0, the denominator collapses to zero while the numerator stays fixed. The output does not approach any finite number — it grows without bound. But it grows predictably, consistently, from both sides. This is not chaos. It is a precise, describable behavior, and we need language for it.

Infinite limits answer: what does it mean, rigorously, for a function to “go to infinity”?

The answer is not “the limit equals ∞” as if ∞ were a number on the real line. It is a carefully crafted statement about the behavior of f(x) for x near some point a.

1. Informal Picture

    f(x)
      |
      |     |        |
  M   | ····|········|·····   ← eventually, f(x) stays above any M
      |     |        |
      |      \      /
      |       \    /
      |        \  /
      |         \/
      +—————————+————————> x
                a

No matter how large M you choose, for x sufficiently close to a (but x=a), f(x)>M. The function escapes every finite ceiling.

2. Formal Definitions

2.1 Limit Equals +∞

Definition (Stewart §2.2; Rudin Ch. 4). We say limx→a​f(x)=+∞ if for every M>0, there exists δ>0 such that 0<∣x−a∣<δ⟹f(x)>M.

Reading it carefully:

  • The role of ε in the standard limit is now played by M — but M measures largeness, not closeness.
  • There is no "∣f(x)−L∣<ε" because there is no finite L to be close to.
  • For every finite ceiling M, we can find a neighborhood of a where f exceeds it.
  • This is not “the limit is undefined.” It is a specific, precise type of behavior.

2.2 Limit Equals −∞

Definition. We say limx→a​f(x)=−∞ if for every N<0 (equivalently, every M>0), there exists δ>0 such that 0<∣x−a∣<δ⟹f(x)<N.

The function falls below every finite floor.

2.3 One-Sided Infinite Limits

We naturally combine the one-sided approach with the infinite behavior:

limx→a+​f(x)=+∞means:∀M>0, ∃δ>0: 0<x−a<δ⟹f(x)>M.

limx→a−​f(x)=−∞means:∀N<0, ∃δ>0: 0<a−x<δ⟹f(x)<N.

All four combinations (±∞, a±) are possible. Each is its own precise definition.

3. Vertical Asymptotes — The Geometric Meaning

Definition. The line x=a is a vertical asymptote of f if at least one of the following holds: limx→a+​f(x)=±∞orlimx→a−​f(x)=±∞.

Key point: a vertical asymptote is a consequence of an infinite limit — not a definition in itself. The limit statement comes first; the asymptote language is shorthand.

4. The Extended Real Line R

In real analysis, one formally adjoins two symbols to R: R=R∪−∞,+∞.

Arithmetic rules on R (partial):

Warning. The indeterminate forms are not undefined because we are ignorant — they are undefined because different functions can approach 0⋅∞ with any answer. L’Hôpital’s Rule is the tool for resolving them.

Example 5.3 — Logarithm at Zero

limx→0+​lnx=−∞.

Proof. Let N<0. We need δ>0 such that 0<x<δ⟹lnx<N.

lnx<N⟺x<eN. Since N<0, we have eN∈(0,1). Choose δ=eN>0. Then 0<x<δ=eN⟹lnx<N. ■

This is why log-loss in machine learning requires the predicted probability p^​ to be clipped away from zero. If p^​→0+, then −lnp^​→+∞ and the loss explodes.

Example 5.4 — Rational Functions

limx→2​(x−2)2x+1​.

Near x=2: numerator →3>0, denominator (x−2)2→0+. Hence the ratio →+∞.

limx→2​(x−2)2x+1​=+∞.

Now consider: limx→3+​x−3x−5​.

Near x=3+: numerator →−2<0, denominator →0+. Hence ratio →−∞.

limx→3+​x−3x−5​=−∞.

The sign rule for rational blow-up:

If limx→a​p(x)=L=0 and limx→a​q(x)=0, then limx→a​q(x)p(x)​=±∞. The sign is determined by the signs of L and q(x) near a.

Example 5.5 — Oscillation vs. Blow-Up

f(x)=x1​sin!(x1​),x=0.

As x→0, ∣f(x)∣≤∣x∣1​→∞ in magnitude, but the function oscillates. Neither one-sided limit is +∞ or −∞ in a consistent way — the limit does not exist in any sense. Blow-up requires monotone escape, not mere unboundedness in fluctuation.

6. Indeterminate Forms and L’Hôpital’s Rule

When a limit naively produces an indeterminate form, further analysis is required.

The seven classical indeterminate forms:

00​,∞∞​,0⋅∞,∞−∞,00,∞0,1∞.

L’Hôpital’s Theorem (Stewart §4.4). Suppose limx→a​f(x)=0 and limx→a​g(x)=0 (or both →±∞), and g′(x)=0 near a. Then limx→a​g(x)f(x)​=limx→a​g′(x)f′(x)​, provided the right-hand limit exists (possibly ±∞).

Key Examples

∞∞​ form: limx→∞​xlnx​=limx→∞​11/x​=0.

Logarithm grows slower than any power. Used in complexity analysis.

0⋅∞ form — rewrite as 00​ or ∞∞​: limx→0+​xlnx=limx→0+​1/xlnx​=limx→0+​−1/x21/x​=limx→0+​(−x)=0.

This is the reason the entropy term plnp→0 as p→0+ — critical in information theory and cross-entropy loss.

∞−∞ form — algebraically combine: limx→0​(sinx1​−x1​)=limx→0​xsinxx−sinx​=L’Hlimx→0​sinx+xcosx1−cosx​=L’Hlimx→0​2cosx−xsinxsinx​=0.

8. Rates of Growth — A Hierarchy

Infinite limits are about how fast functions blow up. This hierarchy is fundamental:

lnx≪xp≪xq≪ax≪x!≪xx(p<q, a>1, as x→+∞)

More precisely, for p>0, a>1: limx→∞​xplnx​=0,limx→∞​axxp​=0,limx→∞​x!ax​=0.

   Growth rate (schematic, as x → ∞):

   x^x  ↑ fastest
   x!   ↑
   a^x  ↑
   x^q  ↑
   x^p  ↑  (p < q)
   ln x ↑ slowest

   Each is "infinitely smaller" than the one above it.

Why this matters in ML. Exponential blow-up appears in softmax without numerical tricks. Factorial blow-up appears in combinatorial search. Understanding the growth hierarchy tells you which quantities need to be log-transformed, normalized, or clipped.

10. Connection to Continuity and Differentiability

Infinite limits and continuity: If limx→a​f(x)=±∞, then f is not continuous at a (continuity requires a finite limit equal to f(a)). This is a type II discontinuity (infinite discontinuity).

Classification of discontinuities:

TypeDescriptionExample
RemovableLimit exists (finite), but =f(a)xsinx​ at 0
JumpBoth one-sided limits finite but unequalsgn(x) at 0
InfiniteAt least one one-sided limit is ±∞x1​ at 0
OscillatoryLimit does not exist, neither finite nor infinitesin(1/x) at 0

Infinite limits and differentiation: By the limit definition, if f′(a)=±∞, we say f has a vertical tangent at a. For instance: f(x)=x1/3,f′(x)=31​x−2/3,limx→0​f′(x)=+∞. The tangent line is vertical. f is continuous but not differentiable (in the usual sense) at 0.

11. Connection to AI / Machine Learning / Deep Learning

11.1 Numerical Overflow and Underflow

In IEEE 754 floating-point, numbers have finite range. When a computation exceeds float32 max (≈3.4×1038), the result is inf. This is a computational infinite limit — the mathematical function is fine, but the representation fails.

Softmax instability: softmax(z)i​=∑j​ezj​ezi​​. If any zi​ is large (say, 1000), ezi​ overflows to inf. The standard fix: subtract the maximum logit. softmax(z)i​=∑j​ezj​−maxj​zj​ezi​−maxj​zj​​. This is valid because limx→∞​exex​=1 — the limit of the ratio is preserved. The numerical trick is justified by a limit argument.

11.2 Log-Loss and the Entropy Limit

Cross-entropy loss: L=−∑i​yi​logp^​i​.

If p^​i​→0+ and yi​=1: −logp^​i​→+∞.

The loss blows up. This is an infinite limit at work. In practice, numerical libraries clip p^​i​ to [ε,1−ε] for small ε>0 to prevent the computation from reaching the vertical asymptote of −logx at x=0.

The mathematical fact: limx→0+​(−logx)=+∞ — rigorously proved as in Example 5.3.

11.3 Vanishing and Exploding Gradients

In deep networks, gradients are products of Jacobians across layers. Two pathologies arise from infinite limit behavior:

Exploding gradients: ∣∇θ​L∣→∞ as network depth increases. The product of many matrices with spectral radius >1 grows without bound — a discrete-time analogue of limn→∞​rn=∞ for r>1.

Vanishing gradients: ∣∇θ​L∣→0 — the other extreme. Sigmoid saturates because: limx→+∞​σ′(x)=limx→+∞​σ(x)(1−σ(x))=1⋅0=0. The derivative approaches zero as input grows. The gradient effectively “dies.”

Gradient clipping (for exploding) and residual connections / batch normalization (for vanishing) are engineering responses to these limit behaviors.

11.4 Softplus as a Smooth Approximation to ReLU

softplus(x)=ln(1+ex).

As x→−∞: softplus(x)→ln(1)=0. As x→+∞: softplus(x)=ln(1+ex)≈ln(ex)=x→+∞.

So softplus approximates ReLU. Its derivative is exactly σ(x) (the sigmoid), which is smooth and bounded. The infinite limit behavior at +∞ is linear — the same growth rate as ReLU — but the transition is smooth.

11.5 KL Divergence and Infinite Penalties

The KL divergence: DKL​(P∣Q)=∑x​P(x)logQ(x)P(x)​.

If P(x)>0 but Q(x)=0 for some x: the term logQ(x)P(x)​→+∞. Hence DKL​(P∣Q)=+∞.

This is not a flaw — it is a feature. It means: if Q assigns zero probability to an event that P says is possible, the distributions are “infinitely different.” Variational autoencoders and variational inference must ensure Q has full support to keep DKL​ finite. This is an infinite limit providing a hard constraint.

11.6 Weight Initialization and the Spectral Norm

For a linear layer y=Wx, the spectral norm ∣W∣2​=σmax​(W). If weights are poorly initialized, activations can grow without bound through layers: limL→∞​∣WLx∣=+∞if σmax​(W)>1.

Xavier/He initialization ensures σmax​(W)≈1, keeping the limit finite. Understanding why initialization matters requires understanding infinite limits.

12. Common Pitfalls

⚠️ limf(x)=∞ does not mean the limit “does not exist.” It means the limit exists in R and equals +∞. In R, it is true that no finite limit exists — but be precise about which sense you mean.

⚠️ ∞ is not a number you can plug in. You cannot write f(∞) for a function f:R→R. The expression limx→∞​ is a limit, not a function evaluation.

⚠️ Indeterminate = undefined. 00​ is indeterminate: the limit might exist; we just can’t determine it from the form alone. 01​ (with 1=0) is not indeterminate — it signals ±∞ (sign depending on the side of approach).

⚠️ L’Hôpital applies only to 00​ or ∞∞​. Applying it to 01​ or ∞3​ (which are not indeterminate) gives wrong answers.

⚠️ Oscillation is not blow-up. f(x)=x1​sinx1​ is unbounded near 0 but has no infinite limit. “Unbounded” and “limit equals ±∞” are different statements.

14. Practice Problems

  1. (Definition) Prove rigorously that limx→0+​x1​=+∞ using the M-δ definition.

  2. (Sign analysis) Determine the sign of each one-sided limit and state whether a vertical asymptote exists: f(x)=(x+1)2(x−2)x−3​atx=−1 and x=2.

  3. (Indeterminate forms) Evaluate using L’Hôpital or algebraic manipulation: limx→∞​xe−x,limx→0+​xx,limx→∞​(1+x1​)x.

  4. (Growth hierarchy) Arrange in increasing order of growth rate as x→∞: x100,ex,ln(lnx),x!,2x,xx. Justify each comparison with a limit.

  5. (ML connection) Let p∈(0,1) be a predicted probability. Compute limp→0+​plnp and explain why this implies that the entropy H(p)=−plnp−(1−p)ln(1−p) extends continuously to [0,1].

  6. (Proof) Let f be continuous on (a,b) with limx→a+​f(x)=+∞. Prove that f is unbounded on (a,a+ε) for every ε>0. (This sounds obvious — make it rigorous.)
