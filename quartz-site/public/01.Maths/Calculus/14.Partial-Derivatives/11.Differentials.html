11.Differentials

Apr 23, 202614 min read

“The derivative tells you the rate. The differential tells you the amount — infinitesimally. One is a number; the other is a linear map. Confusing them is the source of half the errors in applied mathematics.”

§1. Motivation — Why Differentials?

In single-variable calculus, the derivative f′(a) is a number. But the expression

dy=f′(x),dx

is something different: it is a linear approximation to the change in y given a small change dx in x. This object — a differential — carries more structural information than the derivative alone. It:

  • Lives in the dual space (acts on tangent vectors, returns scalars)
  • Transforms correctly under change of variables (chain rule becomes trivial)
  • Generalizes naturally to surfaces, manifolds, and high-dimensional parameter spaces
  • Is the building block of integration, differential forms, and the entire apparatus of modern geometry

The goal of this note is to understand differentials rigorously, compute with them fluently, and see exactly how they power machine learning.

§2. Differentials in One Variable

2.1 — The Setup

Let y=f(x), and suppose f is differentiable at x. Define:

  • dx — an independent variable representing an arbitrary increment in x
  • Δx=dx — the actual change (same thing here)
  • Δy=f(x+dx)−f(x) — the actual change in y

Definition. The differential of y is:

dy=f′(x),dx

Key point. dx is a free variable — it can be anything. dy is then determined by it. Together, (dx,dy) parameterize the tangent line at x.

2.2 — The Error

The relationship between Δy and dy:

Δy=f′(x),dx+ε⋅dx,where ε→0 as dx→0

More precisely, by Taylor’s theorem:

Δy=dy+higher-order terms21​f′′(x)(dx)2+⋯​​

So dy approximates Δy with error O((dx)2) — quadratically small. This is what makes differentials useful for estimation.

2.3 — Geometric Picture

  y
  |          * ← actual point (x+dx, f(x+dx))
  |        /·
  |      /  ← Δy (actual rise)
  |    /·· ← dy (tangent line rise)
  |  * ← (x, f(x))
  |________________________ x
       dx

dy is the rise along the tangent line; Δy is the rise along the curve. They agree to first order.

§3. Differentials in Several Variables

3.1 — Definition

Let z=f(x,y) be differentiable at (a,b). The total differential is:

dz=fx​(x,y),dx+fy​(x,y),dy=∂x∂f​,dx+∂y∂f​,dy​

Here dx and dy are independent free variables (increments in x and y). dz is the resulting increment in z along the tangent plane.

Connection to tangent planes. This is exactly the tangent plane formula in differential form. If we set dx=x−a, dy=y−b:

z≈f(a,b)+dz=f(a,b)+fx​(a,b),dx+fy​(a,b),dy

The total differential is the tangent plane, written infinitesimally.

3.2 — For n Variables

If w=f(x1​,x2​,…,xn​):

dw=∂x1​∂f​,dx1​+∂x2​∂f​,dx2​+⋯+∂xn​∂f​,dxn​=∇f⋅dx

This is a linear functional on the vector of increments dx=(dx1​,…,dxn​).

3.3 — Formal Properties (Differential Rules)

Differentials obey exactly the same rules as derivatives — because they are derivatives, just written in a different notation.

RuleExpression
Constantd(c)=0
Sumd(f±g)=df±dg
Productd(fg)=f,dg+g,df
Quotientd(f/g)=g2g,df−f,dg​
Chaind(f(g))=f′(g),dg
Powerd(xn)=nxn−1,dx

These rules let you compute differentials algebraically, without restating the chain rule every time.

Example. w=x2sin(xy). Compute dw.

dw=d(x2)sin(xy)+x2,d(sin(xy)) =2x,dx⋅sin(xy)+x2cos(xy),d(xy) =2xsin(xy),dx+x2cos(xy)(y,dx+x,dy) =[2xsin(xy)+x2ycos(xy)]dx+x3cos(xy),dy

Read off: ∂x∂w​=2xsin(xy)+x2ycos(xy), ∂y∂w​=x3cos(xy).

§4. Error Estimation and Propagation

This is the most immediate application. Given a quantity Q=f(x1​,…,xn​) where each xi​ is measured with error ∣Δxi​∣≤δi​, the propagated error is estimated by:

∣ΔQ∣≈∣dQ∣≤​∂x1​∂f​​δ1​+⋯+​∂xn​∂f​​δn​

The inequality uses the triangle inequality on the differential.

Relative error:

∣Q∣∣dQ∣​≈​∂x1​∂lnf​​δ1​+⋯

For products and powers, logarithmic differentiation simplifies the relative error enormously.

Example — Resistance

Two resistors R1​=100,Ω±1 and R2​=200,Ω±1 in parallel. Find the error in total resistance R=R1​+R2​R1​R2​​.

Use logarithmic differentials. First,

lnR=lnR1​+lnR2​−ln(R1​+R2​)

RdR​=R1​dR1​​+R2​dR2​​−R1​+R2​dR1​+dR2​​

=dR1​(R1​1​−R1​+R2​1​)+dR2​(R2​1​−R1​+R2​1​)

=dR1​⋅R1​(R1​+R2​)R2​​+dR2​⋅R2​(R1​+R2​)R1​​

With R1​=100, R2​=200, R1​+R2​=300:

R∣dR∣​≤100⋅300200​(1)+200⋅300100​(2)≈0.0067+0.0033=1

So the parallel combination also has roughly 1 error.

§5. The Chain Rule, Written as Differentials

Suppose z=f(x,y), x=x(t), y=y(t). Then:

dz=fx​,dx+fy​,dy=fx​dtdx​,dt+fy​dtdy​,dt=(fx​dtdx​+fy​dtdy​)dt

So dtdz​=fx​dtdx​+fy​dtdy​. The chain rule is just division of the differential by dt.

This is why the notation dy/dx is more than notation — it genuinely behaves like a fraction when differentials are manipulated carefully.

Implicit Differentiation via Differentials

Given F(x,y)=0, take the differential of both sides:

dF=Fx​,dx+Fy​,dy=0⟹dxdy​=−Fy​Fx​​

No quotient rule gymnastics. Just differentiate F, set dF=0, solve for dy/dx.

Example. x3+y3=6xy. Find dy/dx.

d(x3+y3)=d(6xy) 3x2,dx+3y2,dy=6y,dx+6x,dy (3y2−6x),dy=(6y−3x2),dx dxdy​=3y2−6x6y−3x2​=y2−2x2y−x2​

One line of algebra, no chain rule bookkeeping.

§6. Differentials as Linear Maps — The Rigorous View

Here is the fully honest definition. Fix a point a∈Rn.

Definition. If f:Rn→R is differentiable at a, the differential of f at a is the unique linear map dfa​:Rn→R such that:

limh→0​∣h∣f(a+h)−f(a)−dfa​(h)​=0

In coordinates: dfa​(h)=∇f(a)⋅h=∑i​∂xi​∂f​(a),hi​.

What is dxi​? The differential of the coordinate function xi​:Rn→R, (x1​,…,xn​)↦xi​. Evaluated on a vector h: dxi​(h)=hi​. So dxi​ simply extracts the i-th component.

Then:

df=∑i​∂xi​∂f​,dxi​

is an equation between linear maps: both sides, when applied to h, give ∇f⋅h.

For vector-valued f: the Jacobian. If f:Rn→Rm, then dfa​ is the linear map represented by the Jacobian matrix:

J=(∂x1​∂f1​​​⋯​∂xn​∂f1​​ ⋮​⋱​⋮ ∂x1​∂fm​​​⋯​∂xn​∂fm​​​)

The differential is dfa​(h)=Jh. This is the most general form.

§7. Second Differentials and Quadratic Approximation

The second differential of f at a is:

d2f=∑i,j​∂xi​∂xj​∂2f​,dxi​,dxj​

This is a quadratic form in dxi​. It encodes the curvature of f, and the associated matrix is the Hessian Hij​=∂xi​∂xj​∂2f​.

The second-order Taylor expansion:

f(a+h)=f(a)+dfa​(h)+21​d2fa​(h)+O(∣h∣3)

=f(a)+∇f⋅h+21​h⊤H,h+⋯

The differential df approximates f linearly; d2f adds the curvature correction.

§8. Differential Forms (The Bigger Picture)

A differential k-form on Rn is an antisymmetric multilinear map on k tangent vectors. The differentials dx,dy,dz are 1-forms. The exterior product dx∧dy is a 2-form that measures signed area.

The objects you integrate are differential forms:

  • ∫C​f,dx+g,dy — line integral of a 1-form
  • ∬S​f,dA=∬f,dx∧dy — surface integral of a 2-form

Stokes’ theorem (the grand unification) becomes:

∫∂M​ω=∫M​dω

where d is the exterior derivative — the coordinate-free generalization of df. Every theorem of vector calculus (Green’s, Divergence, classical Stokes’) is a special case.

The total differential df=fx​,dx+fy​,dy is a 1-form. It is exact (equals dg for some g) if and only if ∂y∂fx​​=∂x∂fy​​ — the condition for a conservative vector field. This is why the cross-partial condition appears everywhere.

§9. Worked Examples

Example 1 — Differential Computation

Let f(x,y,z)=x2eyz. Compute df.

df=2xeyz,dx+x2zeyz,dy+x2yeyz,dz

Example 2 — Approximation

Approximate (3.98)2+(3.02)2+(5.99)2​ using differentials.

Base point: (4,3,6). f(4,3,6)=16+9+36​=61​.

df=x2+y2+z2​x,dx+y,dy+z,dz​

With dx=−0.02, dy=0.02, dz=−0.01:

df=61​4(−0.02)+3(0.02)+6(−0.01)​=61​−0.08+0.06−0.06​=61​−0.08​

f≈61​−61​0.08​=61​61−0.08​=61​60.92​≈7.803

Example 3 — Implicit Surface

Find the tangent plane to x2+2y2+3z2=6 at (1,1,1).

Let F=x2+2y2+3z2−6. Then dF=2x,dx+4y,dy+6z,dz.

At (1,1,1): ∇F=⟨2,4,6⟩. Tangent plane:

2(x−1)+4(y−1)+6(z−1)=0⟹x+2y+3z=6

Example 4 — Change of Variables

Polar coordinates: x=rcosθ, y=rsinθ.

dx=cosθ,dr−rsinθ,dθ dy=sinθ,dr+rcosθ,dθ

The area element: dA=dx∧dy=(cosθ,dr−rsinθ,dθ)∧(sinθ,dr+rcosθ,dθ)

=cosθ⋅rcosθ,(dr∧dθ)+(−rsinθ)⋅sinθ,(dθ∧dr)

=rcos2θ,(dr∧dθ)+rsin2θ,(dr∧dθ)=r,dr∧dθ

So dA=r,dr,dθ — the Jacobian factor r emerges automatically from the differential calculus of forms. No determinant computation needed.

§10. Connection to AI, Machine Learning, and Deep Learning

10.1 — Differentials Are What Backpropagation Computes

Let L=L(θ) be the loss of a neural network. The total differential is:

dL=∑i​∂θi​∂L​,dθi​=∇θ​L⋅dθ

Backpropagation computes ∇θ​L — i.e., it computes the coefficients of the total differential of the loss with respect to every parameter. The gradient is not a mysterious vector; it is the linear map dL, written in coordinates.

10.2 — The Jacobian and Vector Differentials

A neural network layer f:Rn→Rm computes y=σ(Wx+b). Its differential at x:

dy=diag(σ′(Wx+b))⋅W,dx

This is the Jacobian acting on dx. The forward pass evaluates y; the backward pass evaluates the transpose Jacobian acting on upstream gradients (via the adjoint of the differential):

dx←W⊤diag(σ′)⋅dy

The entire backpropagation algorithm is: compose differentials through the network, then adjoint them back.

10.3 — Automatic Differentiation (Autograd)

Modern frameworks (PyTorch, JAX) implement automatic differentiation, which is a computational implementation of the chain rule on differentials. Two modes:

Forward mode AD: propagates dx forward through the computation graph, computing dy at each node. Efficient when n≪m (few inputs, many outputs).

Reverse mode AD (backprop): propagates dL backward through the graph via adjoint differentials. Efficient when m≪n (scalar loss, many parameters). This is why backprop is used in neural nets — m=1 (scalar loss).

Every operation in the computation graph stores both its value and its differential rule. Backprop is just the chain rule d(f∘g)=df∘dg, applied in reverse.

10.4 — Gradient Descent as Differential Integration

Given dL=∇L⋅dθ, gradient descent takes:

θ←θ−η,∇L

This is a discretization of the differential equation dtdθ​=−∇L, i.e., gradient flow. The continuous version is:

dθ=−∇L,dt

In the continuous limit, L decreases at rate ∣∇L∣2 per unit time. Adam, RMSProp, and other optimizers scale the differential by the inverse of historical gradient magnitudes — they are adaptive scalings of dθ.

10.5 — Second-Order Methods: the Hessian and d2L

The Newton step minimizes the second-order approximation:

L(θ+dθ)≈L(θ)+∇L⊤dθ+21​dθ⊤H,dθ

Setting d(dL)/d(dθ)=0 gives dθ=−H−1∇L. Computing H−1 costs O(n3) — intractable for large networks. Quasi-Newton methods (L-BFGS) approximate H−1 from successive gradient differentials Δ∇L and parameter differentials Δθ, using the secant equation:

H,Δθ≈Δ∇L

This is a finite-difference approximation to the second differential d2L.

10.6 — Differentials in GANs and Score Matching

In generative models, score matching learns the score function ∇x​logp(x) — the differential of the log-density. Diffusion models (DDPM, Score SDE) define dynamics via stochastic differential equations:

dxt​=f(xt​,t),dt+g(t),dWt​

Here dxt​, dt, and dWt​ (Wiener differential, i.e., Brownian increment) are stochastic differentials — the Itô calculus extension of the framework we’ve been building. The score ∇x​logpt​(x) is a differential that the network learns to approximate at each noise level t. Reversing the SDE for generation requires the score — i.e., the differential of the log-density.

§12. Theorems to Know Cold

Theorem 1 (Differentiability and the Differential). f is differentiable at a iff there exists a linear map L such that f(a+h)=f(a)+L(h)+o(∣h∣). In that case, L=dfa​.

Theorem 2 (Chain Rule for Differentials). If g is differentiable at a and f is differentiable at g(a), then d(f∘g)a​=dfg(a)​∘dga​.

In matrix form: Jf∘g​=Jf​⋅Jg​.

Theorem 3 (Exactness Condition). A 1-form P,dx+Q,dy is exact (equals df for some f) iff ∂y∂P​=∂x∂Q​ on a simply connected domain.

Theorem 4 (Error Bound). If ∣fxi​​∣≤Mi​ on a region, then: ∣Δf−df∣≤21​max∣fxi​xj​​∣⋅(∣Δx∣)2

Theorem 5 (Fundamental Theorem via Differentials). ∫ab​df=f(b)−f(a) for any path — the line integral of an exact form is path-independent.

§13. Common Errors

dx is not infinitesimally small. In the definition, dx is a free real variable. It only needs to be “small” when you use df as an approximation to Δf.

df=Δf. They differ by O((dx)2). Writing df=Δf is an approximation, not an equality.

Partial derivatives are not the same as differentials. ∂x∂f​ is a number; df is a linear functional. The partial derivative is the coefficient of dx in df, not the same object.

Not every expression P,dx+Q,dy is a differential of some function. Exactness is not free — it requires Py​=Qx​.

In implicit differentiation, dF=0 only holds because F is held constant on the curve/surface. Make this explicit in your reasoning.
