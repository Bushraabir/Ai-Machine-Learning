06.Higher-Order Partial Derivatives

Apr 23, 202619 min read

“First derivatives tell you where the function is going. Second derivatives tell you how fast it changes its mind. Everything beyond that is the function’s personality.”

Tags

#calculus #multivariable #higher-order-derivatives #Hessian #Taylor-series #Clairaut #machine-learning #MIT-18.02 #Stewart

0. Why Go Higher?

In single-variable calculus, the second derivative f′′(x) encodes concavity — whether the function bends upward or downward. The second derivative test classifies critical points. Taylor series use all higher derivatives to reconstruct the function locally.

In multivariable calculus, the situation is richer and more subtle:

  • There are four second-order partials for a function of two variables, nine for three variables, n2 for n variables.
  • Mixed partials fxy​ and fyx​ may or may not be equal (Clairaut’s theorem).
  • The Hessian matrix packages all second partials and determines the geometry of critical points.
  • Higher-order terms give the multivariable Taylor expansion — the backbone of optimization, physics, and deep learning.

1. Second-Order Partial Derivatives — The Full Set

For f:R2→R, after taking one partial derivative we obtain another function of two variables. We may differentiate again.

Definition

fxx​:=∂x∂​!(∂x∂f​)=∂x2∂2f​

fyy​:=∂y∂​!(∂y∂f​)=∂y2∂2f​

fxy​:=∂y∂​!(∂x∂f​)=∂y,∂x∂2f​

fyx​:=∂x∂​!(∂y∂f​)=∂x,∂y∂2f​

Notation Warning — Order Convention

This is a persistent source of error. The two notations disagree on order:

Subscript notationFraction notationDifferentiate first w.r.t.
fxy​∂y,∂x∂2f​x first, then y
fyx​∂x,∂y∂2f​y first, then x

Rule: In fraction notation, the rightmost denominator variable is applied first (inner derivative). In subscript notation, the leftmost subscript is applied first.

fxy​=∂y,∂x∂2f​←same object, different notation

Internalize this once. Confusing the order is one of the most common errors in multivariable calculus exams.

Example 1.1

f(x,y)=x3y2+exy

First partials: fx​=3x2y2+yexy,fy​=2x3y+xexy

Second partials: fxx​=∂x∂​(3x2y2+yexy)=6xy2+y2exy

fyy​=∂y∂​(2x3y+xexy)=2x3+x2exy

fxy​=∂y∂​(3x2y2+yexy)=6x2y+exy+xyexy

fyx​=∂x∂​(2x3y+xexy)=6x2y+exy+xyexy

fxy​=fyx​ ✓ (Clairaut’s theorem applies — f is smooth everywhere)

2. Clairaut’s Theorem — Equality of Mixed Partials

Theorem (Clairaut–Schwarz)

If f:R2→R and both fxy​ and fyx​ are continuous on an open set D, then: fxy​(x,y)=fyx​(x,y)for all (x,y)∈D

Proof. (Full delta-epsilon argument.) Fix (a,b)∈D. Define:

Δ(h,k):=f(a+h,b+k)−f(a+h,b)−f(a,b+k)+f(a,b)

Step 1. Let ϕ(x):=f(x,b+k)−f(x,b). Then Δ=ϕ(a+h)−ϕ(a).

By the Mean Value Theorem: Δ=hϕ′(a+θ1​h) for some θ1​∈(0,1).

But ϕ′(x)=fx​(x,b+k)−fx​(x,b). Apply MVT again to fx​ in the second variable:

ϕ′(a+θ1​h)=k,fxy​(a+θ1​h,,b+θ2​k)

for some θ2​∈(0,1). Thus:

Δ(h,k)=hk,fxy​(a+θ1​h,,b+θ2​k)

Step 2. Define ψ(y):=f(a+h,y)−f(a,y) and repeat the argument:

Δ(h,k)=hk,fyx​(a+θ3​h,,b+θ4​k)

for some θ3​,θ4​∈(0,1).

Step 3. Divide by hk=0:

fxy​(a+θ1​h,b+θ2​k)=fyx​(a+θ3​h,b+θ4​k)

As (h,k)→(0,0), both sides approach fxy​(a,b) and fyx​(a,b) respectively, by continuity. Therefore fxy​(a,b)=fyx​(a,b). ■

Counterexample — When Continuity Fails

f(x,y)={x2+y2xy(x2−y2)​​(x,y)=(0,0) 0​(x,y)=(0,0)​

Computing fxy​(0,0) from the definition:

fx​(0,y)=limh→0​hf(h,y)−f(0,y)​=limh→0​h(h2+y2)hy(h2−y2)​=y2−y3​=−y

So fx​(0,y)=−y. Then:

fxy​(0,0)=∂y∂​(−y)​y=0​=−1

By symmetry (swapping x and y negates f): fyx​(0,0)=+1.

Therefore fxy​(0,0)=−1=1=fyx​(0,0).

Why Clairaut fails here: fxy​ and fyx​ both exist everywhere, but are discontinuous at the origin. The hypothesis of the theorem is violated.

3. Higher-Order Partials — The General Scheme

For f:Rn→R, a k-th order partial derivative is obtained by differentiating k times, each time with respect to one of the variables (possibly the same one repeated).

Notation

fx1​x1​x2​​=∂x2​∂x1​∂x1​∂3f​

(Subscript: left-to-right order of differentiation; Fraction: right-to-left.)

How Many Are There?

For f:Rn→R, the number of distinct k-th order partial derivatives is:

(kn+k−1​)

(multiset coefficient — choosing k differentiations from n variables with repetition, where order doesn’t matter under Clairaut).

n variablesk=1k=2k=3
n=2234
n=33610
n=441020

(Under Clairaut, many mixed partials are equal — the table counts distinct ones.)

The General Clairaut Theorem

For a smooth function (C∞ or Ck), all partial derivatives of the same order with the same multiset of variables are equal, regardless of the order in which they are taken.

fxxy​=fxyx​=fyxx​

This is because each such permutation can be reached from any other by swapping adjacent differentiation operations, each of which is justified by Clairaut.

Example 3.1 — Third Order

f(x,y)=x4y3

fx​=4x3y3,fxx​=12x2y3,fxxx​=24xy3 fxxy​=36x2y2,fxyy​=36x3y,fyyy​=0

fxxy​=∂y∂​(12x2y3)=36x2y2 fxyx​=∂x∂​(12x3y2)=36x2y2✓

4. The Hessian Matrix

The Hessian is the matrix that organizes all second-order partial derivatives. It is to multivariable calculus what f′′ is to single-variable calculus.

Definition

For f:Rn→R, the Hessian at a point x is the n×n matrix:

Hf​(x)=(fx1​x1​​​fx1​x2​​​⋯​fx1​xn​​ fx2​x1​​​fx2​x2​​​⋯​fx2​xn​​ ⋮​​⋱​⋮ fxn​x1​​​fxn​x2​​​⋯​fxn​xn​​​)

Entry (i,j): Hij​=∂xi​∂xj​∂2f​

By Clairaut’s theorem: If f∈C2, then H is symmetric: Hij​=Hji​.

For n=2:

Hf​(x,y)=(fxx​​fxy​ fxy​​fyy​​)

det(H)=fxx​fyy​−fxy2​

This determinant is the discriminant D that appears in the second derivative test.

Geometric Meaning of the Hessian

The Hessian encodes the curvature of the surface in every direction simultaneously.

For a unit vector u^∈Rn, the second directional derivative of f at a is:

Du^2​f(a)=u^THf​(a),u^

This is a quadratic form in u^. It measures the concavity of the surface in direction u^.

  • If u^THu^>0 for all u^=0: H is positive definite → surface is concave up in every direction → local minimum.
  • If u^THu^<0 for all u^=0: H is negative definite → surface is concave down in every direction → local maximum.
  • If u^THu^ changes sign: H is indefinite → surface curves up in some directions, down in others → saddle point.
LOCAL MINIMUM          LOCAL MAXIMUM          SADDLE POINT
  H positive def.        H negative def.        H indefinite

       z                      z                     z
       |   _                  |  /‾\                |    /
       |  / \                 | /   \               |   /  ← up
       | /   \                |/     \              |  /
       |/     \               *       \             * ← critical point
       *                              \             |\ 
       |                              \_            | \ ← down
       +--x                           +--x         +---x

Example 4.1 — Computing and Classifying

f(x,y)=x4+y4−4xy

First partials (find critical points): fx​=4x3−4y=0⟹y=x3 fy​=4y3−4x=0⟹y3=x

Substituting: (x3)3=x⟹x9=x⟹x(x8−1)=0.

So x=0 or x=±1, giving critical points: (0,0), (1,1), (−1,−1).

Hessian: H=(12x2​−4 −4​12y2​),det(H)=144x2y2−16

At (0,0): det(H)=−16<0 → saddle point.

At (1,1): det(H)=144−16=128>0, fxx​=12>0 → local minimum.

At (−1,−1): det(H)=128>0, fxx​=12>0 → local minimum.

5. The Multivariable Taylor Expansion

This is the crown jewel of higher-order partial derivatives. It generalizes the single-variable Taylor series to functions of several variables.

Single Variable Reminder

f(a+h)=f(a)+f′(a)h+2!f′′(a)​h2+3!f′′′(a)​h3+⋯

Two Variables — Taylor Expansion at (a,b)

Let h=(Δx,Δy). Expand f(a+Δx,,b+Δy):

f(a+Δx,b+Δy)=f(a,b) +order 1 (gradient term)fx​Δx+fy​Δy​​ +order 2 (Hessian term)2!1​(fxx​(Δx)2+2fxy​ΔxΔy+fyy​(Δy)2)​​ +order 33!1​(fxxx​(Δx)3+3fxxy​(Δx)2Δy+3fxyy​Δx(Δy)2+fyyy​(Δy)3)​​ +⋯

where all partials are evaluated at (a,b).

Compact Vector Form

f(a+h)=∑∣α∣=0∞​α!1​∂αf(a)⋅hα

where α=(α1​,…,αn​) is a multi-index, ∣α∣=α1​+⋯+αn​, and:

∂αf=∂x1α1​​⋯∂xnαn​​∂∣α∣f​,hα=h1α1​​⋯hnαn​​,α!=α1​!⋯αn​!

Matrix Form (Up to Second Order)

f(a+h)≈f(a)+∇f(a)Th+21​hTHf​(a),h+O(∣h∣3)

This is the quadratic approximation to f near a:

  • Zero-order: the function value at a
  • First-order: the gradient term (linear, tangent plane)
  • Second-order: the Hessian term (quadratic, captures curvature)

The quadratic form 21​hTHh is what distinguishes a bowl (positive definite) from a saddle (indefinite) near a critical point.

Example 5.1 — Quadratic Approximation

f(x,y)=excosy. Expand near (0,0).

Function value: f(0,0)=1

First partials: fx​=excosy, fy​=−exsiny

At (0,0): fx​=1, fy​=0.

Second partials: fxx​=excosy, fyy​=−excosy, fxy​=−exsiny

At (0,0): fxx​=1, fyy​=−1, fxy​=0.

Taylor expansion:

f(x,y)≈1+x+21​(x2−y2)+⋯

Verification from single-variable series: ex≈1+x+2x2​,cosy≈1−2y2​ excosy≈(1+x+2x2​)(1−2y2​)≈1+x+2x2​−2y2​✓

Example 5.2 — Third-Order Term

f(x,y)=sin(x+y) near (0,0).

At (0,0): f=0, fx​=fy​=cos(0)=1, fxx​=fyy​=fxy​=−sin(0)=0.

Third-order: fxxx​=fyyy​=−cos(0)=−1, and fxxy​=fxyy​=−cos(0)=−1.

f(x,y)≈(x+y)+61​(−x3−3x2y−3xy2−y3)=(x+y)−6(x+y)3​

This is just the single-variable Taylor series for sin(u) evaluated at u=x+y. A beautiful consistency check.

6. Second Derivative Test — Complete Statement

Theorem

Let (a,b) be a critical point of f (i.e., ∇f(a,b)=0). Define:

D=detHf​(a,b)=fxx​(a,b),fyy​(a,b)−[fxy​(a,b)]2

Then:

  1. D>0 and fxx​(a,b)>0 → local minimum
  2. D>0 and fxx​(a,b)<0 → local maximum
  3. D<0 → saddle point
  4. D=0 → inconclusive (higher-order terms needed)

Why this works: Near a critical point, by Taylor’s theorem:

f(a+h)≈f(a)+21​hTHh

(The gradient term vanishes at a critical point.) The behavior is determined entirely by the quadratic form Q(h)=hTHh.

By the theory of quadratic forms:

  • Q>0 for all h=0 iff H is positive definite iff all eigenvalues of H are positive iff detH>0 and H11​>0 (for 2×2).
  • Q<0 for all h=0 iff H is negative definite iff all eigenvalues negative iff detH>0 and H11​<0.
  • Q takes both signs iff H is indefinite iff detH<0.

The discriminant D=detH=λ1​λ2​ (product of eigenvalues). If D<0, the eigenvalues have opposite sign → indefinite → saddle.

What D=0 Means

When detH=0, at least one eigenvalue is zero — a degenerate case. The Hessian is not invertible; the quadratic approximation is degenerate (flat in some direction). We must go to third or higher order.

Example: f(x,y)=x4+y4 at (0,0). Hessian =(0​0 0​0​), D=0. But (0,0) is a global minimum (obvious from the formula). The second derivative test is blind here.

7. The Laplacian — A Distinguished Higher-Order Operator

The Laplacian of f is the sum of the pure second-order partials:

∇2f=Δf:=fxx​+fyy​+⋯+fxn​xn​​=∑i=1n​∂xi2​∂2f​=tr(Hf​)

It is the trace of the Hessian — the sum of the eigenvalues.

Physical Interpretation

  • Heat equation: ∂t∂u​=k,∇2u. The Laplacian measures how much the temperature at a point differs from the average temperature in a small neighborhood around it. If ∇2u>0, the surroundings are hotter than the point — heat flows in.

  • Harmonic functions: ∇2f=0 (Laplace’s equation). A function is harmonic iff it has no net curvature — it is the average of its neighboring values. These appear everywhere: electrostatics, fluid flow, steady-state heat.

  • Geometric meaning: ∇2f(a) measures the average concavity of f at a across all directions, normalized appropriately.

Example 7.1

f(x,y)=x2−y2: fxx​=2, fyy​=−2, ∇2f=0. This function is harmonic!

f(x,y)=x2+y2: fxx​=2, fyy​=2, ∇2f=4>0. Concave up — a paraboloid opening upward.

8. Higher Derivatives in AI and Machine Learning

8.1 Why the Hessian Matters in Optimization

At a local minimum θ∗ of the loss L, the Taylor expansion gives:

L(θ∗+δ)≈L(θ∗)+21​δTH,δ

The eigenvalues of H at θ∗ determine:

  • Eigenvalue λi​ large: The loss rises steeply in the i-th eigendirection. The minimum is sharp in that direction. Learning rate must be small.

  • Eigenvalue λi​≈0: The loss is nearly flat in that direction. This is a near-degenerate direction — the parameter can move a lot without changing the loss.

The condition number κ=λmax​/λmin​ of H governs training difficulty. Large condition number → loss landscape is poorly conditioned → gradient descent zigzags → slow convergence.

  Well-conditioned (κ ≈ 1)    Ill-conditioned (κ >> 1)
  
  Loss contours:               Loss contours:
  
      ·····                        ·············
    ··     ··                   ···             ···
   ·         ·                ··                 ··
   ·    *    ·     ←→         ·        *          ·
   ·         ·    gradient    ··                 ··
    ··     ··     descent       ···             ···
      ·····       goes          ·············
                  straight         (zigzags badly)

8.2 Newton’s Method — The Hessian as a Corrector

Gradient descent: θ←θ−η,∇L

Newton’s method uses the full quadratic approximation:

θ←θ−H−1∇L

Derivation: Find the minimum of the local quadratic approximation:

Q(δ)=L(θ)+∇LTδ+21​δTHδ

Set ∇δ​Q=0: ∇L+Hδ=0⟹δ=−H−1∇L.

Newton’s method converges quadratically near a minimum (the error squares each iteration) — far superior to gradient descent’s linear convergence. The cost: computing and inverting H is O(n2) storage and O(n3) computation for n parameters. With billions of parameters in a modern neural network, this is completely intractable.

Practical substitutes:

  • L-BFGS: Approximates H−1 using recent gradient history.
  • K-FAC: Uses the Kronecker structure of the Hessian in neural networks.
  • Adam optimizer: Adapts learning rates per-parameter using estimates of the diagonal of H — a very crude but effective approximation.

8.3 The Hessian and Generalization — Sharp vs. Flat Minima

Sharp minimum: Large Hessian eigenvalues → the loss valley is narrow.

L(θ∗+δ)≈L(θ∗)+21​λmax​∣δ∣2

A small perturbation of θ∗ (as occurs when moving from training to test distribution) causes a large increase in loss → poor generalization.

Flat minimum: Small Hessian eigenvalues → the loss valley is wide. Perturbations matter less → better generalization.

This motivates Sharpness-Aware Minimization (SAM) — an optimizer that explicitly seeks flat minima by minimizing the worst-case loss in a neighborhood of θ. It is a second-order concept implemented via first-order computations.

8.4 Taylor Expansion in Neural Architecture

The Neural Tangent Kernel (NTK) theory uses a first-order Taylor expansion of a neural network f(x;θ) around its initialization θ0​:

f(x;θ)≈f(x;θ0​)+∇θ​f(x;θ0​)T(θ−θ0​)

This linearization is the basis for understanding training dynamics of infinitely wide networks. Higher-order terms in the Taylor expansion correspond to feature learning — what the network learns beyond the linearization — and this is an active research frontier.

8.5 Second-Order Derivatives in Physics-Informed Neural Networks

In Physics-Informed Neural Networks (PINNs), the loss includes residuals of PDEs like:

L=​∂x2∂2u​+∂y2∂2u​−g​2

where u is approximated by a neural network. Computing ∂x2∂2u​ requires second-order automatic differentiation — differentiating through the computational graph twice. This is natively supported in JAX and PyTorch. The partial derivatives of the network output are themselves part of the loss — the network learns not just to fit data, but to satisfy differential equations.

9. Multi-Index Notation — The Compact Language

For working with arbitrary order partials in n variables, the multi-index notation is indispensable.

A multi-index α=(α1​,…,αn​) with αi​∈Z≥0​:

∣α∣:=α1​+⋯+αn​(order) α!:=α1​!⋯αn​!(multi-factorial) xα:=x1α1​​⋯xnαn​​(monomial) ∂αf:=∂x1α1​​⋯∂xnαn​​∂∣α∣f​(partial derivative)

Taylor’s theorem in multi-index form:

f(a+h)=∑∣α∣=0k​α!∂αf(a)​hα+Rk​(h)

where the remainder Rk​(h)=O(∣h∣k+1).

Example: For n=2, ∣α∣=2: the multi-indices are (2,0),(1,1),(0,2), giving:

∑∣α∣=2​α!∂αf(a)​hα=2!fxx​​h12​+1!⋅1!fxy​​h1​h2​+2!fyy​​h22​

=21​(fxx​h12​+2fxy​h1​h2​+fyy​h22​)=21​hTHh

The Hessian quadratic form is just the second-order term in the multi-index Taylor expansion.

10. Function Classes — Ck and Smoothness

The existence of higher-order partials is organized by function classes.

Definition

f∈Ck(D) (read: ”f is Ck on D”) means all partial derivatives of f up to order k exist and are continuous on D.

C0⊃C1⊃C2⊃⋯⊃C∞⊃Cω

where:

  • C0: continuous
  • C1: continuously differentiable (partials exist and are continuous → f is differentiable)
  • C2: twice continuously differentiable (Hessian exists, Clairaut applies, quadratic Taylor approximation valid)
  • C∞: infinitely differentiable (smooth) — all partial derivatives of all orders exist and are continuous
  • Cω: real analytic — the Taylor series converges to f locally

Key facts:

  • f∈C1⟹f is differentiable (converse fails: differentiable does not imply C1)
  • f∈C2⟹fxy​=fyx​ (Clairaut applies)
  • Most functions encountered in practice (polynomials, exponentials, trig, compositions thereof) are C∞ on their natural domains.

Why This Matters in ML

Activation functions determine the smoothness of the neural network loss landscape:

ActivationSmoothnessNotes
ReLUC0 but not C1Not differentiable at 0; Hessian doesn’t exist at kinks
Leaky ReLUC0 but not C1Same issue
Sigmoid, TanhC∞All derivatives exist and are bounded
GELUC∞Smooth approximation to ReLU; preferred in transformers
SwishC∞x⋅σ(x); smooth

The non-smoothness of ReLU complicates second-order methods. PINNs requiring ∂x2∂2u​ cannot use ReLU networks — they require at least C2 activations (Tanh, GELU, Swish are standard choices).

12. Summary

HIERARCHY OF HIGHER DERIVATIVES
│
├─ SECOND ORDER
│   ├─ f_xx, f_yy : pure second partials → concavity along axes
│   ├─ f_xy, f_yx : mixed partials → twisting of surface
│   │   └─ Equal when continuous (Clairaut)
│   └─ Hessian H = [f_{x_i x_j}]
│       ├─ Symmetric (by Clairaut)
│       ├─ Encodes curvature in all directions via h^T H h
│       └─ Eigenvalues determine min/max/saddle
│
├─ TAYLOR EXPANSION
│   ├─ Order 0: f(a)
│   ├─ Order 1: + ∇f · h  (tangent plane)
│   ├─ Order 2: + ½ h^T H h  (quadratic approximation)
│   └─ Order k: + Σ_{|α|=k} (∂^α f / α!) h^α
│
├─ LAPLACIAN  Δf = tr(H) = Σ f_{x_i x_i}
│   └─ Δf = 0 → harmonic function
│
└─ IN MACHINE LEARNING
    ├─ H eigenvalues → loss landscape geometry
    ├─ Newton's method → H^{-1} ∇L update
    ├─ Sharp vs flat minima → generalization
    ├─ PINNs → second-order autodiff
    └─ NTK → first-order Taylor of neural network
