“When a function depends on two variables, we can still draw it — a surface hovering over a plane. When it depends on three, we lose that luxury. The graph lives in R4, invisible to us. And yet the calculus generalizes perfectly. This is the point where you learn to think analytically rather than geometrically — a skill that will serve you in every dimension you ever encounter.”

0. Motivation: Why More Variables?

Almost nothing in the real world depends on fewer than three quantities simultaneously.

  • Temperature in a room: T(x,y,z) — three spatial coordinates.
  • Pressure in a fluid: P(x,y,z,t) — three space + one time.
  • Gravitational potential: ϕ(x,y,z)=−GM/x2+y2+z2​.
  • A neural network layer: output f(x):Rn→Rm where n can be millions.
  • The loss function of a model: L(θ1​,θ2​,…,θp​) where p∼1010.

The theory of functions of two variables (surfaces, level curves, partial derivatives) extends to three or more variables with essentially no new difficulty — just new notation and a willingness to stop asking “what does this look like?“

1. Functions of Three Variables

Definition

A function of three variables is a rule that assigns a unique real number to each point in some domain D⊆R3:

f:D⊆R3→R,(x,y,z)↦f(x,y,z)

Domain D: the set of all (x,y,z) for which the expression is defined. Range: the set of all values f(x,y,z) as (x,y,z) varies over D.

Examples

Example 1. f(x,y,z)=1−x2−y2−z2​

Domain: (x,y,z)∈R3:x2+y2+z2≤1 — the closed unit ball B(0,1). Range: [0,1].

Example 2. f(x,y,z)=ln(z−x2−y2)

Domain: (x,y,z):z>x2+y2 — the open region above the paraboloid z=x2+y2. Range: R (since ln achieves all real values on (0,∞)).

Example 3. f(x,y,z)=x2+y2+z2xyz​

Domain: R3∖(0,0,0) — all of R3 except the origin.

Example 4 (Physics). Gravitational potential: ϕ(x,y,z)=−x2+y2+z2​GM​

Domain: R3∖(0,0,0). The force field is F=−∇ϕ — the gradient of a scalar function.

2. Level Surfaces

For a function f(x,y,z), we cannot draw its graph (that would live in R4). The geometric substitute is the level surface.

Definition

The level surface of f at value c is:

Sc​=(x,y,z)∈D:f(x,y,z)=c

This is a surface in R3 — the set of all points where f takes the value c.

Level surfaces are the three-variable analog of level curves. They replace the graph as the primary geometric object.

Examples

f(x,y,z)=x2+y2+z2: Level surfaces are spheres x2+y2+z2=c (for c>0), a point (for c=0), empty (for c<0). These are the “shells” at constant distance from the origin.

f(x,y,z)=x2+y2−z2:

  • c>0: Hyperboloid of one sheet
  • c=0: Double cone x2+y2=z2
  • c<0: Hyperboloid of two sheets

f(x,y,z)=ax+by+cz: Level surfaces are planes ax+by+cz=k. All parallel, normal to (a,b,c).

Gravitational potential ϕ=−GM/r: Level surfaces are spheres r= const. — points of constant potential energy (“equipotential surfaces”).

Visualization: Nested Level Surfaces

    ╭───────────────╮
    │   f = 2       │
    │  ╭─────────╮  │
    │  │  f = 1  │  │

Example: f(x,y,z) = x²+y²+z²
Level surfaces are concentric spheres.
Moving outward = increasing f.

The gradient ∇f at any point is perpendicular to the level surface through that point and points in the direction of fastest increase. (This will be proved when we study gradients.)

3. Functions of n Variables

The General Definition

For n≥1, a function of n variables is:

f:D⊆Rn→R,x=(x1​,x2​,…,xn​)↦f(x)

The domain D is a subset of Rn; the range is a subset of R.

Notation conventions:

NotationUsage
f(x,y,z)Emphasize individual variables (3 vars)
f(x)Vector input (any n)
f(x1​,…,xn​)Index notation (general n)

Level Sets in Rn

For f:Rn→R, the level set at c is: Sc​=x∈Rn:f(x)=c

Generically, this is an (n−1)-dimensional hypersurface in Rn:

nLevel setName
21D curveLevel curve
32D surfaceLevel surface
43D hypersurfaceLevel hypersurface
n(n−1)D manifoldLevel hypersurface

4. Limits and Continuity in Rn

The ε-δ Definition

Let f:D⊆Rn→R and let a be a limit point of D. We say:

limx→a​f(x)=L

if for every ε>0, there exists δ>0 such that:

0<∣x−a∣<δ⟹∣f(x)−L∣<ε

where ∣x−a∣=∑i=1n​(xi​−ai​)2​ is the Euclidean distance in Rn.

This is identical to the two-variable definition — the Euclidean norm generalizes seamlessly.

Continuity

f is continuous at a if: limx→a​f(x)=f(a)

f is continuous on D if it is continuous at every point of D.

The Subtlety: Paths in Rn

For the limit limx→a​f(x) to exist, f(x) must approach L along every possible path to a — and in Rn with n≥2, there are uncountably many paths.

Standard technique to prove a limit does NOT exist: Find two paths giving different limits.

Example. Show lim(x,y,z)→(0,0,0)​x2+y2+z2xyz​ does not exist.

Path 1: x=t,y=t,z=t as t→0: f=3t2t3​=3t​→0

Path 2: x=t,y=t,z=0: f=2t20​=0→0

Path 3: x=t,y=t,z=t1/2 (approaching along a curved path) gives a more complex expression. Let us instead try a cleaner example:

Example. g(x,y,z)=x4+y2+z2x2yz​ at the origin.

Path: x=t,y=t2,z=t2: g=t4+t4+t4t2⋅t2⋅t2​=3t4t6​=3t2​→0

Path: x=t,y=t2,z=0: g=t4+t40​=0→0

Path: x=t,y=t2,z=t2 at the limit y=x2: g​y=x2,z=x2​=x4+x4+x4x2⋅x2⋅x2​=3x4x6​=3x2​→0

But along y=x2,z=x2: actually the limit is 0 here. The function g actually goes to 0 along all polynomial paths — but may not if we allow more exotic approach directions.

Remark (the Curse of Paths): In Rn, n≥2, showing a limit exists requires either a squeeze or estimating with the Euclidean norm. Showing it doesn’t exist requires two paths. The squeezing technique is: ∣f(x)−L∣≤g(∣x−a∣)→0 as ∣x∣→∣a∣

5. Partial Derivatives of Functions of Several Variables

Definition

For f(x1​,…,xn​), the partial derivative with respect to xi​ at a point a is:

∂xi​∂f​(a)=limh→0​hf(a1​,…,ai​+h,…,an​)−f(a1​,…,ai​,…,an​)​

Computationally: treat all variables except xi​ as constants, differentiate with respect to xi​.

For Three Variables Explicitly

For f(x,y,z):

fx​=∂x∂f​: differentiate w.r.t. x, treating y,z as constants

fy​=∂y∂f​: differentiate w.r.t. y, treating x,z as constants

fz​=∂z∂f​: differentiate w.r.t. z, treating x,y as constants

Example

f(x,y,z)=x3y−y2z+exzsiny

fx​=3x2y+zexzsiny

fy​=x3−2yz+exzcosy

fz​=−y2+xexzsiny

The Gradient

The gradient of f:Rn→R is the vector of all partial derivatives:

∇f(x)=⟨∂x1​∂f​,,∂x2​∂f​,,…,,∂xn​∂f​⟩

For three variables: ∇f(x,y,z)=⟨fx​,fy​,fz​⟩

The gradient is the generalization of the derivative to higher dimensions. Its key properties:

  • ∇f(a) points in the direction of steepest increase of f at a.
  • ∣∇f(a)∣ is the rate of steepest ascent.
  • ∇f(a) is perpendicular to the level surface f=f(a) at a.

Proof of the last point: Let r(t) be any curve lying in the level surface f(x)=c, so f(r(t))=c for all t. By the chain rule: dtd​f(r(t))=∇f(r(t))⋅r′(t)=0

So ∇f⊥r′(t) for every curve in the level surface — hence ∇f is perpendicular to the level surface. □

6. The Chain Rule in Rn

Suppose f(x1​,…,xn​) and each xi​=xi​(t1​,…,tm​). Then:

∂tj​∂f​=∑i=1n​∂xi​∂f​⋅∂tj​∂xi​​

In matrix/vector form, if x:Rm→Rn and f:Rn→R:

∂t∂f​=∂x∂f​⋅∂t∂x​=∇x​f⋅Jx​

where Jx​=∂x/∂t is the Jacobian matrix.

Example (three variables, two parameters): f(x,y,z) where x=s2t, y=st2, z=est:

∂s∂f​=fx​⋅2st+fy​⋅t2+fz​⋅test

∂t∂f​=fx​⋅s2+fy​⋅2st+fz​⋅sest

7. Directional Derivatives

For f:Rn→R and a unit vector u^=(u1​,…,un​), the directional derivative of f at a in direction u^ is:

Du^​f(a)=limh→0​hf(a+hu^)−f(a)​=∇f(a)⋅u^

Proof: Define g(h)=f(a+hu^). Then g′(0) is the directional derivative, and by the chain rule: g′(h)=∇f(a+hu^)⋅u^⟹g′(0)=∇f(a)⋅u^.□

Maximum directional derivative: By Cauchy–Schwarz: Du^​f(a)=∇f(a)⋅u^≤∣∇f(a)∣

with equality when u^=∇f(a)/∣∇f(a)∣. The gradient points in the direction of maximum rate of increase.

8. Higher-Order Partials and Clairaut’s Theorem

Second Partial Derivatives

For f(x1​,…,xn​), we can take partial derivatives of partial derivatives:

fxi​xj​​=∂xj​,∂xi​∂2f​=∂xj​∂​(∂xi​∂f​)

Note the order convention: ∂xj​,∂xi​ means differentiate first w.r.t. xi​, then xj​.

Clairaut’s Theorem (Symmetry of Mixed Partials)

Theorem. If f is defined near a and fxi​xj​​, fxj​xi​​ are both continuous at a, then: ∂xj​,∂xi​∂2f​(a)=∂xi​,∂xj​∂2f​(a)

Consequence: For smooth functions, the order of differentiation doesn’t matter. For f(x,y,z):

fxy​=fyx​,fxz​=fzx​,fyz​=fzy​,fxyz​=fxzy​=fyxz​=⋯

For a function of n variables with all mixed partials of order k continuous, all k! orderings give the same result.

The Hessian Matrix

The Hessian of f:Rn→R is the n×n matrix of all second partials:

Hf​(x)=(fx1​x1​​​fx1​x2​​​⋯​fx1​xn​​ fx2​x1​​​fx2​x2​​​⋯​fx2​xn​​ ⋮​​⋱​⋮ fxn​x1​​​fxn​x2​​​⋯​fxn​xn​​​)

By Clairaut, Hf​ is symmetric: Hf​=HfT​.

The Hessian generalizes the second derivative to higher dimensions and controls:

  • Local convexity/concavity of f
  • Classification of critical points
  • Second-order Taylor expansion

9. The Taylor Expansion in Rn

For f:Rn→R smooth near a, the second-order Taylor expansion at a is:

f(a+h)=f(a)+∇f(a)⋅h+21​hTHf​(a),h+O(∣h∣3)

This is the master approximation formula. Each term has a name:

  • f(a): zeroth-order (value)
  • ∇f(a)⋅h: first-order (linear/gradient term)
  • 21​hTHf​,h: second-order (quadratic/curvature term)

For n=3 with h=(h1​,h2​,h3​):

f(a+h)≈f(a)+fx​h1​+fy​h2​+fz​h3​+21​(fxx​h12​+fyy​h22​+fzz​h32​+2fxy​h1​h2​+2fxz​h1​h3​+2fyz​h2​h3​)

10. Critical Points and the Second Derivative Test in Rn

Critical Points

a is a critical point of f if ∇f(a)=0, i.e., all partial derivatives vanish simultaneously.

Classification via the Hessian

At a critical point a, the behavior of f near a is determined by Hf​(a):

From the Taylor expansion: f(a+h)−f(a)≈21​hTHf​(a),h

The sign of the quadratic form hTHf​,h determines the type:

Hf​(a)TypeMeaning
Positive definite (all eigenvalues >0)Local minimumf increases in all directions
Negative definite (all eigenvalues <0)Local maximumf decreases in all directions
Indefinite (mixed eigenvalue signs)Saddle pointIncreases some directions, decreases others
Positive/negative semidefiniteDegenerateTest inconclusive

For n=2 (two-variable case): D=fxx​fyy​−fxy2​=detHf​

  • D>0,fxx​>0: local min
  • D>0,fxx​<0: local max
  • D<0: saddle
  • D=0: inconclusive

For n≥3: Check eigenvalues of Hf​ (or use Sylvester’s criterion for positive definiteness).

11. Worked Examples

Example 1: Domain and Level Surfaces

f(x,y,z)=ln(4−x2−y2−z2)

Domain: Need 4−x2−y2−z2>0, i.e., x2+y2+z2<4 — the open ball of radius 2.

Level surfaces: ln(4−x2−y2−z2)=c⟺x2+y2+z2=4−ec

Valid when 4−ec>0, i.e., c<ln4. The level surfaces are concentric spheres of radius 4−ec​ centered at the origin, ranging from radius 0 (as c→ln4−) to radius 2 (as c→−∞).

Example 2: Partial Derivatives of a Physical Function

The ideal gas law: PV=nRT, so P(V,T)=nRT/V.

For a gas with n=1 mole, R=8.314 J/(mol·K):

P(V,T)=VRT​

∂T∂P​=VR​>0(pressure increases with temperature at fixed volume)

∂V∂P​=−V2RT​<0(pressure decreases as volume increases at fixed temperature)

∂V2∂2P​=V32RT​>0(convex in V)

Example 3: Critical Points in R3

f(x,y,z)=x2+y2+z2−2x+4y−6z+14

Find critical points: fx​=2x−2=0⟹x=1 fy​=2y+4=0⟹y=−2 fz​=2z−6=0⟹z=3

One critical point: (1,−2,3).

Hessian: Hf​=(2​0​0 0​2​0 0​0​2​)=2I

Positive definite (all eigenvalues =2>0). So (1,−2,3) is a global minimum.

f(1,−2,3)=1+4+9−2−8−18+14=0.

We can verify: f(x,y,z)=(x−1)2+(y+2)2+(z−3)2≥0. ✓

Example 4: Limit via Squeeze

Show (x,y,z)→(0,0,0)lim​x2+y2+z2x2yz​=0.

Squeeze: By AM-GM, x2≤x2+y2+z2, so x2+y2+z2x2​≤1. Also:

​x2+y2+z2x2yz​​=x2+y2+z2x2​⋅∣y∣⋅∣z∣≤∣y∣∣z∣≤2y2+z2​≤2x2+y2+z2​=2r2​

where r=∣(x,y,z)∣. As (x,y,z)→(0,0,0), r→0, so the expression →0. □

12. Visualization Strategies (Since We Can’t Draw the Graph)

When you can’t visualize the graph of f:R3→R, use:

1. Level surfaces — fix c and draw/describe f(x,y,z)=c.

2. Restriction to lower-dimensional slices:

  • Fix z=z0​: get a function of two variables f(x,y,z0​) — draw its level curves.
  • Fix y=0,z=0: get f(x,0,0) — a standard one-variable graph.

3. The gradient field: ∇f(x,y,z) is a vector field in R3. Its arrows show direction of fastest increase.

4. Color-coded cross-sections: In computational tools (Python, Mathematica), one plots f(x,y,z0​) as a heatmap for several values of z0​.

Strategy for understanding f(x,y,z):

  Full function                Slice at z = z₀
  (invisible in ℝ⁴)  →→→     f(x,y,z₀): a surface in ℝ³
                      →→→     Level curves of f(x,y,z₀): curves in ℝ²

  Level surfaces of f  →→→    Nested shells in ℝ³
  ∇f field             →→→    Arrows ⊥ to level surfaces

13. Connection to AI, Machine Learning, and Deep Learning

Functions of many variables are not a generalization of interest only to physicists. They are the central object of study in machine learning — almost every concept in this section reappears, at billion-dimensional scale.

13.1 The Loss Function Is a Function of Billions of Variables

A neural network with parameters θ=(θ1​,…,θp​)∈Rp defines a loss function:

L:Rp→R,L(θ)=N1​∑i=1N​ℓ(fθ​(xi​),yi​)

This is literally a function of p variables — with p∼1010 for GPT-scale models. Everything in this note applies:

  • Domain: The set of θ for which the network is defined (all of Rp, typically).
  • Level sets: θ:L(θ)=c — the set of parameters achieving loss c. Modern theory shows these level sets are extremely complex, high-dimensional manifolds.
  • Gradient: ∇θ​L — the direction of steepest ascent, whose negative gives the gradient descent direction. Computed by backpropagation, which is an efficient algorithm for the chain rule in Rp.
  • Hessian: HL​(θ) — a p×p matrix. For p=1010, this has 1020 entries — cannot be stored. This is why second-order optimization methods are approximated (L-BFGS, K-FAC, Shampoo).
  • Critical points: ∇θ​L=0 — the training algorithm tries to find these, but in high dimensions most critical points are saddle points, not local minima (Dauphin et al., 2014).

13.2 Backpropagation = Chain Rule in Rn

The chain rule in Rn is the mathematical foundation of deep learning. Given a neural network f=fL​∘fL−1​∘⋯∘f1​:

∂θl​∂L​=∂hL​∂L​⋅∂hL−1​∂hL​​⋯∂hl​∂hl+1​​⋅∂θl​∂hl​​

Each factor ∂hk+1​/∂hk​ is a Jacobian matrix. Backpropagation is the efficient right-to-left evaluation of this chain of matrix products — exactly the multi-variable chain rule, structured to avoid redundant computation.

13.3 Level Sets as “Weight Space Symmetries”

The level sets θ:L(θ)=c for small c are the “good parameter regions.” Recent work shows:

  • For overparameterized networks (p≫N), the global minimum level set is a high-dimensional connected manifold.
  • Neuron permutation symmetry: Swapping two hidden neurons gives a different θ on the same level set — the level set has a large discrete symmetry group of size ∏l​(nl​!).
  • Mode connectivity (Garipov et al., 2018): Two independently trained minima \boldsymbol\theta^__1, \boldsymbol\theta^__2 are often connected by a path of low loss — they lie on the same level-set component.

13.4 The Hessian in Deep Learning

The Hessian HL​ at a minimum encodes:

  • Sharpness: λmax​(HL​) — the largest eigenvalue. Sharp minima (large λmax​) generalize poorly; flat minima generalize well. This is the theoretical basis for SAM (Sharpness-Aware Minimization) (Foret et al., 2021).
  • Learning rate stability: Gradient descent is stable only when η<2/λmax​ — a direct consequence of the quadratic Taylor approximation.
  • Natural gradient: The Fisher information matrix Fθ​ is the expected Hessian of the log-likelihood. The natural gradient Fθ−1​∇θ​L accounts for the Riemannian geometry of the model manifold (Amari, 1998).

13.5 Directional Derivatives and Sensitivity Analysis

The directional derivative D_{\hat\mathbf{u}}\mathcal{L}(\boldsymbol\theta) = \nabla\mathcal{L}\cdot\hat\mathbf{u} answers: “if I perturb the parameters in direction \hat\mathbf{u}, how does the loss change?”

Applications:

  • Adversarial examples (Goodfellow et al., 2014): Find \hat\mathbf{u} (in input space) that maximizes D_{\hat\mathbf{u}}f — the direction that fools the classifier. The FGSM attack is literally xadv=x+ε⋅sign(∇x​L) — a step in the gradient direction in input space.
  • Influence functions: How does the loss on a test point change if we perturb the training data? Answered by directional derivatives in function space.
  • Saliency maps: ∂f/∂xi​ for each input pixel xi​ — a partial derivative of the network output with respect to inputs, used for interpretability.

13.6 Functions of Many Variables in Attention

A transformer attention head computes:

Attention(Q,K,V)=softmax(dk​​QKT​)V

The softmax output Aij​ is a function of all entries of Q and K simultaneously. The partial derivatives ∂Aij​/∂Qkl​ and ∂Aij​/∂Kkl​ are the components of the Jacobian computed during backpropagation. Each attention head is a function from (Q,K,V)∈Rn×dk​×Rn×dk​×Rn×dv​ to Rn×dv​ — a function of hundreds of thousands of variables, differentiated billions of times per second during training.

13.7 Gaussian Processes and Functions of Infinitely Many Variables

A Gaussian Process (GP) is a probability distribution over functions f:Rn→R. The GP can be viewed as the limit of a Bayesian neural network as the width →∞ (Neal, 1994; Lee et al., 2018). In this limit, the “function of parameters” becomes a “function of infinitely many variables” — and the calculus of variations and functional derivatives generalize the partial derivative framework of this note to infinite dimensions.

The key geometric principle: What level curves do for f:R2→R, level surfaces do for f:R3→R, and level hypersurfaces do for f:Rn→R. The gradient is always perpendicular to these, always points toward steepest increase, and always satisfies D_{\hat\mathbf{u}}f = \nabla f\cdot\hat\mathbf{u}.

In machine learning, every one of these concepts operates at scale — the domain is R1010, the level sets are high-dimensional manifolds, the gradient is computed by backpropagation, and the Hessian is approximated rather than stored.
