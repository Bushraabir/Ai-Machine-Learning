10.Linear Approximations

10.Linear Approximations

Apr 23, 202615 min read

“Calculus is, at its heart, the art of replacing curved things with flat things — locally. Linear approximation is that replacement made precise.”

§1. The Central Idea

Every differentiable function looks linear when you zoom in far enough. This is not a metaphor — it is a theorem, and it is the reason calculus works at all.

The project of linear approximation is: given a complicated function f, find the simplest possible function L (a linear/affine one) such that L≈f near a chosen point, with the error being negligible compared to the distance to that point.

This single idea:

  • Is the foundation of numerical analysis
  • Drives every optimization algorithm in machine learning
  • Underlies error propagation in physics and engineering
  • Generalizes to the Fréchet derivative in functional analysis

The tangent plane note established the geometric picture. Here we go deeper: error bounds, higher-order corrections, the multivariable theory, and what “best linear approximation” truly means.

§2. Single Variable — Review and Sharpening

2.1 Definition

Definition. Let f:R→R be differentiable at x=a. The linearization of f at a is:

L(x)=f(a)+f′(a)(x−a)

For x near a, f(x)≈L(x), and the approximation is called the linear approximation or tangent line approximation.

The statement f′(a) exists is equivalent to saying:

limx→a​x−af(x)−f(a)​=f′(a)⟺limx→a​x−af(x)−L(x)​=0

That is, the error f(x)−L(x) vanishes faster than ∣x−a∣. This is little-o notation:

f(x)=L(x)+o(x−a)as x→a

This is the precise meaning of “best linear approximation”: L is the unique affine function for which the error is o(x−a).

2.2 The Error — Taylor’s Theorem

The quality of the approximation is controlled by the second derivative. Taylor’s Theorem with Lagrange remainder:

f(x)=f(a)+f′(a)(x−a)+2f′′(c)​(x−a)2

for some c between a and x. Therefore, the error satisfies:

∣f(x)−L(x)∣=​2f′′(c)​​(x−a)2≤2M​(x−a)2

where M=maxt∈[a,x]​∣f′′(t)∣.

Practical consequence. If you halve the distance ∣x−a∣, the error shrinks by a factor of 4. Linear approximation is a second-order accurate method.

2.3 Quick Examples

Example A. Approximate 4.1​ using f(x)=x​, a=4.

f′(x)=2x​1​⟹f′(4)=41​ L(x)=2+41​(x−4)⟹L(4.1)=2+40.1​=2.025

Exact: 4.1​≈2.02485.... Error ≈0.00015.

Error bound check: f′′(x)=−41​x−3/2, so ∣f′′(c)∣≤41​(4)−3/2=321​ for c∈[4,4.1].

∣f(4.1)−L(4.1)∣≤21​⋅321​⋅(0.1)2=640.01​≈0.000156✓

Example B. Approximate e0.03.

f(x)=ex,a=0,L(x)=1+x e0.03≈1.03

Exact: 1.03045.... Error ≈0.00045. Consistent with 2M​(0.03)2=2e0.03​(0.0009)≈0.00046.

Example C. sin(θ)≈θ for small θ.

f(θ)=sinθ,a=0,L(θ)=θ

This is perhaps the most used approximation in physics. The error is O(θ3) (from the next Taylor term −θ3/6). Valid when θ≪1 radian.

§3. Multivariable Linear Approximation

3.1 Setup

Let f:Rn→R be differentiable at a∈Rn. Write a=(a1​,…,an​) and x=(x1​,…,xn​).

Definition. The linearization of f at a is:

L(x)=f(a)+∇f(a)⋅(x−a)=f(a)+∑i=1n​∂xi​∂f​(a),(xi​−ai​)

For n=2: L(x,y)=f(a,b)+fx​(a,b)(x−a)+fy​(a,b)(y−b) — the tangent plane.

Differentiability condition. f is differentiable at a if and only if:

limx→a​∣x−a∣f(x)−L(x)​=0

Again: error vanishes faster than distance. Linearization is the unique affine function with this property.

3.2 The Total Differential

Write Δxi​=xi​−ai​ and Δf=f(x)−f(a). Then:

Δf≈df=∑i=1n​∂xi​∂f​,dxi​=∇f⋅dx

This is the total differential — a linear functional on displacement vectors dx.

Key point. df is not a number. It is a 1-form, a linear map Rn→R. The gradient ∇f is the vector representation of this map in the standard basis. This distinction matters in differential geometry and becomes essential in deep learning when working on manifolds.

3.3 Error Bound in Rn

If all second-order partial derivatives of f are bounded by M near a, then:

∣f(x)−L(x)∣≤2n2M​∣x−a∣2

The quadratic scaling in distance holds in all dimensions.

3.4 Worked Example — Two Variables

Let f(x,y)=exycos(y). Linearize at (0,0).

f(0,0)=e0cos0=1.

fx​=yexycosy⟹fx​(0,0)=0 fy​=xexycosy−exysiny⟹fy​(0,0)=0−0=0

So L(x,y)=1. Interesting: near (0,0), this function is well-approximated by a constant — its first-order variation is zero. The tangent plane is horizontal.

Compare: f(0.1,0.1)=e0.01cos(0.1)≈1.0101×0.9950≈1.005. L=1. Error ≈0.005=O(0.01). ✓

3.5 Worked Example — Error Propagation

A box has measured dimensions ℓ=50,cm, w=30,cm, h=20,cm, each with uncertainty ±0.2,cm. Estimate the maximum error in volume V=ℓwh.

dV=∂ℓ∂V​dℓ+∂w∂V​dw+∂h∂V​dh=wh,dℓ+ℓh,dw+ℓw,dh

Maximum error (taking ∣dℓ∣=∣dw∣=∣dh∣=0.2):

∣dV∣≤∣wh∣∣dℓ∣+∣ℓh∣∣dw∣+∣ℓw∣∣dh∣ =(30)(20)(0.2)+(50)(20)(0.2)+(50)(30)(0.2) =120+200+300=620,cm3

Relative error: 30000620​≈2.07.

Note: the maximum error formula follows the triangle inequality applied to the total differential. This is standard in experimental physics.

§4. Vector-Valued Functions — The Jacobian

Now let f:Rn→Rm, so f=(f1​,…,fm​) where each fi​:Rn→R.

Definition. The Jacobian matrix of f at a is the m×n matrix:

Jf​(a)=Df(a)=(∂x1​∂f1​​​⋯​∂xn​∂f1​​ ⋮​⋱​⋮ ∂x1​∂fm​​​⋯​∂xn​∂fm​​​)x=a​

The linearization is:

f(x)≈f(a)+Jf​(a),(x−a)

Differentiability. f is differentiable at a iff:

limx→a​∣x−a∣∣f(x)−f(a)−Jf​(a)(x−a)∣​=0

The Jacobian Jf​(a) is the best linear map approximating f near a. This is the proper, coordinate-free definition of the derivative for maps between Euclidean spaces (the Fréchet derivative).

Chain Rule via Jacobians. If g:Rp→Rn and f:Rn→Rm, then:

Jf∘g​(a)=Jf​(g(a)),Jg​(a)

This is matrix multiplication of the Jacobians. It is the multivariable chain rule, and it is precisely what backpropagation computes.

4.1 Example — Jacobian

Let f(x,y)=(x2y,;sin(x+y),;exy).

Jf​(x,y)=(2xy​x2 cos(x+y)​cos(x+y) yexy​xexy​)

At (1,0): Jf​(1,0)=(0​1 1​1 0​1​).

Linearization: f(x,y)≈f(1,0)+Jf​(1,0)(x−1 y​)=(0 1 1​)+(0​1 1​1 0​1​)(x−1 y​).

§5. Linear Approximation vs. Quadratic — When to Use Which

The linearization is the zeroth-order approximation in curvature:

ApproximationFormulaError Order
Constantf(a)O(∥Δx∥)
Linear (1st order)f(a)+∇f⋅ΔxO(∥Δx∥2)
Quadratic (2nd order)+21​ΔxTHΔxO(∥Δx∥3)

where H=∇2f is the Hessian matrix of second partial derivatives.

When linear approximation fails: near critical points (∇f=0), the linear approximation is trivially f(a) (constant). To understand whether it’s a min, max, or saddle, you must go to second order. This is the second derivative test generalized to Rn: check the eigenvalues of H.

§6. Geometric Picture

        f(x)
         |        ← actual curve / surface
         |   ,·'~
         |  / ← tangent line / plane (linearization)
         | /  · P
         |/___________
         a           x

The zoom picture. Let gϵ​(t)=ϵf(a+ϵt)−f(a)​. As ϵ→0, gϵ​→f′(a)⋅t, which is linear. Differentiability says: when you zoom in on the graph of f around a, it looks like a straight line. In R2: zoom in on the surface and it looks like a flat plane.

This is why differentiable functions are tractable — they are locally indistinguishable from affine maps.

Affine vs. linear. Strictly, L(x)=f(a)+∇f(a)⋅(x−a) is affine (linear + constant), not linear (which would require L(0)=0). The distinction matters in linear algebra and functional analysis. In common usage, “linear approximation” means “affine approximation.”

§7. Standard Linearizations to Memorize

These are the first-order Taylor expansions. Commit them to memory — they appear everywhere.

Composition trick. To linearize f(g(x)) near x=0: first write g(x)≈g(0)+g′(0)x, then feed into Lf​:

f(g(x))≈f(g(0))+f′(g(0))⋅g′(0)⋅x

This is just the chain rule, but thinking of it as “linearize inside, then outside” is very efficient.

§8. Connection to AI, Machine Learning, and Deep Learning

Linear approximation is not a background tool in ML — it is the central computational primitive.

8.1 — Gradient Descent is Linear Approximation + Greedy Step

Given loss L(θ), the linear approximation at current parameters θt​ is:

L(θ)≈L(θt​)+∇θ​L(θt​)⊤(θ−θt​)

This is a hyperplane in parameter space. On this plane, L decreases fastest in the direction −∇L. Gradient descent takes a step in that direction:

θt+1​=θt​−η,∇θ​L(θt​)

The step size η (learning rate) controls how far to trust the linear approximation. Too large: the approximation breaks down and the step overshoots. Too small: slow convergence. Choosing η is equivalent to choosing the radius of trust in the linear model. This is formalized in trust region methods.

8.2 — Backpropagation is Jacobian Composition

A neural network f=fL​∘⋯∘f1​ is a composition of layer maps. Backpropagation computes ∇θi​​L by the chain rule:

∂θi​∂L​=∂aL​∂L​⋅JfL​​⋯Jfi+1​​⋅∂θi​∂fi​​

Each Jfk​​ is the Jacobian of the k-th layer — the linear approximation of that layer’s transformation. The backward pass propagates a “sensitivity vector” δ (the gradient with respect to activations) through these Jacobians in reverse. The entire backward pass is a sequence of matrix-vector products with Jacobians.

ReLU note. The activation ReLU(x)=max(0,x) is not differentiable at x=0. In practice, the “subgradient” 1[x>0] is used — a piecewise linear approximation. The network is piecewise linear in its inputs, and the linear regions change depending on which neurons are active.

8.3 — Newton’s Method and Second-Order Optimization

The linear approximation of ∇L (not L itself) gives Newton’s method:

∇L(θ)≈∇L(θt​)+H(θt​)(θ−θt​)=0

Solving: θt+1​=θt​−H(θt​)−1∇L(θt​).

This uses the Hessian H to correct the step direction. Newton’s method converges quadratically (error squared each step) vs. linearly for gradient descent. The catch: computing H−1 for a network with n parameters costs O(n3) — utterly infeasible for modern networks (n∼109).

Practical alternatives: L-BFGS (quasi-Newton, approximates H−1 using past gradient differences) and natural gradient / K-FAC (approximate Fisher information matrix instead of Hessian).

8.4 — Linearization of Neural Networks: the NTK Regime

For very wide networks, the output f(x;θ) barely changes during training — parameters move little. This means the network stays in the regime where its linear approximation in θ around initialization θ0​ is valid:

f(x;θ)≈f(x;θ0​)+∇θ​f(x;θ0​)⊤(θ−θ0​)

In this linear regime, gradient flow (continuous-time gradient descent) has a closed-form solution. The kernel:

K(x,x′)=∇θ​f(x;θ0​)⊤∇θ​f(x′;θ0​)

is the Neural Tangent Kernel (NTK). This shows that in the infinite-width limit, training a neural network is equivalent to kernel regression with a fixed kernel. The tangent (linear) approximation of the network function in parameter space is the entire dynamics.

8.5 — Sensitivity Analysis and Saliency Maps

Given a trained classifier f(x), the linear approximation at input x0​:

f(x)≈f(x0​)+∇x​f(x0​)⋅(x−x0​)

tells us which input features, when perturbed, change the output most. The gradient ∇x​f is the saliency map — used in interpretability to visualize which pixels a convolutional network “attends to.” This is exactly reading off the linear approximation of f at a given image.

LIME (Local Interpretable Model-agnostic Explanations) takes this further: it fits a linear model to the behavior of f in a neighborhood of any input — a literal local linearization — and uses it as an explanation.

8.6 — Adversarial Examples

The linear approximation also explains adversarial examples. A small perturbation ϵ in the direction of ∇x​L maximally increases the loss:

L(x+ϵ)≈L(x)+∇x​L⋅ϵ

Taking ϵ=α⋅sign(∇x​L) gives the FGSM (Fast Gradient Sign Method) adversarial attack (Goodfellow et al., 2014). The adversarial perturbation is explicitly the step in the direction where the linear approximation of the loss increases fastest — it exploits the fact that the network is locally (nearly) linear.

§9. Formal Structure — The Fréchet Derivative

In full generality: let X,Y be normed vector spaces, f:X→Y, a∈X.

Definition. f is Fréchet differentiable at a if there exists a bounded linear operator A:X→Y such that:

lim∣h∣X​→0​∣h∣X​∣f(a+h)−f(a)−Ah∣Y​​=0

A is called the Fréchet derivative Df(a) of f at a.

Special cases:

  • X=R, Y=R: A=f′(a) (scalar multiplication) — ordinary derivative
  • X=Rn, Y=Rm: A=Jf​(a) (matrix multiplication) — Jacobian
  • X=C([0,1]), Y=R: A is an integral operator — calculus of variations

The Fréchet derivative is the unique best linear approximation in the above sense. The chain rule still holds: D(f∘g)(a)=Df(g(a))∘Dg(a) (composition of linear operators).

This framework applies to neural networks as maps between function spaces, and to the analysis of infinite-dimensional optimization problems.

f(x)=0th orderf(a)​​+1st order (linear)∇f(a)⋅(x−a)​​+2nd order (quadratic)21​(x−a)TH(a)(x−a)​​+⋯

OrderNameErrorUse Case
0Constant approx.O(∥Δx∥)Crude estimate
1Linear approx. (this note)O(∥Δx∥2)Gradient descent, error propagation, sensitivity
2Quadratic approx.O(∥Δx∥3)Newton’s method, curvature analysis
kTaylor polynomialO(∥Δx∥k+1)Series solutions, numerical methods

The linear approximation is the sweet spot: cheap to compute (just first derivatives), error decays quadratically, and it captures directional information (which constant approximation misses).

§11. Things That Will Trip You Up

The linear approximation requires differentiability, not just partial derivatives. Existence of fx​ and fy​ is not sufficient. You need them to be continuous, or directly verify the o(∣Δx∣) limit.

The total differential df is not the same as Δf. The differential is exact only for linear functions. For everything else, Δf=df+O(∣Δx∣2).

Error bounds require bounding the second derivative. The approximation "f(x)≈L(x)" is qualitative. Quantitative error analysis always needs the Lagrange remainder.

Affine = linear. A linear approximation passing through (a,f(a)) with f(a)=0 is not a linear function — it is affine. This distinction matters in algebra and optimization.

The Jacobian is a matrix, not a determinant. The Jacobian determinant det(J) is a scalar used for change-of-variables; the Jacobian matrix is the derivative of a vector-valued map. Do not conflate them.

§12. Theorems to Know Cold

Theorem 1 (Linear Approximation, Scalar). If f is differentiable at a, then for x near a: f(x)=f(a)+f′(a)(x−a)+o(x−a)

Theorem 2 (Linear Approximation, Vector). If f:Rn→R is differentiable at a, then: f(x)=f(a)+∇f(a)⋅(x−a)+o(∣x−a∣)

Theorem 3 (Error Bound via Taylor). If ∣f′′∣≤M on [a,x], then ∣f(x)−L(x)∣≤2M​(x−a)2.

Theorem 4 (Jacobian Chain Rule). For differentiable g:Rp→Rn and f:Rn→Rm: Jf∘g​(a)=Jf​(g(a)),Jg​(a)

Theorem 5 (Fréchet Uniqueness). The Fréchet derivative, when it exists, is the unique bounded linear operator satisfying the o(∣h∣) error condition.
