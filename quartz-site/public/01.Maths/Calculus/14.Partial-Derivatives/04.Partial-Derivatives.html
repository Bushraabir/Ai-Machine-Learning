04.Partial Derivatives

Apr 23, 202612 min read

“To understand a function of many variables, hold everything else still — and listen to what one variable says.”

Tags

#calculus #multivariable #analysis #machine-learning #optimization #MIT-18.02 #Stewart

0. Motivation — Why Partial Derivatives?

In single-variable calculus, we ask: how does f(x) change as x changes? The answer is f′(x).

Now suppose temperature in a room depends on position and time: T(x,y,z,t). Or suppose the loss of a neural network depends on millions of weights θ1​,θ2​,…,θn​. We cannot ask “how does f change” without specifying with respect to which variable, while treating the others as frozen constants.

That is precisely the partial derivative.

1. Definition

Let f:Rn→R be a function of n variables. The partial derivative of f with respect to xi​ at a point a=(a1​,…,an​) is:

∂xi​∂f​(a):=limh→0​hf(a1​,…,ai​+h,…,an​)−f(a1​,…,ai​,…,an​)​

provided this limit exists.

Reading this carefully: every variable except xi​ is held fixed. The function g(t)=f(a1​,…,t,…,an​) is an ordinary single-variable function, and ∂xi​∂f​(a)=g′(ai​) in the classical sense.

Notation Zoo

All of the following mean the same thing:

∂x∂f​=fx​=∂x​f=D1​f(when x is the 1st variable)

Stewart uses fx​ and ∂f/∂x interchangeably. MIT 18.02 often prefers subscript notation in physics contexts.

2. Geometric Meaning

Consider z=f(x,y), a surface in R3.

  • fx​(a,b) = slope of the curve obtained by cutting the surface with the plane y=b — a curve that runs in the xz-plane.
  • fy​(a,b) = slope of the curve obtained by cutting with the plane x=a.
        z
        |         /surface z = f(x,y)
        |        /
        |    ---*---   <- slice y = b
        |      / \
        |     /   \   slope here = f_x(a,b)
        +------------- x
       /
      / y

Intuition: partial derivatives measure the instantaneous rate of change along coordinate directions. They do NOT capture all directional information — that requires the gradient and directional derivative.

3. Computing Partial Derivatives — The Practical Rule

Rule: To compute ∂x∂f​, treat every other variable as a constant and differentiate with respect to x using all ordinary differentiation rules.

Example 3.1 — Polynomial

f(x,y)=x3y2+5x2−7y+3

fx​=3x2y2+10x fy​=2x3y−7

In computing fx​: the 5x2 becomes 10x, the −7y vanishes (constant in x), the +3 vanishes.

Example 3.2 — Mixed Transcendental

f(x,y)=exysin(y2)

fx​=yexysin(y2) fy​=xexysin(y2)+exy⋅2ycos(y2)

In fy​: the exy requires the chain rule since xy depends on y; sin(y2) also requires chain rule.

Example 3.3 — Three Variables

f(x,y,z)=x2ln(yz)+zex

fx​=2xln(yz)+zex fy​=yx2​ fz​=zx2​+ex

4. Higher-Order Partial Derivatives

We can differentiate again. For f(x,y), there are four second-order partials:

fxx​=∂x2∂2f​,fyy​=∂y2∂2f​,fxy​=∂x∂y∂2f​,fyx​=∂y∂x∂2f​

Caution on notation: fxy​ means differentiate with respect to x first, then y. In ∂x∂y∂2f​, the convention is the opposite: the denominator is read right-to-left (differentiate y first, then x). This is a common source of confusion. Stewart and MIT 18.02 both note this.

fxy​=∂y,∂x∂2f​

Theorem 4.1 — Clairaut’s Theorem (Symmetry of Mixed Partials)

Theorem (Clairaut/Schwarz): If f:R2→R is defined on an open set D, and if fxy​ and fyx​ are both continuous on D, then: fxy​(x,y)=fyx​(x,y)for all (x,y)∈D.

Proof sketch. Consider the second-order difference quotient:

Δ=f(a+h,b+k)−f(a+h,b)−f(a,b+k)+f(a,b)

Define ϕ(x)=f(x,b+k)−f(x,b). Then Δ=ϕ(a+h)−ϕ(a). By the Mean Value Theorem applied twice:

Δ=hϕ′(a+θ1​h)=hkfxy​(a+θ1​h,,b+θ2​k)

for some θ1​,θ2​∈(0,1). Similarly, define ψ(y)=f(a+h,y)−f(a,y) and obtain:

Δ=hkfyx​(a+θ3​h,,b+θ4​k)

Taking h,k→0 and using continuity of fxy​ and fyx​, both expressions converge to the same limit. ■

This is not trivial. There exist functions where fxy​(0,0)=fyx​(0,0); continuity of the mixed partials is essential.

Counterexample to Clairaut without continuity:

f(x,y)={x2+y2xy(x2−y2)​​(x,y)=(0,0) 0​(x,y)=(0,0)​

One can verify fxy​(0,0)=−1 but fyx​(0,0)=1. Mixed partials exist but are discontinuous at origin.

5. Partial Derivatives and the Gradient

The gradient of f:Rn→R is the vector of all partial derivatives:

∇f(x)=(∂x1​∂f​,∂x2​∂f​,…,∂xn​∂f​)

The gradient:

  • Points in the direction of steepest ascent of f
  • Is perpendicular to level curves (in R2) or level surfaces (in R3)
  • Has magnitude ∣∇f∣ equal to the maximum rate of change

The Directional Derivative

The rate of change of f in the direction of a unit vector u^ is:

Du^​f(a)=∇f(a)⋅u^

Partial derivatives are the special case where u^=ei​ (standard basis vectors).

6. The Chain Rule for Partial Derivatives

Case: z=f(x,y), with x=x(s,t), y=y(s,t)

∂s∂z​=∂x∂z​∂s∂x​+∂y∂z​∂s∂y​

∂t∂z​=∂x∂z​∂t∂x​+∂y∂z​∂t∂y​

Tree diagram mnemonic (MIT 18.02 style):

        z
       / \
      x   y
     / \ / \
    s  t s  t

To find ∂z/∂s: sum over all paths from z to s, multiplying partial derivatives along each branch.

General Chain Rule

If f:Rn→R and g:Rm→Rn, with h=f∘g:

∂tj​∂h​=∑i=1n​∂xi​∂f​∂tj​∂gi​​

In matrix form: the Jacobian — this is where linear algebra and calculus fuse.

7. The Total Differential

If f is differentiable, the total differential is:

df=∂x1​∂f​dx1​+∂x2​∂f​dx2​+⋯+∂xn​∂f​dxn​=∇f⋅dx

This is the linear approximation:

f(a+Δx)≈f(a)+∇f(a)⋅Δx

This is the tangent plane (for n=2) generalized to all dimensions.

8. Existence vs. Differentiability — A Subtle Warning

Existence of all partial derivatives at a point does NOT imply differentiability at that point.

This is one of the most important subtleties in multivariable analysis.

Example. Define:

f(x,y)={1​if y=x2,x=0 0​otherwise​

Then fx​(0,0)=0 and fy​(0,0)=0 both exist. But f is not even continuous at (0,0) (approach along y=x2).

Sufficient condition for differentiability: If fx​ and fy​ exist in a neighborhood of (a,b) and are continuous there, then f is differentiable at (a,b).

9. Connection to AI, Machine Learning, and Deep Learning

This is where the theory becomes extraordinarily powerful in practice.

9.1 Loss Minimization — Gradient Descent

In supervised machine learning, we have a loss function L(θ1​,θ2​,…,θn​) where θi​ are the model parameters (weights). We want:

θ∗=argminθ​L(θ)

Gradient descent iterates:

θi(t+1)​=θi(t)​−η∂θi​∂L​​θ(t)​

where η>0 is the learning rate. Each update uses the partial derivative of the loss with respect to each individual weight — moving each weight in the direction that most decreases the loss. This is literally Clairaut-era calculus operating on billion-dimensional spaces.

9.2 Backpropagation — Chain Rule at Scale

A neural network is a composition of functions:

y^​=fL​∘fL−1​∘⋯∘f1​(x)

The loss is L(y^​,y). To compute ∂θi(k)​∂L​ (the gradient with respect to a weight in layer k), we apply the multivariable chain rule recursively:

∂θi(k)​∂L​=∂ak​∂L​⋅∂θi(k)​∂ak​​

where ak​ is the output of layer k. The term ∂ak​∂L​ is itself computed by chaining through layers k+1,…,L. This is backpropagation — it is the chain rule for partial derivatives, applied recursively through a computational graph.

Loss ← Layer L ← Layer L-1 ← ... ← Layer k ← ... ← Input
           ↑
   ∂L/∂θ computed by chain rule backwards

Every modern deep learning framework (PyTorch, JAX, TensorFlow) implements automatic differentiation — essentially computing partial derivatives of arbitrarily complex compositions automatically.

9.3 The Hessian — Second-Order Methods

The Hessian matrix of L is the matrix of second-order partials:

Hij​=∂θi​∂θj​∂2L​

By Clairaut’s Theorem, H is symmetric (provided the partials are continuous — essentially always true for neural networks with smooth activations).

Second-order optimizers (Newton’s method, L-BFGS, K-FAC) use H or approximations to it. The eigenvalues of H determine the local geometry of the loss landscape — sharp minima (large eigenvalues) vs. flat minima (small eigenvalues), which has profound implications for generalization.

9.4 Partial Derivatives in Probability and Statistics

The log-likelihood ℓ(θ)=logp(data∣θ) is differentiated to find maximum likelihood estimates:

∂θi​∂ℓ​=0for all i

This is a system of equations in partial derivatives. The Fisher information matrix is the expected outer product of the score function — again, partial derivatives everywhere.

9.5 Attention Mechanisms and Softmax

In transformer architectures, the softmax function σ:Rn→Rn is:

σ(z)i​=∑j​ezj​ezi​​

During backpropagation through attention layers, we need ∂zj​∂σi​​ — the Jacobian of softmax — which requires computing all mixed partial derivatives. The result:

∂zj​∂σi​​=σi​(δij​−σj​)

where δij​ is the Kronecker delta. This is a direct application of quotient rule + partial differentiation.

10. Worked Examples — From Definition

Example 10.1 — Verifying with the Limit Definition

Let f(x,y)=x2+xy. Compute fx​(1,2) from the definition.

fx​(1,2)=limh→0​hf(1+h,2)−f(1,2)​

=limh→0​h(1+h)2+(1+h)(2)−(1+2)​

=limh→0​h1+2h+h2+2+2h−3​

=limh→0​h4h+h2​=limh→0​(4+h)=4

Using the rule: fx​=2x+y, so fx​(1,2)=2+2=4. ✓

Example 10.2 — Implicit Partial Differentiation

Suppose F(x,y,z)=x2+y2+z2−1=0 defines z implicitly as a function of x,y near a point. Find ∂x∂z​.

Differentiate F(x,y,z(x,y))=0 with respect to x:

Fx​+Fz​∂x∂z​=0⟹∂x∂z​=−Fz​Fx​​=−2z2x​=−zx​

General implicit function rule:

∂x∂z​=−∂F/∂z∂F/∂x​

This is used constantly in thermodynamics and economics (where multiple constraints define surfaces).

Example 10.3 — Gradient and Level Curves

f(x,y)=x2+4y2. The level curve f=4 is an ellipse x2+4y2=4.

∇f=(2x,8y)

At the point (2,0): ∇f=(4,0) — pointing in the +x direction, perpendicular to the ellipse at that point (the ellipse is vertical there). ✓

Gradient as Compass on a Topographic Map

Think of level curves as contour lines on a map. The gradient ∇f at any point is a vector:

  • Perpendicular to the contour line through that point
  • Pointing uphill (toward higher f values)
  • Longer where the terrain is steeper

This is exactly how gradient descent works in machine learning: the loss landscape is a high-dimensional terrain, and the gradient tells the optimizer which direction is “uphill” in loss — so we step the opposite way.

13. Common Mistakes to Avoid

  1. Forgetting to freeze variables. When computing fx​, every y is a constant. ∂x∂​(y2)=0, not 2y.

  2. Confusing fxy​ with ∂x∂y∂2f​. The subscript and fraction notations have opposite order conventions.

  3. Assuming continuity from existence. All partials can exist at a point while f is discontinuous there.

  4. Applying Clairaut without checking continuity. In 99% of practical cases it holds; but know the hypothesis.

  5. Confusing gradient with derivative. The gradient ∇f is a vector; the derivative of f:Rn→R is a row vector (the transpose). They contain the same information; the distinction matters in matrix calculus.
