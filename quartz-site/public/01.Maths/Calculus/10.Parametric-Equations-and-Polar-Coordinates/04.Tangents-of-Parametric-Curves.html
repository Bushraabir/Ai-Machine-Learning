“A curve does not know it is parametric — but we do, and that changes everything.”

§0 — Motivation & Setup

In standard Cartesian calculus, a curve is a graph y=f(x). The tangent slope is f′(x) — clean and immediate.

But reality is richer. A particle tracing an ellipse, a robot arm sweeping an arc, a neural network’s loss surface following a trajectory in weight space — none of these come with y written neatly as a function of x. They come parametrically:

x=f(t),y=g(t),t∈[a,b]

Here t is the parameter — often time, but need not be. The curve is the image of the map t↦(f(t),g(t)) in the plane.

The central question: What is the slope of the tangent line at a point on such a curve?

§1 — Deriving the Tangent Formula

1.1 The Core Idea: Chain Rule in Disguise

Suppose y is (locally) expressible as a function of x, i.e., y=F(x) near some point. Then by the Chain Rule:

dtdy​=dxdy​⋅dtdx​

Solving for the quantity we want:

dxdy​=dx/dt,dy/dt,​=f′(t)g′(t)​,provided f′(t)=0​

Remark (Implicit Function Theorem backbone). The assumption that y=F(x) exists locally is guaranteed whenever f′(t)=0 — by the Implicit Function Theorem, the map t↦x=f(t) is locally invertible, so t=f−1(x) exists and y=g(f−1(x)).

This is not just symbol manipulation. We are asserting that locally, the parametric curve looks like a regular graph.

1.2 Tangent Line at a Point

At parameter value t=t0​, the point on the curve is (x0​,y0​)=(f(t0​),,g(t0​)).

The tangent line is:

y−g(t0​)=f′(t0​)g′(t0​)​,(x−f(t0​))

§2 — Second Derivatives and Concavity

To understand concavity, we need dx2d2y​. One might guess it’s g′′(t)/f′′(t) — this is wrong. Here’s the correct derivation.

We treat dxdy​ as a new function of t, say h(t)=f′(t)g′(t)​. Then:

dx2d2y​=dxd​!(dxdy​)=dtdx​dtd​!(dxdy​)​

Substituting:

dx2d2y​=f′(t)dtd​![f′(t)g′(t)​]​​

Warning. Notice: dx2d2y​=f′′(t)g′′(t)​. The denominator involves f′(t), not f′′(t).

§4 — Worked Examples

Example 1 — The Cycloid

A circle of radius r rolls along the x-axis. A point on its rim traces a cycloid:

x=r(t−sint),y=r(1−cost)

Derivatives: dtdx​=r(1−cost),dtdy​=rsint

Slope: dxdy​=r(1−cost)rsint​=1−costsint​

Using the half-angle identities sint=2sin(t/2)cos(t/2) and 1−cost=2sin2(t/2):

dxdy​=2sin2(t/2)2sin(t/2)cos(t/2)​=cot!(2t​)

Special points:

  • At t=π (top of arch): cot(π/2)=0 → horizontal tangent ✓
  • As t→0+ or t→2π− (cusps on x-axis): cot(t/2)→∞ → vertical tangent ✓ (the curve has cusps where it touches the ground)

Example 2 — Ellipse

x=acost,y=bsint(a,b>0)

dxdy​=−asintbcost​=−ab​cott

At t=π/4: slope =−b/a, point =(a/2​,,b/2​).

Tangent line: y−2​b​=−ab​(x−2​a​)⟹a2​x​+b2​y​=1

This is the classical tangent-to-ellipse formula, recovered cleanly.

Example 3 — Lissajous Figure (AI-relevant)

x=sin(2t),y=sin(3t)

dxdy​=2cos(2t)3cos(3t)​

Horizontal tangents: cos(3t)=0⇒t=π/6,π/2,5π/6,…

Vertical tangents: cos(2t)=0⇒t=π/4,3π/4,…

These figures appear in signal processing and are related to Fourier analysis — the backbone of transformers’ positional encodings.

§6 — The Tangent Vector Perspective

There is a deeper, coordinate-free way to see this. The velocity vector (tangent vector) at parameter t is:

r′(t)=⟨f′(t),,g′(t)⟩

This vector is tangent to the curve at the point r(t)=⟨f(t),g(t)⟩.

The slope dy/dx is simply the ratio of the components of this tangent vector:

dxdy​=f′(t)g′(t)​=[r′(t)]x​[r′(t)]y​​

The unit tangent vector is:

T^(t)=∣r′(t)∣r′(t)​=f′(t)2+g′(t)2​⟨f′(t),g′(t)⟩​

Key Insight. The slope dy/dx encodes the direction of r′(t), but loses magnitude (speed). The full tangent vector carries both direction and speed — crucial in physics and in optimization.

§7 — Singular Points & L’Hôpital

When f′(t0​)=g′(t0​)=0, the formula g′(t)/f′(t) is a 0/0 indeterminate form. We apply L’Hôpital’s Rule:

limt→t0​​f′(t)g′(t)​=limt→t0​​f′′(t)g′′(t)​(if this limit exists)

Example. The cusp of x=t2, y=t3 at t=0:

dxdy​=2t3t2​=23t​t→0​0

Slope approaches 0, confirming a cusp with horizontal tangent direction (but not a smooth tangent — the curve reverses direction).

§8 — Connection to AI, Machine Learning & Deep Learning

This is where parametric curves cease to be a calculus curiosity and become foundational infrastructure.

8.1 Gradient Descent as a Parametric Curve

Training a neural network is trajectory tracing in parameter space. Let θ∈Rn be the weight vector. Gradient descent defines:

θ(t+1)=θ(t)−η∇θ​L(θ(t))

In continuous time (gradient flow):

dtdθ​=−∇θ​L(θ)

This is a parametric curve t↦θ(t) in Rn. The tangent vector at each point is exactly the negative gradient:

θ′(t)=−∇L(θ(t))

The geometry of this curve — how it turns, where it slows, what tangent directions it follows — determines convergence behavior.

8.2 Neural ODEs

Neural ODEs (Chen et al., 2018) make this explicit: the hidden state of a “network” is a parametric curve satisfying:

dtdh​=fθ​(h(t),t)

The tangent vector h′(t) is learned. Understanding dy/dx in parametric form is the 2D toy version of understanding dh/dt in high-dimensional feature space.

8.3 Bezier Curves in Generative Models

Bezier curves are parametric curves defined by control points:

B(t)=∑k=0n​(kn​)(1−t)n−ktk,Pk​,t∈[0,1]

Their tangent at t=0 is n(P1​−P0​), at t=1 is n(Pn​−Pn−1​).

These appear in:

  • Font rendering (TrueType/OpenType paths)
  • Diffusion model trajectory interpolation
  • NeRF (Neural Radiance Fields) camera path planning
  • Latent space traversal in VAEs and GANs

8.4 Positional Encodings & Lissajous-Like Structure

Transformer positional encodings use: PE(pos,2i)=sin!(100002i/dpos​),PE(pos,2i+1)=cos!(100002i/dpos​)

Each position traces a parametric curve on the unit circle in each 2D frequency subspace. The relative angle between two positions is captured in the inner product — a fact proved using the parametric structure. This is exactly the ellipse/Lissajous machinery.

8.5 Curvature and Loss Landscape Sharpness

The curvature of the optimization trajectory is related to the sharpness of the loss landscape. Sharp minima (high curvature) generalize poorly; flat minima (low curvature) generalize well. Measuring curvature of the training trajectory in weight space uses the second-derivative formula:

κ=(f′2+g′2)3/2∣f′g′′−g′f′′∣​

In high dimensions, this generalizes to the Hessian spectrum — the subject of modern work on loss landscape geometry.

§9 — Rigorous Summary

Theorem. Let r(t)=(f(t),g(t)) be a parametric curve where f,g are differentiable on (a,b).

(i) If f′(t0​)=0, then dxdy​​t=t0​​=f′(t0​)g′(t0​)​.

(ii) If f′(t0​)=0 and f,g are twice differentiable, then dx2d2y​​t=t0​​=f′(t0​)[dtd​!(f′g′​)]t=t0​​​

(iii) The curve has a horizontal tangent at t0​ iff g′(t0​)=0=f′(t0​), and a vertical tangent iff f′(t0​)=0=g′(t0​).
