1. Absolute Convergence — Recollection and Deeper Look

From Alternating Series, we defined:

∑an​ is absolutely convergent⟺∑∣an​∣ converges

∑an​ is conditionally convergent⟺∑an​ converges but ∑∣an​∣ diverges

And we proved: absolute convergence ⇒ convergence.

Now we go deeper. Why does the absolute value help so much? Because ∑∣an​∣ is a non-negative series — it lives in the world where the Comparison, Ratio, and Root Tests operate cleanly. The strategy for a general series ∑an​ is therefore:

Test ∑∣an​∣ first.If it converges⇒∑an​ converges (absolutely).

This reduces the convergence of any series — regardless of signs — to the convergence of a non-negative one. Absolute convergence is not merely a stronger statement; it is a methodological gateway.

The Radius of Convergence Perspective

For a power series ∑cn​xn, absolute convergence defines the open interval (or disk, in C) of convergence. The Ratio and Root Tests applied to ∑∣cn​xn∣ will produce exactly the radius of convergence — a preview of §11.8–11.9.

2. The Ratio Test

Setup and Intuition

The Ratio Test asks: as n→∞, does the series locally resemble a geometric series? If the ratio of successive terms ∣an+1​/an​∣ approaches some L, then for large n:

∣an+1​∣≈L⋅∣an​∣≈L2⋅∣an−1​∣≈⋯

This is precisely the behaviour of a geometric series with ratio L. Geometric series converge iff ∣L∣<1, diverge iff ∣L∣>1.

Theorem

Let ∑an​ be a series with an​=0 eventually, and suppose:

L=limn→∞​​an​an+1​​​

Then:

ConditionConclusion
L<1∑an​ converges absolutely
L>1 (or L=∞)∑an​ diverges
L=1Inconclusive — test fails

Proof

Case L<1 (Convergence). Choose r with L<r<1. Since ∣an+1​/an​∣→L, there exists N such that for all n≥N:

​an​an+1​​​<r

Therefore, for n>N:

∣an​∣=∣aN​∣⋅∣aN​∣∣aN+1​∣​⋅∣aN+1​∣∣aN+2​∣​⋯∣an−1​∣∣an​∣​<∣aN​∣⋅rn−N

So the tail ∑n=N∞​∣an​∣ is bounded term-by-term by ∣aN​∣⋅r−(N)∑n=N∞​rn, a convergent geometric series. By the Comparison Test, ∑∣an​∣ converges. ✓

Case L>1 (Divergence). There exists N such that for n≥N, ∣an+1​/an​∣>1, so ∣an​∣ is strictly increasing for n≥N. In particular, ∣an​∣≥∣aN​∣>0 for all n≥N. Thus an​→0, and the series diverges by the Divergence Test. ✓

Case L=1 (Inconclusive). Consider:

  • ∑1/n: ∣an+1​/an​∣=n/(n+1)→1. Diverges.
  • ∑1/n2: ∣an+1​/an​∣=n2/(n+1)2→1. Converges.

Same L, opposite fates. The test is blind here. □

When does the Ratio Test work best? When an​ involves factorials (n!), exponentials (cn), or products — precisely because these simplify under the ratio an+1​/an​.

3. The Root Test

Setup and Intuition

The Root Test takes a different approach: instead of comparing ratios of consecutive terms, it looks at the n-th root ∣an​∣1/n. This measures the average geometric rate of decay. Again, the geometric series is the benchmark:

For ∑rn, we have (rn)1/n=r. So if ∣an​∣1/n→L<1, then for large n, ∣an​∣≈Ln, which is a convergent geometric series.

Theorem

Let ∑an​ be a series, and suppose:

L=limn→∞​n∣an​∣​=limn→∞​∣an​∣1/n

Then:

ConditionConclusion
L<1∑an​ converges absolutely
L>1 (or L=∞)∑an​ diverges
L=1Inconclusive

Proof

Case L<1. Choose r with L<r<1. There exists N such that for n≥N:

∣an​∣1/n<r⟹∣an​∣<rn

By comparison with the convergent geometric series ∑rn, the series ∑∣an​∣ converges. ✓

Case L>1. There exists N such that for n≥N, ∣an​∣1/n>1, so ∣an​∣>1. Then an​→0 and the series diverges by the Divergence Test. ✓

Case L=1. Same counterexamples as the Ratio Test — ∑1/n and ∑1/n2 both give L=1. □

When does the Root Test work best? When an​ involves an expression raised to the n-th power, especially of the form (f(n))n.

4. Relationship Between the Two Tests

There is a deep and elegant relationship:

Theorem (D’Alembert–Hadamard)

For any sequence an​ of positive terms:

liminfn→∞​an​an+1​​;≤;liminfn→∞​an1/n​;≤;limsupn→∞​an1/n​;≤;limsupn→∞​an​an+1​​

Consequence: Whenever the Ratio Test gives a definitive answer (L=1), so does the Root Test, and they agree. But the Root Test can succeed when the Ratio Test fails (the limit of the ratio may not exist even when the limit of the root does).

Practical hierarchy: Root Test is theoretically stronger; Ratio Test is computationally easier when factorials are present.

5. The L=1 Failure Zone — What To Do

When both tests give L=1, fall back to:

  • p-series recognition: If an​∼C/np, compare to ∑1/np.
  • Limit Comparison Test with a p-series.
  • Alternating Series Test if signs alternate.
  • Integral Test (coming in §11.3) for monotone, positive terms.

The Ratio and Root Tests are blunt near the boundary L=1 because they cannot distinguish between 1/n (divergent) and 1/n2 (convergent) — both look like geometric series with ratio 1 in the limit.

7. Worked Examples

Example 1 — Ratio Test, Factorials

∑n=1∞​nnn!​

an​an+1​​=(n+1)n+1(n+1)!​⋅n!nn​=(n+1)n+1(n+1)⋅nn​=(n+1)nnn​=(n+1n​)n=(1+n1​)n1​

L=limn→∞​(1+n1​)n1​=e1​≈0.368<1

Converges absolutely. ✓

This is Stirling’s approximation territory: n!∼2πn​(n/e)n, so n!/nn∼2πn​/en→0 rapidly.

Example 2 — Ratio Test, Exponential

∑n=0∞​(2n+1)!(−3)n​

​an​an+1​​​=(2n+3)!3n+1​⋅3n(2n+1)!​=(2n+3)(2n+2)3​→0

L=0<1. Converges absolutely. ✓

(This is related to sin(3​) via the Taylor series sinx=∑(−1)nx2n+1/(2n+1)!.)

Example 3 — Root Test

∑n=1∞​(n+12n​)n

∣an​∣1/n=n+12n​=1+1/n2​→2

L=2>1. Diverges. ✓

(The Ratio Test would require computing the ratio of two n-th powers — messy. The Root Test is the natural choice here.)

Example 4 — Root Test with Limsup

∑n=1∞​(2n1​+3n1​)

∣an​∣1/n=(2n1​+3n1​)1/n=(2n1​)1/n(1+(32​)n)1/n=21​⋅(1+(32​)n)1/n

As n→∞, (1+(2/3)n)1/n→11=1. So L=1/2<1. Converges absolutely. ✓

(Alternatively: ∑(1/2n+1/3n)=∑1/2n+∑1/3n — two convergent geometric series.)

Example 5 — Ratio Test Inconclusive, Root Test Too

∑n=1∞​n31​

​an​an+1​​​=(n+1)3n3​=(n+1n​)3→1(inconclusive)

∣an​∣1/n=n3/n1​=e−3lnn/n→e0=1(inconclusive)

Recognise as p-series with p=3>1: converges. Fall back to fundamentals.

Example 6 — Determining Radius of Convergence

∑n=0∞​n!xn​

Apply the Ratio Test:

​an​an+1​​​=​(n+1)!xn+1​⋅xnn!​​=n+1∣x∣​→0

L=0<1 for every x∈R. The series converges absolutely for all x — radius of convergence R=∞. This is the power series for ex.

9. Connection to AI, Machine Learning, and Deep Learning

9.1 Radius of Convergence of the Exponential — Everywhere in Deep Learning

The single most important power series in ML is:

ex=∑n=0∞​n!xn​

As shown in Example 6, the Ratio Test proves this converges absolutely for all x. This is foundational to:

  • Softmax: softmax(x)i​=exi​/∑j​exj​
  • Attention mechanism: Attention(Q,K,V)=softmax(QK⊤/dk​​)V
  • Matrix exponential: etA=∑n=0∞​n!tnAn​, used in continuous-depth ODENets and Neural ODEs.

The absolute convergence of the matrix exponential series is proved using the Ratio Test on the operator norm: ∣An/n!∣≤∣A∣n/n!, and ∑∣A∣n/n!=e∣A∣<∞.

9.2 Ratio Test and the Convergence of Adam / RMSProp

The adaptive learning rate algorithms (Adam, RMSProp) maintain running estimates of the form:

vt​=β2​vt−1​+(1−β2​)gt2​

Unrolling this recurrence:

vt​=(1−β2​)∑k=0t​β2k​gt−k2​

This is a finite geometric series. As t→∞, the infinite series ∑k=0∞​β2k​ converges because β2​∈(0,1) — the Ratio Test gives L=β2​<1. The factor (1−β2​) in the numerator is the bias correction, ensuring the geometric weights sum to 1. The entire analysis rests on the Ratio Test for geometric series applied to moment estimates.

9.3 Root Test and Generalisation Bounds

In statistical learning theory, PAC-Bayes bounds and Rademacher complexity estimates often involve expressions of the form:

∑n=1∞​(εn​C​)n

for some constant C and precision ε. The Root Test immediately gives:

∣an​∣1/n=εn​C​→0

so the series converges absolutely for any C,ε>0. This justifies the finiteness of certain complexity integrals that appear in uniform convergence arguments — specifically in showing that the covering number of a hypothesis class remains finite.

9.4 Absolute Convergence and Backpropagation Through Time (BPTT)

In recurrent neural networks trained by BPTT, the gradient at time step 0 with respect to a parameter involves a sum over all time steps:

∂W∂L​=∑t=1T​∂ht​∂L​⋅∂W∂ht​​

As T→∞ (in continuous-time limits), this becomes an infinite series. Absolute convergence of this gradient series — verified using the Ratio Test on the spectral radius of the Jacobian — is exactly the condition that rules out exploding gradients. If L=ρ(J)<1 (spectral radius of the hidden state Jacobian), the gradient series converges absolutely and training is stable. If L>1, gradients explode.

This is why gradient clipping and spectral normalisation are not heuristics but principled interventions — they enforce L<1.

9.5 Root Test and Information-Theoretic Quantities

In information theory (underlying VAEs, diffusion models, and information-bottleneck methods), the Rényi entropy of order α is:

Hα​(X)=1−α1​log∑x​p(x)α

For discrete distributions, the sum ∑x​p(x)α must converge for the entropy to be well-defined. When the sample space is countably infinite, the Root Test determines the range of α for which this holds. This is not a toy concern: in language models over a countably infinite vocabulary (or in continuous relaxations), the well-posedness of the Rényi entropy depends on this convergence analysis.

9.6 Taylor Series for Activation Functions — Radius of Convergence Matters

Many activation functions have Taylor series representations whose radius of convergence determines the domain of validity for polynomial approximations used in hardware-efficient inference:

FunctionTaylor seriesRadius RHow proved
ex∑xn/n!∞Ratio Test
sinx∑(−1)nx2n+1/(2n+1)!∞Ratio Test
ln(1+x)∑(−1)n+1xn/n1Ratio Test (L=∣x∣)
tanh(x)(Bernoulli number series)π/2Root Test on coefficients
gelu(x)(via Φ(x) expansion)∞Dominated by e−x2/2 series

The radius of convergence determines where a polynomial approximation is numerically valid. Using ln(1+x)≈x−x2/2+x3/3 outside (−1,1] gives garbage — a convergence failure with direct practical consequences.

10. Summary Card

Ratio Test:L=n→∞lim​​an​an+1​​​{<1​⇒abs. convergent >1​⇒divergent =1​⇒inconclusive​​

Root Test:L=n→∞lim​∣an​∣1/n{<1​⇒abs. convergent >1​⇒divergent =1​⇒inconclusive​​

Root Test is theoretically stronger; Ratio Test is computationally easier with factorials​

L=0⟹converges absolutelyL=∞⟹diverges​

Rule of thumb:

  • an​ has n! or products → Ratio Test
  • an​ has (f(n))n → Root Test
  • Both give L=1 → Comparison / p-series / Integral Test

  1. Test n=1∑∞​n!n10⋅2n​ for convergence. (Hint: Ratio Test — what does n10/n simplify to?)

  2. Test n=1∑∞​(n+1n​)n2 for convergence. (Hint: Root Test — recall lim(1+1/n)n=e.)

  3. Find the radius of convergence of n=0∑∞​n+1(2x)n​ using the Ratio Test.

  4. Show that the Ratio Test is inconclusive for ∑n(−1)n​ but the Alternating Series Test settles it.

  5. (ML-flavoured) In an RNN, the hidden state update is ht​=Wht−1​ with ∣W∣=0.9 (operator norm). Show using the Ratio Test that the gradient series ∑t=0∞​Wt converges absolutely. What is the limit? (Hint: geometric series of matrices — what is the matrix analogue of 1/(1−r)?)

  6. (Challenge) Prove the D’Alembert–Hadamard inequality: n→∞limsup​∣an​∣1/n≤n→∞limsup​​an​an+1​​​. (Hint: let L=limsup∣an+1​/an​∣ and show ∣an​∣1/n≤C⋅rn/n=Cr→r for any r>L.)
