“A piecewise function is not a collection of functions. It is one function that happens to be described by different rules on different parts of its domain. The key question is always: what happens at the boundaries?“

0. Motivation — Why Piecewise?

Sometimes a single algebraic formula cannot (or should not) capture the full behavior of a rule. Nature, economics, and computation are full of processes that change their character at certain thresholds:

  • A tax bracket system: tax rate changes at income thresholds.
  • A spring: restoring force is linear until the spring is overstretched, then the model breaks.
  • A neuron: fires only when input exceeds a threshold.
  • Absolute value: reflects negative inputs, leaves positive ones alone.

Piecewise functions are the honest mathematical language for these situations.

1. Formal Definition

Definition. A piecewise defined function on a domain D⊆R is a function f:D→R specified by:

f(x)={f1​(x)​if x∈D1​ f2​(x)​if x∈D2​ ⋮​⋮ fn​(x)​if x∈Dn​​

where D1​,D2​,…,Dn​ are disjoint subsets of D whose union is D:

D=D1​∪D2​∪⋯∪Dn​,Di​∩Dj​=∅ for i=j

Each fk​ is called a branch of f, and the points where the domain partitions — where we transition from one branch to the next — are called breakpoints (or transition points).

Crucial point. f is one function. It has one domain, one graph, one value at each input. The piecewise notation is about how we describe it, not about its unity as a mathematical object.

2. Canonical Examples

2.1 Absolute Value

∣x∣={x​if x≥0 −x​if x<0​

  • Domain: R. Range: [0,∞).
  • Breakpoint: x=0.
  • At the breakpoint: both branches agree — f(0)=0 from either side.
  • Graph: V-shape with vertex at the origin.

Key property: ∣x∣=x2​(alternative closed form)

This is a non-trivial identity. It shows that ∣x∣ has an algebraic representation — but the piecewise form is often more useful for analysis.

2.2 The Sign Function

sgn(x)={1​if x>0 0​if x=0 −1​if x<0​

  • Domain: R. Range: −1,0,1.
  • Breakpoint: x=0.
  • Note: ∣x∣=x⋅sgn(x) for x=0.

2.3 The Heaviside Step Function

H(x)={0​if x<0 1​if x≥0​

  • Domain: R. Range: 0,1.
  • Named after Oliver Heaviside; fundamental in signal processing and differential equations.
  • Models “switching on” at x=0.
  • Any piecewise constant function can be written as a linear combination of shifted Heaviside functions.

Observation. ReLU(x)=x⋅H(x). The Heaviside function is the “derivative” of ReLU in the distributional sense: H′(x)=δ(x), the Dirac delta. This connection — between step functions, ramp functions, and impulses — is the language of distribution theory.

2.4 ReLU (Rectified Linear Unit)

ReLU(x)=max(x,0)={x​if x>0 0​if x≤0​

  • Domain: R. Range: [0,∞).
  • Breakpoint: x=0.
  • Continuous everywhere. Not differentiable at x=0.
f(x) = ReLU(x)

Why not sigmoid? Sigmoid σ(x)=1+e−x1​ is smooth everywhere but σ′(x)→0 as ∣x∣→∞. In deep networks, multiplying many near-zero derivatives during backprop yields vanishing gradients. ReLU’s derivative is exactly 1 for x>0 — gradients flow unchanged. This is why virtually every modern deep network uses ReLU or a variant in its hidden layers.

2.5 A Generic “Gluing” Example

f(x)={x2+1​if x≤0 2x+1​if x>0​

  • Breakpoint: x=0.
  • Left branch value at 0: f(0−)=02+1=1.
  • Right branch limit at 0: limx→0+​(2x+1)=1.
  • Actual value: f(0)=1 (left branch applies).

Both the value and the limit agree: f is continuous at x=0.

Now compare with:

g(x)={x+3​if x<1 x2​if x≥1​

At x=1: left limit =1+3=4, right branch =12=1. These disagree — jump discontinuity at x=1.

3. Continuity at a Breakpoint

This is the central analytical question for piecewise functions. Let c be a breakpoint.

Definition (Continuity at c). f is continuous at c if and only if:

limx→c−​f(x)=limx→c+​f(x)=f(c)

All three must be equal: the left-hand limit, the right-hand limit, and the actual value.

Procedure: Given a piecewise function with breakpoint c:

  1. Compute L−=limx→c−​f(x) using the branch defined left of c.
  2. Compute L+=limx→c+​f(x) using the branch defined right of c.
  3. Determine f(c) from whichever branch includes c in its domain.
  4. f is continuous at c iff L−=L+=f(c).

Example. For ∣x∣ at c=0:

  • L−=limx→0−​(−x)=0.
  • L+=limx→0+​x=0.
  • f(0)=0.
  • All equal ⇒ continuous at 0. ✓

Example. For H(x) (Heaviside) at c=0:

  • L−=limx→0−​0=0.
  • L+=limx→0+​1=1.
  • L−=L+⇒ jump discontinuity at 0.

4. Differentiability at a Breakpoint

Even if f is continuous at the breakpoint c, it may fail to be differentiable there.

Definition. f is differentiable at c if and only if the following limit exists:

f′(c)=limh→0​hf(c+h)−f(c)​

For a piecewise function, this requires checking the one-sided derivatives:

f−′​(c)=limh→0−​hf(c+h)−f(c)​,f+′​(c)=limh→0+​hf(c+h)−f(c)​

f is differentiable at c iff f−′​(c)=f+′​(c) (and the common value is f′(c)).

Theorem. Differentiability ⇒ Continuity. The converse fails.

Example: ∣x∣ at c=0.

f−′​(0)=limh→0−​h∣h∣−0​=limh→0−​h−h​=−1

f+′​(0)=limh→0+​h∣h∣−0​=limh→0+​hh​=1

f−′​(0)=−1=1=f+′​(0). Therefore ∣x∣ is not differentiable at 0, despite being continuous there.

The graph has a corner (kink) at the origin — the left tangent slope is −1, the right tangent slope is +1.

Example: ReLU at c=0.

ReLU−′​(0)=limh→0−​h0−0​=0

ReLU+′​(0)=limh→0+​hh−0​=1

Again 0=1: not differentiable at 0. Same kink, different slopes.

Deep Learning Consequence. Since ReLU is not differentiable at 0, the gradient ∂x∂​ReLU(x) is undefined there in the classical sense. In practice, frameworks like PyTorch and TensorFlow assign the subgradient 0 (or sometimes 0.5) at x=0. This is justified rigorously by convex analysis: for a convex function, the subdifferential ∂f(x) at a point of non-differentiability is an interval, and we pick any element. For ReLU, ∂ReLU(0)=[0,1].

5. Constructing Piecewise Functions: The Matching Conditions

A common exam and problem-set task: given a piecewise function with a free parameter, find the parameter value that makes f continuous (or differentiable) at the breakpoint.

Example. Find a and b so that:

f(x)={ax+b​if x<1 x2+1​if 1≤x<3 2bx−a​if x≥3​

is continuous on R.

At x=1: L−=a(1)+b=a+b L+=(1)2+1=2,f(1)=2 Continuity: a+b=2. — (I)

At x=3: L−=(3)2+1=10 L+=f(3)=2b(3)−a=6b−a Continuity: 6b−a=10. — (II)

Solving (I) and (II): from (I), a=2−b. Substituting into (II): 6b−(2−b)=10⟹7b−2=10⟹b=712​,a=2−712​=72​

Integration respects the partition of the domain.

7. A Menagerie of Important Piecewise Functions

7.1 The Floor and Ceiling Functions

Floor: ⌊x⌋ = greatest integer ≤x.

⌊x⌋=nif n≤x<n+1,n∈Z

Ceiling: ⌈x⌉ = least integer ≥x.

  • Both are piecewise constant, with jump discontinuities at every integer.
  • Used in: hashing, bucket indexing, stochastic rounding in quantized neural networks.

7.2 Leaky ReLU

LReLUα​(x)={x​if x>0 αx​if x≤0​,0<α≪1

Typically α=0.01. The motivation: ReLU neurons can “die” — once a neuron’s input is consistently negative, its gradient is exactly 0 and weights never update. Leaky ReLU gives a small nonzero gradient for negative inputs, preventing dead neurons.

At x=0: continuous (both branches give 0), not differentiable (slopes 1 vs α).

7.3 ELU (Exponential Linear Unit)

ELUα​(x)={x​if x>0 α(ex−1)​if x≤0​,α>0

At x=0: both branches give 0 (continuous). Left derivative: αe0=α. Right derivative: 1. Unless α=1, not differentiable at 0.

For α=1, ELU is continuous and differentiable at 0 (derivative =1 from both sides). It is, however, not twice-differentiable there.

7.4 Huber Loss (ML Loss Function)

Lδ​(r)={21​r2​if ∣r∣≤δ δ(∣r∣−2δ​)​if ∣r∣>δ​

where r=y−y^​ is the residual.

  • Quadratic near zero (like MSE) — sensitive to small errors.
  • Linear for large residuals (like MAE) — robust to outliers.
  • Continuous at r=±δ. Differentiable at r=±δ (left and right derivatives match). Not twice-differentiable there.

The Huber loss is used in regression when the training data contains outliers. MSE (r2) penalizes outliers quadratically and can dominate the loss; Huber dampens this to linear growth.

8. Smooth Piecewise Functions via Blending

Can we make a piecewise function that is infinitely differentiable (smooth, C∞)?

Yes — using smooth cutoff functions (bump functions). But this requires functions like:

ϕ(x)={e−1/x​if x>0 0​if x≤0​

Claim: ϕ is C∞ at x=0, and ϕ(n)(0)=0 for all n≥0.

Proof sketch. By induction, for x>0, ϕ(n)(x)=pn​(1/x)e−1/x for some polynomial pn​. As x→0+, e−1/x→0 faster than any polynomial grows: limt→∞​tke−t=0 for all k. Hence ϕ(n)(0+)=0=ϕ(n)(0).

This function is smooth but not analytic at 0 — its Taylor series is identically zero, yet the function is not. This example is the prototype for the fact that C∞⊋Cω (smooth does not imply analytic) — a cornerstone of differential geometry and PDE theory.

9. Piecewise Linear Functions and Neural Networks

Definition. A function f:R→R is piecewise linear if there exist a=c0​<c1​<⋯<cn​=b such that f is linear on each [ck−1​,ck​].

Any piecewise linear function on R can be written as:

f(x)=αx+β+∑k=1n​γk​,ReLU(x−ck​)

for appropriate constants α,β,γ1​,…,γn​. This is a fundamental theorem, and it explains why a neural network with ReLU activations computes a piecewise linear function.

Theorem (Universal Approximation, informal). A feedforward network with a single hidden layer and sufficiently many ReLU neurons can approximate any continuous function on a compact domain to arbitrary precision.

The proof strategy: approximate the target function by a piecewise linear function (possible since continuous functions on compact sets are uniformly approximable by piecewise linears), then represent that piecewise linear function as a sum of ReLU terms.

This is why depth matters. A shallow network needs exponentially many neurons to represent certain functions that a deep network can represent with polynomially many. Deep networks compose piecewise linear functions — each layer introduces new breakpoints exponentially in the depth. This is the mathematical core of the “depth efficiency” argument in deep learning theory.

Key insight from the table: The engineering choice of activation function is a choice about the regularity of the function class you’re learning over. ReLU → C0 but not C1. Smooth activations (GELU, Swish) → C∞. The choice affects optimization landscape smoothness, gradient behavior, and generalization.

11. GELU — The Modern Activation

For completeness: the GELU (Gaussian Error Linear Unit), used in transformers (GPT, BERT):

GELU(x)=x⋅Φ(x)=x⋅21​[1+erf!(2​x​)]

where Φ is the CDF of the standard normal. This is not piecewise-defined — it is smooth (C∞) everywhere. It approximates ReLU but with a smooth, probabilistic interpretation: it weights the input by the probability that a standard Gaussian exceeds it. The smooth transition avoids the kink at 0 entirely.
