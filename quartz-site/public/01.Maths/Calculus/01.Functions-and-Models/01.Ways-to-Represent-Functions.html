“A function is not a formula. It is a rule — a machine that takes input and returns output. How we describe that machine matters enormously.” — Personal note, inspired by Stewart §1.1 and MIT 18.02

0. Preliminary: What Even Is a Function?

Before talking about representations, we need to be precise about what we’re representing.

Definition. A function f from a set A to a set B — written f:A→B — is a rule that assigns to each element x∈A exactly one element f(x)∈B.

  • A is the domain — the set of valid inputs.
  • B is the codomain — the set of possible outputs live here.
  • The range (or image) of f is f(x)∣x∈A⊆B — the set of actual outputs.

Remark. The range is a subset of the codomain, but they need not be equal. For f:R→R, f(x)=x2, the codomain is R but the range is [0,∞).

The vertical line test: A curve in the xy-plane is the graph of a function of x if and only if no vertical line intersects the curve more than once. This is just the uniqueness condition made geometric.

1. The Four Ways — An Overview

Stewart identifies four fundamental modes of representation. Each has its place; a mature mathematician moves fluidly between all four.

RepresentationDescriptionWhen it shines
VerbalDescription in wordsCommunicating intent, modeling from prose
NumericalTable of valuesExperimental/empirical data
VisualGraph or diagramIntuition, qualitative behavior
AlgebraicFormula/equationComputation, analysis, generalization

In AI/ML, you will encounter all four: datasets are numerical, loss landscapes are visual, architectures described verbally, and weight updates computed algebraically.

2. Verbal Representation

A function defined by a description in words.

Example.

“Let C(t) be the number of COVID-19 cases in Bangladesh on day t since January 1, 2020.”

This is a perfectly valid definition of a function — even if we have no formula. The domain is t∈Z≥0​, and for each such t, there is a unique count C(t).

Example (Ramp function).

“The function R that returns x if x≥0, and 0 if x<0.”

This is the ReLU (Rectified Linear Unit) — the most important activation function in deep learning — described verbally. We’ll see it again below.

Why it matters in ML. When designing a loss function, you often start with a verbal description: “penalize predictions that are too large more than predictions that are too small.” This verbal intent then gets translated into an algebraic form (e.g., asymmetric Huber loss).

3. Numerical Representation (Table of Values)

A function specified by a finite table of input-output pairs.

Example. Suppose we measure the temperature T (in °C) at a specific location in Dhaka every 4 hours:

t (hours)04812162024
T(t) (°C)26252834353127

This is a function. Domain = 0,4,8,12,16,20,24. No formula is needed.

Critical observation. We cannot evaluate T(6) from this table alone — it is outside the domain as defined. Any value we assign would require interpolation (an additional modeling choice), not deduction.

Example: The Dataset as a Function.

In supervised machine learning, a training dataset D=(xi​,yi​)i=1N​ is precisely a numerically-represented function:

fD​:x1​,x2​,…,xN​⟶y1​,y2​,…,yN​,xi​↦yi​

The entire enterprise of supervised learning is: given a numerical representation, find an algebraic representation that generalizes. That is, find f^​:Rd→R (a formula, a neural network) such that f^​(xi​)≈yi​ for all i, and f^​(x)≈f(x) for unseen x.

Interpolation vs. Extrapolation. Evaluating f^​ at points between training data is interpolation. Evaluating outside the training distribution is extrapolation — and this is precisely why ML models can fail catastrophically on out-of-distribution data.

4. Visual Representation (The Graph)

Definition. The graph of a function f:A→R (where A⊆R) is the set of ordered pairs:

graph(f)=(x,f(x))∣x∈A⊆R2

This is a subset of the Cartesian plane, not the function itself — but it determines the function uniquely (over the given domain).

4.1 What a Graph Reveals Immediately

A graph communicates things that a formula obscures:

  • Monotonicity: Is f increasing? Decreasing? On what intervals?
  • Extrema: Where are the peaks and valleys?
  • Concavity: Is the graph curving upward or downward? (This is f′′>0 or f′′<0.)
  • Asymptotic behavior: What happens as x→±∞?
  • Discontinuities / singularities: Where does the function break?

4.2 Visualization

f(x) = x²          Parabola — even function, global min at x=0
f(x) = sin(x)       Oscillatory — periodic with period 2π
f(x) = eˣ          Exponential growth — range is (0,∞)
f(x) = ln(x)        Logarithm — domain is (0,∞), range is ℝ
f(x) = |x|          V-shaped — not differentiable at x=0
f(x) = max(x,0)     ReLU — the activation function of deep learning

Graph of ReLU and its “derivative”:

  f(x) = ReLU(x)          f'(x) (subgradient)
  
  |    /                   |___
  |   /                    |   |
  |  /                     |   |___________
  | /                      |
  |/___________     →      +---+----------→
  0                        0

The kink at x=0 means ReLU is not differentiable there in the classical sense. In deep learning, we use the subgradient (assign f′(0)=0 or 0.5 by convention), and backpropagation still works. This is a non-trivial fact rooted in convex analysis.

4.3 Graphs in High Dimensions — Loss Landscapes

In ML, the “function” we care about is the loss:

L:Rp⟶R

where p is the number of parameters (for GPT-4, p∼1012). We cannot draw this graph — but we can take 2D slices through parameter space and visualize those. Such loss landscape visualization is an active area of research. The key insight:

  • Sharp minima → poor generalization (overfit)
  • Flat minima → good generalization

This is a qualitative, geometric insight that the algebraic formula L(θ)=N1​∑i​ℓ(fθ​(xi​),yi​) does not immediately reveal.

5. Algebraic Representation (Explicit Formula)

The most powerful representation — and the one that can mislead us into thinking it is the only representation.

5.1 Types of Explicit Formulas

Polynomials: p(x)=an​xn+an−1​xn−1+⋯+a1​x+a0​

Domain: all of R. Smooth everywhere. Closed under addition, multiplication.

Rational functions: r(x)=q(x)p(x)​,q(x)=0

Domain: R∖x:q(x)=0. Discontinuities / poles where denominator vanishes.

Piecewise-defined functions: f(x)={x2​if x<0 x​​if x≥0​

This is a single function — not two functions glued together. The domain is R.

Example: Absolute value as piecewise: ∣x∣={x​if x≥0 −x​if x<0​

Example: ReLU as piecewise (the algebraic form of our verbal description): ReLU(x)=max(x,0)={x​if x>0 0​if x≤0​

5.2 Implicit vs. Explicit

An explicit formula gives y directly as a function of x: y=f(x).

An implicit formula gives a relation between x and y: F(x,y)=0.

Example. The unit circle: x2+y2=1.

This is not a function (fails vertical line test). But we can extract two functions from it:

y=1−x2​(upper semicircle),y=−1−x2​(lower semicircle)

The Implicit Function Theorem (a theorem you will encounter in MIT 18.02 and analysis) gives conditions under which an implicit relation F(x,y)=0 locally defines y as a function of x. This is one of the deepest theorems in calculus.

ML Connection. Neural networks define functions implicitly through a computational graph. The function fθ​:Rd→Rk has no closed-form formula for general architectures — it is defined by the sequence of matrix multiplications, nonlinearities, and other operations. In this sense, a neural network is a kind of implicit algebraic representation.

5.3 Parametric Representation

Sometimes a curve is best described by giving x and y each as functions of a third variable t (the parameter):

x=x(t),y=y(t),t∈[a,b]

Example: Unit circle parametrically: x(t)=cost,y(t)=sint,t∈[0,2π]

This represents the full circle — something no single explicit y=f(x) can do.

Example: Lissajous curve: x(t)=sin(at+δ),y(t)=sin(bt)

For different ratios a/b, you get different closed curves. These appear in signal processing and oscilloscope demonstrations.

ML Connection: Latent Space Trajectories. In a variational autoencoder or diffusion model, the generation process is parametric: a latent variable z(t) traces a path through latent space as t varies, and the decoder maps this path to a sequence of images. The “interpolation” between two images in latent space is literally a parametric curve.

6. Composition: Building New Functions from Old

Given f:A→B and g:B→C, the composition g∘f:A→C is defined by:

(g∘f)(x)=g(f(x))

Warning: Composition is not commutative. In general, f∘g=g∘f.

Example. f(x)=x2,g(x)=sinx g∘f(x)=sin(x2),f∘g(x)=(sinx)2=sin2x

These are different functions.

Deep Learning: Neural Networks as Composed Functions.

A neural network with L layers is literally a composition of functions: fθ​=fL​∘fL−1​∘⋯∘f2​∘f1​ where each fℓ​(x)=σ(Wℓ​x+bℓ​) is an affine map followed by a nonlinear activation σ.

Backpropagation is nothing more than the chain rule applied to this composition: ∂Wℓ​∂L​=∂fL​∂L​⋅∂fL−1​∂fL​​⋯∂fℓ​∂fℓ+1​​⋅∂Wℓ​∂fℓ​​

Every representation choice for each layer function fℓ​ affects how efficiently we can compute this.

7. Even and Odd Functions

Definition. A function f with domain symmetric about the origin is:

  • Even if f(−x)=f(x) for all x in the domain.
  • Odd if f(−x)=−f(x) for all x in the domain.

Even: f(x)=x2, cosx, ∣x∣ — symmetric about the y-axis.

Odd: f(x)=x3, sinx, x — symmetric about the origin (rotational symmetry of order 2).

Note. Most functions are neither even nor odd. Every function can be decomposed uniquely: f(x)=even part2f(x)+f(−x)​​​+odd part2f(x)−f(−x)​​​

ML Connection. This decomposition is related to Fourier analysis, where even functions correspond to cosine terms and odd functions to sine terms. In attention mechanisms, the distinction between symmetric and antisymmetric operations appears in the design of positional encodings and kernels.

8. Functions of Several Variables (Preview — MIT 18.02)

In MIT 18.02, the domain extends to Rn. A function f:Rn→R is called a scalar field. A function F:Rn→Rm is a vector-valued function (or vector field if m=n).

The four representations extend naturally:

  • Verbal: “Let T(x,y) be the temperature at point (x,y) in the plane.”
  • Numerical: A grid of values — this is a raster image or a 2D array.
  • Visual: A surface z=f(x,y) in R3, or a contour plot (level curves f(x,y)=c).
  • Algebraic: f(x,y)=x2+y2 (paraboloid), f(x,y)=e−(x2+y2) (Gaussian).

Level curves (x,y):f(x,y)=c are the multivariable analogue of points where f(x)=c. On a topographic map, level curves are contour lines of equal elevation.

ML Connection: Loss Contours. The contour plot of L(θ1​,θ2​) (restricting to 2 parameters) shows the “terrain” that gradient descent navigates. Elongated elliptical contours → slow convergence (ill-conditioned); circular contours → fast convergence. This motivates preconditioning and Adam optimizer (which adapts step size per parameter).

The sigmoid σ appears as the binary classification output in logistic regression and early neural networks. The softmax is its multiclass generalization. The derivative σ′=σ(1−σ) is elegant — but the vanishing gradient problem occurs because σ′(x)→0 as ∣x∣→∞, causing gradients to die in deep networks. This is precisely why ReLU replaced sigmoid in hidden layers.

10. Formal Summary

Every function f has four faces:

                         ┌─────────────────┐
                         │   THE FUNCTION   │
                         │    f : A → B     │
                         └────────┬────────┘
                                  │
          ┌───────────────────────┼───────────────────────┐
          │                       │                       │
     VERBAL               NUMERICAL                  VISUAL
  "f returns the       table of (x, f(x))         graph in ℝ²
  positive root..."       pairs                  (or surface in ℝ³)
          │                       │                       │
          └───────────────────────┼───────────────────────┘
                                  │
                            ALGEBRAIC
                          f(x) = √x, x ≥ 0
                         (formula / equation)

The choice of representation is not merely aesthetic — it determines what operations are easy, what questions are answerable, and what errors are possible.
