0. What Does “Symmetry” Mean, Precisely?

Informally, a symmetry is a transformation that leaves something unchanged. A square looks the same after a 90° rotation. The sine curve looks the same after a shift of 2π.

Formally, a symmetry of a function f is a transformation T of the domain such that: f(T(x))=f(x)for all x in the domain

Different choices of T give different symmetries. The two classical ones in single-variable calculus are:

TransformationSymmetry typeCondition
T(x)=−x (reflect across y-axis)Evenf(−x)=f(x)
T(x)=−x + sign flipOddf(−x)=−f(x)
T(x)=x+p (shift by p)Periodicf(x+p)=f(x)

Each of these is a theorem-generator: once you know a function has a symmetry, you get facts for free.

1. Even Functions — Symmetry About the y-Axis

Definition. f is even if its domain is symmetric about 0 and: f(−x)=f(x)for all x in the domain

Geometric meaning. The graph is symmetric about the y-axis: the left half is the mirror image of the right half.

Canonical examples: f(x)=x2,f(x)=x4,f(x)=cosx,f(x)=∣x∣,f(x)=e−x2

Even: the bell curve is perfectly symmetric. This is not a coincidence — it encodes the fact that the normal distribution treats +δ and −δ deviations identically.

1.1 Integral Consequence

If f is even and integrable on [−a,a]: ∫−aa​f(x),dx=2∫0a​f(x),dx

Proof. Split the integral and substitute x↦−x on the left piece: ∫−a0​f(x),dx=x=−u∫a0​f(−u)(−du)=∫0a​f(−u),du=∫0a​f(u),du Adding to ∫0a​f(x),dx gives the result. □

Example. ∫−22​(x4+cosx),dx=2∫02​(x4+cosx),dx=2[5x5​+sinx]02​=2(532​+sin2)

Half the work — literally.

2. Odd Functions — Symmetry About the Origin

Definition. f is odd if its domain is symmetric about 0 and: f(−x)=−f(x)for all x in the domain

Geometric meaning. The graph has 180° rotational symmetry about the origin: rotating the graph by π about (0,0) maps it to itself.

Canonical examples: f(x)=x,f(x)=x3,f(x)=sinx,f(x)=tanx,f(x)=sinhx

Special value. If f is odd and 0 is in its domain, then: f(0)=f(−0)=−f(0)⟹2f(0)=0⟹f(0)=0 Every odd function (with 0 in its domain) passes through the origin. This is a theorem, not a coincidence.

2.1 Integral Consequence

If f is odd and integrable on [−a,a]: ∫−aa​f(x),dx=0

Proof. By the same substitution as above, ∫−a0​f(x),dx=−∫0a​f(u),du. These cancel. □

Example. ∫−ππ​sin(x)cos2(x),dx=0 — because sin(x)cos2(x) is odd (odd × even = odd). No computation needed.

3. The Decomposition Theorem

Theorem. Every function f defined on a domain symmetric about 0 can be written uniquely as the sum of an even function and an odd function: f(x)=fe​(x), even2f(x)+f(−x)​​​+fo​(x), odd2f(x)−f(−x)​​​

Proof.

Existence. Define fe​ and fo​ as above. Then: fe​(−x)=2f(−x)+f(x)​=fe​(x)✓ fo​(−x)=2f(−x)−f(x)​=−fo​(x)✓ fe​(x)+fo​(x)=2f(x)+f(−x)​+2f(x)−f(−x)​=f(x)✓

Uniqueness. Suppose f=g+h where g even, h odd. Then f(−x)=g(x)−h(x). Adding and subtracting with f(x)=g(x)+h(x) gives g(x)=2f(x)+f(−x)​ and h(x)=2f(x)−f(−x)​ uniquely. □

Example. Decompose f(x)=ex: fe​(x)=2ex+e−x​=coshx(hyperbolic cosine, even) fo​(x)=2ex−e−x​=sinhx(hyperbolic sine, odd)

So ex=coshx+sinhx — a fundamental identity in hyperbolic functions.

The last two rows are worth proving. If f(−x)=f(x), differentiate both sides: −f′(−x)=f′(x), i.e., f′(−x)=−f′(x). So f′ is odd. Symmetry is preserved — and transformed — under differentiation.

4. Periodic Functions — Translational Symmetry

Definition. f is periodic with period p>0 if: f(x+p)=f(x)for all x

The fundamental period (or primitive period) is the smallest such p.

Examples:

FunctionPeriod
sinx, cosx2π
tanx, cotxπ
sin(kx)2π/k
eix (complex)2π
Sawtooth waveT (by definition)

Consequence. If f has period p, then ∫aa+p​f(x),dx is the same for every a — integrating over any full period gives the same result.

Proof. Let I(a)=∫aa+p​f(x),dx. Then I′(a)=f(a+p)−f(a)=0, so I is constant. □

5. Symmetry in the Plane — Even and Odd Together

Consider the relation x2+y2=1. This has three symmetries:

  • Reflection across y-axis: (x,y)↦(−x,y)
  • Reflection across x-axis: (x,y)↦(x,−y)
  • Rotation by π: (x,y)↦(−x,−y)

This is not a function, but each symmetry tells us: if (a,b) satisfies the equation, so do (−a,b), (a,−b), (−a,−b).

For a function y=f(x):

  • Symmetry about y-axis ⇔ f is even
  • Symmetry about x-axis ⇒ not a function (unless f≡0) — because (x,y) and (x,−y) would both be on the graph
  • Symmetry about origin ⇔ f is odd

6. Worked Examples

Example 1. Determine if f(x)=x4+1x2​ is even, odd, or neither.

f(−x)=(−x)4+1(−x)2​=x4+1x2​=f(x)

Even. (Numerator is x2, even; denominator is x4+1, even; even/even = even.)

Example 2. Determine if g(x)=x3sinx is even, odd, or neither.

g(−x)=(−x)3sin(−x)=(−x3)(−sinx)=x3sinx=g(x)

Even. (Odd × odd = even — consistent with our table.)

Example 3. Evaluate ∫−11​(x5+3x3−x)ex2,dx.

Let h(x)=(x5+3x3−x)ex2.

  • x5+3x3−x is odd (sum of odd powers).
  • ex2 is even (since (−x)2=x2).
  • odd × even = odd.

Therefore ∫−11​h(x),dx=0.

No antiderivative needed.

Example 4. Decompose f(x)=x2+x+1 into even and odd parts.

fe​(x)=2(x2+x+1)+(x2−x+1)​=22x2+2​=x2+1

fo​(x)=2(x2+x+1)−(x2−x+1)​=22x​=x

Check: fe​(x)+fo​(x)=(x2+1)+x=x2+x+1=f(x). ✓

7. Symmetry in Several Variables (MIT 18.02)

For f:R2→R, symmetry generalizes:

  • Even in x: f(−x,y)=f(x,y) — graph symmetric about yz-plane
  • Even in y: f(x,−y)=f(x,y) — graph symmetric about xz-plane
  • Radially symmetric: f(x,y) depends only on r=x2+y2​, i.e., f(x,y)=g(r)

Example. f(x,y)=e−(x2+y2)=e−r2 is radially symmetric. Its graph is a symmetric bell surface. The Gaussian integral: ∫−∞∞​∫−∞∞​e−(x2+y2),dx,dy=π

is computed by switching to polar coordinates — a trick made possible by the radial symmetry. From this, we extract ∫−∞∞​e−x2,dx=π​.

Double integral consequence of symmetry. If the domain D is symmetric about the y-axis and f is odd in x: ∬D​f(x,y),dA=0

Same logic, same power.

8. Connections to AI / Machine Learning

8.1 Symmetric Activation Functions

ActivationEven/OddConsequence
tanh(x)Oddtanh(0)=0; gradients symmetric; zero-centered outputs
sigmoid(x)NeitherOutputs in (0,1); not zero-centered → gradient issues
ReLU(x)NeitherAsymmetric; dying neuron problem for x<0
sin(x) (SIREN networks)OddUsed in implicit neural representations

The zero-centered property of odd activations (like tanh) is practically important: if activations are not zero-centered, gradients in earlier layers tend to be all-positive or all-negative, causing zig-zag gradient updates. This is called the zero-mean activation problem and was a key reason tanh was preferred over sigmoid in early deep learning.

8.2 Symmetry in the Loss Function

The Mean Squared Error loss: L(θ)=N1​∑i=1N​(yi​−y^​i​)2

is even as a function of the residual ri​=yi​−y^​i​: it treats overestimation and underestimation identically. This is a modeling choice — you might not want that.

The Huber loss and MAE are also even in the residual. An asymmetric loss (neither even nor odd) would be used when, e.g., false negatives are more costly than false positives in a medical diagnostic setting.

8.3 The Even-Odd Decomposition and Fourier Analysis

The decomposition f=fe​+fo​ is the seed of Fourier analysis:

f(x)=2a0​​+∑n=1∞​even termsan​cos(nx)​​+odd termsbn​sin(nx)​​

The even part of f determines the an​ (cosine) coefficients; the odd part determines the bn​ (sine) coefficients. In signal processing and sequence modeling (Transformers), Fourier features and positional encodings exploit this decomposition:

  • RoPE (Rotary Position Embedding) in modern LLMs encodes position using rotation matrices built from cos and sin — i.e., from even and odd functions.
  • Fourier Features in kernel methods: random Fourier features approximate shift-invariant (translationally symmetric) kernels.

8.4 Equivariance and Invariance — The Modern Generalization

In modern deep learning, symmetry is formalized as:

  • Invariance: f(T(x))=f(x) — the output doesn’t change under transformation T. (Even functions are Z2​-invariant.)
  • Equivariance: f(T(x))=T′(f(x)) — the output transforms consistently with the input.

Convolutional Neural Networks (CNNs) are equivariant to translation: if you shift the image, the feature map shifts correspondingly. This is translational symmetry built into the architecture.

Graph Neural Networks (GNNs) are equivariant to permutation of nodes.

SE(3)-equivariant networks (used in protein structure prediction, e.g., AlphaFold) are equivariant to 3D rotation and translation — they respect the physical symmetry of molecules.

The mathematical foundation: the functions f:X→Y that respect the action of a group G form a rich structure. Geometric deep learning (Bronstein et al., 2021) unifies CNNs, GNNs, Transformers, and more under this framework. Every major architectural innovation in deep learning can be understood as encoding the right symmetry into the model.

9. Summary

SYMMETRY OF f
│
├── REFLECTIVE SYMMETRY
│   ├── About y-axis:  f(-x) = f(x)   → EVEN function
│   └── About origin:  f(-x) = -f(x)  → ODD function
│
├── TRANSLATIONAL SYMMETRY
│   └── f(x+p) = f(x)                 → PERIODIC, period p
│
├── RADIAL SYMMETRY (ℝ²)
│   └── f(x,y) = g(√(x²+y²))         → depends only on r
│
└── GENERAL (Group Theory)
    ├── f(T(x)) = f(x)                → T-INVARIANT
    └── f(T(x)) = T'(f(x))           → T-EQUIVARIANT
                                         (CNN, GNN, AlphaFold)

Key theorems to remember:

  1. ∫−aa​fodd​,dx=0
  2. ∫−aa​feven​,dx=2∫0a​feven​,dx
  3. Every f on a symmetric domain decomposes uniquely as fe​+fo​
  4. Derivative of even = odd; derivative of odd = even
  5. f(0)=0 for every odd function with 0 in its domain
