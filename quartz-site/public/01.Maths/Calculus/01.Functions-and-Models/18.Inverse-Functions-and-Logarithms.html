18.Inverse Functions and Logarithms

18.Inverse Functions and Logarithms

“An inverse function is not a formula trick — it is a question of whether a process can be undone.”

0. Motivation

The exponential ex encodes growth. Its inverse — the logarithm — decodes it: given the result of growth, how long did it run? In machine learning, log-likelihoods, cross-entropy, softmax, and the entire information-theoretic foundation of learning are built on logarithms. Inverse functions more broadly appear whenever we ask: can we recover the input from the output? This note answers that question rigorously.

1. One-to-One Functions

1.1 Definition

A function f is one-to-one (injective) if distinct inputs produce distinct outputs:

x1​=x2​⟹f(x1​)=f(x2​)​

Equivalently (contrapositive):

f(x1​)=f(x2​)⟹x1​=x2​

1.2 The Horizontal Line Test

f is one-to-one if and only if every horizontal line y=c intersects the graph of f at most once.

  One-to-one ✓              NOT one-to-one ✗
  
  y │    /                  y │    ∩
    │   /                     │   / \
 ───┼──/──── y=c           ───┼──/───\── y=c (hits twice!)
    │ /                       │ /     \
    │/                        │/       \
    └────── x                 └────────── x
    
    f(x) = x³                 f(x) = x²

1.3 Strictly Monotone ⟹ One-to-One

Theorem. If f is strictly increasing or strictly decreasing on an interval I, then f is one-to-one on I.

Proof. Suppose f is strictly increasing and x1​=x2​. WLOG x1​<x2​. Then f(x1​)<f(x2​), so f(x1​)=f(x2​). □

This is why restricting domain restores injectivity. f(x)=x2 is not injective on R, but is strictly increasing on [0,∞), hence injective there.

2. The Inverse Function

2.1 Definition

Let f:A→B be one-to-one and onto (bijective onto its range). The inverse function f−1:B→A is defined by:

f−1(y)=x⟺f(x)=y​

The domain of f−1 is the range of f, and the range of f−1 is the domain of f.

Notation warning. f−1(x)=f(x)1​. The superscript −1 denotes the inverse function, not the reciprocal. The reciprocal is written [f(x)]−1.

2.2 The Cancellation Identities

For all x in the appropriate domain:

f−1(f(x))=x(for all x∈Df​) f(f−1(x))=x(for all x∈Df−1​)

These say: applying f then f−1 (or vice versa) returns to the original input.

2.3 How to Find f−1 Explicitly

Algorithm:

  1. Write y=f(x).
  2. Solve for x in terms of y.
  3. Swap x↔y (by convention, we want y=f−1(x)).
  4. State the domain of f−1 (= range of f).

Example. f(x)=2x+3.

y=2x+3⟹x=2y−3​⟹f−1(x)=2x−3​

Example. f(x)=x3+1.

y=x3+1⟹x=(y−1)1/3⟹f−1(x)=(x−1)1/3

Example (domain restriction). f(x)=x2 on [0,∞).

y=x2,;x≥0⟹x=y​⟹f−1(x)=x​,x≥0

Without the restriction, the inverse would not be a function (two x values map to the same y).

2.4 Graph of f−1

The graph of f−1 is the reflection of the graph of f across the line y=x.

  y │         /  f(x)
    │     ╱  /
    │   ╱  ·/·
    │ ╱  ·/ · (reflected points)
    │╱  /  ╱  f⁻¹(x)
  ──┼──/──╱──────── x
    │ / ╱
    │/╱
    
    Points (a,b) on f  ↔  points (b,a) on f⁻¹

Proof. If (a,b) is on the graph of f, then f(a)=b, so f−1(b)=a, meaning (b,a) is on the graph of f−1. Swapping coordinates (a,b)↦(b,a) is exactly reflection across y=x. □

2.5 Derivative of the Inverse (Preview to Chapter 3)

If f is differentiable and one-to-one, then:

(f−1)′(a)=f′(f−1(a))1​​

Intuition. Differentiate the cancellation identity f(f−1(x))=x using the chain rule:

f′(f−1(x))⋅(f−1)′(x)=1⟹(f−1)′(x)=f′(f−1(x))1​

Geometrically: if f has slope m at a point, f−1 has slope 1/m at the reflected point. Steep f gives shallow f−1, and vice versa.

3. The Exponential Function

3.1 Definition and Properties

For a>0, a=1, the exponential function f(x)=ax satisfies:

ax+y=ax⋅ay,(ax)y=axy,a0=1

It is strictly monotone (increasing if a>1, decreasing if 0<a<1), hence injective on all of R.

The natural exponential f(x)=ex, where e=2.71828…, is the unique exponential whose derivative equals itself:

dxd​ex=ex

  y │        e^x
    │       /
    │      /
    │     /
    │   _/
    │__/
  ──┼──────────── x
    │
    
  Domain: ℝ,  Range: (0, ∞)
  Horizontal asymptote: y = 0 as x → -∞

4. The Logarithmic Function

4.1 Definition

Since f(x)=ax is one-to-one, it has an inverse. The logarithm base a is:

loga​x=y⟺ay=x​

Domain: (0,∞). Range: R. This is the answer to: “To what power must I raise a to get x?“

4.2 The Natural Logarithm

The inverse of ex is the natural logarithm:

lnx=y⟺ey=x

This is the most important logarithm in analysis. All other logarithms are scalar multiples of it:

loga​x=lnalnx​

4.4 Laws of Logarithms

Let x,y>0 and r∈R:

ln(xy)=lnx+lny ln!(yx​)=lnx−lny ln(xr)=rlnx

Proof of the first law. Let a=lnx and b=lny, so x=ea and y=eb. Then:

ln(xy)=ln(ea⋅eb)=ln(ea+b)=a+b=lnx+lny□

The other two follow similarly.

4.5 Cancellation Identities for ln and ex

elnx=x(x>0) ln(ex)=x(x∈R)

These are just the general cancellation identities for f and f−1 specialized to ex and ln.

4.6 The Derivative

dxd​lnx=x1​,x>0

Proof via inverse function derivative. We know elnx=x. Differentiate both sides:

elnx⋅dxd​lnx=1⟹x⋅dxd​lnx=1⟹dxd​lnx=x1​□

More generally: dxd​ln∣x∣=x1​ for x=0.

5. Inverse Trigonometric Functions

5.1 Arcsine

sinx is not injective on R. Restricting to [−π/2,π/2] makes it strictly increasing, hence invertible.

arcsin(x)=sin−1(x)=y⟺sin(y)=x and y∈[−2π​,2π​]

Domain: [−1,1]. Range: [−π/2,π/2].

  y │  π/2 ─────────────·
    │              ·
    │          ·
  ──┼─────·────────────── x
    │  ·         -1   1
    │·
  -π/2
  
  Cancellation: sin(arcsin x) = x  for x ∈ [-1,1]
               arcsin(sin x) = x  for x ∈ [-π/2, π/2]

Derivative:

dxd​arcsin(x)=1−x2​1​,∣x∣<1

Proof. Let y=arcsinx, so siny=x. Differentiate: cosy⋅y′=1, so y′=cosy1​=1−sin2y​1​=1−x2​1​. □

5.2 Arctangent

tanx restricted to (−π/2,π/2):

arctan(x)=y⟺tan(y)=x and y∈(−2π​,2π​)

Domain: R. Range: (−π/2,π/2).

limx→∞​arctanx=2π​,limx→−∞​arctanx=−2π​

  y │  π/2 ─ ─ ─ ─ ─ ─ ─ ─ (asymptote)
    │          ___──────
    │    ___───
  ──┼───────────────────── x
    │     ───___
    │ ─────
  -π/2 ─ ─ ─ ─ ─ ─ ─ ─ ─ (asymptote)

Derivative:

dxd​arctan(x)=1+x21​

Proof. Let y=arctanx, so tany=x. Differentiate: sec2y⋅y′=1, so y′=cos2y=1+tan2y1​=1+x21​. □

6. Solving Exponential and Logarithmic Equations

6.1 Strategy

  • To isolate an exponential: take ln of both sides.
  • To isolate a logarithm: exponentiate both sides.

Example. Solve 3e2x=15:

e2x=5⟹2x=ln5⟹x=2ln5​

Example. Solve ln(x+1)+ln(x−1)=1:

ln((x+1)(x−1))=1⟹x2−1=e⟹x=e+1​

(Reject −e+1​ since x>1 required for domain.)

7. Connection to AI / Machine Learning / Deep Learning

7.1 The Sigmoid as an Inverse of Logit

The sigmoid function used in logistic regression and neural network output layers is:

σ(x)=1+e−x1​

Its inverse is the logit (log-odds):

σ−1(p)=ln!(1−pp​)

Sigmoid maps R→(0,1) — converting any real score into a probability. Its inverse maps probabilities back to log-odds. The fact that σ and logit are mutual inverses is why logistic regression and binary cross-entropy form a natural pair.

  Sigmoid:                         Logit (inverse):
  
  y  1 ─ ─ ─ ─────────────        y  │         /
     │      ___/                      │        /
     │   __/                          │       /
  0.5│  /                          ───┼──────/────── x
     │ /                              │    /       0.5  1
     │/                               │   /
  ───┼──────────── x               (−∞)│  /
     
  Domain: ℝ → (0,1)               Domain: (0,1) → ℝ

7.2 Log-Likelihood and Cross-Entropy

Maximum Likelihood Estimation (MLE) — the theoretical basis for training — maximizes:

L(θ)=∏i=1n​pθ​(xi​)

Because this product is numerically unstable and hard to differentiate, we take the log:

ℓ(θ)=lnL(θ)=∑i=1n​lnpθ​(xi​)

The logarithm converts a product into a sum — this is the third law of logarithms at work. Maximizing ℓ(θ) is equivalent to maximizing L(θ) because ln is strictly increasing (a consequence of it being a one-to-one function). This is the entire theoretical justification.

Cross-entropy loss (minimized in classification):

H(y,y^​)=−∑c​yc​lny^​c​

The ln here comes directly from log-likelihood. Training a classifier with cross-entropy is MLE.

7.3 Softmax Is a Multi-Class Generalization of Sigmoid

The softmax function maps a vector z∈RK to a probability distribution:

softmax(z)k​=∑j=1K​ezj​ezk​​

Its inverse is the log-softmax:

lnsoftmax(z)k​=zk​−ln!(∑j​ezj​)

Log-softmax is more numerically stable to compute directly than softmax followed by ln. This is why torch.nn.LogSoftmax exists as a separate primitive in PyTorch.

7.4 Entropy and Information Theory

The entropy of a distribution p is:

H(p)=−∑x​p(x)lnp(x)=E[−lnp(X)]

The ln here quantifies surprise: low-probability events have high −lnp (lots of information). High-probability events carry little information. The logarithm is the unique function that converts multiplicative independence into additive information:

if p(A∩B)=p(A)p(B), then −lnp(A∩B)=−lnp(A)−lnp(B)

This additive property — the logarithm law — is why information is measured in log-units (bits or nats).

7.5 Numerical Stability: The Log-Sum-Exp Trick

Softmax involves ∑j​ezj​. For large zj​, this overflows. The trick:

ln!(∑j​ezj​)=c+ln!(∑j​ezj​−c),c=maxj​zj​

This works because ln(ec⋅X)=c+lnX. The cancellation identity for ln and ex makes this manipulation exact. Every modern deep learning framework uses this.

7.6 Learning Rate Schedules and Log-Scale

Hyperparameter search over learning rates is done on a log scale. Searching η∈[10−5,10−1] uniformly in log-space means sampling log10​η∈[−5,−1] uniformly. This reflects that the learning rate’s effect on training is multiplicative, not additive — the natural domain for a logarithm.

7.7 Invertibility and Autoencoders

In an autoencoder, the encoder f:Rn→Rk (with k≪n) compresses input to a latent code, and the decoder g:Rk→Rn reconstructs. The goal is for g≈f−1, i.e., the decoder approximates the inverse of the encoder. The theory of whether a map can have a left-inverse is precisely the theory of injective (one-to-one) functions. A non-injective encoder cannot have a true inverse — information is irreversibly lost.

7.8 Normalizing Flows — Exact Invertibility

Normalizing flows are generative models that require the transformation f:Rn→Rn to be exactly invertible. The change-of-variables formula for densities involves the Jacobian determinant:

pX​(x)=pZ​(f−1(x))⋅​detJf−1​(x)​

This requires f to be a bijection. The entire architecture of a normalizing flow (RealNVP, Glow, etc.) is engineered so that f−1 can be computed efficiently. Invertibility is not a convenience — it is the structural requirement.

9. Exercises

Exercise 1. Prove that f(x)=x3+x is one-to-one on R without computing its inverse explicitly. (Hint: show it is strictly increasing.)

Exercise 2. Find the inverse of f(x)=2ex−e−x​ (this is sinhx). State its domain.

Answer: f−1(x)=ln(x+x2+1​), domain R.

Exercise 3. Use the inverse function derivative formula to find dxd​arctan(x) from scratch, without memorizing the formula.

Exercise 4. Simplify: ln(e3x⋅e−x)−2ln(ex).

Answer: 3x−x−2x=0.

Exercise 5. Solve for x: ;2x=3x−1.

Hint: Take ln of both sides and use ln(ab)=blna.

Exercise 6 (ML flavour). The sigmoid satisfies σ(x)=1+e−x1​.

  • (a) Show that σ(−x)=1−σ(x).
  • (b) Find σ−1(p) explicitly.
  • (c) Show that σ′(x)=σ(x)(1−σ(x)). (This identity is used in the backprop update rule for logistic output neurons.)

Exercise 7. Let f:Rn→Rk with k<n. Explain rigorously why f cannot be injective, and therefore cannot have a left inverse. (Hint: dimension / rank argument.)
