“A model is a lie that helps you see the truth.” — paraphrased from Box’s aphorism

What Is a Mathematical Model?

A mathematical model is a description of a system using mathematical concepts and language — equations, functions, inequalities, probability distributions, differential equations, matrices. The act of modelling is the deliberate choice to abstract away physical complexity and retain only what matters for the question at hand.

Formally: Given a real-world system S, a mathematical model M is a tuple:

M=(X, Y, f, Θ)

where:

  • X — the input space (independent variables, features, causes)
  • Y — the output space (dependent variables, responses, targets)
  • f:X×Θ→Y — the model map (the equation relating inputs to outputs, parameterised)
  • Θ — the parameter space (constants to be determined or fitted)

The art of modelling is choosing which variables to include and which to discard.

A Taxonomy of Mathematical Models

Mathematical Models
│
├── By Time Dependence
│   ├── Static (no time variable)
│   └── Dynamic (time-varying; ODEs, PDEs)
│
├── By Randomness
│   ├── Deterministic (same input → same output always)
│   └── Stochastic (incorporates probability; same input → distribution of outputs)
│
├── By Linearity
│   ├── Linear (superposition holds)
│   └── Nonlinear (superposition fails; much richer behaviour)
│
└── By How They Are Built
    ├── Mechanistic / First-Principles (derived from physics, chemistry, biology)
    └── Empirical / Data-Driven (fitted to observed data)

Note to self: Machine learning models almost always live in the empirical, nonlinear, stochastic corner. Classical physics models are mechanistic, deterministic, often linear (or linearised).

The Modelling Cycle

Realityabstraction​Modelanalysis​Predictionsvalidation​Reality

  1. Formulation — Identify variables, assumptions, governing relationships.
  2. Mathematical Analysis — Solve, simulate, or approximate f.
  3. Prediction — Use f(x;θ) to produce outputs for new inputs.
  4. Validation — Compare predictions against data. Refine if necessary.
  5. Interpretation — Extract meaning, not just numbers.

Canonical Examples

1. Linear Model (Static, Deterministic)

y=w⊤x+b,x∈Rn, y∈R

The simplest non-trivial model. w are weights, b is a bias. Every linear regression, every hyperplane classifier, every filter in early signal processing is secretly this.

Example — Hooke’s Law: F=kx. Force is a linear model of displacement. One parameter k.

Example — Temperature conversion: F=59​C+32. Exact, no randomness, first-principles derivation trivial.

2. Exponential Growth / Decay (Dynamic, Deterministic)

dtdy​=ky,y(0)=y0​

Solution: y(t)=y0​ekt

  • k>0: growth (population, compound interest, early epidemic spread)
  • k<0: decay (radioactive decay, drug clearance)

Example — Carbon-14 Dating: Half-life t1/2​=5730 years. If y(t)=y0​ekt and y(t1/2​)=y0​/2:

ek⋅5730=21​⟹k=5730−ln2​≈−1.21×10−4 yr−1

Given a sample with 75% of original C-14 remaining: 0.75,y0​=y0​,ekt⟹t=kln(0.75)​≈2378 years

3. Logistic Growth (Dynamic, Nonlinear)

dtdP​=rP!(1−KP​)

Corrects exponential growth with a carrying capacity K. The term (1−P/K) is the nonlinearity — it suppresses growth as P→K.

Exact solution: P(t)=1+(P0​K−P0​​)e−rtK​

Visualisation concept:

This exact sigmoid curve is foundational to machine learning. See §Connection to AI and Machine Learning below.

4. Linear Systems (Static, Deterministic)

Ax=b,A∈Rm×n

Encodes m linear constraints on n unknowns. The entire machinery of linear algebra — eigenvalues, SVD, pseudoinverse — is about understanding these systems.

Example — Traffic Flow: At each junction, flow in = flow out. Each junction gives one linear equation. The system Ax=b models the entire network.

5. Probabilistic / Statistical Models (Stochastic)

y=f(x;θ)+ε,ε∼N(0,σ2)

The additive noise ε acknowledges that no deterministic model is exact. This is not a weakness — it is epistemically honest. From this single assumption, ordinary least squares, maximum likelihood estimation, and Bayesian inference all follow naturally.

Dimensionless Analysis and Scaling

One of the most powerful (and criminally underused) techniques. By non-dimensionalising a model, we:

  1. Reduce the number of free parameters.
  2. Identify which terms dominate.
  3. Make the model universal.

Example — Simple Pendulum: dt2d2θ​+Lg​sinθ=0

Let τ=tg/L​ (dimensionless time). Then: dτ2d2θ​+sinθ=0

All pendulums, regardless of length or gravitational field, obey the same equation in dimensionless time. One equation rules them all.

For small θ: sinθ≈θ, so θ(τ)=Acos(τ+ϕ) — simple harmonic motion.

Connection to AI and Machine Learning

This is where classical modelling and modern ML fuse in ways that are deeply elegant.

Neural Networks as Parameterised Function Approximators

A deep neural network is a mathematical model: f(x;θ)=(Lk​∘σ∘Lk−1​∘⋯∘σ∘L1​)(x)

where Li​(z)=Wi​z+bi​ are affine maps and σ is a nonlinear activation. This is just a highly nested, highly parameterised function in Θ=Wi​,bi​.

The Universal Approximation Theorem (Cybenko 1989, Hornik 1991) guarantees that a sufficiently wide one-hidden-layer network can approximate any continuous function on a compact set to arbitrary precision. Deep networks extend this with exponentially more efficient representations.

The Sigmoid: From Logistic ODE to Activation Function

The solution to the logistic ODE above is the logistic function:

σ(z)=1+e−z1​=1+(P0​K−P0​​)e−rtK​​K=1, r=1, P0​=1+ez0​1​​

In logistic regression and early neural networks, this is used as the activation function. It maps R→(0,1), perfect for probabilities.

The ReLU σ(z)=max(0,z) dominates modern practice because it avoids vanishing gradients — but it is a piecewise linear model, just as the logistic is a smooth nonlinear one.

Linear Regression: A First-Principles Model Fitted to Data

y^​=w⊤x+b

Fitting this model = finding θ=(w,b) that minimises the loss:

L(θ)=n1​∑i=1n​(yi​−y^​i​)2

This has a closed-form solution (the Normal Equations): θ^=(X⊤X)−1X⊤y

But for large-scale ML, we use gradient descent instead: θ←θ−η,∇θ​L

where η is the learning rate. All of deep learning optimisation is gradient descent on a very complicated L.

Differential Equations in Deep Learning: Neural ODEs

A modern and beautiful idea (Chen et al., NeurIPS 2018): model the hidden state of a network as the solution of an ODE:

dtdh(t)​=f(h(t), t; θ)

where f is a neural network. A residual network ht+1​=ht​+f(ht​) is the Euler discretisation of this ODE with step size 1. This connection is not metaphorical — it is exact. Neural ODEs allow continuous-depth models and are elegant tools in time-series and physical simulation.

Inductive Bias: The Hidden Modelling Choice

Every ML model encodes prior beliefs about f through its architecture. This is called inductive bias:

ArchitectureInductive Bias
Linear modelf is affine
CNNf has local spatial correlations; translation equivariance
RNN / LSTMf depends on sequential history
Transformerf depends on global pairwise relationships
GNNf respects graph symmetries

Choosing the right architecture is the modelling step in deep learning. It is the same intellectual act as choosing whether to model population dynamics with an exponential or a logistic — you are encoding your beliefs about the structure of reality.

Worked Example: Epidemic Modelling (SIR Model)

A beautiful mechanistic model that became globally prominent in 2020.

Variables:

  • S(t) — Susceptible fraction of population
  • I(t) — Infected fraction
  • R(t) — Recovered (immune) fraction

Constraint: S+I+R=1 (closed population)

Governing ODEs: dtdS​=−βSI dtdI​=βSI−γI dtdR​=γI

Parameters:

  • β — transmission rate
  • γ — recovery rate
  • R0​=β/γ — basic reproduction number

Key insight: The epidemic grows iff dI/dt>0, i.e. βS>γ, i.e. S>γ/β=1/R0​.

Herd immunity is achieved when S<1/R0​. For measles R0​≈15, so ∼93 immunity needed.

Qualitative phase portrait concept:

I
│    *
│   * *
│  *   *
│ *      *
│*         ──────────────
└────────────────────────── S
  S decreases monotonically →

The system has no closed-form solution in general — it is studied via phase plane analysis, numerical integration (Runge-Kutta), and perturbation theory for small I0​.

AI connection: This ODE system can be embedded into a neural ODE, where β and γ are learnt from data rather than estimated epidemiologically. The model structure (the equations) is the mechanistic prior; the network fits the parameters. This hybrid approach is called physics-informed machine learning.

Error, Uncertainty, and Model Validation

A model without a notion of its own error is dangerous.

Residuals: ei​=yi​−f(xi​;θ^). If the model is correct, residuals should look like noise.

Coefficient of determination: R2=1−∑i​(yi​−yˉ​)2∑i​ei2​​∈(−∞,1]

R2=1 means perfect fit. R2=0 means the model explains nothing beyond the mean. R2<0 means the model is worse than a constant.

Overfitting: A model with too many parameters fits the training data perfectly but fails on new data. The polynomial of degree n−1 through n points has R2=1 but is useless.

Bias-variance tradeoff: E[(y−f^​)2]=underfittingBias[f^​]2​​+overfittingVar[f^​]​​+irreducible noiseσ2​​

This is perhaps the most important equation in all of statistical learning theory. Simple models have high bias, low variance. Complex models have low bias, high variance. The art — and the active research — is in finding the right balance.

Summary: What Makes a Good Model?

“All models are wrong, but some are useful.” — George Box

CriterionWhat It Means
ParsimonyUses the fewest parameters necessary (Occam’s Razor)
Predictive accuracyGeneralises to unseen data
InterpretabilityParameters have physical/statistical meaning
TractabilityCan be analysed or solved (exactly or approximately)
RobustnessSmall perturbations in data → small changes in output

No model satisfies all five simultaneously. Every modelling choice is a trade-off. This is the intellectual content of the discipline.
