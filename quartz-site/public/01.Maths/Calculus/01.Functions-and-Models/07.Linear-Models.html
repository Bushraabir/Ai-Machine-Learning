“The first approximation is always linear. The question is whether you can afford the second.”

What Is a Linear Model?

A function f:X→Y is linear if it satisfies two axioms simultaneously:

f(x+y)=f(x)+f(y)(additivity) f(αx)=αf(x)(homogeneity)

Together these are called superposition. Any map satisfying both is linear.

Affine vs. Linear: In practice, we almost always mean affine: f(x)=w⊤x+b

The term b (bias or intercept) breaks strict linearity but is essential for modelling. An affine map is a linear map composed with a translation. In ML literature, “linear model” universally means affine.

The One-Variable Case

y=mx+b,m,b∈R

Geometry: a line in R2. Every point on it satisfies this equation exactly.

Parameters:

  • m = slope = ΔxΔy​ — rate of change of y per unit change in x
  • b = y-intercept — value of y when x=0

Example — Fahrenheit/Celsius: F=59​C+32

This is an exact linear model. m=9/5, b=32. No residual, no noise, no approximation. Physical law, not a fit.

Example — Hooke’s Law: F=kx

Spring force is proportional to displacement. b=0 here (passes through origin — a strictly linear model, not just affine). k is the spring constant, units N/m.

The Multivariable Case

y=w1​x1​+w2​x2​+⋯+wn​xn​+b=w⊤x+b

where w=(w1​,…,wn​)⊤∈Rn is the weight vector and x∈Rn is the feature vector.

Geometry: a hyperplane in Rn+1, or equivalently, the level sets x:w⊤x=c are hyperplanes in Rn.

Example — House Price (toy model): price^​=150⋅(area)+20000⋅(bedrooms)−5000⋅(age)+30000

Each weight has a direct physical interpretation: 150peradditionalsqft,20,000 per bedroom, etc.

Matrix Form: The System Perspective

When we have m observations and n features, stack everything:

y=Xw+b⋅1

Absorb the bias by appending a column of ones to X:

m×1y​​=m×(n+1)X​​(n+1)×1θ​​

where θ=(b,w1​,…,wn​)⊤. Now the entire dataset fits into one equation.

Three regimes:

  • m<n+1: underdetermined — infinitely many solutions (minimum norm solution via pseudoinverse)
  • m=n+1, X invertible: exactly determined — unique solution θ=X−1y
  • m>n+1: overdetermined — no exact solution in general → least squares

Linear Regression: Fitting a Linear Model to Data

We have data (xi​,yi​)i=1m​ and we want to find θ such that Xθ≈y.

The Least Squares Objective

L(θ)=∣Xθ−y∣2=∑i=1m​(yi​−θ⊤xi​)2

This is a convex quadratic in θ — it has a unique global minimum.

The Normal Equations

Proof of the closed-form solution:

Set ∇θ​L=0:

∇θ​∣Xθ−y∣2=2X⊤(Xθ−y)=0

X⊤X,θ=X⊤y​

These are the Normal Equations. If X⊤X is invertible (columns of X are linearly independent, which requires m≥n+1 and no multicollinearity):

θ^=(X⊤X)−1X⊤y

The matrix X+=(X⊤X)−1X⊤ is the Moore-Penrose pseudoinverse of X (when m>n).

Geometric Interpretation

The prediction y^​=Xθ^ is the orthogonal projection of y onto the column space col(X).

         y
        /|
       / |  ← residual e = y - ŷ  ⊥ col(X)
      /  |
     /   |
    ŷ────┘
   (in col(X))

The residual e=y−y^​ is orthogonal to every column of X, which is precisely what X⊤e=0 says. The normal equations are this orthogonality condition.

Projection matrix: H=X(X⊤X)−1X⊤ is called the hat matrix because y^​=Hy. It satisfies H2=H (idempotent) and H⊤=H (symmetric) — the definition of an orthogonal projection.

Worked Example: Fitting a Line

Data: (x,y)=(1,2.1), (2,3.9), (3,6.2), (4,7.8), (5,10.1)

Model: y=w1​x+b. Design matrix (with bias column):

X=(1​1 1​2 1​3 1​4 1​5​),y=(2.1 3.9 6.2 7.8 10.1​)

Compute: X⊤X=(5​15 15​55​),X⊤y=(30.1 104.3​)

Solving (X⊤X)θ=X⊤y: det(X⊤X)=5⋅55−152=275−225=50

(X⊤X)−1=501​(55​−15 −15​5​)

θ^=501​(55​−15 −15​5​)(30.1 104.3​)=501​(55(30.1)−15(104.3) −15(30.1)+5(104.3)​)

=501​(1655.5−1564.5 −451.5+521.5​)=501​(91 70​)=(1.82 1.40​)

So: y^​=1.40,x+1.82.

Statistical Interpretation: The Linear Model with Noise

yi​=θ⊤xi​+εi​,εi​∼iidN(0,σ2)

Under this assumption, the maximum likelihood estimator (MLE) for θ coincides exactly with the least squares estimator. Proof:

LMLE​(θ)=∏i=1m​2πσ2​1​exp!(−2σ2(yi​−θ⊤xi​)2​)

Taking log: logLMLE​=−2m​log(2πσ2)−2σ21​∑i=1m​(yi​−θ⊤xi​)2

Maximising over θ is equivalent to minimising ∑i​(yi​−θ⊤xi​)2. Least squares = MLE under Gaussian noise. Not an accident. A theorem.

Gauss-Markov Theorem

Under the assumptions:

  1. E[ε]=0
  2. Cov(ε)=σ2I (homoscedastic, uncorrelated errors)
  3. X is deterministic and full column rank

The OLS estimator θ^=(X⊤X)−1X⊤y is the Best Linear Unbiased Estimator (BLUE) — it has the smallest variance among all linear unbiased estimators.

Polynomial Regression: Still Linear!

The model y=θ0​+θ1​x+θ2​x2+⋯+θd​xd is nonlinear in x but linear in the parameters θ. Define the feature map:

ϕ(x)=(1,x,x2,…,xd)⊤

Then y=θ⊤ϕ(x), and the same Normal Equations apply with ϕ(xi​) replacing xi​. The design matrix becomes:

X=(1​x1​​x12​​⋯​x1d​ ⋮​​​​⋮ 1​xm​​xm2​​⋯​xmd​​)

This is the Vandermonde matrix. The model is in the linear model class because L is convex quadratic in θ. The feature map ϕ does the heavy lifting.

This is the key insight that generalises to machine learning: by choosing rich enough features ϕ(x), a linear model in feature space can represent highly nonlinear functions of the original input x.

Regularisation: Constraining the Parameter Space

Ridge Regression (L2 Penalty)

\hat{\boldsymbol{\theta}}_{\text{ridge}} = \arg\min_{\boldsymbol{\theta}} \left{|X\boldsymbol{\theta} - \mathbf{y}|^2 + \lambda|\boldsymbol{\theta}|^2\right}

Closed form: Differentiate and set to zero: 2X⊤(Xθ−y)+2λθ=0

θ^ridge​=(X⊤X+λI)−1X⊤y​

The λI term makes the matrix invertible even when X⊤X is singular (rank-deficient). This is Tikhonov regularisation. Probabilistically, this is the MAP estimator under a Gaussian prior θ∼N(0,λσ2​I).

LASSO (L1 Penalty)

\hat{\boldsymbol{\theta}}_{\text{LASSO}} = \arg\min_{\boldsymbol{\theta}} \left{|X\boldsymbol{\theta} - \mathbf{y}|^2 + \lambda|\boldsymbol{\theta}|_1\right}

No closed form, but can be solved via coordinate descent or convex optimisation. The L1 penalty induces sparsity: many components of θ^ are driven to exactly zero. LASSO performs automatic feature selection.

Linear Models for Classification

Logistic Regression

Not a regression — a classifier. The linear model w⊤x+b outputs an unbounded real number. Pass it through the sigmoid:

p(y=1∣x)=σ(w⊤x+b)=1+e−(w⊤x+b)1​

The decision boundary x:w⊤x+b=0 is a hyperplane. Points on one side get class 1, the other side class 0.

Loss function (cross-entropy / negative log-likelihood): L(w,b)=−∑i=1m​[yi​logp^​i​+(1−yi​)log(1−p^​i​)]

This is convex but has no closed form. Solved by gradient descent.

Support Vector Machines (Hard Margin)

Find the hyperplane w⊤x+b=0 that maximises the margin ∣w∣2​ between the two classes:

minw,b​21​∣w∣2s.t.yi​(w⊤xi​+b)≥1∀,i

A constrained quadratic programme. The solution depends only on the support vectors — the training points closest to the hyperplane.

Connection to AI and Deep Learning

Every Layer of a Neural Network Is a Linear Model

A feedforward network layer is: z(ℓ)=W(ℓ)a(ℓ−1)+b(ℓ)

This is a linear map Rnℓ−1​→Rnℓ​ followed by a nonlinear activation σ. Without σ, stacking linear layers gives nothing new:

W(2)(W(1)x+b(1))+b(2)=W~W(2)W(1)​​x+b~W(2)b(1)+b(2)​​

A composition of linear maps is still linear. Depth without nonlinearity is useless. The nonlinear activations (ReLU, sigmoid, tanh) are what make deep networks powerful. But the linear maps carry the representation; the nonlinearities merely fold and cut the space.

The Kernel Trick: Linear in Feature Space = Nonlinear in Input Space

For a feature map ϕ:Rn→H (possibly infinite-dimensional), define the kernel:

k(x,x′)=⟨ϕ(x),,ϕ(x′)⟩H​

The kernel RBF k(x,x′)=exp(−∣x−x′∣2/2σ2) corresponds to an infinite-dimensional feature map — yet we never compute ϕ(x) explicitly. The SVM dual and kernel regression are linear in ϕ-space but highly nonlinear in x-space.

Deep learning implicitly learns a feature map ϕ (all layers except the last) and then fits a linear classifier on top. The last layer of almost every deep network — a softmax over Wh+b — is logistic regression on learned features h.

Gradient Descent on Linear Models

For a linear model with squared loss: L(θ)=m1​∣Xθ−y∣2

Gradient: ∇θ​L=m2​X⊤(Xθ−y)

Gradient descent update: θt+1​=θt​−η⋅m2​X⊤(Xθt​−y)

This is a linear recurrence in θt​. Convergence is guaranteed if η<λmax​(X⊤X/m)1​ where λmax​ is the largest eigenvalue of X⊤X/m. The condition number κ=λmax​/λmin​ governs how fast (ill-conditioned = slow). This analysis is exact for linear models and motivates preconditioning and adaptive learning rates (Adam, RMSProp) in deep learning.

Linear Attention and Transformers

The attention mechanism in a Transformer can be written: Attention(Q,K,V)=softmax!(dk​​QK⊤​)V

Linear Attention (Katharopoulos et al., 2020) approximates the softmax by a kernel ϕ(Q)ϕ(K)⊤ with a positive feature map ϕ. This makes attention linear in sequence length rather than quadratic — a direct application of the kernel trick to replace a nonlinear similarity with a linear inner product in feature space.

Assumptions, Violations, and Diagnostics

The linear model y=Xθ+ε carries assumptions that must be interrogated:

AssumptionViolationConsequenceFix
LinearityTrue f is nonlinearSystematic residual patternFeature engineering, polynomial terms, neural networks
E[εi​]=0Omitted variable biasθ^ biased and inconsistentInclude missing variables
HomoscedasticityVariance σ2 varies with xOLS inefficient; SEs wrongWLS, robust standard errors
No multicollinearityColumns of X nearly dependent(X⊤X)−1 near-singular; large variance in θ^Ridge, PCA, drop variables
IndependenceAutocorrelated errors (time series)OLS inefficient; SEs wrongGLS, time-series models

Residual diagnostics:

  • Plot ei​ vs. y^​i​ → should show no pattern
  • Q-Q plot of ei​ → should lie on diagonal if Gaussian
  • ∣ei​∣ vs. y^​i​ → should be flat (homoscedasticity)

Bias-Variance in Linear Models

For the linear model f^​(x)=x⊤θ^:

Bias[f^​(x0​)]2=(x0⊤​θ∗−E[x0⊤​θ^])2

Under correct model specification (true f is linear), OLS is unbiased by Gauss-Markov: E[θ^]=θ∗, so bias = 0.

Variance: Var[f^​(x0​)]=σ2x0⊤​(X⊤X)−1x0​

Large when x0​ is far from the training data, when σ2 is large, or when X⊤X is ill-conditioned.

Ridge regression deliberately introduces bias (θ^λ​=θ∗ in general) in exchange for reduced variance: Var[f^​λ​(x0​)]=σ2x0⊤​(X⊤X+λI)−2X⊤X,x0​<VarOLS​

For some λ>0, the reduction in variance dominates the increase in bias, reducing total MSE. This is not ad hoc — it follows from the James-Stein phenomenon (shrinkage estimators dominate OLS in Rn for n≥3).

Summary

θ^=(X⊤X)−1X⊤y​

This single equation — four matrices, one formula — is the foundation of:

  • Classical statistics (OLS, ANOVA, GLMs)
  • Signal processing (Wiener filter, matched filter)
  • Machine learning (linear regression, logistic regression, SVMs, last-layer classifiers)
  • Numerical linear algebra (least squares solvers, pseudoinverse)

The linear model is not a simplification to graduate beyond. It is the skeleton on which everything else is built. Understanding it deeply — its geometry, its statistics, its failure modes — is non-negotiable.
