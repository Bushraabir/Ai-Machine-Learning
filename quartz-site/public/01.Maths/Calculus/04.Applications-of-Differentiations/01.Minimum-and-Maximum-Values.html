01.Minimum and Maximum Values

01.Minimum and Maximum Values

Apr 17, 202612 min read

“Nature is thrifty in all her actions.” — Pierre Louis Maupertuis

Personal note: Every optimization algorithm in machine learning — gradient descent, Adam, RMSProp — is, at its core, a machine trying to do what we’re about to describe rigorously. Understanding this chapter is understanding the soul of modern AI.

§1. The Absolute Extrema — Definitions

Let f be a function defined on a domain D⊆R.

Definition 1.1 (Absolute Maximum). A value f(c) is the absolute maximum of f on D if f(c)≥f(x)for all x∈D.

Definition 1.2 (Absolute Minimum). A value f(c) is the absolute minimum of f on D if f(c)≤f(x)for all x∈D.

The absolute maximum and minimum are collectively called extreme values or absolute extrema.

Remark. Existence is not guaranteed in general. Consider:

  • f(x)=x on (0,1): no maximum, no minimum — the interval is open.
  • f(x)=x1​ on (0,∞): no minimum.
  • f(x)=sin(x) on R: maximum value 1 achieved at infinitely many points, but the set of maxima is well-defined.

This motivates the fundamental existence theorem.

§2. The Extreme Value Theorem

Theorem 2.1 (Extreme Value Theorem — EVT). If f is continuous on a closed, bounded interval [a,b], then f attains both an absolute maximum and an absolute minimum on [a,b].

That is, there exist c,d∈[a,b] such that f(c)≤f(x)≤f(d)for all x∈[a,b].

Why both conditions are necessary:

Condition droppedCounterexampleWhat fails
Continuityf(x)={x​x∈(0,1] 2​x=0​ on [0,1]Min not attained
Closed intervalf(x)=x on (0,1)Neither attained
Bounded intervalf(x)=x on [0,∞)No max

Proof sketch. The proof uses two deep facts from real analysis:

  1. A continuous image of a compact set is compact (Heine–Cantor).
  2. A compact subset of R is closed and bounded, hence contains its supremum and infimum.

Since [a,b] is compact and f is continuous, f([a,b]) is compact, so supf([a,b]) and inff([a,b]) are attained. ■

§3. Local Extrema

Global search is hard. We begin locally.

Definition 3.1 (Local Maximum). f has a local maximum at c if there exists δ>0 such that f(c)≥f(x)for all x∈(c−δ,c+δ)∩D.

Definition 3.2 (Local Minimum). f has a local minimum at c if there exists δ>0 such that f(c)≤f(x)for all x∈(c−δ,c+δ)∩D.

Intuition. A local max is the highest point in its neighborhood — it doesn’t need to beat everyone, just its neighbors. This is critical in optimization: most algorithms find local extrema, and global optimization is generally NP-hard.

§4. Fermat’s Theorem — The Critical Point Condition

Theorem 4.1 (Fermat’s Theorem). If f has a local extremum at c and f′(c) exists, then f′(c)=0.

Proof. Suppose f has a local maximum at c. Then for all x sufficiently close to c: f(x)−f(c)≤0.

Case 1: x>c. Then x−cf(x)−f(c)​≤0, so taking x→c+: f′(c)=limx→c+​x−cf(x)−f(c)​≤0.

Case 2: x<c. Then x−cf(x)−f(c)​≥0, so taking x→c−: f′(c)=limx→c−​x−cf(x)−f(c)​≥0.

Since f′(c) exists and satisfies both f′(c)≤0 and f′(c)≥0, we conclude f′(c)=0. The local minimum case is symmetric. ■

Warning (Converse is FALSE). f′(c)=0 does not imply c is an extremum.

Example: f(x)=x3. Then f′(0)=0, but x=0 is an inflection point, not an extremum. The function changes sign of its derivative here — it’s increasing on both sides of 0.

§5. Critical Numbers

Definition 5.1. A number c in the domain of f is a critical number (or critical point) if either:

  1. f′(c)=0, or
  2. f′(c) does not exist.

Why include non-differentiable points? Fermat’s theorem requires f′(c) to exist. But extrema can occur where the derivative fails to exist.

Example: f(x)=∣x∣ on [−1,1]. The minimum is at x=0, but f′(0) doesn’t exist (corner point). So 0 is a critical number.

Example: f(x)=x1/3. Then f′(x)=31​x−2/3, which doesn’t exist at x=0. The point x=0 is a critical number (it’s an inflection point here, but could be an extremum in other examples).

Corollary 5.1. If f has a local extremum at c, then c is a critical number of f.

This is the contrapositive of Fermat’s theorem combined with the observation about non-differentiable points.

§6. The Closed Interval Method

The EVT guarantees extrema exist on [a,b]. The Closed Interval Method finds them:

Algorithm 6.1 (Closed Interval Method). To find the absolute extrema of a continuous f on [a,b]:

  1. Find all critical numbers of f in (a,b).
  2. Evaluate f at each critical number.
  3. Evaluate f at the endpoints: f(a) and f(b).
  4. The largest value is the absolute maximum; the smallest is the absolute minimum.

Why does this work? By EVT, the absolute extrema exist. By Corollary 5.1, any interior extremum must be a critical point. The endpoints are candidates by default (boundary of the domain). Exhausting all candidates and comparing gives the answer.

§9. Connection to AI, Machine Learning, and Deep Learning

This is not a digression. This entire chapter IS the theoretical foundation of machine learning.

9.1 Loss Minimization as the Core Problem

In supervised learning, we train a model with parameters θ∈Rn by minimizing a loss function: L(θ)=m1​∑i=1m​ℓ(fθ​(x(i)),y(i))

where ℓ is a pointwise loss (e.g., squared error, cross-entropy). Finding optimal θ∗ is exactly an absolute minimum problem.

The critical point condition becomes: ∇θ​L(θ∗)=0(gradient is the zero vector)

This is Fermat’s theorem in Rn.

9.2 Gradient Descent — Iterative Fermat

Since L is typically non-convex and high-dimensional (GPT-4 has ~1012 parameters), we can’t solve ∇L=0 analytically. Instead:

θt+1​=θt​−η∇θ​L(θt​)

where η>0 is the learning rate. This is a discrete approximation to following the steepest descent path toward a local minimum. The fixed points of this update (θt+1​=θt​) are exactly the critical points.

Variants:

  • SGD (Stochastic Gradient Descent): Uses a minibatch to approximate ∇L
  • Adam: Adapts the learning rate per parameter using first and second moment estimates
  • RMSProp: Divides by running average of squared gradients

All seek the same thing: a point where ∇L≈0.

9.3 The Local vs Global Minimum Problem

A deep neural network’s loss landscape is non-convex, so gradient descent finds local minima, not necessarily global ones. This is the direct multi-dimensional generalization of our observation that f′(c)=0 does not guarantee a global minimum.

Surprising empirical finding (2014–present): In practice, local minima of large neural networks tend to have similar loss values to the global minimum. The more dangerous critical points are saddle points — where ∇L=0 but the Hessian H is indefinite (some eigenvalues positive, some negative). These are the analog of f(x)=x3 at x=0.

Theorem (informal, Dauphin et al., 2014). In high dimensions, most critical points with high loss are saddle points, not local minima. True local minima with high loss are exponentially rare.

9.4 Second-Order Methods and the Hessian

The second derivative test in 1D:

  • f′′(c)>0 at a critical point ⇒ local min
  • f′′(c)<0⇒ local max
  • f′′(c)=0⇒ inconclusive

In Rn, the Hessian matrix H=∇2L plays this role:

  • H positive definite ⇒ local min
  • H negative definite ⇒ local max
  • H indefinite ⇒ saddle point

Newton’s method for optimization uses the full Hessian: θt+1​=θt​−H−1∇L(θt​)

This converges quadratically near a minimum but costs O(n3) to invert H — infeasible for large networks. Quasi-Newton methods (L-BFGS) approximate H−1 cheaply.

9.5 Convex Optimization — When Local = Global

If L is convex (e.g., linear regression with MSE loss, logistic regression), then: every local minimum is a global minimum

This is the analog of: a function with f′′>0 everywhere on an interval has at most one local (= global) minimum. Convexity is defined by: L(λθ1​+(1−λ)θ2​)≤λL(θ1​)+(1−λ)L(θ2​),λ∈[0,1]

Support Vector Machines and linear models exploit convexity to guarantee finding the global minimum. This is why they have convergence guarantees that deep networks lack.

9.6 Regularization as a Constraint

L2 regularization (weight decay) solves: minθ​L(θ)+2λ​∣θ∣2

This is equivalent to finding the minimum of the unconstrained loss subject to ∣θ∣≤R for some R — a constrained optimization problem. The method of Lagrange multipliers (multivariable calculus) formalizes this connection, and the critical point condition becomes the KKT conditions in convex optimization.

§10. The Second Derivative Test (Preview)

Full treatment in the next section, but the setup:

If f′(c)=0, how do we classify c?

Theorem 10.1 (Second Derivative Test). Suppose f′′ is continuous near c and f′(c)=0:

  • If f′′(c)>0: c is a local minimum (f is concave up)
  • If f′′(c)<0: c is a local maximum (f is concave down)
  • If f′′(c)=0: inconclusive (need higher derivatives or sign analysis)

Intuition. Near a local min, the graph looks like a upward parabola — f′′>0 means concave up, i.e., the function curves away from the tangent line upward. This is exactly why gradient descent converges: near a true minimum, the loss surface curves upward in all directions.

§12. Common Mistakes and Traps

Trap 1. Assuming f′(c)=0 implies c is an extremum. Counterexample: f(x)=x3 at x=0. Always check sign change of f′.

Trap 2. Forgetting to check endpoints on closed intervals. The absolute max/min can occur at a or b.

Trap 3. Applying EVT to open intervals or discontinuous functions. The theorem’s conclusion is false without both hypotheses.

Trap 4. In ML: confusing “gradient is zero” with “global minimum found.” In non-convex problems, ∇L=0 only guarantees a critical point.

Trap 5. Using the second derivative test when f′′(c)=0. The test is inconclusive. Use first derivative sign analysis instead.
