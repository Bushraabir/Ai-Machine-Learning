02.Fermat's Theorem

02.Fermat's Theorem

Apr 17, 202613 min read

“To find the maxima and minima of a quantity, one takes the ordinary derivative and sets it equal to zero.” — Pierre de Fermat, c. 1638 (paraphrase)

Personal note: Fermat wrote this before calculus existed — before Newton, before Leibniz. He was computing what we now call derivatives using an ad-hoc “method of adequality.” The theorem bearing his name is the rigorous formalization of his geometric intuition: at a peak or valley, the tangent line must be horizontal.

§1. Motivation — What Does Extremum Mean Geometrically?

Stand on a smooth hill. At the very top, the ground beneath your feet is flat — the slope is zero in every direction. If you’re in a valley, same thing. The tangent plane is horizontal.

In one dimension: if f has a local max at c, then just to the left of c the function is increasing (f′>0), and just to the right it is decreasing (f′<0). At the transition point itself, f′(c)=0.

        f(c) ← local max
       /     \
      /        \       f' changes + → −
─────              ─────
    f' > 0   f'=0   f' < 0

Fermat’s Theorem makes this intuition a theorem — rigorous, with clear hypotheses.

§2. Statement of the Theorem

Theorem (Fermat’s Theorem). Let f be defined on an open interval containing c. Suppose:

  1. f has a local extremum at c (either a local max or local min), and
  2. f is differentiable at c.

Then f′(c)=0.

Logically: (f has local extremum at c);∧;(f′(c) exists);⟹;f′(c)=0

§3. Complete Proof

We prove the local maximum case. The local minimum case is symmetric (or apply the result to −f).

Setup. Suppose f has a local maximum at c. By definition, there exists δ>0 such that: f(x) \leq f(c) \quad \text{for all } x \in (c - \delta,; c + \delta). \tag{$*$}

We are given that f′(c) exists, so the limit f′(c)=limh→0​hf(c+h)−f(c)​ exists (as a finite real number). Since the two-sided limit exists, the one-sided limits both exist and equal f′(c).

Case 1: Right-hand limit (h→0+, i.e., h>0 small).

For 0<h<δ, we have c+h∈(c−δ,c+δ), so by (∗): f(c+h)−f(c)≤0.

Since h>0: hf(c+h)−f(c)​≤0.

Taking the limit as h→0+ (the inequality is preserved under limits): f'(c) = \lim_{h \to 0^+} \frac{f(c+h)-f(c)}{h} \leq 0. \tag{1}

Case 2: Left-hand limit (h→0−, i.e., h<0 small).

For −δ<h<0, we have c+h∈(c−δ,c+δ), so by (∗): f(c+h)−f(c)≤0.

But now h<0, so dividing reverses the inequality: hf(c+h)−f(c)​≥0.

Taking the limit as h→0−: f'(c) = \lim_{h \to 0^-} \frac{f(c+h)-f(c)}{h} \geq 0. \tag{2}

Conclusion. From (1) and (2): f′(c)≤0andf′(c)≥0⟹f′(c)=0.​

For the local minimum case: the inequality (∗) reverses to f(x)≥f(c), which flips the signs in Cases 1 and 2, and we again conclude f′(c)=0. ■

§4. The Converse is FALSE — This is Critical

f′(c)=0 does NOT imply c is an extremum.

This is one of the most common errors. Fermat’s theorem is a one-way implication only.

Counterexample: f(x)=x3 at c=0

f′(x)=3x2⟹f′(0)=0.

Yet f is strictly increasing on all of R: for x>0, f(x)>0=f(0), and for x<0, f(x)<0=f(0). So x=0 is neither a local max nor a local min — it is an inflection point.

  f(x) = x³

       │      /
       │     /
       │    /
  ─────┼───────── x
       │  /
       │ /
       │/
         ↑
    f'(0) = 0, but NOT an extremum
    (function strictly increasing through 0)

Summary of Logical Structure

StatementTrue?
Local extremum at c + differentiable ⇒ f′(c)=0✓ Fermat’s Theorem
f′(c)=0 ⇒ local extremum at c✗ FALSE (x3 counterexample)
f′(c)=0 ⇒ c is a critical number✓ (by definition)
Local extremum at c ⇒ c is a critical number✓ (Fermat + non-diff. case)

The correct chain is: local extremum⟹critical number\centernot⟸critical number

§5. Why the Hypothesis “Differentiable at c” is Essential

Fermat’s theorem requires f′(c) to exist. Drop this and the conclusion fails.

Example: f(x)=∣x∣ at c=0

f has an absolute (and local) minimum at c=0. But: f′(0)=limh→0​h∣h∣−0​=limh→0​h∣h∣​

The right limit is +1, the left limit is −1 — they disagree. So f′(0) does not exist.

The minimum occurs at a corner, not a smooth point. There is no horizontal tangent — there is no tangent line at all.

  f(x) = |x|

   \   /
    \ /
     *  ← global min, f'(0) DNE
     |
─────┼───── x

This is why the definition of critical number includes both f′(c)=0 and f′(c) DNE — to capture all possible extrema locations.

The Full Picture: Where Can Extrema Occur?

local extremum at c⟹c is a critical number

c is a critical number⟺f′(c)=0; or ;f′(c) does not exist

Fermat’s theorem handles the differentiable case. The non-differentiable case is separate (but the conclusion — that c is a critical number — holds trivially).

§6. Why the Hypothesis “Open Interval” is Essential

The theorem requires f to be defined on an open interval containing c (not just at c, and not on a closed interval where c is an endpoint).

Why? The proof uses the limit from both sides of c. If c=a is the left endpoint of [a,b], only the right-hand limit is available:

f′(a+)≤0

But we can’t conclude f′(a)≥0 from the left (there is no left side). So we can’t squeeze to f′(a)=0.

Example. f(x)=x on [0,1]. The absolute minimum is at x=0 and the absolute maximum at x=1. But f′(x)=1=0 everywhere — including at the endpoints. Fermat’s theorem simply doesn’t apply here, because 0 and 1 are not interior to the domain.

Consequence. This is precisely why the Closed Interval Method must check endpoints separately — Fermat doesn’t cover them.

§8. Examples

Example 8.1 — Polynomial, All Cases

f(x)=x4−4x3

f′(x)=4x3−12x2=4x2(x−3)

Critical numbers: f′(x)=0⇒x=0 or x=3.

Classify x=0:

Sign of f′(x)=4x2(x−3) near x=0:

  • For x slightly <0: 4x2>0, (x−3)<0 → f′(x)<0
  • For x slightly >0: 4x2>0, (x−3)<0 → f′(x)<0

Sign does not change → x=0 is not an extremum (inflection point). f′(0)=0, Fermat’s conclusion holds, but the converse is false.

Classify x=3:

  • For x<3: 4x2>0, (x−3)<0 → f′(x)<0
  • For x>3: 4x2>0, (x−3)>0 → f′(x)>0

Sign changes −→+ → x=3 is a local minimum.

f'(x) sign chart:
      − − − 0 − − − 0 + + +
      ──────┼───────┼──────
            0       3
         inflec.  loc min

Example 8.2 — Non-differentiable Extremum

f(x)={−x+1​x<0 x2+1​x≥0​

At c=0: limh→0−​hf(h)−f(0)​=limh→0−​h(−h+1)−1​=limh→0−​h−h​=−1 limh→0+​hf(h)−f(0)​=limh→0+​hh2+1−1​=limh→0+​h=0

One-sided limits disagree: f′(0) DNE. Fermat’s theorem does not apply. Yet f(0)=1 is a local minimum (approaching from left, f→1+; from right, f→1+ through x2+1≥1).

Example 8.3 — Verifying Fermat Directly

f(x)=sinx,c=2π​

f′(x)=cosx, so f′(π/2)=cos(π/2)=0. ✓

f(π/2)=1 is a local (and global) maximum on any interval containing π/2. Fermat’s theorem confirms f′(π/2)=0, consistent.

§9. Connection to AI, Machine Learning, Deep Learning

Fermat’s Theorem is the theoretical certificate that gradient descent is doing the right thing — and also explains why it can get stuck.

9.1 The Training Objective

In machine learning, we minimize a loss: L(θ)=m1​∑i=1m​ℓ(fθ​(x(i)),y(i)),θ∈Rn

At any interior local minimizer \theta^_ where L is differentiable, Fermat’s theorem (in Rn) gives: \nabla_\theta \mathcal{L}(\theta^_) = \mathbf{0}

This is the necessary condition gradient descent tries to satisfy. Every weight update moves toward making this gradient zero.

9.2 The Converse Failure = The Saddle Point Problem

The converse of Fermat’s theorem fails in 1D with x3. In high-dimensional ML it fails catastrophically at saddle points.

A saddle point \theta^_ satisfies \nabla \mathcal{L}(\theta^_) = \mathbf{0} but is neither a max nor a min — it’s a max in some directions and a min in others. In Rn for large n, saddle points are exponentially more common than local minima.

  Saddle point in 2D:
  
    θ₂
    │    ╲   ╱   ← increasing in θ₂ direction (local max)
    │     ╲ ╱
    │      ×  ← ∇L = 0 here, but saddle
    │     ╱ ╲
    │    ╱   ╲   ← decreasing in θ₁ direction (local min)
    └──────────── θ₁

Consequence for training: Gradient descent near a saddle point has gradient ≈0, so updates become tiny — training stalls. This is a major practical problem in deep learning.

Solutions used in practice:

  • Momentum (SGD with momentum): carries velocity through saddle regions
  • Adam: uses second moment estimates to escape flat regions
  • Noise in SGD (from random minibatches): perturbs away from saddle points

All of these are engineering responses to the failure of the converse of Fermat’s theorem.

9.3 ReLU and Non-differentiable Points in Neural Networks

The ReLU activation σ(x)=max(0,x) is not differentiable at x=0: σ′(x)={1​x>0 0​x<0 undefined​x=0​

This is the neural network version of ∣x∣ — a corner. In practice, we use the subgradient (set σ′(0)=0 or 0.5 by convention). Fermat’s theorem doesn’t directly apply at these points, but the critical number concept extends to the non-smooth setting via subdifferential calculus.

The entire field of non-smooth optimization — used when training networks with ℓ1​ regularization, ReLU activations, max-pooling — is a generalization of the observation that extrema can occur where f′ fails to exist.

9.4 Fermat’s Theorem in Convex Optimization

For convex loss functions (e.g., logistic regression, ridge regression), Fermat’s theorem becomes if and only if:

\theta^_ is a global minimum ⟺ \nabla \mathcal{L}(\theta^_) = \mathbf{0}

This is because for convex differentiable functions, every critical point is a global minimum (there are no saddle points, no local-but-not-global minima). This is the reason logistic regression and linear SVM have convergence guarantees — gradient descent provably reaches the global minimum.

For non-convex deep networks, only the ⇒ direction holds (Fermat), not ⇐.

§10. The Contrapositive — A Useful Form

Fermat’s theorem by contrapositive:

f′(c)=0⟹c is NOT a local extremum (for interior points).

This is algorithmically useful. If you’re doing gradient descent and ∣∇L(θ)∣>ε, you can certify: θ is not (approximately) a local minimum. Training should continue.

Conversely, ∣∇L(θ)∣≈0 is a necessary condition for convergence — but not sufficient (saddle point!). This is why modern optimizers also monitor the loss value and validation metrics, not just the gradient norm.

§11. Connections Within Calculus

Fermat's Theorem
        │
        ├──→ Definition of Critical Numbers
        │           │
        │           ├──→ Closed Interval Method (absolute extrema)
        │           └──→ First Derivative Test (local extrema)
        │
        ├──→ Second Derivative Test
        │     (f'(c)=0 + f''(c)>0 → local min; classifies critical pts)
        │
        ├──→ Rolle's Theorem
        │     (f(a)=f(b) → ∃c: f'(c)=0; uses Fermat in proof)
        │
        └──→ Mean Value Theorem
              (follows from Rolle's; one of the deepest theorems in calculus)

Rolle’s Theorem proof sketch using Fermat. If f is continuous on [a,b], differentiable on (a,b), and f(a)=f(b): by EVT, f attains its max and min on [a,b]. If both occur at endpoints, f is constant and f′≡0 (any c works). Otherwise, an extremum occurs at some interior c∈(a,b), and by Fermat, f′(c)=0. ■

Fermat’s theorem is thus the seed from which Rolle’s and the MVT grow.

§12. Key Points — Professor’s Summary

  1. The theorem: differentiable local extremum ⇒ zero derivative. The tangent is horizontal.

  2. The proof idea: squeeze the derivative between ≤0 (from the right) and ≥0 (from the left). Both sides of the derivative limit must agree, forcing f′(c)=0.

  3. The converse is false. f′(c)=0 only gives a candidate. Test the sign of f′ around c, or use the second derivative test.

  4. Two hypotheses matter: differentiability at c (corners can be extrema without f′=0), and c being interior (endpoints escape Fermat).

  5. In ML: this theorem is why ∇L=0 is the training convergence condition — and why convergence to zero gradient is necessary but not sufficient for a good model.
