“The midpoint rule is not merely a better rectangle. It is the first hint that the geometry of approximation has a deeper structure — one that will eventually lead to Gaussian quadrature, spectral methods, and the numerical backbone of scientific computing.”

0. Motivation: Why Not Just Use Left or Right Endpoints?

From The Definite Integral, we know:

∫ab​f(x),dx=limn→∞​∑i=1n​f(xi∗​),Δx

The choice of sample point xi∗​ is free. Left endpoints (Ln​) and right endpoints (Rn​) are the obvious first choices — but they are systematically biased.

For an increasing function:

  • Ln​ always underestimates (samples the low end of each strip)
  • Rn​ always overestimates (samples the high end)

The errors do not cancel within each strip; they only cancel when averaged: Tn​=(Ln​+Rn​)/2 — the Trapezoid Rule.

But there is a smarter single-point choice: the midpoint xˉi​=2xi−1​+xi​​.

The Midpoint Rule is not just “splitting the difference.” Its superiority over Ln​ and Rn​ has a precise algebraic reason — and it is second-order accurate, not first-order. Understanding why is the point of this note.

1. The Rule: Definition

Definition (Midpoint Rule — Stewart §7.7). Let [a,b] be partitioned into n equal subintervals of width Δx=(b−a)/n. The midpoint of the i-th subinterval [xi−1​,xi​] is:

xˉi​=2xi−1​+xi​​=a+(i−21​)Δx

The Midpoint Rule approximation is:

Mn​=i=1∑n​f(xˉi​),Δx=Δx[f(xˉ1​)+f(xˉ2​)+⋯+f(xˉn​)]​

Geometrically: erect a rectangle of height f(xˉi​) over each subinterval. Sum the areas.

2. Geometric Interpretation

f(x)
  |
  |        ___________
  |       |     *     |        ← height = f(x̄ᵢ) at midpoint
  |       |   *   *   |
  |       |  *     *  |
  |       | *       * |
  |_______|___________|______> x
         x_{i-1}  x_i
              ↑
             x̄ᵢ (midpoint)

The rectangle’s height is set at the exact center of the interval. For a curve that is concave up (like x2), the midpoint rectangle slices through the curve — part of the rectangle pokes above the curve, part sits below. These local errors partially cancel.

Contrast with Ln​:

Left endpoint:             Midpoint:
  |                          |
  |**                        |    **
  |  **                      |  **  **
  |    **                    |**      **
  |____**____                |__________
  x₀        x₁              x̄ᵢ
  [systematically low]    [errors partially cancel]

5. Error Analysis: Why Midpoint is Better Than Trapezoid

This is the heart of the note. The claim:

∣EM​∣≤24n2(b−a)3​K,∣ET​∣≤12n2(b−a)3​K,K=maxa≤x≤b​∣f′′(x)∣

So ∣EM​∣≤21​∣ET​∣. The Midpoint Rule is twice as accurate as the Trapezoid Rule, at the same cost (both use n function evaluations).

5.1 Where the Error Formula Comes From

Proof (one subinterval, then scale). On a single subinterval [xi−1​,xi​] with midpoint xˉ=(xi−1​+xi​)/2 and half-width h=Δx/2, expand f in a Taylor series about xˉ:

f(x)=f(xˉ)+f′(xˉ)(x−xˉ)+2f′′(xˉ)​(x−xˉ)2+6f′′′(xˉ)​(x−xˉ)3+O((x−xˉ)4)

Integrate over [xi−1​,xi​]=[xˉ−h,xˉ+h]:

∫xˉ−hxˉ+h​f(x),dx=2h,f(xˉ)+f′(xˉ)=,0∫−hh​u,du​​+2f′′(xˉ)​=,2h3/3∫−hh​u2,du​​+6f′′′(xˉ)​=,0∫−hh​u3,du​​+⋯

(The odd-power integrals vanish by symmetry of [xˉ−h,xˉ+h].)

=2h,f(xˉ)+3f′′(xˉ)​h3+O(h5)

The Midpoint Rule approximation for this strip is f(xˉ)⋅2h. So the local error is:

ei​=∫xˉ−hxˉ+h​f,dx−f(xˉ)⋅2h=3f′′(xˉ)​h3+O(h5)

Since h=Δx/2=(b−a)/(2n):

∣ei​∣≤3K​⋅8n3(b−a)3​

Summing over n subintervals:

∣EM​∣=∣∑i=1n​ei​∣≤n⋅3K​⋅8n3(b−a)3​=24n2K(b−a)3​

■

5.2 Why the First-Order Error Vanishes: The Symmetry Argument

The key insight: expanding about the midpoint makes ∫−hh​u,du=0 by odd symmetry. The first-order error term cancels exactly — not approximately.

For left/right endpoints, there is no such symmetry. Expanding about xi−1​ (left endpoint):

∫xi−1​xi​​f,dx=f(xi−1​)Δx+2f′(xi−1​)​(Δx)2+O((Δx)3)

Local error ∼C(Δx)2, total error ∼C(b−a)Δx=O(1/n). First order.

For midpoint: local error ∼C(Δx)3, total error ∼Cn⋅(Δx)3=O(1/n2). Second order.

The midpoint is special precisely because it is the center of symmetry of the interval. Symmetry kills the linear error term. This is the same reason Gaussian quadrature is so powerful — it chooses nodes to kill even higher-order error terms.

7. Choosing n: Solving for Required Accuracy

Problem. How large must n be to guarantee ∣EM​∣≤10−4 for ∫12​x1​,dx?

Use the error bound ∣EM​∣≤24n2K(b−a)3​ with K=2, b−a=1:

24n22​≤10−4⟹n2≥24×10−42​=0.00242​≈833.3

n≥833.3​≈28.9⟹n=29​

For the Trapezoid Rule with the same tolerance: n≥1666.7​≈41. The Midpoint Rule reaches the same accuracy with 29% fewer function evaluations.

8. Visualization: Error Cancellation in Action

Concave-up curve (f'' > 0), one subinterval [x_{i-1}, x_i]:

         true curve
            /‾‾‾\
           /     \
  ________/  (+)  \________
  |       \       /        |
  |    (–) \_____/ (–)     |   ← Midpoint rectangle
  |_________________________|
  x_{i-1}      x̄ᵢ       xᵢ

  (+) region: rectangle ABOVE curve (overestimates here)
  (–) region: rectangle BELOW curve (underestimates here)

  For concave-up f: the (–) regions at the tails are EXACTLY
  equal by symmetry → first-order errors cancel.
  Residual error is third-order in h.

For a concave-up function (f′′>0):

  • Midpoint Rule underestimates (the rectangle is below the chord)
  • Trapezoid Rule overestimates (the trapezoid is above the curve)

This means Mn​≤∫ab​f≤Tn​ when f is concave up — giving a guaranteed enclosure of the true value.

9. Connection to AI / Machine Learning / Deep Learning

9.1 Numerical Integration in Probabilistic Models

In Bayesian deep learning and probabilistic ML, we regularly need:

Ez∼p(z)​[f(z)]=∫f(z),p(z),dz

When p is Gaussian and f is a neural network output, this is intractable analytically. The Gauss-Hermite quadrature (a higher-order analog of the Midpoint Rule optimized for Gaussian measure) is used to approximate it. Understanding why the midpoint outperforms endpoints — symmetry cancels error — is the conceptual foundation of quadrature theory.

9.2 The Midpoint Method as a Time Integrator

In continuous-time RL and Neural ODEs, we integrate the ODE:

x˙=f(x,t),x(0)=x0​

The explicit midpoint method (a Runge-Kutta 2 scheme):

k1​=f(xn​,tn​) k2​=f!(xn​+2h​k1​,;tn​+2h​) xn+1​=xn​+h,k2​

This is exactly the Midpoint Rule applied to the integral x(tn+1​)=xn​+∫tn​tn+1​​f(x(t),t),dt. Evaluating f at the estimated midpoint of the time step — rather than the left endpoint (Euler’s method) — doubles the convergence order from O(h) to O(h2). Neural ODE solvers (like torchdiffeq) use exactly this principle, extended to higher-order Runge-Kutta schemes.

9.3 Mini-Batch Gradient Estimation as Midpoint Sampling

When we estimate ∇θ​R(θ)=∫∇θ​ℓ,dD using a mini-batch, the choice of which data points to include is analogous to the choice of quadrature node.

  • Random sampling (SGD) ≈ random Riemann sum (high variance)
  • Stratified sampling: divide the dataset into strata and sample one from each — this is conceptually the Midpoint Rule (sample the “center” of each stratum)
  • Quasi-random sequences (Halton, Sobol) place sample points more uniformly, achieving O(1/n2) or better convergence — exactly the gain from midpoint vs. left endpoint

The variance reduction in stratified sampling for gradient estimation is the direct ML analog of the accuracy gain in the Midpoint Rule.

9.4 Symmetry in Initialization

The reason the midpoint is optimal on [xi−1​,xi​] is the same reason symmetric weight initialization is preferred in neural networks. Kaiming and Xavier initializations are designed so that the forward and backward passes have symmetric variance — odd-order moments cancel, just as the ∫u,du=0 term vanished in our Taylor expansion. The underlying mathematical principle is identical: exploit symmetry to cancel leading-order error terms.
