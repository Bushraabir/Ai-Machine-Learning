“The same act of intellectual courage that lets us find distance from velocity will, three centuries later, let a neural network find a minimum of a loss landscape.”

0. Why This Problem Matters

Before limits, before derivatives, before any of the formal machinery — there was a question so elementary it seems almost embarrassing:

If an object moves with non-constant velocity, how far does it travel?

This is the distance problem. It sounds like a physics homework exercise. It is, in fact, the conceptual seed of integral calculus — and, as we will see, the philosophical ancestor of optimization in machine learning.

1. The Easy Case: Constant Velocity

If velocity is constant, say v=60 km/h for t=3 hours, then:

d=v⋅t=60×3=180 km

Geometrically, this is the area of a rectangle under the horizontal line v=60 on a velocity-time graph.

Area =60×3=180. Distance = Area under the v-t curve. File this away — it is everything.

2. The Hard Case: Variable Velocity

Now suppose v(t)=t2 m/s. What is the distance traveled from t=0 to t=3?

We cannot simply multiply, because v is changing at every instant.

The Key Idea: Approximate, then Refine

Partition the interval [0,3] into n subintervals of width Δt=3/n.

On each tiny subinterval [ti−1​,ti​], pretend the velocity is constant — equal to v(ti−1​)=ti−12​ (left endpoint). Then the distance on that piece is approximately:

Δdi​≈v(ti−1​)⋅Δt=ti−12​⋅Δt

The total approximate distance is a Riemann sum:

Dn​=∑i=1n​v(ti−1​)⋅Δt=∑i=1n​ti−12​⋅Δt

Worked Example: n=3

With Δt=1, sample points t=0,1,2:

D3​=0+1+4=5 m

Worked Example: n=6

With Δt=0.5, sample points 0,0.5,1,1.5,2,2.5:

D6​=(02+0.52+12+1.52+22+2.52)(0.5)=(0+0.25+1+2.25+4+6.25)(0.5)=13.75×0.5=6.875

4. The Rigorous Limit

Definition (Definite Integral — Stewart §5.2). Let f be defined on [a,b]. Partition [a,b] into n subintervals of equal width Δx=(b−a)/n. Choose sample points xi∗​ in [xi−1​,xi​]. Then:

∫ab​f(x),dx=limn→∞​∑i=1n​f(xi∗​),Δx

provided this limit exists and is the same for every choice of sample points.

For the distance problem specifically:

d=∫ab​v(t),dt​

This is not a definition of distance — it is a theorem, grounded in the fact that the Riemann sums converge.

Proof Sketch for v(t)=t2 on [0,b]

Use right endpoints: ti​=ib/n, Δt=b/n.

Dn​=∑i=1n​(nib​)2⋅nb​=n3b3​∑i=1n​i2=n3b3​⋅6n(n+1)(2n+1)​

=6b3​⋅n2(n+1)(2n+1)​=6b3​⋅(2+n3​+n21​)

limn→∞​Dn​=6b3​⋅2=3b3​

For b=3: d=27/3=9. ■

5. The Fundamental Theorem Closes the Loop

The distance problem motivates the integral, but computing it via limits of Riemann sums is painful. The Fundamental Theorem of Calculus (FTC) tells us we can instead find an antiderivative:

∫ab​v(t),dt=V(b)−V(a),where V′(t)=v(t)

For v(t)=t2: V(t)=t3/3, so ∫03​t2,dt=27/3−0=9.

The FTC is the miracle that makes calculus practical. The distance problem is why we went looking for it.

6. Connection to AI / Machine Learning / Deep Learning

This is not a detour. The conceptual architecture of the distance problem is load-bearing in modern ML.

6.1 Loss as an Integral — Expected Risk

In statistical learning theory, we don’t minimize loss on a single point — we minimize expected risk:

R(f)=∫X×Y​ℓ(f(x),y),dP(x,y)

This is an integral. In practice, P is unknown, so we approximate it with a finite sum over the training set:

R^(f)=n1​∑i=1n​ℓ(f(xi​),yi​)

This is a Riemann sum approximation to the integral R(f). The training loss is the empirical Riemann sum; the true risk is the integral. As n→∞, R^→R — exactly the story of the distance problem.

6.2 Gradient Descent as Continuous Limit

Gradient descent with step size η:

θk+1​=θk​−η∇θ​L(θk​)

In the limit η→0, this is the Euler method for the ODE:

dtdθ​=−∇θ​L(θ)

The parameter trajectory θ(t) satisfies:

θ(T)−θ(0)=−∫0T​∇θ​L(θ(t)),dt

Discrete gradient descent ≈ Riemann sum approximation to this integral. The distance problem lives here: total parameter displacement = integral of gradient velocity.

6.3 Backpropagation and the Chain Rule — Not a Coincidence

The chain rule of calculus is what makes differentiation composable. Backprop is the chain rule applied to computational graphs. The same derivative that tells us dtdv​= acceleration in the distance problem is what backprop uses to compute ∂w∂L​ through layers.

6.4 Neural ODEs (Deep Learning → Integral)

A ResNet layer is:

ht+1​=ht​+f(ht​,θt​)

In the continuum limit (infinitely many layers), this becomes:

dtdh​=f(h(t),θ(t)),h(T)=h(0)+∫0T​f(h(t),θ(t)),dt

This is a Neural ODE (Chen et al., 2018). The forward pass of a deep network is literally numerically integrating an ODE — and the Riemann sums used to approximate that integral are exactly the architecture of a ResNet. The distance problem is a ResNet.

7. A Note on Rigor — What Are We Really Doing?

When we write limn→∞​∑i=1n​f(xi∗​)Δx, the word limit is doing enormous work. Formally, this requires:

  1. Existence: The limit must exist and be independent of the partition refinement and choice of xi∗​. This is guaranteed if f is Riemann integrable — which holds for all continuous f, and more generally for bounded f with at most countably many discontinuities.

  2. Uniqueness: The integral is uniquely defined (up to measure-zero sets for Lebesgue integration, but that’s a story for real analysis).

  3. The squeeze: The rigorous proof that Ln​≤∫≤Rn​ and both → same limit uses the ε-δ definition of the limit. For a monotone f, the error of the n-th Riemann sum is bounded by n(b−a)(f(b)−f(a))​→0.

Instructor’s note to self: Students at this level often “know” the integral is an area without internalizing that the Riemann sum definition is both the definition and the computational algorithm. The distance problem forces them to see both simultaneously.
