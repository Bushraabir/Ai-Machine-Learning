10.The Logistic Model

Apr 19, 202612 min read

“Malthus said populations grow forever. Verhulst said: no — the world pushes back. That pushback, encoded as a single quadratic term, gives us one of the most consequential ODEs in all of science.”

1. Motivation — From Malthus to Verhulst

1.1 The Malthusian Model (Too Simple)

The simplest population model assumes growth proportional to current population:

dtdP​=kP,k>0

Solution: P(t)=P0​ekt — unbounded exponential growth. This is biologically absurd for large t: no environment has infinite resources.

1.2 The Logistic Correction (Pierre François Verhulst, 1838)

Verhulst’s insight: the per-capita growth rate P1​dtdP​ should not be constant — it should decrease linearly as P approaches the carrying capacity K of the environment:

P1​dtdP​=r(1−KP​)

This gives the logistic equation:

\boxed{\frac{dP}{dt} = rP\left(1 - \frac{P}{K}\right)} \tag{1}

Parameters:

  • r>0: intrinsic growth rate (units: 1/time)
  • K>0: carrying capacity (units: population)
  • P0​=P(0): initial population

Qualitative behavior before solving:

  • If P≪K: 1−P/K≈1, so dP/dt≈rP — exponential growth.
  • If P=K: dP/dt=0 — equilibrium.
  • If P>K: dP/dt<0 — population declines back toward K.

2. Solving the Logistic ODE — Full Derivation

Equation (1) is separable: g(t)=r, h(P)=P(1−P/K).

Step 1 — Separate

\frac{dP}{P(1 - P/K)} = r, dt \tag{2}

Step 2 — Partial Fractions

Decompose the left side. Write 1−P/K=(K−P)/K:

P⋅(K−P)/K1​=P(K−P)K​

Partial fractions:

P(K−P)K​=PA​+K−PB​

K=A(K−P)+BP

  • Set P=0: K=AK⟹A=1.
  • Set P=K: K=BK⟹B=1.

So:

P(K−P)K​=P1​+K−P1​

Step 3 — Integrate Both Sides

∫(P1​+K−P1​)dP=∫r,dt

ln∣P∣−ln∣K−P∣=rt+C1​

ln​K−PP​​=rt+C1​

\frac{P}{K-P} = Ae^{rt}, \quad A = e^{C_1} > 0 \tag{3}

Step 4 — Solve for P

From (3): P=Aert(K−P):

P=KAert−PAert

P(1+Aert)=KAert

P(t)=1+AertKAert​=1+A−1e−rtK​

Step 5 — Apply Initial Condition

At t=0: P(0)=P0​:

P0​=1+A−1K​⟹1+A−1=P0​K​⟹A−1=P0​K−P0​​

Let B=A−1=P0​K−P0​​. The general solution is:

\boxed{P(t) = \frac{K}{1 + \left(\dfrac{K - P_0}{P_0}\right)e^{-rt}}} \tag{4}

Step 6 — Singular Solutions

Setting h(P)=0:

  • P≡0: trivially satisfies (1) (extinct population). Recovered from (4) as P0​=0.
  • P≡K: also satisfies (1). Recovered from (4) as P0​=K (giving B=0).

Both are unstable/stable equilibria respectively (see §4).

3.2 The Inflection Point

Where is growth fastest? Differentiate (1):

dt2d2P​=rdtdP​(1−KP​)+rP(−K1​dtdP​)=rdtdP​(1−K2P​)

Setting d2P/dt2=0 (and dP/dt=0):

1−K2P​=0⟹P∗=2K​​

The inflection point — where the population grows fastest — occurs exactly at half the carrying capacity. This is a structural feature independent of r and P0​.

The time t^_ at which P(t^_) = K/2:

\frac{K}{2} = \frac{K}{1 + Be^{-rt^_}} \implies 1 + Be^{-rt^_} = 2 \implies e^{-rt^*} = \frac{1}{B}

t∗=r1​lnB=r1​lnP0​K−P0​​

3.3 Limiting Behavior

limt→∞​P(t)=K(approaches carrying capacity) limt→−∞​P(t)=0(approached zero in the past)

4. Phase Line Analysis — Qualitative Theory

The logistic ODE P˙=rP(1−P/K) is autonomous: the right side depends only on P, not t explicitly.

Equilibria

Set P˙=0: rP(1−KP​)=0⟹P∗=0orP∗=K

Stability via dPd​[rP(1−P/K)]

Let f(P)=rP(1−P/K). Then f′(P)=r(1−2P/K).

  • At P∗=0: f′(0)=r>0 → unstable equilibrium (small perturbations grow).
  • At P∗=K: f′(K)=r(1−2)=−r<0 → stable equilibrium (small perturbations decay).

Phase Line

f(P) = dP/dt

      ↑ f(P)
      │         ╭──────╮
      │        /        \
      │       /          \
──────┼──────/────────────\──────── P
      0                   K
   unstable            stable
   
Sign of dP/dt:
  P ∈ (0, K):  dP/dt > 0  →  P increases toward K
  P ∈ (K, ∞):  dP/dt < 0  →  P decreases toward K
  P < 0:  biologically invalid

All solutions with P0​>0 converge to K as t→∞. The carrying capacity is a global attractor on (0,∞).

5. The Logistic Function as a Special Case

Setting K=1, r=1, P0​=1/2 (so B=1):

σ(t)=1+e−t1​

This is the standard logistic / sigmoid function. Its derivative:

σ′(t)=σ(t)(1−σ(t))

This is exactly the logistic ODE evaluated at K=1: P˙=P(1−P).

The sigmoid is not just a convenient S-shape — it is the explicit solution to the logistic ODE, evaluated at K=1.

Its key analytic properties:

PropertyValue
σ(0)1/2 (inflection point)
limt→∞​σ(t)1
limt→−∞​σ(t)0
σ′(t)σ(t)(1−σ(t))≤1/4
Maximum of σ′1/4, attained at t=0
σ(−t)1−σ(t) (antisymmetry about (0,1/2))

7. Variations and Extensions

7.1 Logistic with Harvesting

dtdP​=rP(1−KP​)−H

where H>0 is a constant harvesting rate. The equilibria shift; for H>rK/4 (the maximum of rP(1−P/K)) there are no equilibria and the population collapses to zero in finite time. The threshold H∗=rK/4 is the maximum sustainable yield.

7.2 Gompertz Model

dtdP​=rPlnPK​

Used in tumor growth modeling and sometimes ML (Gompertz activation). The per-capita rate rln(K/P) decays logarithmically rather than linearly. More pessimistic than logistic for large P.

7.3 Allee Effect

dtdP​=rP(1−KP​)(AP​−1),0<A<K

Introduces a minimum viable population A: populations below A decline to extinction. Three equilibria: 0 (stable), A (unstable), K (stable).

8. Connection to AI, Machine Learning & Deep Learning

The logistic model is not background material for ML — it is ML, in several precise senses.

8.1 Logistic Regression — The Static Logistic Model

In binary classification, given features x∈Rd, logistic regression models:

P(y=1∣x)=σ(w⊤x+b)=1+e−(w⊤x+b)1​

The sigmoid here is the logistic solution at a fixed “time” t=w⊤x+b. The model is literally evaluating the logistic ODE solution on a linear projection of the input.

Training minimizes the cross-entropy loss:

L=−n1​∑i=1n​[yi​lnp^​i​+(1−yi​)ln(1−p^​i​)]

The gradient:

∂w∂L​=n1​∑i=1n​(p^​i​−yi​)xi​

uses σ′(z)=σ(z)(1−σ(z)) — the logistic ODE identity — to simplify the chain rule derivative cleanly.

8.2 Sigmoid Activation — Every Neuron Solves a Logistic ODE

A sigmoid neuron computes σ(z) where z=w⊤x+b. The value σ(z) is the solution to P˙=P(1−P) evaluated at t=z.

The vanishing gradient problem in deep networks has an ODE interpretation: for large ∣z∣, σ′(z)=σ(z)(1−σ(z))→0 — the logistic curve flattens at both ends. Gradients flowing through many sigmoid layers multiply these near-zero derivatives, causing exponential decay of gradient signal (vanishing) or, in certain architectures, exponential growth (exploding).

This is why ReLU (which does not saturate) largely replaced sigmoid in hidden layers — it does not suffer from the saturation inherent in the logistic ODE’s asymptotic approach to 0 and 1.

8.3 Softmax — The Multiclass Logistic Model

Softmax generalizes the sigmoid to C classes:

softmax(z)c​=∑j=1C​ezj​ezc​​

For C=2: softmax(z)1​=ez1​+ez2​ez1​​=1+e−(z1​−z2​)1​=σ(z1​−z2​).

Softmax is the multivariate generalization of the logistic solution — the carrying capacity K becomes a normalization constraint forcing probabilities to sum to 1.

8.4 Neural ODEs and the Logistic Vector Field

A Neural ODE (Chen et al., 2018) defines the hidden state dynamics as:

dtdh​=fθ​(h(t),t)

The logistic ODE is the simplest nontrivial choice: fθ​(h)=rh(1−h) (component-wise, with K=1). The residual network (ResNet) layer:

ht+1​=ht​+f(ht​)

is the Euler discretization of a Neural ODE with step size Δt=1. As the number of layers →∞ and step size →0, the ResNet converges to a Neural ODE. The logistic model is the prototype for understanding what these continuous-depth networks are computing.

8.5 Population Dynamics of SGD — Loss Landscape as Carrying Capacity

There is a striking analogy between the logistic model and stochastic gradient descent (SGD) convergence:

Logistic modelSGD convergence
Population P(t)Model performance (e.g. accuracy)
Carrying capacity KOptimal achievable accuracy
Growth rate rLearning rate η
1−P/K (saturation)Diminishing returns near optimum
Inflection at K/2Fastest learning at intermediate performance
t→∞:P→KTraining convergence

Under certain loss landscape assumptions, the training accuracy a(t) satisfies approximately:

dtda​≈η⋅a⋅(1−a)

— a logistic ODE with K=1. The S-shaped learning curve (fast initial progress, slowing near perfect accuracy) is the logistic curve. This model motivates learning rate warmup (matching the low-growth phase near P0​) and learning rate decay (near saturation at K).

8.6 Diffusion Models — Logistic Noise Schedules

In DDPM (denoising diffusion probabilistic models), the noise schedule αˉt​ (fraction of signal remaining at timestep t) is often chosen as a cosine schedule which closely approximates the logistic curve run in reverse:

αˉt​=σ(0)σ(s)​⋅σ(s)σ(1−t/T+s)​,s=0.008

The logistic shape ensures the signal-to-noise ratio degrades smoothly — neither too fast (poor sample quality) nor too slow (poor training) — mirroring the inflection point structure of the logistic ODE.

8.7 Grokking — Delayed Generalization as Logistic Dynamics

Grokking (Power et al., 2022) refers to the phenomenon where a neural network first memorizes training data (loss on train →0), then — after a long delay — suddenly generalizes (test loss →0).

The generalization dynamics follow a near-perfect logistic curve: a long near-zero plateau, then rapid S-shaped improvement, then saturation at high accuracy. The “carrying capacity” is set by the model’s capacity and the task’s algorithmic structure. The logistic ODE is the minimal model that captures this behavior.

9. The Logistic Map — Discrete Chaos

The discrete-time logistic model is:

Pn+1​=rPn​(1−Pn​),r∈(0,4]

(Euler discretization of P˙=rP(1−P) with step size 1, K=1.)

Its dynamics are radically different from the continuous ODE:

r rangeBehavior
0<r<1Pn​→0
1<r<3Pn​→ fixed point 1−1/r
3<r<3.57Period doubling (2, 4, 8, 16, …)
r>3.57Chaos
r=4Full chaos on [0,1]

The logistic map is the canonical example of deterministic chaos — a simple, deterministic, one-dimensional rule generating unpredictable trajectories. It demonstrates how discretization (Euler with too large a step) can destroy the stability guaranteed by the continuous ODE.

In ML, this is a warning: discretizing a Neural ODE with too large a time step can destabilize training, turning smooth convergent dynamics into chaotic parameter oscillations.

11. Common Pitfalls

  1. Confusing r and K. r sets the speed of growth; K sets the ceiling. They are independent parameters with different units (r: time−1; K: population).
  2. Forgetting the P>K case. If P0​>K, the solution still exists and decreases monotonically to K. The formula (4) handles this: B<0, but the solution remains valid and positive.
  3. Assuming the inflection is at t=0. The inflection is at P=K/2, which occurs at t∗=r1​lnP0​K−P0​​. Only when P0​=K/2 is t∗=0.
  4. Linearizing too aggressively. Near P=0, P˙≈rP (exponential). Near P=K, letting u=K−P gives u˙=−ru+O(u2) (exponential decay). The global S-shape is not captured by either local linearization alone.
  5. Applying the logistic to non-bounded phenomena. The model assumes a fixed carrying capacity K. If K itself changes over time (e.g., technology shifts the food supply), you need the non-autonomous logistic P˙=r(t)P(1−P/K(t)), which is generally not separable.
