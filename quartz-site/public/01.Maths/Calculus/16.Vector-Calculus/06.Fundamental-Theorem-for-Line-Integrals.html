06.Fundamental Theorem for Line Integrals

06.Fundamental Theorem for Line Integrals

Apr 23, 202611 min read

“The deepest theorems in mathematics are those that reveal a hidden structure you never suspected was there.”

§1. Motivation — Why Should We Care?

Computing a line integral ∫C​F⋅dr directly is often brutal. You parameterize the curve, substitute, and grind through an ugly integral. But sometimes — if you’re lucky — the answer depends only on the endpoints, not the path. The Fundamental Theorem for Line Integrals (FTLI) tells you exactly when this miracle occurs, and hands you a shortcut that reduces the entire integral to a two-point evaluation.

This is the multivariable soul of the single-variable FTC: ∫ab​f′(x),dx=f(b)−f(a)

The FTLI says: if F=∇f, then ∫C​F⋅dr=f(r(b))−f(r(a))

§2. Setup and Definitions

2.1 Vector Fields and Line Integrals

Let F:U⊆Rn→Rn be a vector field on an open set U. A smooth curve C in U is given by a parameterization r:[a,b]→U, r∈C1. The line integral of F along C is: ∫C​F⋅dr=∫ab​F(r(t))⋅r′(t),dt

In R2: if F=⟨P,Q⟩ and r(t)=⟨x(t),y(t)⟩, ∫C​F⋅dr=∫ab​(P,dtdx​+Q,dtdy​)dt=∫C​P,dx+Q,dy

2.2 Conservative Fields and Potential Functions

Definition. A vector field F on U is called conservative (or a gradient field) if there exists a scalar function f:U→R, called a potential function, such that: F=∇f

Explicitly in R3: P=∂x∂f​,Q=∂y∂f​,R=∂z∂f​

Notation remark. Some texts write f as φ or ϕ for the potential. Physics uses V (potential energy) with a sign flip: F=−∇V.

§3. The Theorem

Theorem (Fundamental Theorem for Line Integrals). Let U⊆Rn be an open set and f:U→R a function of class C1. Let C be a piecewise smooth curve in U parameterized by r:[a,b]→U. Then: ∫C​∇f⋅dr=f(r(b))−f(r(a))​

Proof.

Apply the chain rule. Since f∘r:[a,b]→R is C1, the single-variable FTC applies:

∫C​∇f⋅dr=∫ab​∇f(r(t))⋅r′(t),dt

By the multivariable chain rule: dtd​[f(r(t))]=∇f(r(t))⋅r′(t)

Therefore: ∫ab​∇f(r(t))⋅r′(t),dt=∫ab​dtd​[f(r(t))],dt=f(r(b))−f(r(a))□

Note. The proof works equally for piecewise smooth curves by applying the argument on each smooth piece and telescoping.

§4. Immediate Corollaries

Corollary 1: Path Independence

If F=∇f on U, and C1​,C2​ are any two piecewise smooth curves in U with the same initial point A and terminal point B, then: ∫C1​​F⋅dr=∫C2​​F⋅dr=f(B)−f(A)

The integral depends only on the endpoints, not the path.

Corollary 2: Closed Curves Give Zero

If C is a closed curve (i.e., r(a)=r(b)), then: ∮C​∇f⋅dr=f(r(b))−f(r(a))=0

This is one of the key characterizations of conservative fields.

Corollary 3: Equivalences

For a vector field F on a simply connected open domain U, the following are equivalent:

  1. F is conservative (F=∇f for some f)
  2. ∫C​F⋅dr is path-independent in U
  3. ∮C​F⋅dr=0 for every closed curve C in U
  4. In R2: ∂y∂P​=∂x∂Q​ (the curl condition)

Why simply connected matters. On a domain with a “hole” (like R2∖0), a field can satisfy the curl condition without being conservative. The canonical example: F=⟨x2+y2−y​,x2+y2x​⟩ satisfies ∂y∂P​=∂x∂Q​ but ∮C​F⋅dr=2π=0 around the unit circle. The hole at the origin is the obstruction.

§5. Finding the Potential Function

Given that F=⟨P,Q,R⟩ is conservative, how do we find f?

Algorithm (method of integration):

  1. Integrate P with respect to x: f=∫P,dx+g(y,z)
  2. Differentiate with respect to y, set equal to Q, solve for ∂g/∂y
  3. Integrate to get g, which may depend on z
  4. Differentiate with respect to z, set equal to R, determine g‘s dependence on z

Example. Let F=⟨2xy+z2,;x2,;2xz⟩.

Check conservativeness: ∂y∂P​=2x=∂x∂Q​✓,∂z∂P​=2z=∂x∂R​✓,∂z∂Q​=0=∂y∂R​✓

Find f:

f=∫(2xy+z2),dx=x2y+xz2+g(y,z)

∂y∂f​=x2+∂y∂g​=x2⟹∂y∂g​=0⟹g=h(z)

∂z∂f​=2xz+h′(z)=2xz⟹h′(z)=0⟹h=C

f(x,y,z)=x2y+xz2+C​

§6. Worked Examples

Example A — Direct Application

Problem. Evaluate ∫C​F⋅dr where F=⟨yex,ex+2y⟩ and C is any smooth curve from (0,1) to (1,2).

Solution. Check: ∂y∂P​=ex=∂x∂Q​. Conservative. ✓

Find f: f=∫yex,dx=yex+g(y). Then ∂y∂f​=ex+g′(y)=ex+2y⟹g′(y)=2y⟹g=y2.

So f(x,y)=yex+y2.

∫C​F⋅dr=f(1,2)−f(0,1)=(2e+4)−(1⋅1+1)=2e+4−2=2e+2

No messy parameterization needed. Done.

Example B — Verifying Path Independence Numerically

Field: F=⟨2x,2y⟩=∇(x2+y2). Integrate from A=(0,0) to B=(1,1).

Path 1: Along y=x, parameterize r(t)=(t,t), t∈[0,1]: ∫01​(2t,2t)⋅(1,1),dt=∫01​4t,dt=2

Path 2: Along y=x2, r(t)=(t,t2): ∫01​(2t,2t2)⋅(1,2t),dt=∫01​(2t+4t3),dt=[t2+t4]01​=2

Via FTLI: f(B)−f(A)=(1+1)−(0+0)=2. ✓

Example C — Non-Conservative Field (Failure Case)

Field: F=⟨−y,x⟩.

Check: ∂y∂P​=−1=1=∂x∂Q​. Not conservative.

Around the unit circle C:r(t)=(cost,sint), t∈[0,2π]: ∮C​F⋅dr=∫02π​(−sint,cost)⋅(−sint,cost),dt=∫02π​1,dt=2π=0

The FTLI does not apply here. This field is a rotation field; it does work around loops.

7.2 Level Curves and Gradient Arrows (ℝ²)

For f(x,y)=x2+y2 (paraboloid), level curves are circles, ∇f=⟨2x,2y⟩ points radially outward:

        ·····  f=4  ·····
      ·· ↑↖  f=2  ↗↑ ··
     · ←    ↑ f=1 ↑    → ·
      ·· ↙  ↓     ↓ ↘ ··
        ·····  f=4  ·····
           (gradient arrows
           always ⊥ level curves)

Key insight: Any path from f=1 circle to f=4 circle, regardless of how it winds, gives ∫∇f⋅dr=4−1=3.

7.3 The “Altitude” Analogy

Think of f as a topographic map of elevation.

  • ∇f = the gradient vector = direction and steepness of ascent
  • F⋅dr = “how much you climb” along each infinitesimal step
  • ∫C​F⋅dr = total elevation gain along the hike

FTLI says: Total elevation gain = (final elevation) − (initial elevation). Whether you switchback, spiral, or go straight up — doesn’t matter.

§8. Connection to AI, Machine Learning, and Deep Learning

This is where the FTLI stops being just a calculus theorem and becomes a foundational idea behind how neural networks are trained.

8.1 Gradient Descent and Conservative Fields

The loss function L(θ) in machine learning (where θ∈Rn is the parameter vector) plays the role of the potential f.

The gradient ∇θ​L is exactly the vector field F of the FTLI. Gradient descent updates: θt+1​=θt​−η,∇θ​L(θt​)

This is numerically following −∇f — moving downhill in the loss landscape. The FTLI tells us that, in principle, the cumulative change in loss along any optimization path depends only on the starting and ending parameter values: L(θfinal​)−L(θinit​)=∫C​∇L⋅dθ

8.2 Backpropagation and the Chain Rule

The proof of the FTLI is essentially a chain rule argument: dtd​[f(r(t))]=∇f⋅r′(t)

Backpropagation in deep learning is the same chain rule, applied through the composition of layers: ∂θ(1)∂L​=∂a(L)∂L​⋅∂a(L−1)∂a(L)​⋯∂θ(1)∂a(2)​

This is literally the multivariable chain rule telescoped through the computational graph — the same mathematical mechanism that proves the FTLI.

8.3 Path Independence in Optimization

The FTLI’s path-independence corollary has a deep implication: if the loss landscape were a perfect gradient field (which it often approximately is locally), then the order of gradient steps wouldn’t matter — only the endpoints would. This is why:

  • Stochastic gradient descent (SGD) with different orderings of mini-batches converges to similar loss values (not exactly, due to noise, but approximately)
  • Learning rate schedules affect the path C through parameter space, but the final L depends primarily on where you end up, not how you got there

8.4 Conservative vs Non-Conservative Dynamics

Not all vector fields in ML are conservative (gradient fields):

ScenarioConservative?Implication
Standard gradient descentYesFTLI applies; pure descent
Momentum (SGD with momentum)NoNon-conservative; path matters
GAN training dynamicsNoCan cycle; no potential function
Natural gradient (Fisher matrix)RiemannianModified FTLI on manifold

GANs are particularly interesting: the generator and discriminator create a game where the dynamics are a non-conservative vector field in the joint parameter space. This is why GAN training can cycle and is notoriously unstable — there is no global potential function whose minimum you’re descending toward.

8.5 Energy Functions in Physics-Inspired ML

In Energy-Based Models (EBMs), the model learns an explicit energy function Eθ​(x) — literally the potential function f of the FTLI. The probability of a data point x is: pθ​(x)=Z(θ)e−Eθ​(x)​

Training EBMs involves computing gradients of E — exactly ∇E — and the geometry of the energy landscape (level curves, gradient flow) directly determines model behavior.

8.6 The Geometry of Loss Landscapes

Modern deep learning research studies the loss landscape L:Rn→R (where n can be 109 parameters). Key concepts directly from FTLI/multivariable calculus:

  • Saddle points: where ∇L=0 but it’s not a minimum — gradient descent escapes these due to the asymmetry of the Hessian
  • Flat regions / loss plateaus: where ∣∇L∣ is small; gradient steps are tiny
  • Mode connectivity: recent work shows that different minima of neural networks are often connected by paths of low loss — this is a statement about the topology of level sets of L, directly the level curve language of the FTLI

§10. Personal Notes & Things to Remember

  • The proof is embarrassingly short once you see it — it’s just the chain rule and the FTC working in concert. The hard part is believing path independence is possible.
  • The simply connected condition is not just technical hygiene — it’s the reason electrostatics works differently outside a charged wire than outside a charged sphere.
  • In ML, “loss landscape” is the n-dimensional analog of a topographic map, and every intuition from the FTLI (level curves, gradient orthogonality, path independence) carries over, just in n≫3 dimensions.
  • The failure of conservativeness in GANs is not a bug — it’s a feature of two-player games. The fixed point is not a minimum of anything; it’s a Nash equilibrium.
  • Always verify the curl condition before hunting for a potential function. Saves a lot of wasted work.
