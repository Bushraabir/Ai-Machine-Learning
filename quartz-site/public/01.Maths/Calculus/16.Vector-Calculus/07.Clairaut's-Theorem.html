07.Clairaut's Theorem

07.Clairaut's Theorem

Apr 23, 202613 min read

§1. Motivation — The Question Nobody Thinks to Ask

When you differentiate f(x,y) first with respect to x, then with respect to y, do you get the same thing as differentiating first in y, then in x?

∂y∂​(∂x∂f​)=?∂x∂​(∂y∂f​)

In shorthand: fxy​=?fyx​.

Intuitively, differentiation feels like a linear operation — order shouldn’t matter. But that intuition is not a proof, and it’s not always true. Clairaut’s theorem gives the precise sufficient conditions under which order genuinely doesn’t matter, and the failure cases reveal something deep about regularity.

§2. Notation and Setup

Let f:U⊆R2→R where U is open. The mixed partial derivatives are:

fxy​=∂y,∂x∂2f​=∂y∂​(∂x∂f​)

fyx​=∂x,∂y∂2f​=∂x∂​(∂y∂f​)

Warning on notation. The Leibniz notation ∂y,∂x∂2f​ means: differentiate x first, then y. The denominator is read right to left — the innermost operation is on the right. The subscript notation fxy​ is read left to right — x first, then y. These two notations agree in their convention, but double-check in whatever textbook you’re using.

For f:U⊆Rn→R, higher-order mixed partials are defined analogously: fxi​xj​​=∂xj​,∂xi​∂2f​

§3. The Theorem

Theorem (Clairaut, also attributed to Schwarz / Young). Let f:U⊆R2→R. Suppose that fxy​ and fyx​ both exist on U, and that they are both continuous at a point (a,b)∈U. Then: fxy​(a,b)=fyx​(a,b)​

More practically — and the form you’ll use in 99% of computations:

Corollary. If f∈C2(U) (i.e., all second-order partial derivatives exist and are continuous on U), then all mixed second-order partials are equal throughout U.

§4. Proof

This is a genuine ε-δ argument. It’s worth doing once carefully.

Setup. Fix (a,b)∈U. For small h,k=0 (chosen so the rectangle stays in U), define the double increment:

Δ(h,k)=f(a+h,b+k)−f(a+h,b)−f(a,b+k)+f(a,b)

The key observation: Δ(h,k) can be factored in two ways using the single-variable Mean Value Theorem.

Factoring via x first. Define φ(x)=f(x,b+k)−f(x,b). Then: Δ(h,k)=φ(a+h)−φ(a)

By MVT applied to φ on [a,a+h]: ∃,θ1​∈(0,1) such that: Δ(h,k)=h,φ′(a+θ1​h)=h[fx​(a+θ1​h,,b+k)−fx​(a+θ1​h,,b)]

Apply MVT again to fx​(a+θ1​h,⋅) on [b,b+k]: ∃,θ2​∈(0,1) such that: Δ(h,k)=hk,fxy​(a+θ1​h,,b+θ2​k)

Factoring via y first. Define ψ(y)=f(a+h,y)−f(a,y). By the same MVT argument: Δ(h,k)=hk,fyx​(a+θ3​h,,b+θ4​k)

for some θ3​,θ4​∈(0,1).

Conclusion. Since both expressions equal Δ(h,k): hk,fxy​(a+θ1​h,,b+θ2​k)=hk,fyx​(a+θ3​h,,b+θ4​k)

Dividing by hk=0: fxy​(a+θ1​h,,b+θ2​k)=fyx​(a+θ3​h,,b+θ4​k)

Now take h,k→0. Since fxy​ and fyx​ are continuous at (a,b), both sides converge to their values at (a,b): fxy​(a,b)=fyx​(a,b)□

§5. The Counterexample — When It Fails

The continuity hypothesis is not superfluous. The following classic example shows Clairaut can fail without it.

Define: f(x,y)={xy,x2+y2x2−y2​​(x,y)=(0,0) 0​(x,y)=(0,0)​

Compute fx​(0,y) for y=0 via the limit definition: fx​(0,y)=limh→0​hf(h,y)−f(0,y)​=limh→0​hhy⋅h2+y2h2−y2​​=y⋅y2−y2​=−y

So fx​(0,y)=−y for y=0, and fx​(0,0)=0.

Then: fxy​(0,0)=∂y∂​[fx​(0,y)]​y=0​=∂y∂​(−y)​y=0​=−1

By symmetry (swap x↔y, note sign change): fyx​(0,0)=+1

fxy​(0,0)=−1=1=fyx​(0,0)

Why did it fail? You can verify that fxy​ and fyx​ exist everywhere, but are not continuous at the origin. Clairaut’s hypothesis is violated, and the conclusion fails. ■

§6. Worked Examples

Example A — Standard Verification

Let f(x,y)=x3y2−sin(xy)+ex+y.

f∈C∞(R2), so Clairaut applies everywhere. Let’s verify explicitly.

fx​=3x2y2−ycos(xy)+ex+y fxy​=6x2y−cos(xy)+xysin(xy)+ex+y

fy​=2x3y−xcos(xy)+ex+y fyx​=6x2y−cos(xy)+xysin(xy)+ex+y

fxy​=fyx​. ✓

Example B — Checking the Curl Condition (FTLI Connection)

F=⟨P,Q⟩=⟨2xy+y3,;x2+3xy2⟩.

For F to be conservative, we need Py​=Qx​ (this is exactly Clairaut applied to the potential f):

Py​=2x+3y2,Qx​=2x+3y2

Py​=Qx​ ✓. So F is conservative.

Find f: fx​=2xy+y3⇒f=x2y+xy3+g(y). fy​=x2+3xy2+g′(y)=x2+3xy2⇒g′(y)=0⇒f=x2y+xy3+C.

The whole machinery of conservative fields depends on Clairaut: that fxy​=fyx​ is what makes Py​=Qx​ a valid test.

Example C — Higher Order Partials (R3, f∈C3)

For f∈C3(U), Clairaut extends to third-order: any ordering of three variables gives the same result. For example:

fxyz​=fxzy​=fyxz​=fyzx​=fzxy​=fzyx​

There are 3!=6 orderings of x,y,z — all equal for C3 functions.

Check: f(x,y,z)=x2yz3

fxyz​=∂z∂​∂y∂​(2xyz3)=∂z∂​(2xz3)=6xz2

fzyx​=∂x∂​∂y∂​(3x2yz2)=∂x∂​(3x2z2)=6xz2 ✓

§7. Visualization

7.1 What Do Mixed Partials Measure?

Single partials: rate of change in one direction.

Mixed partials: how the rate of change in one direction varies as you move in another direction.

fxy​: “How does the slope in the x-direction change as you move in the y-direction?”

Clairaut says: this is the same as asking “How does the slope in the y-direction change as you move in the x-direction?” — at least when these quantities are continuous.

7.2 The Rectangle Argument — Geometric Core of the Proof

The double increment Δ(h,k) is exactly the signed sum of f at the four corners of a rectangle:

(a, b+k) ───────────── (a+h, b+k)
    |                       |
    |    Δ(h,k) = f(a+h,b+k)
    |           - f(a+h, b)
    |           - f(a,  b+k)
    |           + f(a,  b)
    |                       |
 (a, b)  ───────────── (a+h, b)

This quantity Δ(h,k) measures the “twist” of f across the rectangle. Both mixed partials try to measure the same twist — from different directions — and Clairaut says they agree in the limit when continuity holds.

7.3 Saddle Surface — Where Mixed Partials Are Non-Zero

For f(x,y)=xy (the standard saddle):

          z
          |     ↗ (tilts up this way)
          |   /
  ────────+────────  y
         /|  ↘
        / |    (tilts down this way)
       x
       
  f_x = y,   f_y = x
  f_{xy} = 1,  f_{yx} = 1  ✓ (Clairaut holds)

The mixed partial fxy​=1 says: as you move in the y-direction, the slope in the x-direction increases at rate 1. The symmetry fyx​=fxy​ is visually obvious on the saddle — the surface has a clean bilinear structure.

7.4 Clairaut Failure — Visualization at Origin

For the counterexample f(x,y)=xyx2+y2x2−y2​, the function is smooth away from the origin but has a “pinched” behavior there — the mixed partial derivatives “disagree” about the twist because the surface has an asymmetric singularity in its curvature at the origin.

  Along x-axis:  f(x,0) = 0  (flat)
  Along y-axis:  f(0,y) = 0  (flat)
  Along y=x:     f(x,x) = 0  (flat)
  Along y=-x:    f(x,-x) = x²  (curves up!)
  
  The surface behaves differently from different approach directions.
  This asymmetry is what causes f_{xy} ≠ f_{yx} at (0,0).

§8. Generalizations

8.1 Schwarz’s Theorem (Full Generality)

The result is sometimes stated in a stronger form (due to H.A. Schwarz):

Theorem (Schwarz). If fxy​ and fyx​ merely both exist and one of them is continuous at (a,b), then they are equal at (a,b).

Clairaut’s version (both continuous) is the practically useful form. Schwarz’s is the sharpest version.

8.2 Young’s Theorem (n Variables)

For f:U⊆Rn→R of class Ck, any two k-th order partial derivatives that use the same multiset of variables are equal.

Explicitly: if α and β are permutations of the same index sequence, then Dαf=Dβf.

8.3 Distribution Theory Perspective

In the theory of distributions (Sobolev spaces), partial derivatives commute automatically in the distributional sense — the Clairaut condition is always satisfied weakly. This is one reason distributional derivatives are so powerful in PDE theory and modern ML.

§9. Connection to AI, Machine Learning, and Deep Learning

Clairaut’s theorem sits silently behind nearly every numerical optimization algorithm used in modern ML. Its presence is so pervasive it’s almost invisible.

9.1 Hessian Matrices and Second-Order Optimization

The Hessian of a loss function L(θ) is the matrix of all second-order partial derivatives:

Hij​=∂θi​,∂θj​∂2L​

Clairaut’s theorem says: the Hessian is symmetric, i.e., H=HT, whenever L∈C2.

This symmetry is not cosmetic — it has profound algorithmic consequences:

Property of Symmetric HImplication for Optimization
Real eigenvaluesCurvature is real-valued; well-defined notion of “concave/convex”
Orthogonal eigenvectorsNatural axes for the loss landscape
Spectral decomposition H=QΛQTNewton’s method, natural gradient are geometrically meaningful
Positive definite ⇒ local minThe second derivative test works

Without Clairaut — if H were not symmetric — eigenvalues could be complex, and the geometry of the loss landscape would be fundamentally broken.

9.2 Newton’s Method and Curvature

Newton’s method for optimization uses the full Hessian: θt+1​=θt​−H−1∇L(θt​)

This requires computing and inverting H. The assumption that H is symmetric (Clairaut) is what allows:

  • Cholesky decomposition: H=LLT (only valid for symmetric positive definite matrices) — far cheaper than general LU
  • Eigendecomposition: used in understanding saddle points, where H has negative eigenvalues
  • Conjugate gradient solvers: exploit symmetry for efficiency

Quasi-Newton methods (L-BFGS, BFGS) approximate H−1 while explicitly maintaining symmetry in each update — a direct enforcement of Clairaut.

9.3 Backpropagation and Order of Differentiation

Backprop computes ∇θ​L — first-order derivatives. Second-order backprop (Hessian-vector products, used in Hessian-free optimization) requires computing: Hv=∂θ∂​(∇L⋅v)

This is a mixed partial derivative computation. Clairaut guarantees that it doesn’t matter whether you differentiate ∇L with respect to θ, or vice versa — the numerical result is the same. Automatic differentiation libraries (PyTorch, JAX) silently rely on this to compute Hessian-vector products efficiently via forward-over-reverse or reverse-over-forward autodiff — two different orderings of differentiation that give the same answer, by Clairaut.

9.4 Fisher Information Matrix and Natural Gradient

The Fisher Information Matrix in statistics/ML is: Fij​=E[∂θi​∂logpθ​(x)​∂θj​∂logpθ​(x)​]

F is symmetric by construction (it’s a covariance matrix), and equals the negative expected Hessian of the log-likelihood under regularity conditions — another application of Clairaut linking information geometry to second-order calculus.

Natural gradient descent (used in TRPO, PPO, and other RL algorithms) uses F−1∇L as the update direction. Its validity depends on the symmetric structure guaranteed by Clairaut.

9.5 Symmetry in Attention and Transformer Architectures

In self-attention, the attention score between query q and key k is: score(q,k)=dk​​q⋅k​

This is symmetric in an informal sense. More concretely: when analyzing the sensitivity of transformer outputs to inputs, one computes second-order interactions (analogous to mixed partials of the output with respect to different input tokens). The symmetry of these interaction terms — a continuous analog of Clairaut — is what allows interpretability methods like integrated gradients and SHAP to attribute model behavior consistently.

9.6 Implicit Differentiation and Neural ODEs

Neural ODEs define the forward pass via an ODE: dtdh​=fθ​(h,t)

Training requires differentiating the loss with respect to θ, which involves the adjoint method — a form of implicit differentiation through the ODE. The correctness of the adjoint relies on the commutativity of differentiation in t and θ, which is precisely Clairaut’s theorem applied to the joint (t,θ) parameter space.

§10. The Curl Test — Clairaut’s Most Famous Application

For F=⟨P,Q⟩ on a simply connected domain, F is conservative ⇔ Py​=Qx​.

Why Clairaut? If F=∇f=⟨fx​,fy​⟩, then: Py​=(fx​)y​=fxy​=fyx​=(fy​)x​=Qx​

The equality fxy​=fyx​ — which is Clairaut — is the entire reason the curl test works. Without Clairaut, there would be no reason to expect Py​=Qx​.

In R3: F conservative ⇒∇×F=0. Explicitly:

curl(F)=(∂y∂R​−∂z∂Q​,;∂z∂P​−∂x∂R​,;∂x∂Q​−∂y∂P​)=0

Each component vanishes by Clairaut applied to the corresponding potential f.

§11. Summary

f∈C2(U)⟹fxy​=fyx​ on U​

ItemDetail
Hypothesisfxy​ and fyx​ both exist and are continuous at the point
Conclusionfxy​=fyx​ at that point
Proof techniqueDouble increment + MVT twice, then take limits using continuity
Failure modeContinuity of mixed partials can fail; gives fxy​=fyx​ at origin
Key applicationCurl test for conservative fields (FTLI); Hessian symmetry in ML
GeneralizationCk functions: all k-th mixed partials with same variables are equal

§12. Personal Notes

  • The proof is longer than Clairaut’s theorem deserves to be, but it teaches you something: the Mean Value Theorem is the fundamental tool in multivariable calculus, not the definition of the derivative.
  • The failure example is genuinely surprising the first time. A function can be differentiable everywhere, have both mixed partials everywhere, and still fail symmetry — because differentiability alone doesn’t imply the partials are continuous.
  • In practice, every function you encounter in ML is C∞ (neural networks with smooth activations like GELU, sigmoid, tanh), so Clairaut always holds. The Hessian is always symmetric. The issue in ML is not Clairaut failing — it’s the Hessian being enormous (n×n with n=109) and computationally inaccessible.
  • There is something philosophically satisfying here: commutativity of partial derivatives is a regularity statement. The more regular (smooth) a function is, the more operations commute. This theme runs all the way through PDE theory, functional analysis, and the foundations of modern ML.
  • Remember the mnemonic for Leibniz notation: ∂y,∂x∂2f​ — the denominator reads right-to-left (x first, then y). Get this backwards once on an exam and you’ll never forget it.
