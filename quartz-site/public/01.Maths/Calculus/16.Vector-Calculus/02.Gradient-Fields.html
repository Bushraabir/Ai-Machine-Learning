1. Motivation

We already know the derivative of f:R→R captures the rate of change of f at a point. In higher dimensions, f:Rn→R, the question becomes richer:

“In which direction does f increase most rapidly, and at what rate?”

The gradient answers this — completely and canonically. It packages all partial derivatives into a single geometric object: a vector field that, at every point, aims uphill.

But there is a subtlety hiding here. The gradient is an operation on a scalar function. A gradient field is the resulting vector field ∇f. Not every vector field is a gradient field. The question of which ones are is one of the most beautiful problems in vector calculus, with deep topological content.

2. The Gradient of a Scalar Field

Definition. Let f:U⊆Rn→R be differentiable on the open set U. The gradient of f at a point x∈U is the vector ∇f(x)=(∂x1​∂f​(x),;∂x2​∂f​(x),;…,;∂xn​∂f​(x))∈Rn

In R2 and R3 respectively: ∇f(x,y)=∂x∂f​,i+∂y∂f​,j

∇f(x,y,z)=∂x∂f​,i+∂y∂f​,j+∂z∂f​,k

The operator ∇ (nabla or del) is the vector differential operator: ∇=⟨∂x1​∂​,∂x2​∂​,…,∂xn​∂​⟩

Crucial point. ∇f(x0​) is a vector at a single point. The gradient field ∇f:U→Rn is the function that assigns this vector to every point in U.

3. Gradient Fields — The Vector Field Perspective

Definition. A vector field F:U⊆Rn→Rn is a gradient field (equivalently, a conservative field) if there exists a scalar function f:U→R such that F=∇f The function f is called the potential function (or scalar potential) for F.

Terminology across disciplines:

PhysicsMathematicsML/Optimisation
Potential ϕPotential function fLoss / objective L
Conservative force F=−∇ϕGradient field F=∇fNegative gradient −∇L
Energy conservationPath independenceConvergence guarantees

Note the sign convention: in physics, forces are F=−∇ϕ (particle moves toward lower potential energy). In optimisation, we descend: −∇L. In pure mathematics we usually write F=∇f without the sign.

4. Geometric Anatomy

4.1 Level Sets and Orthogonality

The level set of f at height c is: Lc​=x∈U:f(x)=c

In R2 these are level curves; in R3 they are level surfaces.

Theorem. If f is C1 and ∇f(x0​)=0, then ∇f(x0​) is perpendicular to the level set Lf(x0​)​ at x0​.

Proof sketch. Let r(t) be any smooth curve on the level set Lc​, so f(r(t))=c for all t. Differentiating: dtd​f(r(t))=∇f(r(t))⋅r′(t)=0 So ∇f is perpendicular to every tangent vector of Lc​ at x0​, hence perpendicular to the level set. ■

4.2 Direction and Magnitude

Theorem. Among all unit vectors u^, the directional derivative Du^​f(x0​)=∇f(x0​)⋅u^ is:

  • maximised when u^=∣∇f(x0​)∣∇f(x0​)​ (direction of gradient), with maximum value ∣∇f(x0​)∣
  • minimised (steepest descent) when u^=−∣∇f(x0​)∣∇f(x0​)​, with minimum value −∣∇f(x0​)∣
  • zero when u^⊥∇f(x0​) (tangent to level set)

Proof. Du^​f=∇f⋅u^=∣∇f∣∣u^∣cosθ=∣∇f∣cosθ. This is maximised at θ=0 (same direction) and minimised at θ=π (opposite direction). ■

The gradient is the compass of optimisation: at every point, it tells you exactly which direction to move to increase f most rapidly.

5. Directional Derivatives — The Gradient as a Linear Form

The total derivative (Fréchet derivative) of f at x0​ is the unique linear map Df(x0​):Rn→R such that: f(x0​+h)=f(x0​)+Df(x0​)h+o(∣h∣)as h→0

By the Riesz representation theorem on Rn with the standard inner product, every linear functional Rn→R is represented by dot product with some fixed vector. That vector is precisely ∇f(x0​): Df(x0​)h=∇f(x0​)⋅h

So: the gradient is the vector that represents the total derivative as a dot product. This is the coordinate-free definition — it explains why the gradient changes when you change the inner product (e.g., in Riemannian geometry).

Directional derivative (formal definition): Du^​f(x0​)=limh→0​hf(x0​+hu^)−f(x0​)​=∇f(x0​)⋅u^

6. Critical Points and the Second Derivative Test

Definition. x0​ is a critical point of f if ∇f(x0​)=0.

Critical points are where the gradient field vanishes — where the “force” is zero. They are candidates for local minima, local maxima, or saddle points.

The Hessian

The Hessian matrix of f at x0​ is: Hf​(x0​)=[∂xi​∂xj​∂2f​(x0​)]i,j=1n​

For f:R2→R: Hf​=(fxx​​fxy​ fxy​​fyy​​)

(Symmetric by Clairaut’s theorem if f∈C2.)

Second Derivative Test. At a critical point x0​ with ∇f(x0​)=0:

  • Hf​(x0​) positive definite ⟹ local minimum
  • Hf​(x0​) negative definite ⟹ local maximum
  • Hf​(x0​) indefinite ⟹ saddle point
  • Hf​(x0​) singular ⟹ test inconclusive

In R2, let D=fxx​fyy​−fxy2​=detHf​:

Dfxx​Type
D>0>0Local minimum
D>0<0Local maximum
D<0—Saddle point
D=0—Inconclusive

Example. f(x,y)=x2−y2 at (0,0): ∇f=⟨2x,−2y⟩=0 at origin. ✓ Critical point. Hf​=(2​0 0​−2​), D=−4<0 → saddle point. The gradient field flows outward along x-axis and inward along y-axis.

7. Conservative Fields and Potential Functions

Finding the Potential Function

Given F=⟨P,Q,R⟩ known to be conservative, recover f such that ∇f=F:

Method (integration and matching):

  1. Integrate P=∂f/∂x with respect to x: f(x,y,z)=∫P,dx+g(y,z)
  2. Differentiate with respect to y, set equal to Q, solve for ∂g/∂y: ∂y∂f​=(known)+∂y∂g​=Q⟹∂y∂g​=Q−(known)
  3. Integrate to get g(y,z)=∫(…),dy+h(z).
  4. Differentiate with respect to z, set equal to R, solve for h′(z), integrate.

Worked example. F=⟨yz,;xz,;xy⟩.

Step 1. f=∫yz,dx=xyz+g(y,z).

Step 2. ∂f/∂y=xz+∂g/∂y=xz⟹∂g/∂y=0⟹g=h(z).

Step 3. ∂f/∂z=xy+h′(z)=xy⟹h′(z)=0⟹h=C.

Potential: f(x,y,z)=xyz+C. ✓ Check: ∇(xyz)=⟨yz,xz,xy⟩. ✓

Uniqueness

Proposition. If F=∇f=∇g on a connected domain U, then f−g=C (constant on U).

Proof. ∇(f−g)=0 everywhere on U. On a connected open set, a function with zero gradient is constant. ■

So the potential is unique up to an additive constant — exactly like indefinite integrals in 1D.

The Fundamental Theorem for Line Integrals

Theorem. Let F=∇f on an open set U containing a smooth curve C from point A to point B. Then: ∫C​F⋅dr=f(B)−f(A)

Proof. Let r(t), t∈[a,b], parametrise C with r(a)=A, r(b)=B. Then: ∫C​F⋅dr=∫ab​∇f(r(t))⋅r′(t),dt=∫ab​dtd​[f(r(t))],dt=f(r(b))−f(r(a))=f(B)−f(A) by the chain rule and the 1D Fundamental Theorem of Calculus. ■

This is the n-dimensional generalisation of ∫ab​f′(x),dx=f(b)−f(a).

8. When is a Vector Field a Gradient Field?

This is the central question of the theory. The answer has a beautiful topological flavour.

Necessary Condition — Zero Curl

Theorem. If F=∇f and f∈C2, then ∇×F=0.

Proof. In R2, the scalar curl is ∂Q/∂x−∂P/∂y. If P=fx​,Q=fy​: ∂x∂Q​−∂y∂P​=fyx​−fxy​=0 by Clairaut’s theorem (equality of mixed partials for C2 functions). In R3 all three components of ∇×∇f vanish by the same argument. ■

Sufficient Condition — Simply Connected Domains

Theorem. Let F be a C1 vector field on a simply connected open domain U⊆Rn. Then: F=∇f for some f⟺∇×F=0 on U

Simply connected means U has no holes — every closed loop in U can be continuously shrunk to a point within U.

The topological subtlety. On a domain with holes, zero curl does NOT imply conservative.

Standard counterexample. Let U=R2∖(0,0) and: F(x,y)=⟨x2+y2−y​,;x2+y2x​⟩

Check curl: ∂x∂Q​−∂y∂P​. One computes this is =0 on all of U.

But: integrate around the unit circle C:r(t)=(cost,sint), t∈[0,2π]: ∮C​F⋅dr=∫02π​(cos2t+sin2t−sint​⋅(−sint)+cos2t+sin2tcost​⋅cost)dt=∫02π​1,dt=2π=0

Non-zero line integral around a closed loop ⟹ not conservative, despite zero curl. The hole at the origin makes U not simply connected, and the field “detects” the hole via its winding number.

(This F is ∇θ where θ=arctan(y/x) is the polar angle — but θ is not well-defined as a single-valued function on all of U.)

The full picture (first de Rham cohomology): The obstruction to a curl-free field being a gradient is measured by HdR1​(U). For simply connected U, H1=0 and curl-free ⟹ exact. For U=R2∖0, H1≅R and there is one independent non-exact closed form — the one in the counterexample.

9. The Gradient in Curvilinear Coordinates

In coordinates other than Cartesian, the gradient takes a different form. This matters for numerical methods (especially on meshes) and physics.

Polar coordinates (r,θ) in R2: ∇f=∂r∂f​r^+r1​∂θ∂f​θ^

Spherical coordinates (r,θ,ϕ) in R3: ∇f=∂r∂f​r^+r1​∂θ∂f​θ^+rsinθ1​∂ϕ∂f​ϕ^​

General orthogonal curvilinear coordinates (u1​,u2​,u3​) with scale factors hi​=∣∂r/∂ui​∣: ∇f=∑i=13​hi​1​∂ui​∂f​e^i​

In Riemannian geometry with metric tensor gij​, the gradient is the vector field dual to df via g: (∇f)i=gij∂j​f. The Cartesian case is just gij​=δij​.

10. Worked Examples

Example A — Full analysis of f(x,y)=x2y−y3/3

Gradient field: ∇f=⟨2xy,;x2−y2⟩

Critical points: Set ∇f=0: 2xy=0⟹x=0 or y=0

  • If x=0: x2−y2=−y2=0⟹y=0. Point: (0,0).
  • If y=0: x2−0=x2=0⟹x=0. Same point.

So the only critical point is (0,0).

Hessian: Hf​=(2y​2x 2x​−2y​),Hf​(0,0)=(0​0 0​0​)

D=0: test inconclusive. Direct inspection: f(t,0)=0 for all t, while f(0,t)=−t3/3 changes sign. So (0,0) is neither a local min nor max — it is a degenerate saddle.

Example B — Verify conservatism and find potential

F=⟨2xey+1,;x2ey−siny⟩

Curl check: ∂x∂Q​−∂y∂P​=2xey−2xey=0✓

Find f: f=∫(2xey+1),dx=x2ey+x+g(y) ∂y∂f​=x2ey+g′(y)=x2ey−siny⟹g′(y)=−siny⟹g(y)=cosy+C

f(x,y)=x2ey+x+cosy+C​

Line integral shortcut: Compute ∫C​F⋅dr from (0,0) to (1,π) along any path: f(1,π)−f(0,0)=(eπ+1+cosπ)−(0+0+cos0)=eπ+1−1−1=eπ−1

11. Connection to AI / Machine Learning / Deep Learning

11.1 Gradient Descent — Following the Gradient Field

Every training algorithm in deep learning follows the gradient field of the loss. Gradient descent is: θt+1​=θt​−η,∇θ​L(θt​)

This is discrete-time integration along the trajectory of the vector field −∇L. The continuous-time limit is the gradient flow ODE: θ˙(t)=−∇L(θ(t))

This ODE drives θ toward critical points of L. Because L is a potential function, the flow is conservative — it always descends L and cannot orbit indefinitely.

Fact. Along any gradient flow trajectory, dtd​L(θ(t))=∇L⋅θ˙=−∣∇L∣2≤0. The loss is non-increasing. Equality iff ∇L=0.

This is the energy dissipation property, directly from the theory of conservative fields.

11.2 The Loss Landscape as a Scalar Field

The loss L(θ) for a neural network with n parameters lives in Rn. Its geometry:

Feature of LVector field language
Local minimum∇L=0, HL​ positive definite
Saddle point∇L=0, HL​ indefinite
Flat region∇L≈0, slow gradient flow
Sharp minimumLarge curvature (large eigenvalues of HL​)
Wide minimumSmall curvature (small eigenvalues) — generalises better

11.3 Variants of Gradient Descent — Preconditioned Gradient Fields

Modern optimisers do not follow −∇L directly; they follow a preconditioned version:

θt+1​=θt​−η,Mt−1​∇L(θt​)

where Mt​ is a preconditioning matrix. This changes the effective vector field being followed.

OptimiserPreconditioner Mt​
SGDI (identity — plain gradient field)
Momentum SGDExponential moving average of ∇L
AdaGraddiag(∑τ​∇Lτ​⊙∇Lτ​)
RMSPropdiag(E[∇2]) — running average
Adamdiag(m^/v^​) — bias-corrected moments
Natural GradientFisher information matrix F(θ)

Adam does not follow the gradient field of any potential. It is not a conservative vector field. This has deep implications: Adam can get stuck in places gradient descent would not, and vice versa.

11.4 Natural Gradient — The Riemannian Gradient

In information geometry, the parameter space of a probabilistic model carries a natural Riemannian metric — the Fisher information metric: gij​(θ)=Fij​(θ)=E[∂θi​∂logpθ​​∂θj​∂logpθ​​]

The natural gradient is the Riemannian gradient of L: ∇~L=F−1∇L

This is the correct gradient in the intrinsic geometry of the model manifold — it accounts for the fact that equal Euclidean steps in θ-space correspond to very unequal changes in the distribution pθ​. K-FAC and Shampoo are practical approximations.

11.5 Gradient Fields in Generative Models

Score matching. The score function of a distribution p(x) is: s(x)=∇x​logp(x)

This is a gradient field over data space Rd. It is the gradient of logp, so it is conservative by construction — it has logp as its potential.

Denoising diffusion models (DDPM, Score SDE) learn an approximation sθ​(x,t)≈∇x​logpt​(x) at each noise level t. Sampling is done via Langevin dynamics: xk+1​=xk​+ϵ,sθ​(xk​)+2ϵ​,ξk​,ξk​∼N(0,I)

The deterministic part is gradient ascent on logp (moving toward higher probability). The noise term prevents collapse to a mode.

Every image Stable Diffusion generates is obtained by integrating along a learned gradient field.

11.6 Energy-Based Models — Explicit Potential Functions

An energy-based model (EBM) directly parametrises a potential Eθ​(x) and defines: pθ​(x)=Zθ​e−Eθ​(x)​,Zθ​=∫e−Eθ​(x),dx

The gradient field is: ∇x​logpθ​=−∇x​Eθ​

Inference dynamics follow −∇Eθ​: particles roll downhill on the energy landscape to the most probable configurations. Hopfield networks are a classical special case with a quadratic energy.

11.7 Backpropagation is Gradient Computation

Backpropagation is the algorithm for computing ∇θ​L efficiently via the chain rule. For a network y=fL​∘fL−1​∘⋯∘f1​(x) with loss ℓ(y,y∗):

∂θl​∂L​=∂y∂ℓ​⋅∂hL​∂y​⋯∂hl​∂hl+1​​⋅∂θl​∂hl​​

Each factor is a Jacobian. The full backprop is computing one row of the gradient field of L per parameter layer, propagated backwards. The gradient field is the reason backprop exists — you need the gradient to descend.

11.8 Second-Order Methods — Using the Hessian

Newton’s method uses the Hessian of the loss: θt+1​=θt​−HL−1​(θt​),∇L(θt​)

This is not following the gradient field of L, but the gradient field of the quadratic approximation to L at θt​. At a saddle point, Newton’s method can move toward the saddle (it just finds critical points, not minima). Saddle-free Newton and trust-region methods fix this by using ∣H∣ instead.
