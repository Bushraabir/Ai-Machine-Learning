11.Approximate Integration

11.Approximate Integration

Apr 18, 202618 min read

“Most integrals that arise in practice cannot be evaluated in closed form. This is not a failure of technique — it is a theorem. The response is not despair but quadrature.”

0. Motivation — Why Approximate?

Three situations force us to abandon exact integration:

  1. No elementary antiderivative exists. By the Risch algorithm (Computer Algebra Systems §2.1), ∫e−x2dx, ∫xsinx​dx, ∫1−k2sin2θ​,dθ provably have no closed form.

  2. The function is known only at discrete points. Experimental data, sensor readings, simulation outputs — there is no formula f(x) to integrate, only a table of values (xi​,f(xi​)).

  3. The exact form exists but is impractical. The antiderivative may involve hundreds of terms or special functions that are themselves expensive to evaluate.

In all three cases, we replace ∫ab​f(x),dx with a weighted sum: ∫ab​f(x),dx≈∑i=0n​wi​,f(xi​).

The study of which nodes xi​ and weights wi​ to choose, and how large the resulting error is, is called numerical quadrature.

1. Setup and Notation

Partition [a,b] into n subintervals of equal width: h=nb−a​,xi​=a+ih,i=0,1,…,n.

Write fi​=f(xi​). The exact value is: I=∫ab​f(x),dx.

The absolute error of an approximation I~ is ∣I−I~∣.

The order of a method is p if its error satisfies ∣I−I~∣=O(hp) as h→0, i.e., the error shrinks like hp when the step size halves. Higher order = faster convergence.

2. The Riemann Sums — Zero-th Order

2.1 Left, Right, and Midpoint Rules

The simplest approximations replace f by a constant on each subinterval.

Ln​=h∑i=0n−1​f(xi​)(Left Rule)

Rn​=h∑i=1n​f(xi​)(Right Rule)

Mn​=h∑i=0n−1​f!(xi​+2h​)(Midpoint Rule)

Error bounds:

∣I−Ln​∣≤2nM1​(b−a)2​,∣I−Rn​∣≤2nM1​(b−a)2​,∣I−Mn​∣≤24n2M2​(b−a)3​

where Mk​=maxx∈[a,b]​∣f(k)(x)∣.

Observation: The midpoint rule is secretly second order O(h2), not first order. This is because the error on each subinterval has a sign that partially cancels. This makes Mn​ far superior to Ln​ or Rn​ for the same n.

Derivation of midpoint error (Taylor expansion):

On subinterval [xi​,xi+1​], let c=xi​+h/2 be the midpoint. Expand f around c: ∫xi​xi+1​​f(x),dx=∫−h/2h/2​f(c+t),dt=∫−h/2h/2​[f(c)+f′(c)t+2f′′(c)​t2+⋯]dt.

The odd-power terms (t,t3,…) vanish by symmetry of [−h/2,h/2]: =f(c)⋅h+2f′′(c)​⋅12h3​+O(h5)=h,f(c)+24f′′(c)h3​+O(h5).

Error per subinterval: 24f′′(c)h3​. Sum over n subintervals: n⋅24Mh3​=24M(b−a)h2​. Hence O(h2).

3. The Trapezoid Rule — First Order

Approximate f by a linear function (chord) on each subinterval.

Tn​=2h​[f0​+2f1​+2f2​+⋯+2fn−1​+fn​]=h[2f0​+fn​​+∑i=1n−1​fi​].

Error bound: ∣I−Tn​∣≤12n2M2​(b−a)3​=12M2​(b−a)​h2,M2​=max∣f′′∣.

So the trapezoid rule is O(h2) — same order as the midpoint rule, but the midpoint constant is half as large (1/24 vs 1/12). The midpoint rule is twice as accurate as the trapezoid rule per evaluation.

Derivation (single interval [a,b]):

The trapezoid approximates f by its linear interpolant p1​(x)=f(a)+b−af(b)−f(a)​(x−a): ∫ab​p1​(x),dx=2(b−a)​[f(a)+f(b)].

Error: ∫ab​[f(x)−p1​(x)],dx. Using the error formula for linear interpolation f(x)−p1​(x)=2f′′(ξ)​(x−a)(x−b) for some ξ, and integrating: ET​=2f′′(ξ)​∫ab​(x−a)(x−b),dx=2f′′(ξ)​⋅(−6(b−a)3​)=−12(b−a)3​f′′(ξ).

This exact one-subinterval error confirms the h3 per-panel formula (sum n of these to get O(h2) global error).

4. Simpson’s Rule — The Crown Jewel

Approximate f by a quadratic polynomial (parabola) on each pair of subintervals. Requires n even.

Sn​=3h​[f0​+4f1​+2f2​+4f3​+2f4​+⋯+4fn−1​+fn​].

The weight pattern is 1,4,2,4,2,…,4,2,4,1, then divide by 3.

Error bound: ∣I−Sn​∣≤180n4M4​(b−a)5​=180M4​(b−a)​h4,M4​=max∣f(4)∣.

O(h4) — two orders better than trapezoid for the same n. Halving h reduces the error by a factor of 16.

Derivation:

On [x0​,x2​] with h=(x2​−x0​)/2, fit a quadratic p2​ through (x0​,f0​), (x1​,f1​), (x2​,f2​) using Lagrange interpolation: ∫x0​x2​​p2​(x),dx=3h​(f0​+4f1​+f2​).

This is the Simpson panel formula. The surprise: the quadratic integrand is exact for cubics too, because the error term f(x)−p2​(x) involves (x−x0​)(x−x1​)(x−x2​), which integrates to zero over the symmetric interval by a parity argument. This “super-convergence” (order 4 from order 3 interpolant) is a hallmark of Gaussian quadrature.

Derivation via Lagrange polynomials:

With nodes −h,0,h (centred), the three Lagrange basis polynomials are: ℓ0​=(−h)(−2h)x(x−h)​,ℓ1​=h(−h)(x+h)(x−h)​,ℓ2​=2h⋅h(x+h)x​.

Integrate each over [−h,h]: ∫−hh​ℓ0​,dx=3h​,∫−hh​ℓ1​,dx=34h​,∫−hh​ℓ2​,dx=3h​.

Hence: ∫−hh​p2​,dx=3h​(f−h​+4f0​+fh​). Rescale to [x0​,x2​]. □

Key insight: The jump from O(h2) to O(h4) (trapezoid → Simpson) is not gradual. It comes from the accidental cancellation of the cubic error term. This pattern — where interpolating with degree 2k−1 polynomials gives order 2k — is the deep principle behind Gaussian quadrature.

6. Richardson Extrapolation and Romberg Integration

6.1 Richardson Extrapolation

If we know the error structure of a method, we can cancel the leading error term algebraically using two computations at different step sizes.

Suppose T(h)=I+c2​h2+c4​h4+⋯ (trapezoid rule). Then: T(h/2)=I+c2​4h2​+c4​16h4​+⋯

Multiply the second by 4 and subtract the first: 4T(h/2)−T(h)=3I+O(h4).

So: I≈34T(h/2)−T(h)​.

But this is exactly Simpson’s rule. Richardson extrapolation derives Simpson from Trapezoid.

Theorem: Richardson extrapolation applied to the trapezoid rule at step sizes h and h/2 yields Simpson’s rule exactly. This is not a coincidence — it is the algebraic content of the Euler–Maclaurin formula.

6.2 Romberg Integration

Apply Richardson extrapolation repeatedly to build a triangular tableau of increasing accuracy:

R(n,0)=T(h/2n)(trapezoid at level n) R(n,m)=4m−14mR(n,m−1)−R(n−1,m−1)​(extrapolation step)

nR(n,0)R(n,1)R(n,2)R(n,3)
0T(h)
1T(h/2)S(h)
2T(h/4)S(h/2)R(2,2)
3T(h/8)S(h/4)R(3,2)R(3,3)
  • Column 0: Trapezoid rule (order O(h2)).
  • Column 1: Simpson’s rule (order O(h4)).
  • Column 2: Order O(h6).
  • Column m: Order O(h2m+2).

Romberg converges extremely fast for smooth functions — essentially exponentially in the number of function evaluations.

7. Gaussian Quadrature — Optimal Node Placement

All previous methods use equally spaced nodes xi​=a+ih. This is convenient but not optimal. Gaussian quadrature asks:

Given n function evaluations, where should we place the nodes to maximise accuracy?

Answer: Choose both nodes and weights optimally.

7.1 The Key Theorem

∫−11​f(x),dx≈∑i=1n​wi​f(xi​)

is exact for all polynomials of degree ≤2n−1 when the nodes xi​ are the roots of the n-th Legendre polynomial Pn​(x), and the weights are: wi​=(1−xi2​)[Pn′​(xi​)]22​.

Remarkable: n carefully chosen points integrate polynomials up to degree 2n−1 exactly. Equally spaced trapezoid with n points only integrates polynomials up to degree 1 exactly.

Change of interval: To integrate over [a,b], transform x=2b−a​t+2a+b​: ∫ab​f(x),dx=2b−a​∫−11​f!(2b−a​t+2a+b​)dt≈2b−a​∑i=1n​wi​,f!(2b−a​xi​+2a+b​).

7.2 Error Formula

∫−11​f(x),dx−∑i=1n​wi​f(xi​)=(2n+1)[(2n)!]322n+1(n!)4​f(2n)(ξ),ξ∈(−1,1).

The error decays faster than any polynomial power of h for analytic (infinitely differentiable) f — this is spectral convergence.

7.3 Proof Sketch — Why Legendre Polynomials?

We want ∑i=1n​wi​f(xi​)=∫−11​f(x),dx for all f of degree ≤2n−1.

Write f=q⋅Pn​+r where degr<n (polynomial division by Pn​). Then: ∫−11​f=∫−11​q⋅Pn​+∫−11​r.

The first term vanishes because Pn​ is orthogonal to all polynomials of degree <n in L2[−1,1] (the defining property of Legendre polynomials). So ∫f=∫r.

Now evaluate: since r has degree <n, the interpolating polynomial through the n nodes xi​ (roots of Pn​) reproduces r exactly. So ∑wi​f(xi​)=∑wi​r(xi​)=∫−11​r(x),dx=∫−11​f(x),dx. □

8. Adaptive Quadrature

For non-smooth or rapidly varying f, uniform step size is wasteful. Adaptive methods allocate evaluations where f changes rapidly.

8.1 The Idea

  1. Apply Simpson’s rule on [a,b] to get S1​=S(a,b).
  2. Split into [a,m] and [m,b], apply Simpson to each: S2​=S(a,m)+S(m,b).
  3. Compare: if ∣S2​−S1​∣<15ε, accept S2​+(S2​−S1​)/15 (Richardson-corrected).
  4. Else, recurse on each half independently.

The factor 15 comes from the O(h4) error of Simpson: splitting h→h/2 reduces the error by 24=16, so ∣S2​−S1​∣≈15⋅∣E2​∣, giving error estimate ∣E2​∣≈∣S2​−S1​∣/15.

8.2 Gauss–Kronrod Rules

SciPy’s quad uses Gauss–Kronrod pairs: a 7-point Gauss rule nested inside a 15-point Kronrod rule. The Kronrod points extend the Gauss points optimally, so the two results share function evaluations and give an error estimate almost for free.

9. Improper Integrals

9.1 Infinite Limits

∫a∞​f(x),dx=limb→∞​∫ab​f(x),dx.

Strategy: Truncate at a large B and estimate the tail. If ∣f(x)∣≤g(x) for x>B and ∫B∞​g(x),dx is small, the error is controlled.

Substitution to finite interval: x=a+1−tt​ maps t∈[0,1) to x∈[a,∞): ∫a∞​f(x),dx=∫01​f!(a+1−tt​)(1−t)21​,dt.

Now apply any finite-interval rule to the right side.

For doubly-infinite integrals, the substitution x=tan(πt/2), t∈(−1,1) works.

9.2 Integrable Singularities

If f(x)∼(x−a)−α near x=a with 0<α<1, the integral converges but f is unbounded. Standard rules lose accuracy near the singularity.

Strategy: Factor out the singularity. Write f(x)=(x−a)−αg(x) where g is smooth, then: ∫ab​f(x),dx=∫ab​(x−a)−αg(x),dx.

Use Gauss–Jacobi quadrature which incorporates the weight (x−a)−α into the quadrature rule exactly.

10. Error Analysis — Rigorous Treatment

10.1 The Euler–Maclaurin Formula

This formula reveals the exact error structure of the trapezoid rule and is the foundation for understanding all Newton–Cotes methods.

∫ab​f(x),dx=Tn​−12h2​[f′(b)−f′(a)]+720h4​[f′′′(b)−f′′′(a)]−⋯

More precisely: ∫ab​f(x),dx=h[2f0​+fn​​+∑i=1n−1​fi​]−∑k=1p​(2k)!B2k​​h2k[f(2k−1)(b)−f(2k−1)(a)]+Rp​,

where B2k​ are Bernoulli numbers (B2​=1/6, B4​=−1/30, B6​=1/42, …) and Rp​ is a remainder.

Consequences:

  • The trapezoid error is a power series in h2 — only even powers appear. This is why Richardson extrapolation works so cleanly.
  • For periodic functions on a full period: all boundary terms f(k)(b)−f(k)(a)=0, so the trapezoid rule has exponential convergence — it becomes spectral.

This explains why the trapezoid rule is, paradoxically, the best method for integrating periodic functions (used in signal processing and Fourier analysis).

Compute ∫01​ex,dx=e−1≈1.71828 with n=10.

Why Simpson beats Trapezoid geometrically: The trapezoid uses the chord — always above or below a convex/concave function. Simpson uses a parabola — which can match the curvature of f and thus makes a much smaller error.

12. Multidimensional Integration

For ∫!∫R​f(x,y),dA and higher dimensions, the situation changes dramatically.

12.1 Iterated 1D Quadrature

If R=[a,b]×[c,d], apply a 1D rule in each dimension: ∫cd​∫ab​f(x,y),dx,dy≈∑i=1nx​​∑j=1ny​​wix​wjy​f(xi​,yj​).

For dimension d, this requires N=nd evaluations — the curse of dimensionality. With n=10 points per dimension, d=10 requires 1010 evaluations.

12.2 Monte Carlo Integration

For high-dimensional integrals, Monte Carlo is the only practical method.

∫[0,1]d​f(x),dx≈N1​∑i=1N​f(xi​),xi​∼Uniform([0,1]d).

Error: By the Central Limit Theorem, the error is: ​I−N1​∑f(xi​)​≈N​σf​​, where σf2​=Var(f(x)). This is O(N−1/2) regardless of dimension d.

The fundamental tradeoff:

MethodPoints needed for error εDimension dependence
Simpson (1D)N∼ε−1/4Nd for d dims
Gaussian (n pts)N∼ε−1/(2n)Nd for d dims
Monte CarloN∼ε−2None

For d≥5 or so, Monte Carlo dominates all deterministic methods.

12.3 Quasi-Monte Carlo

Replace random xi​ with low-discrepancy sequences (Halton, Sobol) that fill the domain more uniformly. Achieves O(N−1(logN)d) error vs O(N−1/2) for true Monte Carlo — a dramatic improvement in low-to-moderate dimensions.

14. Connection to AI / Machine Learning

Approximate integration is not incidental to ML — it is structurally embedded in how probabilistic models are trained and evaluated.

14.1 The ELBO and Variational Inference

The Evidence Lower BOund (ELBO) in a Variational Autoencoder (VAE) is: L(θ,ϕ)=Eqϕ​(z∣x)​[logpθ​(x∣z)]−KL(qϕ​(z∣x)∣p(z)).

The expectation Eqϕ​​[⋅] is an integral: Eqϕ​(z∣x)​[f(z)]=∫f(z),qϕ​(z∣x),dz.

This integral is approximated by Monte Carlo with a single sample: ≈f(z0​),z0​∼qϕ​(z∣x).

The reparametrisation trick (z=μ+σϵ, ϵ∼N(0,1)) makes this one-sample estimator differentiable — it is a change-of-variable substitution that pushes the randomness into a fixed distribution, exactly as in Rationalising Substitutions.

The gradient of the ELBO is itself estimated by Monte Carlo — stochastic gradient descent is approximate integration at every step.

14.2 Monte Carlo in MCMC Sampling

Markov Chain Monte Carlo (MCMC) constructs a Markov chain whose stationary distribution is the target posterior p(θ∣D). After burn-in, the chain samples θ1​,…,θN​ approximately from p(θ∣D), and: E[f(θ)∣D]=∫f(θ),p(θ∣D),dθ≈N1​∑i=1N​f(θi​).

This is Monte Carlo integration applied to the posterior. Algorithms: Metropolis–Hastings, Hamiltonian Monte Carlo (HMC), No-U-Turn Sampler (NUTS) (used in PyMC, Stan).

Hamiltonian Monte Carlo uses gradient information (∇logp) to propose samples that traverse the posterior efficiently — it exploits the geometry of the integral’s domain.

14.3 Numerical Integration in Diffusion Models

The forward process of a diffusion model is the SDE: dxt​=−21​β(t)xt​,dt+β(t)​,dWt​.

Training requires computing: αˉ(t)=exp!(−21​∫0t​β(s),ds).

For a linear schedule β(s)=βmin​+s(βmax​−βmin​), this integral is elementary. For cosine schedules or learned schedules, it is computed numerically at training time — trapezoid or Simpson’s rule over the discretised time grid.

The reverse process (denoising) is an ODE: dx=[−21​β(t)x−β(t)sθ​(x,t)]dt, solved numerically by DDIM (a second-order ODE solver analogous to the trapezoid rule) or DPM-Solver (a high-order Adams method).

14.4 Gauss–Hermite Quadrature in Bayesian Deep Learning

When the variational posterior q(z)=N(μ,σ2), expectations like Eq​[logσ(z)] (where σ is sigmoid) can be computed by Gauss–Hermite quadrature: ∫−∞∞​f(z),N(z;μ,σ2),dz=π​1​∑i=1n​wi​f(μ+2​σ,ti​), where ti​ are roots of the Hermite polynomial Hn​ and wi​ are the corresponding weights.

This gives exact results for polynomial f and high-accuracy results for smooth f, using only n≈10–20 function evaluations — far more efficient than Monte Carlo for low-dimensional Gaussian expectations.

14.5 Numerical ODE Solvers = High-Order Quadrature

A first-order ODE y′=f(x,y), y(a)=y0​ is equivalent to: y(b)=y0​+∫ab​f(x,y(x)),dx.

Numerical ODE solvers are quadrature rules applied iteratively:

Euler methodLeft Riemann sumO(h)

Neural ODEs (Chen et al., 2018) parametrise f=fθ​ and use RK4 or RK45 to integrate — every forward pass of a Neural ODE is a numerical integration. Backpropagation through the solver uses the adjoint method, which is itself an ODE integration run backwards.

14.6 The Curse of Dimensionality — Implications for ML

The O(N−1/2) Monte Carlo rate is slow, but it does not depend on dimension. This is why:

  • All probabilistic deep learning uses Monte Carlo, not Gaussian quadrature, for expectations over latent spaces of dimension d>10.
  • Importance sampling reduces variance by choosing proposal distributions closer to f⋅p — the same idea as choosing good quadrature nodes.
  • Control variates reduce the variance σf2​ by subtracting a known integral: E[f]=E[f−c]+cE[1]. Choosing c to correlate with f reduces variance dramatically.
