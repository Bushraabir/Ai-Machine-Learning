07.A stationary distribution

07.A stationary distribution

Apr 02, 202610 min read

“A stationary distribution is a fixed point of the dynamics. Start there, and you never leave — not because you’re frozen, but because the outflow from every state is exactly balanced by the inflow. It’s equilibrium, not stasis. The chain is still moving; the distribution just doesn’t notice.”

The Definition

Let (Xn​)n≥0​ be a Markov chain on state space S with transition matrix Q.

Definition. A probability distribution s (row vector, si​≥0, ∑i​si​=1) is a stationary distribution (also called steady-state, invariant, or equilibrium distribution) if:

sQ=s

Entrywise, for each j∈S:

∑i∈S​si​,qij​=sj​

Equivalent characterization: If X0​∼s, then Xn​∼s for all n≥1.

Proof of equivalence: If sQ=s, then t(1)=sQ=s, and by induction t(n)=sQn=s for all n. Conversely, if t(1)=s whenever t(0)=s, then sQ=s. ■

The language of “stationary” can be misleading. The chain is not stationary in the sense of being stuck — it’s still making random transitions at every step. What’s stationary is the distribution: the probability mass on each state doesn’t change over time. Think of it like a river at steady state: water flows, but the water level stays constant.

The Balance Equation

Rewrite ∑i​si​qij​=sj​ as:

sj​=∑i=j​si​qij​+sj​qjj​

sj​(1−qjj​)=∑i=j​si​qij​

sj​∑k=j​qjk​=∑i=j​si​qij​

Left side: Total rate of flow out of state j (weighted by sj​).
Right side: Total rate of flow into state j from all other states.

This is called the global balance equation: at stationarity, the flow out of every state equals the flow into it. It is the probabilistic version of conservation of mass.

Existence and Uniqueness

Theorem (Finite Irreducible Chains)

If (Xn​) is an irreducible Markov chain on a finite state space, then:

  1. A stationary distribution s exists.
  2. It is unique.
  3. It is given by si​=E[Ti​∣X0​=i]1​ — the reciprocal of the expected return time to state i.

Proof of existence. Since S is finite, every state in an irreducible chain is positive recurrent (no escape to infinity, pigeonhole forces infinitely many returns, and recurrence is a class property). For a positive recurrent state i, define si​=1/mi​ where mi​=E[Ti​∣X0​=i]<∞. One can verify (via the renewal theory argument) that this defines a probability distribution satisfying sQ=s.

Proof of uniqueness. Suppose s and s′ are both stationary. Then sQn=s and s′Qn=s′ for all n. For an irreducible aperiodic chain, Qn→1s (convergence theorem). Taking n→∞: s′=s′⋅1s=s. □

For an irreducible periodic chain, Qn doesn’t converge, but the uniqueness of s still holds — periodicity only breaks convergence, not uniqueness.

The formula si​=1/mi​ is one of the most useful things to know. It says: the fraction of time the chain spends in state i in the long run is the reciprocal of the average time between visits. This is exactly what you’d expect from the law of large numbers — if returns happen every mi​ steps on average, the chain is in state i a fraction 1/mi​ of the time. The stationary distribution is the long-run time average.

What Can Go Wrong Without Irreducibility

Multiple stationary distributions. If the chain has two closed communicating classes C1​ and C2​, each has its own stationary distribution s1​ and s2​, and every convex combination αs1​+(1−α)s2​ is also stationary. Infinitely many stationary distributions.

No stationary distribution. If all states are transient (e.g., a random walk on Z with drift), there is no stationary distribution.

Null recurrence. On an infinite state space, an irreducible chain can be recurrent but null recurrent — every state is visited infinitely often, but mi​=∞ for all i. Then si​=1/mi​=0 for all i, which doesn’t define a probability distribution. No stationary distribution exists.

How to Find s: The Method

The System to Solve

Given transition matrix Q, find s satisfying:

sQ=s(balance equations) ∑i​si​=1(normalization)

The balance equations sQ=s are equivalent to s(Q−I)=0, i.e., s is a left null vector of Q−I.

Important: The system sQ=s alone has rank M−1 (for an irreducible chain on M states) — one equation is redundant, since they all sum to the same thing. Always drop one equation and replace it with the normalization ∑i​si​=1.

General Procedure

  1. Write out sQ=s as M scalar equations.
  2. Drop any one equation (it’s redundant).
  3. Add ∑i​si​=1.
  4. Solve the resulting M×M linear system.

Two-State Example

Q=(1−α​α β​1−β​),s=(s1​,s2​)

Balance equations: sQ=s:

s1​(1−α)+s2​β=s1​⇒−αs1​+βs2​=0⇒s2​=βα​s1​

Drop the second equation (redundant). Add normalization: s1​+s2​=1:

s1​+βα​s1​=1⟹s1​=α+ββ​,s2​=α+βα​

s=(α+ββ​, α+βα​)​

Sanity check via si​=1/mi​: the expected return time to state 1 should be (α+β)/β. From state 1, the chain goes to state 2 with probability α, then returns to state 1 in a geometric number of steps. This is consistent. ✓

Detailed Balance and Reversibility

Definition

The chain satisfies detailed balance with respect to distribution s if for all i,j:

si​,qij​=sj​,qji​

Detailed balance says: the probability flux from i to j equals the flux from j to i, at every pair of states individually.

This is stronger than global balance. Global balance requires total inflow = total outflow at each state. Detailed balance requires this pairwise, for every directed edge.

Theorem

If s satisfies detailed balance with respect to Q, then s is stationary.

Proof. Sum the detailed balance condition over i:

∑i​si​qij​=∑i​sj​qji​=sj​∑i​qji​=sj​⋅1=sj​

This is exactly sQ=s. ■

The converse is false: a chain can have a stationary distribution without satisfying detailed balance.

Reversibility

A chain that satisfies detailed balance with respect to its stationary distribution is called reversible. The terminology comes from the following:

Proposition. If (Xn​) is a stationary reversible chain, then the time-reversed process (XT−n​)0≤n≤T​ has the same distribution as (Xn​)0≤n≤T​.

In other words, you cannot tell from the distribution whether the chain is running forward or backward in time.

Reversibility is a strong structural property. Physical systems in thermal equilibrium satisfy it (it’s the content of the principle of detailed balance in statistical mechanics). In MCMC, the Metropolis-Hastings algorithm is specifically designed to satisfy detailed balance — that’s how it guarantees the target distribution is stationary. So detailed balance is not just a mathematical curiosity; it’s an algorithmic tool.

Using Detailed Balance to Find s

For reversible chains, detailed balance is often easier to solve than the global balance equations. The method:

  1. Write si​qij​=sj​qji​ for all pairs (i,j) with qij​>0.
  2. Express all si​ in terms of s1​ (or any reference state) by multiplying ratios.
  3. Normalize.

Example — Birth-Death Chain:

States 0,1,…,M, qk,k+1​=pk​, qk,k−1​=rk​, qkk​=1−pk​−rk​. Detailed balance:

sk​pk​=sk+1​rk+1​

So sk+1​=sk​⋅rk+1​pk​​. Telescoping:

sk​=s0​⋅r1​r2​⋯rk​p0​p1​⋯pk−1​​

Normalize to find s0​. Birth-death chains always satisfy detailed balance — they’re always reversible.

Birth-death chains are the Coupon Collector and Gambler’s Ruin in disguise. The Coupon Collector is a birth-death chain with pk​=(n−k)/n and rk​=0 (only births, no deaths — an absorbing chain). The two-state chain is the simplest birth-death chain. Detailed balance applies to all of them.

The Stationary Distribution and Long-Run Behavior

Theorem (Ergodic Theorem for Markov Chains)

For an irreducible positive recurrent chain, for any bounded function f:S→R, almost surely:

n1​∑k=0n−1​f(Xk​)⟶∑i∈S​si​f(i)=Es​[f(X)]

In particular, taking f=1j​ (indicator of state j):

n1​∑k=0n−1​1[Xk​=j]⟶sj​

The long-run fraction of time spent in state j is sj​, regardless of the initial state.

This is the law of large numbers for Markov chains. It holds without any aperiodicity assumption — unlike the distributional convergence theorem (t(n)→s), which requires aperiodicity. The time-average always converges; the distribution at a fixed time might oscillate (if periodic).

This is why s is called the stationary distribution and not the “limiting distribution.” Limiting distribution requires aperiodicity. Stationary distribution just requires irreducibility and positive recurrence. The ergodic theorem is the more fundamental statement — it’s about time averages, which always converge.

Stationary Distribution Does Not Require Convergence

A periodic chain still has a unique stationary distribution — it just doesn’t converge to it in the distributional sense.

Example: Two-state chain with α=β=1 (deterministic alternation):

Q=(0​1 1​0​)

The stationary distribution is s=(1/2,1/2) (solve sQ=s). But starting from state 1: Xn​=1 if n even, Xn​=2 if n odd. The distribution of Xn​ oscillates between δ1​ and δ2​ — it never converges to (1/2,1/2).

However, the time average n1​∑k=0n−1​1[Xk​=1]→1/2 almost surely. The ergodic theorem holds; distributional convergence doesn’t.

Summary: Three Levels of “Convergence”

StatementRequiresWhat it says
s exists and is uniqueIrreducible + positive recurrent (automatic for finite irreducible)There is a well-defined long-run distribution
Time average →sj​ a.s.Irreducible + positive recurrentFraction of visits to j converges to sj​
t(n)→sIrreducible + aperiodic (+ positive recurrent)Distribution at time n converges to s

Each level is strictly stronger than the one above.

One-Line Summary for Future Me

A stationary distribution s satisfies sQ=s; for finite irreducible chains it exists, is unique, and equals si​=1/mi​ (reciprocal of mean return time). Find it by solving the balance equations with normalization. Detailed balance si​qij​=sj​qji​ is sufficient for stationarity and characterizes reversibility. The ergodic theorem says time averages converge to sj​ always; distributional convergence t(n)→s additionally requires aperiodicity.
