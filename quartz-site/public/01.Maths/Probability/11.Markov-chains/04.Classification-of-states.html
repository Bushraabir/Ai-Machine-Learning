04.Classification of states

04.Classification of states

Apr 02, 202613 min read

“Before asking where a chain goes in the long run, I have to ask what kind of states it even has. Some states the chain visits forever. Some it eventually abandons and never returns to. The classification of states is the taxonomy that makes the convergence theory possible.”

Why Classify States?

The convergence theorem — that t(n)→s — doesn’t hold for every Markov chain. It requires conditions: irreducibility and aperiodicity. Both of these are properties of the chain’s states. Before I can state or prove the convergence theorem, I need a precise vocabulary for describing how states relate to each other and how the chain revisits them.

The classification of states answers two fundamental questions:

  1. Will the chain ever return to state i? (Recurrence vs. transience)
  2. How does the chain’s graph structure look? (Communicating classes, irreducibility)
  3. Is the chain’s return behavior periodic? (Aperiodicity)

Accessibility and Communication

Definition: Accessibility

State j is accessible from state i, written i→j, if:

qij(n)​=P(Xn​=j∣X0​=i)>0for some n≥0

There exists some n for which there is positive probability of reaching j starting from i.

Convention: i→i always, since qii(0)​=1.

Definition: Communication

States i and j communicate, written i↔j, if:

i→jandj→i

Both states are accessible from each other.

Lemma: Communication is an Equivalence Relation

Communication satisfies:

  • Reflexivity: i↔i (trivially, i→i)
  • Symmetry: i↔j⇒j↔i (by definition)
  • Transitivity: i↔j and j↔k ⇒ i↔k

Proof of transitivity: If i→j in m steps and j→k in n steps, then by Chapman-Kolmogorov:

qik(m+n)​=∑ℓ​qiℓ(m)​qℓk(n)​≥qij(m)​qjk(n)​>0

So i→k. Similarly k→i. ■

Because communication is an equivalence relation, it partitions the state space S into equivalence classes.

Definition: Communicating Classes

The equivalence classes under ↔ are called communicating classes. Within a class, every state can reach every other. Between different classes, communication is broken in at least one direction.

I think of the communicating classes as the strongly connected components of the directed graph on S, where there’s an edge i→j whenever qij​>0. The Chapman-Kolmogorov transitivity argument is exactly graph reachability — if I can get from i to j and from j to k, I can get from i to k in the concatenated number of steps.

Irreducibility

Definition

A Markov chain is irreducible if there is only one communicating class — i.e., every state communicates with every other state:

i↔jfor all i,j∈S

Equivalently: from any state, every other state is reachable in some finite number of steps.

Why It Matters

An irreducible chain cannot get “stuck” in a subset of states. The long-run behavior is not sensitive to which communicating class the chain is initialized in, because there’s only one. This is the condition that guarantees the stationary distribution is unique.

Without irreducibility, different communicating classes might have different stationary distributions — or some classes might have none — and the long-run behavior depends entirely on which class the chain starts in.

The simplest failure of irreducibility: two absorbing states a and b, with no way to move between them. If the chain starts near a it gets absorbed there; near b it gets absorbed there. There are two stationary distributions, δa​ and δb​, and every convex combination is also stationary. Irreducibility kills all of this pathology.

Recurrence and Transience

This is the deeper classification — not about the graph structure, but about whether the chain returns to each state.

Definition: First Return Time

Define the first return time to state i:

Ti​=minn≥1:Xn​=i

with the convention Ti​=∞ if the chain never returns. Then:

fii​=P(Ti​<∞∣X0​=i)=P(chain ever returns to i∣starts at i)

Definition: Recurrent and Transient States

  • State i is recurrent if fii​=1 — the chain returns to i with probability 1.
  • State i is transient if fii​<1 — there is positive probability of never returning.

The Canonical Theorem: Return Count Criterion

Let Ni​=∑n=1∞​1[Xn​=i] be the total number of visits to state i after time 0.

Theorem.

i is recurrent⟺E[Ni​∣X0​=i]=∞⟺∑n=1∞​qii(n)​=∞

i is transient⟺E[Ni​∣X0​=i]<∞⟺∑n=1∞​qii(n)​<∞

Proof.

Write Ni​=∑n=1∞​1[Xn​=i]. By linearity of expectation:

E[Ni​∣X0​=i]=∑n=1∞​P(Xn​=i∣X0​=i)=∑n=1∞​qii(n)​

Now I need to connect this to fii​.

Given X0​=i, the number of returns Ni​ is a geometric-type random variable. The chain returns to i for the first time with probability fii​. Each time it returns, the future is independent of the past (Markov property), so the chain again returns with probability fii​. Therefore Ni​∣X0​=i has a Geometric distribution on 0,1,2,… with success probability fii​:

P(Ni​≥k∣X0​=i)=fiik​

So:

E[Ni​∣X0​=i]=∑k=1∞​P(Ni​≥k∣X0​=i)=∑k=1∞​fiik​=1−fii​fii​​

when fii​<1 (transient), this is finite. When fii​=1 (recurrent), this is ∞. ■

The geometric structure here is the Markov property in action again. Each return to state i “resets” the chain — from i‘s perspective, the chain has no memory of how many times it has been there before. So the number of visits is exactly geometric. This is the cleanest proof I know of the recurrence criterion.

Corollary: Transient States Are Visited Finitely Often

If i is transient, then Ni​<∞ almost surely — the chain visits i only finitely many times, and eventually leaves and never comes back.

If i is recurrent, then Ni​=∞ almost surely — the chain returns to i infinitely often.

This is a 0-1 law: not “sometimes finite, sometimes infinite” — it’s always one or the other, depending only on whether fii​=1.

Recurrence and Transience Are Class Properties

Theorem

If i↔j (they communicate), then i is recurrent if and only if j is recurrent.

Proof.

Suppose i↔j. Then there exist m,n≥1 such that qij(m)​>0 and qji(n)​>0. Let α=qij(m)​qji(n)​>0.

For any k≥0, by Chapman-Kolmogorov:

qii(m+k+n)​≥qij(m)​⋅qjj(k)​⋅qji(n)​=α⋅qjj(k)​

Summing over k:

∑k=0∞​qii(m+k+n)​≥α∑k=0∞​qjj(k)​

If j is recurrent, ∑k​qjj(k)​=∞, so ∑k​qii(m+k+n)​=∞, hence ∑k​qii(k)​=∞, so i is recurrent. By symmetry, j recurrent ⇒ i recurrent. ■

Consequence

Every state in a communicating class has the same recurrence/transience classification. So I can speak of recurrent classes and transient classes without ambiguity.

Closed and Open Classes

Definition

A communicating class C is closed if no state outside C is accessible from any state inside C:

i∈C,,j∈/C⇒qij(n)​=0 for all n

A class that is not closed is open.

Theorem

Every recurrent class is closed. Every finite closed class is recurrent.

Proof sketch (recurrent ⇒ closed): Suppose C is recurrent but not closed. Then some i∈C can reach j∈/C. Since j∈/C and i∈C, we have j→i (otherwise i↔j, contradicting j∈/C). So once the chain reaches j, it never returns to i — contradicting recurrence of i. ■

Proof sketch (finite closed class ⇒ recurrent): In a finite closed class, the chain can never escape. It must visit some state infinitely often (by pigeonhole — finitely many states, infinite time). By the class property, all states in the class are visited infinitely often, so all are recurrent. ■

The pigeonhole argument for finite closed classes is the reason finite irreducible chains are always recurrent — there’s nowhere to escape to, and with finitely many states, the chain must keep coming back. This is why the theory simplifies so much in the finite case.

Aperiodicity

Definition: Period

The period of state i is:

d(i)=gcdn≥1:qii(n)​>0

the greatest common divisor of all return times. If n≥1:qii(n)​>0=∅ (i.e., i is transient and never returns), set d(i)=∞ by convention.

State i is aperiodic if d(i)=1 and periodic with period d>1 if d(i)=d.

Lemma: Period Is a Class Property

If i↔j, then d(i)=d(j).

Proof. Since i↔j, there exist m,n with qij(m)​>0 and qji(n)​>0. Note qii(m+n)​≥qij(m)​qji(n)​>0, so d(i) divides m+n.

For any k with qjj(k)​>0:

qii(m+k+n)​≥qij(m)​qjj(k)​qji(n)​>0

so d(i) divides m+k+n. Since d(i) divides m+n, it divides k. So d(i) divides every element of k:qjj(k)​>0, hence d(i)≤d(j). By symmetry d(j)≤d(i), so d(i)=d(j). ■

So I can speak of the period of a communicating class.

What Periodicity Looks Like

A chain with period d>1 cycles through d groups of states in a fixed order. The canonical example:

Cycle graph on 0,1,…,d−1: qi,i+1modd​=1. The chain moves deterministically around the cycle, returning to any state only at times d,2d,3d,…. Period = d.

For such a chain, qii(n)​=0 whenever d∤n, and the chain does not converge in distribution — it oscillates. This is why aperiodicity is a hypothesis in the convergence theorem.

Sufficient Conditions for Aperiodicity

  • If qii​>0 for some i (self-loop), then d(i)=1, so i is aperiodic. If the chain is irreducible, the whole chain is aperiodic.
  • If the chain can return to i in both k and k+1 steps (for some k), then gcd(k,k+1)=1, so d(i)=1.

In practice, whenever I see a self-loop in the transition matrix, I immediately know the chain is aperiodic (if irreducible). Many applied chains — random walks with laziness, MCMC with rejection — are made aperiodic precisely by adding a self-loop: stay with probability 1/2, move with probability 1/2. This is a standard trick.

The Full Picture: State Classification Tree

States of a Markov Chain
│
├── Recurrent (return with prob. 1; visited infinitely often)
│   │
│   ├── Positive recurrent: E[T_i | X_0 = i] < ∞
│   │   └── These states have a stationary distribution
│   │
│   └── Null recurrent: E[T_i | X_0 = i] = ∞
│       └── Return a.s., but expected return time is infinite
│           (occurs only in countably infinite state spaces)
│
└── Transient (positive prob. of never returning; visited finitely often)

For finite state spaces: Null recurrence cannot occur. Every recurrent state is positive recurrent. So the classification simplifies to just recurrent vs. transient.

For countably infinite state spaces (e.g., random walks on Z): null recurrence is possible and important. The simple random walk on Z is null recurrent — it returns to 0 with probability 1, but the expected return time is infinite.

Null recurrence is the strange middle ground: the chain keeps coming back, but it takes so long on average that there’s no stationary distribution. I find this the most counterintuitive phenomenon in the classification — “recurrent but no stationary distribution” feels paradoxical. It only happens in infinite state spaces, which is why the finite theory is cleaner.

Putting It Together: The Convergence Theorem

Theorem (Convergence to Stationarity). Let (Xn​) be an irreducible and aperiodic Markov chain on a finite state space. Then:

  1. There exists a unique stationary distribution s.
  2. For all i,j∈S:

qij(n)​→sj​as n→∞

  1. For any initial distribution t(0):

t(n)→sas n→∞

The role of each condition:

  • Irreducibility: Ensures there is only one communicating class, so the stationary distribution is unique. Without it, the limit could depend on the starting class.
  • Aperiodicity: Ensures qij(n)​ actually converges (doesn’t oscillate). Without it, Qn might not converge even if a stationary distribution exists.
  • Finite state space: Ensures positive recurrence (no null recurrence). In infinite state spaces, need to additionally assume positive recurrence.

This theorem is the payoff for all the classification work. Every condition in the hypothesis corresponds to exactly one pathology that it rules out. Irreducibility rules out multiple stationary distributions. Aperiodicity rules out oscillation. Finiteness rules out null recurrence. It’s a beautifully tight set of hypotheses.

Examples

Example 1: Irreducible and Aperiodic

Q=(1/2​1/2 1/3​2/3​)

Both states communicate (q12​,q21​>0), so irreducible. Self-loops (q11​=1/2>0), so aperiodic. Convergence theorem applies. Unique stationary distribution: solve sQ=s, get s=(2/5,3/5).

Example 2: Irreducible but Periodic

Q=(0​1 1​0​)

States communicate, so irreducible. But q11(n)​=1 if n even, 0 if n odd. Period d=2. The chain oscillates forever — Qn does not converge. The stationary distribution (1/2,1/2) exists but t(n) oscillates around it rather than converging to it.

Example 3: Reducible — Absorbing States

Q=(1​0​0 1/2​0​1/2 0​0​1​)

States 1 and 3 are absorbing (closed recurrent classes). State 2 is transient — it can reach 1 or 3 but neither can reach it back. The chain gets absorbed in 1 or 3; the long-run distribution depends on the starting state.

One-Line Summary for Future Me

States are classified by two independent axes: recurrence (does the chain return?) and period (does the return time have a GCD >1?). Both are class properties. An irreducible (one class), aperiodic (d=1), positive recurrent chain on a finite state space is the “nice” case — unique stationary distribution, convergence from anywhere.
