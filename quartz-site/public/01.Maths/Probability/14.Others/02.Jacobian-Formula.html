02.Jacobian Formula

02.Jacobian Formula

Apr 23, 20268 min read

Big Picture The Jacobian formula is the answer to one question: if I know the distribution of X, what is the distribution of Y=g(X)? It is the fundamental tool for transforming continuous distributions. Every time you derive the distribution of a ratio, a product, a square root, or any nonlinear function of a random variable — you are using this. Get the intuition for why it works, not just the formula.

Why We Need This

Suppose X has a known PDF fX​(x). Define Y=g(X) for some function g. We want fY​(y).

The naive wrong answer: fY​(y)=fX​(g−1(y)).

This is wrong. It ignores the fact that g stretches or compresses regions of the real line, and probability mass must be conserved. The Jacobian corrects for this stretching.

Personal note: I made this mistake on a problem set early on — just substituted x=g−1(y) into fX​ and forgot the correction factor. The resulting “PDF” didn’t integrate to 1. That failure is the best way to remember why the Jacobian exists.

The 1D Case — Derivation from First Principles

Setup

Let g:R→R be strictly monotone and differentiable on supp(X). Then g is invertible on this domain. Write h=g−1, so x=h(y).

The CDF Method (The Honest Derivation)

Case 1: g is strictly increasing.

FY​(y)=P(Y≤y)=P(g(X)≤y)=P(X≤g−1(y))=FX​(h(y))

Differentiate both sides with respect to y:

fY​(y)=fX​(h(y))⋅h′(y)

Since g is increasing, h′=(g−1)′>0, so this is positive. ✓

Case 2: g is strictly decreasing.

FY​(y)=P(Y≤y)=P(g(X)≤y)=P(X≥g−1(y))=1−FX​(h(y))

Differentiate:

fY​(y)=−fX​(h(y))⋅h′(y)

Since g is decreasing, h′<0, so −h′(y)>0. The formula stays positive. ✓

The Unified Formula

Both cases are captured by:

fY​(y)=fX​(h(y))⋅∣h′(y)∣​

where h=g−1 and the absolute value handles both monotone cases simultaneously.

Equivalently, since h′(y)=dydx​:

fY​(y)=fX​(x)⋅​dydx​​,where x=g−1(y)​

This is the 1D Jacobian formula. The term ​dydx​​ is the (absolute value of the) Jacobian.

The Geometric Intuition — What the Jacobian Is Doing

Forget the formula for a moment. Think about what a PDF actually says:

P(Y∈(y,y+dy))≈fY​(y),dy

The probability of Y landing in a tiny interval of width dy is fY​(y),dy. But Y=g(X), so:

P(Y∈(y,y+dy))=P(X∈(x,x+dx))

where x=g−1(y) and dx is the corresponding interval in X-space. That probability is:

fX​(x),∣dx∣

Setting these equal:

fY​(y),dy=fX​(x),∣dx∣

fY​(y)=fX​(x)⋅​dydx​​

The Jacobian ​dydx​​ is the ratio of infinitesimal lengths: how much the interval in x-space shrinks or stretches when mapped to y-space. If g compresses a region (small ∣dx∣ for a given ∣dy∣), then fY​ must be larger there to preserve the total probability.

x-space:   [────────────] dx = 2
                ↓ g = x²
y-space:   [──] dy = 0.5

The region shrank. So f_Y must be larger than f_X there.
|dx/dy| = 2/0.5 = 4  →  f_Y = 4 · f_X

The slogan: Probability is conserved. If g squeezes an interval, the density there must grow proportionally.

The Non-Monotone Case — Handle With Care

If g is not monotone, g−1 is multi-valued — there are multiple x values mapping to the same y. We must sum over all inverse images.

Formula:

fY​(y)=∑x,:,g(x)=y​fX​(x)⋅​g′(x)1​​

equivalently written as:

fY​(y)=∑i​fX​(hi​(y))⋅∣hi′​(y)∣

where h1​,h2​,… are the branches of g−1.

Example: Y=X2, X∼Normal(0,1)

g(x)=x2 is not monotone on R — both x and −x map to the same y=x2.

Two branches: h1​(y)=y​, h2​(y)=−y​, for y>0.

h1′​(y)=2y​1​,h2′​(y)=−2y​1​

fY​(y)=fX​(y​)⋅2y​1​+fX​(−y​)⋅2y​1​

Since fX​ is symmetric: fX​(y​)=fX​(−y​)=2π​1​e−y/2

fY​(y)=2⋅2π​1​e−y/2⋅2y​1​=2π​1​⋅y−1/2e−y/2,y>0

This is the Chi-Squared(1) distribution — which is Gamma(1/2,1/2). A beautiful result from one Jacobian calculation.

Personal note: The non-monotone case is where students lose marks. Always ask: how many preimages does y have? Draw g(x) first if in doubt.

The Multivariate Case — The Full Jacobian

Setup

Let X=(X1​,…,Xn​) have joint PDF fX​(x). Define a transformation:

Y=g(X),i.e.,(Y1​,…,Yn​)=g(X1​,…,Xn​)

where g:Rn→Rn is a bijection (one-to-one and onto) with inverse h=g−1.

The Jacobian Matrix

Define the Jacobian matrix of h as the n×n matrix of partial derivatives:

J=∂(y1​,…,yn​)∂(x1​,…,xn​)​=(∂y1​∂x1​​​⋯​∂yn​∂x1​​ ⋮​⋱​⋮ ∂y1​∂xn​​​⋯​∂yn​∂xn​​​)

The Formula

fY​(y)=fX​(h(y))⋅∣det(J)∣​

where ∣det(J)∣ is the absolute value of the determinant of the Jacobian matrix.

The 1D formula ​dydx​​ is exactly this — the 1×1 “determinant.”

Why the Determinant?

In Rn, the Jacobian determinant measures how the transformation g scales n-dimensional volume. If g maps a small box of volume dVx​ in x-space to a box of volume dVy​ in y-space, then:

dVx​=∣det(J)∣⋅dVy​

The probability conservation argument generalizes:

fY​(y),dVy​=fX​(x),dVx​=fX​(h(y))⋅∣det(J)∣⋅dVy​

Cancel dVy​ and you have the formula. ✓

Note: You can equivalently define J as the Jacobian of the forward transformation g (i.e., ∂yi​/∂xj​) and use 1/∣detJg​∣. Both conventions appear in textbooks. I prefer ∂x/∂y — derivatives of the inverse — because the formula fY​=fX​⋅∣J∣ then has ∣J∣ naturally as a correction factor, not its reciprocal.

A Canonical Multivariate Example — Polar Coordinates

Let (X,Y) have joint PDF fX,Y​(x,y). Transform to polar coordinates:

R=X2+Y2​,Θ=arctan(Y/X)

Inverse: X=RcosΘ, Y=RsinΘ.

Jacobian matrix ∂(x,y)/∂(r,θ):

J=(∂r∂x​​∂θ∂x​ ∂r∂y​​∂θ∂y​​)=(cosθ​−rsinθ sinθ​rcosθ​)

det(J)=cosθ⋅rcosθ−(−rsinθ)⋅sinθ=rcos2θ+rsin2θ=r

∣det(J)∣=r

So:

fR,Θ​(r,θ)=fX,Y​(rcosθ,,rsinθ)⋅r

Application — Normal to Rayleigh. If X,Y∼iidN(0,1):

fX,Y​(x,y)=2π1​e−(x2+y2)/2

Then:

fR,Θ​(r,θ)=2π1​e−r2/2⋅r=2πr​e−r2/2

Marginalizing over Θ∈[0,2π):

fR​(r)=re−r2/2,r>0

This is the Rayleigh distribution. The extra factor of r in the Jacobian is what produces it — without the Jacobian, you’d get the wrong answer entirely. This calculation also sits at the heart of the Box-Muller transform for generating Normal samples. See Simulation Methods.

Procedure — How to Apply the Jacobian Formula

1. Identify the transformation. Write y=g(x) explicitly.

2. Find the inverse. Solve for x=h(y)=g−1(y).

3. Check monotonicity (1D) or bijectivity (multivariate). If g is not monotone, identify branches.

4. Compute the Jacobian.

  • 1D: differentiate h(y) with respect to y. Take absolute value.
  • Multivariate: form the matrix ∂xi​/∂yj​. Compute ∣det∣.

5. Identify the new support. supp(Y)=g(supp(X)).

6. Write the answer. fY​(y)=fX​(h(y))⋅∣h′(y)∣,y∈supp(Y)

7. Verify. Check that fY​ integrates to 1 (or at least check that it is non-negative and bounded on the correct support). This catches sign errors and forgotten absolute values.

Common Mistakes

Forgetting the Jacobian entirely. Writing fY​(y)=fX​(g−1(y)). Wrong — doesn’t integrate to 1 in general.

Wrong direction of the Jacobian. Computing ∣dy/dx∣ instead of ∣dx/dy∣. The formula uses the derivative of the inverse with respect to y. If you compute the forward derivative, take its reciprocal.

Forgetting the support. fY​ is zero outside g(supp(X)). A common error: writing fY​(y) without specifying that it holds only for y>0 (or whatever the correct domain is), then getting confused when normalization fails.

Non-monotone g with only one branch. If g(x)=x2 and X can be negative, there are two preimages for each y>0. Missing one branch gives you half the correct answer.

Sign errors in the determinant. In multivariate problems, compute det(J) carefully. If it comes out negative, take the absolute value — densities are non-negative.
