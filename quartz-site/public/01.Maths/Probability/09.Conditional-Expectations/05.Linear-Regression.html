05.Linear Regression

05.Linear Regression

Apr 02, 20268 min read

Linear regression sits at the intersection of everything we’ve built. It’s not just a fitting procedure — it’s a statement about conditional expectation, a consequence of the projection interpretation of E[X∣Y], and a direct application of Eve’s Law. The moment I saw that the regression line minimises MSE by the same argument as the projection theorem, the whole thing clicked into place.

0. The Setup and the Question

We have two random variables X and Y on the same probability space. We want to predict Y from X — find a function g(X) that is “close” to Y in some sense.

The best predictor (minimising mean squared error) is E[Y∣X] — this is the projection theorem from Conditional Expectation §4. But E[Y∣X] can be any function of X: nonlinear, discontinuous, anything.

Restriction: What if we constrain g to be linear — g(X)=a+bX? What are the optimal a and b?

This is simple linear regression: find a,b∈R minimising:

MSE(a,b)=E[(Y−a−bX)2]

1. Solving for the Optimal Coefficients

1.1 Finding b: The Slope

Expand MSE(a,b):

E[(Y−a−bX)2]=E[Y2]+a2+b2E[X2]−2aE[Y]−2bE[XY]+2abE[X]

Differentiate with respect to a and b and set to zero:

\frac{\partial}{\partial a}\text{MSE} = 2a - 2\mathbb{E}[Y] + 2b\mathbb{E}[X] = 0 \implies a = \mathbb{E}[Y] - b\mathbb{E}[X] \tag{1}

\frac{\partial}{\partial b}\text{MSE} = 2b\mathbb{E}[X^2] - 2\mathbb{E}[XY] + 2a\mathbb{E}[X] = 0 \tag{2}

Substitute (1) into (2):

bE[X2]−E[XY]+(E[Y]−bE[X])E[X]=0

b(E[X2]−(E[X])2)=E[XY]−E[X]E[Y]

b=Var(X)Cov(X,Y)​​

1.2 Finding a: The Intercept

From (1):

a=E[Y]−b,E[X]​

1.3 The Regression Line

The optimal linear predictor is:

Y^=E[Y]+Var(X)Cov(X,Y)​(X−E[X])

Written symmetrically: the line passes through (E[X],E[Y]) — the centre of mass of the joint distribution — with slope Cov(X,Y)/Var(X).

The intercept formula a=E[Y]−bE[X] tells you something immediately: the regression line always passes through the point of means. This is not a coincidence — it’s forced by the first-order condition on a. The mean is the anchor; the slope tells you the direction.

2. The Correlation Coefficient

Define the correlation:

ρ=Corr(X,Y)=SD(X),SD(Y)Cov(X,Y)​​

where SD(X)=Var(X)​. Then ρ∈[−1,1] (proved below) and the slope becomes:

b=Var(X)Cov(X,Y)​=ρ⋅SD(X)SD(Y)​

So the regression line is:

SD(Y)Y^−E[Y]​=ρ⋅SD(X)X−E[X]​

In standardised units: a 1 standard deviation move in X corresponds to a ρ standard deviation move in Y^. The correlation is exactly the slope in standardised coordinates.

Proof that ∣ρ∣≤1. Apply Cauchy-Schwarz:

∣Cov(X,Y)∣=∣E[(X−μX​)(Y−μY​)]∣≤E[(X−μX​)2]​E[(Y−μY​)2]​=SD(X),SD(Y)

Divide both sides by SD(X),SD(Y): ∣ρ∣≤1. ■

Equality ∣ρ∣=1 iff Y−μY​=c(X−μX​) a.s. for some constant c — i.e. Y is a.s. a linear function of X.

Alternatively via non-negativity. For all t∈R:

0≤Var(tX+Y)=t2Var(X)+2t,Cov(X,Y)+Var(Y)

This quadratic in t is non-negative, so its discriminant is ≤0:

4,Cov(X,Y)2−4,Var(X),Var(Y)≤0⟹ρ2≤1■

3. The Minimum MSE and R2

What is the MSE achieved by the optimal linear predictor?

MSE∗=E[(Y−Y^)2]

Claim:

MSE∗=Var(Y)(1−ρ2)​

Proof. Write the residual Y−Y^=Y−E[Y]−b(X−E[X]). Let Y~=Y−E[Y], X~=X−E[X] (centred variables). Then:

MSE∗=E[(Y~−bX~)2]=Var(Y)−2b,Cov(X,Y)+b2Var(X)

Substitute b=Cov(X,Y)/Var(X):

=Var(Y)−2Var(X)Cov(X,Y)2​+Var(X)Cov(X,Y)2​=Var(Y)−Var(X)Cov(X,Y)2​

=Var(Y)(1−Var(X)Var(Y)Cov(X,Y)2​)=Var(Y)(1−ρ2)■

Reading the formula:

  • ρ2=0: no linear relationship, MSE∗=Var(Y) — predicting Y^=E[Y] (the constant predictor) is optimal
  • ρ2=1: perfect linear relationship, MSE∗=0 — we can predict Y from X without error
  • ρ2∈(0,1): partial predictability; ρ2 is the proportion of variance explained

This is R2 from regression: R2=ρ2=1−MSE∗/Var(Y).

4. Connection to Eve’s Law

This is the punchline I promised at the top.

Eve’s Law (Conditional Expectation §3) says:

Var(Y)=E[Var(Y∣X)]+Var(E[Y∣X])

Now if E[Y∣X] is linear in X — i.e. E[Y∣X]=a+bX — then:

Var(E[Y∣X])=b2Var(X)=Var(X)Cov(X,Y)2​=ρ2,Var(Y)

E[Var(Y∣X)]=Var(Y)−ρ2,Var(Y)=(1−ρ2),Var(Y)

So:

  • Explained variance = ρ2,Var(Y) = variance of the fitted values
  • Unexplained variance = (1−ρ2),Var(Y) = variance of the residuals = MSE∗

Eve’s Law is exactly the ANOVA decomposition: SStotal​=SSregression​+SSresidual​.

When E[Y∣X] is truly linear — e.g. in the bivariate normal — this isn’t an approximation. The linear predictor IS the conditional expectation. When E[Y∣X] is nonlinear, the regression line is the best linear approximation to it, and R2=ρ2 understates the true predictive power of X.

5. The Bivariate Normal: When Linearity is Exact

(X,Y) jointly bivariate normal with means μX​,μY​, variances σX2​,σY2​, correlation ρ. Then:

E[Y∣X]=μY​+ρσX​σY​​(X−μX​)

Var(Y∣X)=σY2​(1−ρ2)

This is exact — not an approximation. For bivariate normals, the conditional expectation E[Y∣X] is linear in X. So the linear regression IS the optimal predictor, not merely the best linear one.

Note also: Var(Y∣X)=σY2​(1−ρ2) is constant in X (homoskedasticity). The residual variance does not depend on where you are on the X-axis. This is a special property of the normal.

Proof sketch. Write Y=μY​+ρσX​σY​​(X−μX​)+ε where ε∼N(0,σY2​(1−ρ2)) and ε⊥X (verify by computing Cov(ε,X)=0 and using joint normality implies independence). Then E[Y∣X]=μY​+ρσX​σY​​(X−μX​) and Var(Y∣X)=Var(ε)=σY2​(1−ρ2). ■

6. Regression to the Mean

This is the phenomenon Galton discovered and named “regression.” It’s worth understanding precisely.

In standardised units, the regression prediction is Z^Y​=ρZX​ where ZX​=(X−μX​)/σX​, ZY​=(Y−μY​)/σY​.

If ∣ρ∣<1, then ∣Z^Y​∣<∣ZX​∣ — the predicted Y is closer to the mean (in standard deviations) than X is. An extreme observation of X predicts a less extreme Y.

Why? Because extreme X values arise partly from the linear relationship with Y and partly from noise. The noise doesn’t persist into Y. The factor ρ attenuates the signal.

The Galton paradox. Tall parents tend to have tall children, but children of the tallest parents are on average shorter than their parents (though still taller than average). This is not biology — it’s mathematics. ρ<1 for any two non-perfectly-correlated variables.

Regression to the mean is responsible for an enormous number of misattributed causal stories. Intervention after an extreme outcome looks effective simply because of this phenomenon. Keep this in the back of your head whenever someone claims “it worked” after treating an outlier.

Open Questions

  • Multiple regression: generalise to Y^=a+b1​X1​+⋯+bp​Xp​. The normal equations become a matrix system b=(X⊤X)−1X⊤y — derive this as the multivariate projection
  • When E[Y∣X] is nonlinear, is the linear regression slope still Cov(X,Y)/Var(X)? (Yes — the formula is always optimal among linear predictors regardless of the true conditional expectation)
  • Prove that in the bivariate normal, ε=Y−E[Y∣X] is independent of X — not just uncorrelated. This uses the fact that joint normality plus uncorrelated implies independent
  • What is Corr(X,Y−Y^)? (It’s 0 — the residual is uncorrelated with the predictor by the first-order condition. Verify this directly from the formula for a.)
