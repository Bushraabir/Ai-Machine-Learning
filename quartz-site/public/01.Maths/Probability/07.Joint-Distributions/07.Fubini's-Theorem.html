07.Fubini's Theorem

Mar 28, 20266 min read

Fubini is the theorem that lets you stop worrying about order. The moment you swap dx,dy to dy,dx without thinking, you’re invoking it. The point of this note is to know exactly when you’re allowed to, and what goes wrong when you’re not.

The Core Question

Given a double integral

∬R2​f(x,y),dx,dy,

when can I evaluate it as an iterated integral, and when does the order of integration not matter?

∫−∞∞​!∫−∞∞​f(x,y),dy,dx=?∫−∞∞​!∫−∞∞​f(x,y),dx,dy.

The answer is: always, if f≥0 (Tonelli); and if f is integrable (Fubini). These are different theorems with different hypotheses, and conflating them is the source of every “illegal swap” in probability.

Tonelli’s Theorem

Theorem (Tonelli). Let f:R2→[0,∞] be measurable. Then:

∫!!∫f(x,y),d(x,y)=∫!(∫f(x,y),dy)dx=∫!(∫f(x,y),dx)dy.

All three expressions are equal (possibly +∞), and the inner integrals are measurable functions of the outer variable.

Hypotheses: f≥0 and measurable. That’s it. No finiteness required.

What it gives: You can freely interchange the order of integration for nonneg functions. The common value might be +∞, which is allowed.

Why this is the right theorem for PDFs. Joint PDFs are nonneg by definition. So every marginalisation step — every ∫−∞∞​fX,Y​(x,y),dy — is justified by Tonelli, not Fubini. This is why the 06.Marginal PDF proof works without any integrability assumption beyond what the PDF already satisfies.

Fubini’s Theorem

Theorem (Fubini). Let f:R2→R be measurable. Suppose

∫!!∫∣f(x,y)∣,d(x,y)<∞,

i.e., f is integrable (equivalently, ∫!∫f+,d(x,y)<∞ and ∫!∫f−,d(x,y)<∞ separately). Then:

  1. For a.e. x, the function y↦f(x,y) is integrable.
  2. The function x↦∫f(x,y),dy is integrable.
  3. The iterated integrals equal the double integral:

∫!!∫f(x,y),d(x,y)=∫!(∫f(x,y),dy)dx=∫!(∫f(x,y),dx)dy.

Hypotheses: f integrable — meaning ∫!∫∣f∣<∞.

What it gives: Order of integration is interchangeable for integrable functions (which may change sign).

The key difference from Tonelli: Fubini requires absolute integrability. If f takes both positive and negative values and ∫!∫∣f∣=∞, the iterated integrals may exist but give different values — the double integral doesn’t exist in the Lebesgue sense.

The Unified Statement

In practice, the two theorems are often stated together as:

Fubini-Tonelli. If either (a) f≥0, or (b) ∫!∫∣f∣<∞, then all iterated integrals and the double integral coincide.

When in doubt about which applies: if f≥0, cite Tonelli. If f changes sign, first use Tonelli on ∣f∣ to check ∫!∫∣f∣<∞, then apply Fubini.

The Counterexample: Why Fubini Can Fail

This is the example that justifies the hypotheses. Let

f(x,y)=(x2+y2)2x2−y2​,(x,y)=(0,0).

Iterated integral in one order:

∫01​!(∫01​(x2+y2)2x2−y2​,dy)dx.

The inner integral ∫01​(x2+y2)2x2−y2​,dy=[x2+y2y​]01​=x2+11​.

So the outer integral is ∫01​x2+11​,dx=arctan(1)−arctan(0)=4π​.

Iterated integral in the other order:

By antisymmetry (f(x,y)=−f(y,x)), swapping gives −π/4.

Conclusion: 4π​=−4π​. The two iterated integrals disagree.

Why did this happen? Because ∫01​!∫01​∣f(x,y)∣,dx,dy=∞ — f is not integrable on [0,1]2. Fubini’s hypothesis fails, and the conclusion fails too.

Moral: Never swap integration order for a sign-changing function without first verifying absolute integrability.

How This Appears in Probability

Marginalisation

fX​(x)=∫−∞∞​fX,Y​(x,y),dy.

Tonelli applies (PDFs are nonneg). The interchange in the normalisation proof:

∫−∞∞​fX​(x),dx=∫−∞∞​∫−∞∞​fX,Y​(x,y),dy,dx=Tonelli∫−∞∞​∫−∞∞​fX,Y​(x,y),dx,dy=1.

Expected Value of a Function

E[g(X,Y)]=∫!!∫g(x,y),fX,Y​(x,y),dx,dy.

If g≥0: Tonelli. If g changes sign: need E[∣g(X,Y)∣]<∞ before swapping.

This is why E[X] exists requires E[∣X∣]<∞ — the same logic one dimension down.

Independence and Product Expectations

If X⊥Y and g,h are measurable:

E[g(X)h(Y)]=∫!!∫g(x)h(y),fX​(x),fY​(y),dx,dy=∫g(x),fX​(x),dx∫h(y),fY​(y),dy=E[g(X)],E[h(Y)].

The factorisation of the double integral into a product requires swapping, which requires Fubini (if g⋅h changes sign). If g,h≥0, Tonelli suffices.

Convolutions

If X⊥Y and Z=X+Y:

fZ​(z)=∫−∞∞​fX​(z−y),fY​(y),dy.

This is derived by marginalising the joint of (Z,Y), which involves swapping the order of integration. Tonelli applies (all factors are nonneg PDFs).

Moment Generating Functions

MX​(t)=E[etX]=∫−∞∞​etxfX​(x),dx.

When exchanging expectation and differentiation: dtd​MX​(t)=E[XetX]. Justifying the swap of dtd​ and ∫ uses the dominated convergence theorem or Fubini (depending on how you set it up). For t in the interior of the MGF’s domain, this is fine.

The Discrete Analogue

For double sums over nonneg terms (i.e., PMFs):

∑x​∑y​pX,Y​(x,y)=∑y​∑x​pX,Y​(x,y).

This is Tonelli for sums — also called the “nonneg interchange” or just “obvious by absolute convergence.” The same counterexample logic applies: for sums of sign-changing terms, you need absolute convergence (∑x​∑y​∣axy​∣<∞) to interchange freely. The discrete analogue of the Fubini counterexample is a conditionally convergent double series whose iterated sums disagree.

Practical Decision Tree

When I want to swap ∫dx,dy to ∫dy,dx:

Is the integrand f ≥ 0 everywhere?
    YES → Tonelli applies. Swap freely. (Citation: Tonelli)
    NO  → Compute ∬|f| dx dy (use Tonelli on |f|, which is nonneg)
              Is ∬|f| < ∞?
                  YES → Fubini applies. Swap freely. (Citation: Fubini)
                  NO  → DO NOT SWAP. The iterated integrals may disagree.

In probability: almost everything uses Tonelli (PDFs are nonneg). Fubini enters when computing E[g(X,Y)] for g that may be negative — e.g. covariance computations, characteristic functions (which are complex-valued), or when proving the tower property of conditional expectation rigorously.

A Subtlety: “Almost Everywhere”

Fubini’s conclusion says the inner integral exists “for a.e. x” — not necessarily for every x. The set of x where the inner integral is undefined has Lebesgue measure zero and doesn’t affect the outer integral. In practice this is never an issue for the integrands that arise in probability, but it’s worth knowing the theorem says a.e., not everywhere.

Statement in Measure-Theoretic Language (for Later)

The full theorem lives in the language of product measures. If (X,A,μ) and (Y,B,ν) are σ-finite measure spaces, then there exists a unique product measure μ⊗ν on (X×Y,A⊗B) such that (μ⊗ν)(A×B)=μ(A)ν(B).

Tonelli: For f≥0 measurable,

∫X×Y​f,d(μ⊗ν)=∫X​∫Y​f(x,y),dν(y),dμ(x)=∫Y​∫X​f(x,y),dμ(x),dν(y).

Fubini: If additionally ∫X×Y​∣f∣,d(μ⊗ν)<∞, the same equalities hold for f (not just ∣f∣).

The σ-finiteness condition on the measure spaces is necessary — the theorem can fail for non-σ-finite spaces. For probability, μ=ν= Lebesgue measure on R, which is σ-finite. Never a concern in this course.
