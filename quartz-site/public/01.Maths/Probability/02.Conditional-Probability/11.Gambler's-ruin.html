11.Gambler's ruin

Apr 23, 202614 min read

A gambler starts with k\k kdollars.Ateachround,theywin1$1 1withprobabilitypppandlose1$1 1withprobabilityq=1−pq=1−pq=1−p.ThegameendswhentheyeitherreachN$N N(target—theywin)orhit0$0 $0 (ruin — they go broke). What is the probability of ruin?

1) Setting Up the Model Precisely

The state space. Two players, A and B, share a fixed total of N dollars. At any moment, let the state be i= A’s current fortune, so i∈0,1,2,…,N.

The dynamics. At each round, independently of all previous rounds: Xn+1​={Xn​+1​with probability p Xn​−1​with probability q:=1−p​

The absorbing states. States 0 and N are absorbing: once reached, the process stays there. State 0 = A is ruined. State N = A has won everything.

The question. Starting from X0​=i, define

Pi​:=P(A wins∣X0​=i)=P(process hits N before 0∣X0​=i)

We want a closed-form expression for Pi​ for every i∈0,1,…,N.

This is a finite-state Markov chain. The transient states are 1,2,…,N−1 and the two absorbing states are 0,N. Absorption is guaranteed because the chain is irreducible on the transient states and those states are all transient — the process must eventually leave them. I'll take this for granted here; the proof uses the fact that from any transient state, there's a positive probability path to an absorbing state in finitely many steps.

2) First-Step Analysis: Deriving the Recurrence

This is the key technique. Instead of thinking about the whole trajectory at once, we condition on just the first step and use the Markov property.

For 1≤i≤N−1:

Pi​=P(hit N before 0∣X0​=i)

Condition on X1​:

Pi​=P(X1​=i+1)⋅P(hit N before 0∣X1​=i+1)+P(X1​=i−1)⋅P(hit N before 0∣X1​=i−1)

By the Markov property, the future evolution depends only on the current state, not on how we got there. So P(hit N before 0∣X1​=j)=Pj​. Therefore:

Pi​=p⋅Pi+1​+q⋅Pi−1​​for i=1,2,…,N−1

with boundary conditions:

P0​=0PN​=1

This is a second-order linear recurrence — the discrete analogue of a second-order ODE. Since it’s linear with constant coefficients, we solve it exactly as we would an ODE: find the characteristic equation, get the general solution, then apply boundary conditions to pin down the constants.

3) Solving the Recurrence: Full Algebra

Step 1 — Rewrite in standard form

The recurrence is: Pi​=p⋅Pi+1​+q⋅Pi−1​

Since p+q=1, multiply the left side by (p+q)=1: p⋅Pi​+q⋅Pi​=p⋅Pi+1​+q⋅Pi−1​

Rearrange: p(Pi+1​−Pi​)=q(Pi​−Pi−1​)

Step 2 — Introduce the differences

Define di​:=Pi​−Pi−1​ for i=1,2,…,N. Then the relation above becomes:

p⋅di+1​=q⋅di​

∴di+1​=pq​⋅di​

This says the sequence (di​) is geometric with common ratio r:=q/p.

Step 3 — Write out the geometric sequence

d1​=d1​ d2​=r⋅d1​ d3​=r2⋅d1​ ⋮ di​=ri−1⋅d1​

Step 4 — Telescope to get Pi​

Since P0​=0, we can recover Pi​ by summing the differences:

Pi​=P0​+∑k=1i​dk​=∑k=1i​rk−1⋅d1​=d1​∑k=0i−1​rk

Now we split into two cases depending on whether r=1.

4) Case 1: Fair Game (p=q=21​, so r=1)

When r=1, all differences are equal: dk​=d1​ for all k.

The sum becomes:

Pi​=d1​⋅∑k=0i−1​1=i⋅d1​

Apply the boundary condition PN​=1:

1=N⋅d1​⟹d1​=N1​

Therefore:

Pi​=Ni​​(Fair game)

What this is saying. Your probability of winning is exactly your share of the total wealth. If you bring 30toatablewherethetotalmoneyinplayis100, you will — on average — win with probability 30%. This is a beautiful result: no matter how the game plays out round by round, the long-run probability reduces to a simple ratio.

Notice the asymmetry baked into this formula. Even though the game is fair round-by-round (zero expected gain per step), the outcome is not symmetric in terms of survival. If you have 1andyouropponenthas99, you win with probability only 1%. Fairness in each step does not mean fairness in the long run when players have unequal resources. This is the core message of the whole theorem.

5) Case 2: Biased Game

When r=1, the sum is a standard finite geometric series:

∑k=0i−1​rk=1−r1−ri​

So:

Pi​=d1​⋅1−r1−ri​

Now apply PN​=1:

Substitute back:

Pi​=1−rN1−r​⋅1−r1−ri​

Pi​=1−rN1−ri​​r=pq​,r=1

Sanity checks

Let me verify this actually satisfies what it should:

  • P0​: 1−rN1−r0​=1−rN0​=0 ✓
  • PN​: 1−rN1−rN​=1 ✓
  • Limit as r→1: Apply L’Hôpital (or Taylor expand): 1−rN1−ri​→Ni​ as r→1 ✓ — recovers the fair game case continuously.

The continuity at r=1 is reassuring. There's no discontinuous "phase transition" between fair and biased games — the biased formula smoothly collapses to the fair formula as p→21​.

6) Expected Duration of the Game

While we’re here, let’s also derive the expected duration. This requires the same first-step analysis, applied to a different function.

Let Di​=E[number of rounds∣X0​=i], with D0​=DN​=0.

Step 1 — Write the recurrence

Conditioning on the first step:

Di​=1+p⋅Di+1​+q⋅Di−1​for 1≤i≤N−1

The “1” accounts for the current round. This is an inhomogeneous second-order recurrence (the +1 on the right is the forcing term).

Step 2 — Find the particular solution

We need a particular solution to Di​−p⋅Di+1​−q⋅Di−1​=1.

For the fair game (p=q=21​): The homogeneous part has general solution A+Bi (since r=1 gives a repeated root). Try a particular solution of the form Di(p)​=Ci2.

Substituting: Ci2=1+21​C(i+1)2+21​C(i−1)2 Ci2=1+2C​(i2+2i+1)+2C​(i2−2i+1) Ci2=1+Ci2+C

This gives 0=1+C, so C=−1.

Particular solution: Di(p)​=−i2.

Step 3 — General solution

Di​=A+Bi+(−i2)=A+Bi−i2

Step 4 — Apply boundary conditions

D0​=0: A=0

DN​=0: BN−N2=0⟹B=N

Therefore:

Di​=i(N−i)​(Fair game)

This is a downward parabola in i, symmetric about i=N/2, with maximum value N2/4 at i=N/2.

Interpretation. The longest games happen when the players start with equal wealth. If one player is much richer, the game ends quickly — the poor player gets wiped out fast. Equal wealth maximises the duration because neither absorbing state is “nearby.” The maximum expected duration scales as N2, which grows much faster than N — doubling the total wealth quadruples the expected game length.

If you want the biased-game formula for Di​, the algebra is similar but messier. The key thing to notice is that when p<q (unfavorable game), this grows much faster — the game can still take a very long time even when ruin is nearly certain, because the walk wanders around a lot before hitting 0.

7) The Martingale Proof (The “Right” Way to See It)

Once you know martingales, this whole problem has a cleaner proof that’s also more illuminating.

7a — Fair game via Xn​

Claim. When p=q=21​, the wealth process (Xn​) is a martingale with respect to Fn​=σ(X0​,X1​,…,Xn​).

Proof. E[Xn+1​∣Fn​]=Xn​⋅P(no change)+(Xn​+1)⋅p+(Xn​−1)⋅q=Xn​+(p−q)=Xn​

since p=q. ✓

Now let T=minn:Xn​∈0,N be the stopping time. Since the process is bounded (0≤Xn​≤N) and T is finite almost surely (the process must eventually absorb), the Optional Stopping Theorem applies:

E[XT​]=E[X0​]=i

But at time T, we know XT​∈0,N:

E[XT​]=N⋅P(XT​=N)+0⋅P(XT​=0)=N⋅Pi​

Therefore N⋅Pi​=i, giving Pi​=i/N. ■

Notice what we just did: we derived Gambler's Ruin without solving any recurrence. The whole proof is: "wealth is a martingale → OST → done." This is why martingales are so powerful. The recurrence proof works from the bottom up; the martingale proof works from the top down, using structure.

7b — Biased game via (q/p)Xn​

For the biased case, Xn​ itself is not a martingale (it has a drift of p−q per step). But we can find a function of Xn​ that is a martingale.

Claim. When p=q, the process Yn​=(pq​)Xn​ is a martingale.

Proof. Let r=q/p. Then:

E[Yn+1​∣Fn​]=p⋅rXn​+1+q⋅rXn​−1

=rXn​[p⋅r+q⋅r−1]

=rXn​[p⋅pq​+q⋅qp​]

=rXn​[q+p]=rXn​=Yn​

So Yn​ is a martingale. ✓

Apply the Optional Stopping Theorem to Yn​ (same conditions apply — bounded, finite stopping time):

E[YT​]=E[Y0​]=ri

But XT​∈0,N:

ri=rN⋅Pi​+r0⋅(1−Pi​)=rN⋅Pi​+1−Pi​

ri−1=Pi​(rN−1)

Pi​=rN−1ri−1​=1−rN1−ri​​✓

Same formula. The two proofs are completely consistent — but the martingale proof reveals why the formula has the form it does. It’s because (q/p)Xn​ is the natural “harmonic function” for this walk.

7c — What about the duration? (Optional Stopping, again)

For the fair game, the process Mn​=Xn2​−n is a martingale (you can verify this directly). Apply OST:

E[XT2​−T]=E[X02​−0]=i2

So:

E[XT2​]−E[T]=i2

Now E[XT2​]=N2⋅Pi​+0⋅(1−Pi​)=N2⋅Ni​=Ni.

Therefore:

Ni−E[T]=i2⟹E[T]=Ni−i2=i(N−i)✓

Again, same formula — derived in two lines using the right martingale.

The general pattern. For a random walk with a drift, there's a systematic way to find martingales. If f is "harmonic" for the generator of the walk — meaning E[f(X1​)∣X0​=i]=f(i) — then f(Xn​) is a martingale. For the fair walk, the harmonic functions are f(i)=1 (trivial) and f(i)=i (gives the win probability). For the biased walk, they are f(i)=1 and f(i)=(q/p)i. This is deeply connected to the theory of harmonic functions for Markov chains, which generalises to continuous-time diffusions and Brownian motion.

8) What “Ruin is Certain” Means as N→∞

A natural question: what happens if we remove the upper boundary and let the opponent have infinite wealth? This models a gambler vs. an infinitely rich casino.

Take the formula Pi​=1−rN1−ri​ (biased case) and let N→∞.

If r>1 (i.e. p<q, unfavorable game):

rN→∞⟹Pi​=1−rN1−ri​→−rN1−ri​→0

Ruin is certain.

If r<1 (i.e. p>q, favorable game):

rN→0⟹Pi​=1−rN1−ri​→11−ri​=1−ri=1−(pq​)i

There is a positive probability of never being ruined — specifically, P(survive forever)=1−(q/p)i.

If r=1 (fair game):

Pi​=Ni​→0 as N→∞

Ruin is certain even in a fair game against an infinitely rich opponent.

This last point is the gut-punch result. A fair game against a casino with infinite resources = certain ruin. There is no strategy that changes this. The only variable is when you go broke, not whether. This is the mathematical reason why "systems" like Martingale betting or any other strategy fail in the long run — against an infinite house, the absorbing state 0 is unavoidable.

10) Connection to the Big Picture

Here’s the chain of ideas this feeds into, and what to study next:

Gambler's Ruin
     ↓
First-step analysis (recurrence relations for Markov chains)
     ↓
Harmonic functions for Markov chains
     ↓
Optional Stopping Theorem (discrete time)
     ↓
Doob's martingale convergence theorems
     ↓
Brownian motion as the limit of scaled random walks
     ↓
Dirichlet problem (harmonic analysis / PDEs)
     ↓
Itô calculus and stochastic differential equations

The Gambler’s Ruin is literally the first step in this entire tower. The “first-step analysis” recurrence is the discrete analogue of solving a boundary value ODE. The martingale proof is the discrete analogue of the maximum principle for harmonic functions. When you later see Brownian motion hit a boundary, or an SDE absorbed at zero, you’ll recognise the same structure.
